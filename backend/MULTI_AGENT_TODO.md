# 多 Agent（超级个体）—— 占位与规划

> 状态：**未实装**。这是占位文档，记下以后怎么扩，免得忘。
> 现在的超能小助是「单 agent」。下面是变成「养几个分工 agent」需要做的事。

## 目标
从「一套记忆 + 一个心跳」扩成「N 个各有身份、各自心跳的 agent」，
你像项目经理一样在上面调度、看结果。建议规模：**3-5 个分工明确的**，不放养一大群。

## 需要改的三块

### 1. 多身份（改动小）
把 `backend/memory/` 改成 `backend/agents/<名字>/`，每个 agent 一套：
SOUL/AGENTS/USER/heartbeat/MEMORY + conversations。
`build_system_prompt()` 加 `agent_name` 参数，读对应目录即可。

### 2. 调度器（改动中）
新增 `scheduler.py`：按各 agent 自己的心跳间隔轮流（或并行）唤醒，
各读各的 heartbeat.md、各干各的、各记各的笔记。
**务必**：每个 agent 设单独「每日调用次数上限」，防失控烧钱/烧电脑。

### 3. 协作 + 成本控制（最关键）
- agent 间传消息：共享 `agents/_inbox/` 目录，A 把结果丢进去，B 心跳时读取。
- 护栏：每个 agent 每日调用硬上限；高风险工具默认人工确认；一键暂停所有 agent。

## 界面侧（以后做）
左侧栏从「单一对话」变成「agent 列表」（像微信聊天列表）。再加「全部暂停」按钮。

## 提醒
网上「一个人管几十个 agent 躺赚」是夸大的。能稳的是少数几个、分工明确、
有人工检查点的 agent。先把 1 个用扎实，再逐步加。
