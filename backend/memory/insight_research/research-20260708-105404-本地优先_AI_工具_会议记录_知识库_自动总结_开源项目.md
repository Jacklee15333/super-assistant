 为什么你需要一个本地化的AI会议助手

 在数字化办公时代，会议记录已成为团队协作中不可或缺的一环。然而，传统方法存在诸多痛点：手动记录效率低下，容易遗漏关键信息；云端转录服务虽方便，却让敏感的商业讨论暴露在第三方服务器上；昂贵的订阅费用也让许多团队望而却步。

 Meetily应运而生，这是一款基于Rust构建的隐私优先AI会议助手。它最大的特点就是 100%本地处理 ——从音频捕获到转录，从语音识别到智能总结，所有计算都在你的设备上完成，无需连接任何云端服务器。这意味着你的会议内容永远不会离开你的电脑，为企业安全和个人隐私提供了最高级别的保障。

 核心功能亮点：不只是转录，更是智能协作

 🎯 4倍速实时转录，专注讨论本身

 Meetily采用优化的Parakeet和Whisper模型，实现了比传统方法快4倍的实时转录速度。这意味着在会议进行中，你就能看到文字化的讨论内容，无需等待会后整理。系统支持说话人分离技术，能自动区分不同发言者，让会议记录更加清晰。

 🤖 智能会议总结，自动提取关键信息

 会议结束后，真正的价值才刚刚开始。Meetily内置的Ollama总结引擎能够自动分析转录内容，提取关键决策、待办事项和重要讨论点。你可以选择不同的模板，如日常站会、项目同步、销售客户会议等，系统会根据模板结构自动组织内容。

 ✏️ 强大的编辑功能，打造完美会议记录

 生成的会议纪要不是终点，而是起点。Meetily提供了完整的富文本编辑器，支持多级标题、引用块、列表等格式。你可以在AI生成的基础上进行微调，添加个人笔记，或者重新组织内容结构。

 🔧 完全可控的数据管理

 所有数据都存储在你的本地设备上。你可以自定义录音文件、数据库和AI模型的存储位置，完全掌控数据流向。系统还提供了详细的设置选项，包括通知管理、匿名数据分析等。

 实际应用场景指南

 团队日常会议管理

 对于需要频繁开会的团队，Meetily可以成为标准的会议记录工具。每天早上的站会、每周的项目同步、每月的复盘会议——所有内容都会被自动记录和整理，形成可搜索的知识库。

 客户沟通与销售跟进

 在与客户沟通时，准确记录讨论要点至关重要。Meetily不仅能记录对话内容，还能自动提取关键承诺、后续行动和决策点，帮助销售团队更好地跟进客户需求。

 教育培训与知识分享

 个人学习与思考记录

 快速上手指南：三步开启智能会议记录

 第一步：获取和安装

 Meetily的安装过程非常简单。如果你是技术爱好者，可以直接从源代码构建：

 git clone https://gitcode.com/GitHub_Trending/me/meetily
cd meetily
# 根据你的平台运行相应的构建脚本

 对于普通用户，项目提供了预编译的安装包，只需下载并按照向导安装即可。

 第二步：基础配置

 首次启动后，建议进行以下基础配置：

 音频设备选择 ：选择你的麦克风和系统音频输入
 存储位置设置 ：指定会议录音和数据的保存路径
 AI模型下载 ：根据需要下载合适的转录和总结模型
 偏好设置 ：调整界面语言、通知选项等

 第三步：开始使用

 配置完成后，你就可以开始使用Meetily了：

 点击"开始录音"按钮，系统会自动捕获音频
 实时查看转录文本，标记重要段落
 会议结束后，点击"生成总结"获取AI分析结果
 根据需要编辑和导出会议记录

 核心模块深度解析

 要充分利用Meetily的强大功能，了解其核心架构很有帮助：

 音频处理模块 ：位于 src/audio/ 目录，负责实时音频捕获和处理。这个模块支持从麦克风和系统音频同时录制，并进行了深度优化，确保低延迟和高保真。

 转录引擎 ：包含Parakeet和Whisper两种引擎，位于 src/parakeet_engine/ 和 src/whisper_engine/ 。你可以根据需求选择不同的模型大小，平衡速度和准确性。

 总结系统 ：基于Ollama的智能总结引擎在 src/summary/ 中实现。它支持自定义模板，可以根据不同类型的会议生成结构化总结。

 数据库管理 ：所有数据都存储在本地SQLite数据库中，相关代码位于 src/database/ 。这种设计确保了数据的持久化和快速检索。

 进阶使用技巧

 自定义总结模板

 如果你有特定的会议格式需求，可以创建自定义总结模板。模板文件位于 templates/ 目录，支持JSON格式，你可以定义总结的结构和字段。

 批量处理历史录音

 对于已经录制的音频文件，Meetily支持批量导入和处理。你可以将现有的会议录音导入系统，让AI自动生
