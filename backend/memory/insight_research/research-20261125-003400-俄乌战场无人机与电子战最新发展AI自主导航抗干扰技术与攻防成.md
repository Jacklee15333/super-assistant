 配置入口与启用指南

 正确的基础配置是保证输入流畅的前提。请根据您的操作系统执行以下初始设置。

 Windows 环境启用配置

 安装完成后，进入系统“时间和语言”设置 -> “语言”，确保已将搜狗输入法添加至首选语言列表。按下 Ctrl + Shift 即可唤出。若需调整默认按键，请右键点击状态栏进入属性设置。

 macOS 系统权限验证

 前往“系统偏好设置” -> “键盘” -> “输入法”，点击“+”号添加搜狗输入法。为了实现云端词库同步与智能纠错，请务必勾选“允许完全访问”权限。

 常见障碍诊断

 针对日常使用中出现的高频问题，提供直接的操作建议与情境说明。

 候选词悬浮窗意外消失？

 此现象通常由底层输入法框架焦点丢失引起。请尝试在搜狗输入法状态栏右键选择“属性设置”，进入“外观”选项卡，点击“恢复默认窗口位置”。若无效，请重启当前正在打字的应用程序。

 个人词库无法跨屏同步？

 首先确认状态栏头像是否显示已登录。若已登录但未同步，请检查网络连接及防火墙设置，确保未拦截输入法的网络请求。随后进入“账户”设置，手动点击“立即同步”以强制拉取云端数据。

 繁简切换快捷键失效或冲突？

 默认的繁简切换快捷键为 Ctrl + Shift + F 。若您同时运行了其他占用此热键的软件（如IDE工具），请进入属性设置的“按键”分类，在系统功能快捷键列表中为其重新分配一个独立的组合键。

 全屏游戏中打字出现卡顿？

 部分大型3D游戏会对输入法的界面渲染产生干扰。建议在游戏前，通过状态栏菜单开启搜狗输入法的“游戏模式”。该模式会精简界面特效，降低内存占用，从而保障游戏内的打字流畅度。

 自定义快捷短语突然清空？

 可能是由于非正常关机导致本地配置文件受损。建议养成定期通过“高级” -> “自定义短语设置”导出备份的习惯。如果目前已清空，可尝试重新登录账号从云端恢复历史备份。
