 DeepSeek Harness 是 DeepSeek 开源的智能体框架，支持桌面端（macOS M系列、Windows）和 Web 端（Node.js 22.19+）两种安装方式，10 分钟内可启动。核心功能包括文件读写、终端命令执行、子任务拆分及插件化扩展。首次需配置 DeepSeek 或兼容 OpenAI/Anthropic 协议的模型 API Key，并指定安全工作区。强调运行于隔离环境，避免执行未审核命令。适用于 AI Agent 开发与本地自动化任务场景。

 发布日期：2026-10-20 ｜ 适用版本：v0.2.1-rc.2（开发者预览）

 DeepSeek Harness（命令名 dsh ）是 DeepSeek 开源的智能体框架，采用 MIT 许可证，基于 Cordis 的"一切皆插件"架构构建，目前处于开发者预览阶段。它有两种用法：一是直接下载桌面应用，目前只提供 macOS（Apple 芯片）和 Windows 64 位安装包；二是装好 Node.js 22.19 或更高版本后，运行 npx @deepseek-ai/dsh web ，在本机 3080 端口打开 Web 界面。截至 2026 年 10 月 20 日，GitHub 仓库有 25.4 万 Star，最新发布是 10 月 17 日的 v0.2.1-rc.2。装好后只需在"设置 → 模型"里填入 DeepSeek API Key、选好工作区就能开始用；也可以通过"自定义模型 API"接入兼容 OpenAI 或 Anthropic 协议的其他模型服务。官方安全说明提醒：它会执行模型生成的命令，建议在隔离环境里运行，并备份它能访问到的文件。

 DeepSeek Harness 是什么

 DeepSeek Harness 是 DeepSeek 在 2026 年 8 月开源的 Agent 运行框架，能读写项目文件、执行终端命令、拆分子任务、跑定时任务，功能全部以插件形式组合。 官网对它的自我介绍是：“我既可以是桌面应用，也可以通过代码启动为网页。”

 它和普通聊天窗口的区别在于"能动手"。官方插件列表里有终端、Agent 循环、子 Agent，还有 Agent 团队、自动授权审核、定时任务、语音输入四个实验性插件。产出的 Word、Excel、PDF、HTML、Python 等文件可以在界面里直接预览，每一轮的改动都能看到差异对比。

 先说一下它的热度。仓库创建于 2026 年 8 月 13 日，两个多月 Star 数超过 25 万；npm 包 @deepseek-ai/dsh 和 GitHub Release 都在 10 月 17 日更新到 v0.2.1-rc.2，几乎每天都有新的预发布版本。需要注意的是，README 写明"未来将出现破坏兼容性的变更"，所以这篇教程以 10 月中旬的版本为准。

 先选装法：桌面端还是 Web 端

 只想尽快用上、不碰命令行的人，装桌面端；用 Linux、Intel 芯片 Mac，或者想放在服务器上跑的人，用 Web 端。 

 装法 适用系统 前置条件 适合谁 
 桌面安装包 macOS（Apple 芯片）、Windows 64 位 无 普通用户，双击安装 
 npx 启动 Web 端 任何能装 Node.js 的系统 Node.js 22.19 及以上，或 24 及以上 开发者、Linux 用户、远程服务器 
 源码运行 同上 Node.js、pnpm、git 想改源码或开发插件的人 
 官网目前没有提供 Linux 和 Intel Mac 的安装包，这两类设备只能走 Web 端。

 方法一：桌面端下载安装

 桌面端安装包都在官网 deepseek.com/harness 的下载区，macOS 是 .dmg 文件，Windows 是 .exe 文件。 

 打开 DeepSeek Harness 官网，按系统选择下载。实测（2026-10-20）macOS 安装包约 265 MB，Windows 安装包约 289 MB，两个文件都是 10 月 17 日更新的。
 macOS ：双击 dsh-latest-macos-arm64.dmg ，把应用拖进"应用程序"文件夹。安装包只支持 M 系列芯片。
 Windows ：双击 dsh-latest-windows-x64.exe ，按向导完成安装。如果弹出"Windows 已保护你的电脑"，确认是从官网下载的，再点"仍要运行"。
 启动应用，跳到下面的"首次配置"一节。

 下载文件名里带 latest ，说明这个地址始终指向最新版，以后重新下载就能拿到最新版本。

 方法二：Web 端一行命令启动

 装好 Node.js 后，在终端运行一行 npx 命令，浏览器就会自动打开 http://127.0.0.1:3080 。 

 第一步，确认 Node.js 版本。项目要求 22.19.0 或更高的 22.x，也可以用 24 及以上版本：

 node -v 
 # 输出 v22.19.0 或更高的 v22.x，或 v24.x 及以上即可 

 版本不够的话，先到 nodejs.org 下载 LTS 版本升级。

 第二步，在你想让 Agent 操作的项目目录里启动：

 cd ~/my-project
npx @deepseek-ai/dsh web

 dsh 会把启动时所在的目录作为默认文件位置，所以建议先 cd 进项目目录再启动。

 几个常用的启动选项：

 只启动服务、不自动打开浏览器： npx @deepseek-ai/dsh web --no-open 
 通过 SSH 在远程机器上启动时， dsh 只打印访问地址，需要你在本地自行转发 3080 端口
 想把服务开放给外网访问，官方文档有单独的公开部署指南， 不要直接把 3080 端口暴露到公网 

 进阶：从源码运行

 需要改代码或开发插件时，按 README 的步骤从源码运行：

 git clone https://github.com/deepseek-ai/deepseek-harness.git
 cd deepseek-harness
 pnpm install 
 pnpm run build
 pnpm dsh web

 pnpm dsh web 直接使用已构建的产物，不会重新构建。改完代码记得重新执行一次 pnpm run build 。

 首次配置：填 API Key、选工作区

 不管哪种装法，第一次打开都要做两件事：配置模型，选择工作区。没选工作区之前，输入框是灰的。 

 配置模型 ：进入"设置 → 模型"，在 DeepSeek 卡片里填入从 platform.deepseek.com 申请的 API Key 并保存。保存后立即生效，不需要重启。Key 是只写的，界面上只显示脱敏后的信息，实际存放在 $DSH_HOME/.credentials.yaml 。
 选择工作区 ：点击"选择工作区"，添加启动 dsh 时所在的项目目录，然后选中它。
 发送第一个任务 ：新建会话，试试官方示例：“Summarize this repository and identify its main packages.”。如果 Agent 要执行的操作需要授权，界面会先弹窗询问你。

 如何在Mac上高效安装DeepSeek：从环境配置到优化指南
 一、DeepSeek简介与安装前准备
 DeepSeek是一款基于 深度学习 的高性能推理框架，支持 自然语言处理 、计算机视觉等多领域任务。其核心优势在于低延迟、高吞吐量的模型推理能力，尤其适合资源受限的边缘设备部署。在Mac系统上安装DeepSeek前，需确认硬件兼容性：推荐使用配备Apple Silicon芯片（M1/M2系列）的Mac，因其内置的 神经网络 引擎可显著加速模型推理；若使用Intel芯片机型，需确保系统版本为macOS 12.0及以上，并预留至少8GB内存。

 环境配置方面，需安装Python 3.8+版本（推荐通过Homebrew管理）：

 brew install python@3 . 10 
 echo 'export PATH="/usr/local/opt/python@3.10/libexec/bin:$PATH"' >> ~/. zshrc 
 source ~/. zshrc 

 同时，建议创建独立虚拟环境以隔离依赖：

 python - m venv deepseek_env 
 source deepseek_env / bin / activate 

 二、安装流程详解
 1. 通过pip安装（推荐）
 DeepSeek官方提供预编译的wheel包，兼容macOS的ARM/x86架构。执行以下命令安装：

 pip install deepseek - core -- upgrade 

 安装完成后，可通过版本验证确认成功：

 python - c "import deepseek; print(deepseek.__version__)" 

 若输出类似 1.2.3 的版本号，则表明安装成功。

 2. 源码编译安装（高级用户）
 对于需要定制化修改的场景，可通过源码编译安装。首先克隆官方仓库：

 git clone https :// github . com / deepseek - ai / deepseek - core . git 
 cd deepseek - core 

 安装编译依赖（需Xcode命令行工具）：

 xcode - select -- install 
 pip install - r requirements - dev . txt 

 编译并安装：

 python setup . py build_ext -- inplace 
 pip install . 

 此方式可针对特定硬件优化性能，但编译过程可能耗时较长（约10-15分钟）。

 三、安装后验证与基础使用
 1. 模型加载测试
 启动Python交互环境，加载预训练模型进行验证：

 from deepseek import Model 
 model = Model . from_pretrained ( "deepseek/base-en" ) 
 input_text = "Explain quantum computing in simple terms." 
 output = model . generate ( input_text , max_length = 50 ) 
 print ( output ) 

 若成功输出推理结果，则表明框架运行正常。首次加载模型时，系统会自动下载权重文件（约2GB），建议保持网络畅通。

 2. 性能基准测试
 使用内置基准工具评估推理速度：

 deepseek - benchmark -- model deepseek / base - en -- batch - size 4 -- sequence - length 32 

 输出示例：

 Batch Size : 4 | Seq Len : 32 | Latency : 12.3ms | Throughput : 325 tokens / s 
 此数据可帮助判断硬件性能是否达标。
