# 趋势与机会：人工智能

## 一句话结论
2027—2029年，人工智能产业的商业重心将逐渐从“谁的模型更聪明”转向“谁能用AI更低成本、更稳定地完成真实业务”，普通人和小团队最值得抓住的机会，不是训练大模型，而是利用现成模型改造细分行业的工作流程、掌握高质量行业数据、帮助企业降本增收，并建立能够持续收费的业务。

## 现在的格局
截至2026年11月26日，AI产业正在从技术能力竞争进入商业价值验证阶段。模型能力仍在快速进步，但模型、算力、应用入口和客户资源之间的竞争已经越来越紧密。
目前，整个产业可以分为五层：

| 产业层级 | 代表企业及产品 | 核心竞争力 | 小团队进入难度 |
| --- | --- | --- | --- |
| 算力基础设施 | NVIDIA、AMD、谷歌TPU、国产AI芯片厂商 | 芯片、能源、数据中心 | 极高 |
| 基础大模型 | OpenAI、Anthropic、Google、DeepSeek、通义千问 | 算力、人才、训练数据 | 极高 |
| AI应用入口 | ChatGPT、Claude、Gemini、豆包 | 用户规模、分发渠道、产品生态 | 高 |
| AI应用及智能体 | 编程助手、企业自动化、行业Agent | 行业经验、业务流程、执行能力 | 中 |
| AI配套服务 | 数据治理、系统集成、成本优化、安全评估 | 专业能力、客户关系、交付质量 | 低至中 |

从你提供的资料来看，有四个值得重视的变化：
第一，头部公司的竞争已经不只是模型竞争。 谷歌的科研、自研芯片、搜索、云计算和办公生态可以互相支持；微软、OpenAI、Anthropic等企业也在争夺企业软件、编程工具和工作入口。未来单次模型排行榜的商业参考价值会相对下降。【笔记1】【笔记4】【笔记16】
第二，AI正在从聊天工具变成生产工具。 用户不再只是让AI回答问题，而是让它读取资料、调用软件、编写代码、生成报告、处理订单和执行连续任务。这意味着AI有机会直接分走原本属于软件服务和人工外包的预算。【笔记2】【笔记11】【品玩】【VentureBeat】
第三，AI行业出现了单位价格与总成本可能反向变化的现象。 单个Token（模型处理信息的计量单位）可以越来越便宜，但智能体反复规划、调用工具、检查结果，会消耗更多Token。因此，企业真正应该关注的是完成一项合格任务需要多少钱，而不是单纯比较模型报价。【笔记5】【笔记10】【笔记13】【笔记20】

## 趋势
趋势1：AI从回答问题进化为直接完成工作
- 趋势是什么：AI Agent（智能体）将逐渐承担完整的工作任务，例如寻找客户、整理询盘、制作报价单、检查合同、处理售后和生成经营报告。用户提供目标，AI负责执行，人负责审核关键结果。
- 依据：【笔记2】【笔记8】【笔记11】【笔记16】。Menlo Ventures于2026年11月发布的报告显示，在OpenRouter平台上，智能体产生的Token已经占总使用量的80%，自2026年2月以来，智能体流量增长了37倍。这是单个平台的数据，但能够反映使用方式的变化。
Menlo Ventures
- 大概什么时候：2027年，单一业务流程的智能体进一步普及；2028—2029年，跨软件、跨部门的智能体协作逐渐成熟。
- 确定性：高。
- 商业影响：未来企业可能不再为软件的功能数量买单，而是为软件实际完成的工作量买单。传统外包、客服、运营和行政服务将受到冲击。

趋势2：基础模型逐渐商品化，行业应用成为主要创业机会
- 趋势是什么：普通任务不再需要使用最强模型。企业会根据任务难度选择不同模型，简单任务使用低价模型，复杂任务使用高性能模型。模型本身的差异化价值下降，客户资源、行业知识和工作流程的重要性上升。
- 依据：【笔记3】【笔记8】【笔记10】【笔记18】【笔记20】。Menlo Ventures报告显示，开源模型的使用量份额从11%上升至19%，说明低成本、可替换的模型正在获得更多使用机会。
Menlo Ventures
- 大概什么时候：2027年多模型组合成为常见方案，2028—2029年大部分标准化AI功能面临进一步价格竞争。
- 确定性：高。
- 商业影响：仅仅给大模型套一个界面，很难形成长期竞争优势。掌握某个行业的客户、业务规则和历史数据，比掌握某个模型的使用技巧更有价值。

趋势3：AI使用量继续暴涨，但低成本使用AI成为一门生意
- 趋势是什么：未来AI的单位推理价格仍有下降空间，但重度用户和企业的实际账单未必下降。智能体的长时间运行、多轮推理、重复执行都会增加费用。企业将更加重视AI预算、模型调度和任务成功率。
- 依据：【笔记2】【笔记5】【笔记10】【笔记13】。OpenAI已经推出每月500美元的Pro套餐；麦肯锡2026年调查显示，约20%的受访者表示AI运行成本已经限制了其所在组织对AI的使用。
OpenAI Help Center
- 大概什么时候：2027年开始明显，2028—2029年逐步形成成熟的AI成本管理市场。
- 确定性：高。
- 商业影响：帮助企业减少无效Token消耗、避免重复调用、选择性价比更高的模型，本身就可以成为收费服务。

这里需要修正【笔记5】中的一个判断：Token不一定越来越贵，更可能出现的是单价越来越便宜，使用量越来越大，总账单越来越高。
趋势4：AI编程降低软件开发门槛，小团队能够经营更复杂的业务
- 趋势是什么：过去需要专门开发团队才能完成的网站、内部管理系统、数据分析平台和自动化工具，越来越多可以由懂业务的人借助AI完成。软件开发能力正在从稀缺资源变成更容易获得的生产要素。
- 依据：【笔记11】【笔记19】【智源社区】【InfoQ】。麦肯锡2026年调查显示，32%的受访者表示，其所在组织已经因为能够使用AI编程工具自行开发，而放弃购买至少一种软件产品或功能。
McKinsey
- 大概什么时候：2027年大量小型定制软件出现，2028—2029年部分传统通用软件的收费模式受到挑战。
- 确定性：高。
- 商业影响：懂销售、制造、财务、外贸等行业的人，可以自己开发过去买不起的软件；程序员的价值也会更多体现在系统架构、业务理解、安全和交付质量上。

但开发成本下降不代表获客成本、售后维护成本也会同步下降。
趋势5：AI成为新的商业流量入口，商家需要适应AI推荐机制
- 趋势是什么：过去消费者通过百度、谷歌、淘宝、小红书等平台寻找商品，未来越来越多消费者会直接告诉AI自己的需求，由AI搜集信息、比较价格、推荐商品，甚至协助完成交易。
- 依据：【笔记6】【笔记21】。OpenAI于2026年11月推出Business Agent商业代理功能，并于11月19日将符合条件的企业范围扩展到美国以外的电商及在线服务企业；11月13日还公布了ChatGPT Wallet。
OpenAI
- 大概什么时候：2027年处于商业探索期，2028—2029年有望成为部分商品和服务的重要获客渠道。
- 确定性：中。
- 商业影响：企业除了做传统SEO（搜索引擎优化），还需要关注GEO（生成式引擎优化），即如何让AI准确理解、引用和推荐自己的商品与服务。

这个方向值得提前进入，但目前尚不能保证AI推荐能够带来稳定的订单量。
趋势6：企业真正缺少的是高质量数据、安全机制和AI运维能力
- 趋势是什么：企业使用AI的难点正在从“模型会不会回答”转向“模型能不能访问正确的数据、遵守业务规则、稳定运行并且不犯严重错误”。企业知识库、数据清洗、权限控制、运行监控和人工审核将成为重要基础设施。
- 依据：【笔记13】【笔记17】【InfoQ中文】。麦肯锡调查显示，年收入超过10亿美元的大型企业受访者中，40%报告正在规模化应用智能体，而较小企业的对应比例仅为22%。
McKinsey
- 大概什么时候：2027年需求增长，2028—2029年随着AI拥有更多业务操作权限，安全和运维需求进一步扩大。
- 确定性：高。
- 商业影响：帮助一家企业整理过去五年的产品文档、客户问答、操作流程，并建立可持续更新的知识库，可能比单纯卖一个AI聊天机器人更有商业价值。

趋势7：中国AI应用及服务出海将迎来新的政策和市场窗口
- 趋势是什么：中国团队可以利用国内模型、软件开发能力和供应链优势，为海外企业提供价格有竞争力的AI自动化服务、多语言客服、商品营销和垂直行业软件。
- 依据：【财联社】【界面新闻】【钛媒体】。2026年11月26日，商务部等8部门印发《服务贸易发展“十五五”规划》，明确提出有序推动云计算、大模型等AI相关服务出海，培育人工智能服务贸易新业态。该政策已通过商务部官网及财联社核实。
商务部
- 大概什么时候：2027—2030年持续推进，其中2027—2028年适合小团队验证海外客户需求。
- 确定性：中。
- 商业影响：中国小团队不必局限于国内市场，可以利用AI降低多语言沟通、产品开发和客户服务成本，直接服务海外细分市场。

政策支持的确定性较高，但具体企业能否盈利仍取决于产品质量、获客能力及当地合规要求。
趋势8：AI从数字世界走向物理世界，但商业化速度将出现分化
- 趋势是什么：随着多模态模型、世界模型和机器人技术发展，AI将逐渐从处理文字、图片和代码，扩展到理解真实环境、操作设备、辅助工业生产和控制机器人。
- 依据：【笔记1】【笔记4】【笔记12】。斯坦福大学《2026 AI Index Report》也将机器人及人工智能技术性能列为重点研究方向。
Stanford HAI
- 大概什么时候：2027—2028年，工业质检、仓储、巡检等结构化场景更容易取得进展；2029年及以后，通用机器人可能进入更多商业场景，但具体普及时间待核实。
- 确定性：中；通用家庭机器人在三年内大规模普及的确定性低。
- 商业影响：普通创业者不适合直接制造人形机器人，但可以关注机器视觉、设备维护、行业数据采集、机器人部署和培训等周边服务。

- 机会：利用AI建立面向单一行业的付费商业情报服务｜适合谁：行业研究员、自媒体作者、投资研究人员、有信息搜集能力的个人｜怎么切入：只聚焦一个细分领域，例如AI应用出海、工业机器人或跨境电商，自动追踪政策、招标、公司财报、产品更新和价格变化，人工核实后形成每周情报报告，向企业或专业人士收取订阅费｜启动成本：低｜风险：信息同质化、来源版权、错误信息损害信誉、用户续费不足｜依据：【笔记1】【笔记6】【笔记8】【笔记9】【笔记20】

最值得优先尝试的三个方向：

| 优先级 | 方向 | 推荐理由 | 首次验证周期（建议） |
| --- | --- | --- | --- |
| 1 | 企业AI流程自动化 | 客户需求明确，节省的时间容易衡量 | 2—4周 |
| 2 | 企业AI知识库 | 容易从服务切入，具备后续维护收入 | 2—4周 |
| 3 | AI搜索优化与商业情报 | 启动资金少，有机会形成长期数据积累 | 4—8周 |

对于没有技术背景的人，建议先做服务，再逐步把重复服务变成软件；对于有技术背景的人，建议先找到愿意付费的客户，再开发产品。
举一个具体的商业模式测算：假设一家小团队服务10家中小企业，每家每月收取2000元维护及运营服务费。

| 项目 | 每月金额 |
| --- | --- |
| 客户收入 | 20,000元 |
| AI模型及API费用 | 2,000元 |
| 软件及服务器费用 | 1,000元 |
| 外包及人工审核费用 | 3,000元 |
| 获客及其他费用 | 2,000元 |
| 扣除上述费用后的余额 | 12,000元 |

以上只是用于判断商业模式是否成立的假设测算，不是实际经营数据，尚未扣除创始人工资、税费等支出。
关键不是一开始服务多少客户，而是能否将第一个客户的解决方案，以较低的额外成本复制给第二个、第三个客户。

## 不建议碰的方向

| 方向 | 不建议的原因 | 风险程度 |
| --- | --- | --- |
| 从零训练通用大模型 | 算力、资金、人才和数据门槛极高，直接与巨头竞争 | 极高 |
| 没有行业特色的AI聊天套壳 | 功能容易被官方产品覆盖，缺乏用户黏性 | 高 |
| 单纯转售AI账号和Token额度 | 依赖平台补贴、价格差及账号政策，经营稳定性差 | 高 |
| 批量生成低质量自媒体内容 | 内容供给过剩，平台治理、版权及流量变现风险突出 | 高 |
| 只卖提示词和基础AI教程 | 知识容易被免费内容和AI本身替代，缺乏持续收入 | 高 |
| 没有客户就提前购买大量GPU | 硬件折旧、利用率、价格波动及现金流风险较大 | 极高 |
| 完全无人监管的AI金融、医疗、法律服务 | 错误成本高，涉及专业资质、责任和监管问题 | 极高 |
| 普通小团队直接研发通用人形机器人 | 研发周期长、供应链复杂、资金投入大 | 极高 |

此外，需要警惕一个特别容易出现的创业误区：把AI能够实现的功能，误认为客户愿意付费的需求。
例如，AI能够在几分钟内生成一份行业报告，并不意味着有人愿意购买这份报告；AI能够快速制作一个网站，也不意味着这个网站能够获得流量。
未来真正稀缺的可能不是生产内容和开发软件的能力，而是获得客户信任、找到真实需求和掌握销售渠道的能力。

## 接下来观察什么
建议未来12个月重点追踪以下指标，不必每天花大量时间关注新模型发布和排行榜。

| Anthropic财报 | 营收、毛利率、亏损、现金流、算力支出 | 判断前沿模型商业模式是否成立 | 每季度 |

| 传统软件公司的变化 | 是否降价、增加AI功能、改用按量收费 | 判断哪些软件市场正在被重新划分 | 每季度 |
| AI安全与监管 | 数据保护、生成内容标识、智能体责任 | 判断合规及安全服务的新需求 | 每月 |

从个人创业角度，建议给自己设定一个90天的商业验证周期，而不是花90天单纯学习AI工具。

## 90天AI创业验证计划
第1—30天

找到真实需求
访谈20个潜在客户，选择一个重复发生、耗费人工、容易衡量结果的问题，做出一个可以现场演示的解决方案。

第31—60天

获得真实收入
争取3个付费试点客户，记录交付时间、Token成本、人工审核成本和客户实际获得的收益。

第61—90天

验证能否复制
将解决方案标准化，争取5—10个付费客户，测试续费意愿和实际利润，决定是否继续投入。
以上数字为建议执行目标，不是行业统计数据或收入承诺。
判断一个AI创业项目是否值得长期经营，可以使用下面五个筛选标准：
- 客户在没有AI之前，就已经愿意花钱解决这个问题。
- 需求不是一次性的，每周或每月都会发生。
- AI带来的成本节省或收入增长能够被衡量。
- 即使模型供应商涨价或更换，业务仍然能够运行。
- 随着客户增加，自己的工作量不需要同比例增加。

满足的条件越多，项目越有可能形成可持续业务。
未来三年，值得争取的不是成为最会使用AI的人，而是成为某个细分行业里，最会利用AI解决实际商业问题的人。
