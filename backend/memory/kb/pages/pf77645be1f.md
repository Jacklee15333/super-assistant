# 人民币石油结算
人民币石油结算通过扩大人民币在国际能源贸易中的使用，为能源进口国和出口国提供美元之外的货币选择。〔S28〕

## 要点

### 发展动力
- 中国庞大的原油进口需求被来源1视为推动人民币进入国际能源贸易的重要经济基础。〔S28〕
- 俄罗斯、伊朗受到美国制裁及美元支付体系限制，被来源1视为具有使用人民币等替代结算货币的现实动力。〔S28〕
- 来源1认为，能源出口国采用多种结算货币，有助于分散对单一货币及其金融政策的依赖。〔S28〕
- S33来源1认为，美国金融制裁、债务扩张及货币政策波动可能推动其他国家减少对美元支付和储备体系的依赖。〔S33〕

### 人民币能源交易与支付基础设施
- 来源1称，2023年中国石油通过上海石油天然气交易中心完成首笔数字人民币石油交易。〔S28〕
- 来源1提到，沙特参与多边央行数字货币桥项目，该项目被文章视为发展替代性跨境支付渠道的重要探索。〔S28〕
- 来源1称，阿联酋等海湾国家正在建设人民币清算机制，并逐步扩大人民币在对华能源贸易中的使用。〔S28〕
- 上述支付基础设施及交易案例反映的是人民币跨境支付应用的探索，不能直接证明人民币已经取得国际石油定价主导权。〔S28〕
- [[人民币跨境支付系统CIPS]]被S33来源2视为支持人民币石油交易的重要跨境支付清算基础设施。〔S33〕
- S33来源2认为，通过CIPS直接参与行处理跨境人民币支付，可能减少部分中间银行环节，提高资金周转效率并降低交易成本。〔S33〕
- S33来源2称，沙特和阿联酋通过多边央行数字货币桥与CIPS实现秒级跨境支付，但未提供系统互联文件、具体交易记录及适用范围。〔S33〕

### 2025年资料中的人民币石油结算数据
以下信息来自2025年6月29日金融界文章及2025年8月2日搜狐号自媒体文章，相关资料未附能源企业正式公告、完整交易统计表或原始支付记录，应作为待核实线索保存。〔S33〕
- S33来源1提到中国与沙特的人民币石油合作安排，并将其视为石油美元体系受到竞争的表现，但未提供协议原文。〔S33〕
- S33来源1将人民币原油期货交易量增长视为人民币参与国际石油定价的重要发展方向，但未给出具体交易规模。〔S33〕
- S33来源2称，沙特阿美对华原油出口中约12%采用人民币及CIPS结算，但未说明统计周期、合同数量和交易金额。〔S33〕
- S33来源2称，俄罗斯、伊朗对华石油交易中的人民币结算比例已达到65%以上，但未分别列出两个国家的数据及统计口径。〔S33〕
- S33来源2称，CIPS能源类交易金额一年内增长67%，但未给出起止时间、业务分类及交易金额基数。〔S33〕
- S33来源2称，2024年人民币在中俄贸易结算中的占比达到67%，而2019年仅为3%；该数字属于整体贸易结算口径，不能直接等同于石油贸易结算比例。〔S33〕
- S33来源2还以巴西淡水河谷铁矿石贸易为例，称相关人民币支付通过CIPS处理后，资金到账时间由两天缩短至40分钟；该案例属于非石油大宗商品贸易，不能直接作为石油结算效率的实证数据。〔S33〕

### 2026年人民币石油结算的相关报道
以下信息主要来自2026年4月3日网易号自媒体文章，资料未附官方公告、完整统计表或企业原始披露，应作为待核实线索保存。〔S28〕
- 文章称，2026年3月霍尔木兹海峡32%的油轮使用人民币结算，较2023年增长约6倍，但未说明统计样本、交易金额和结算范围。〔S28〕
- 文章称，伊朗开始实施人民币结算优先的港口通行规则，并将人民币结算与船舶通行条件挂钩。〔S28〕
- 文章称，中国石化、印度信实工业调整了相关结算策略，俄罗斯卢克石油将对华原油出口的结算货币全部切换为人民币。〔S28〕
- 文章称，伊朗约90%的石油出口流向中国，因此具有推动人民币能源结算的动力。〔S28〕
- 文章称，沙特外汇储备中人民币的占比由2022年的1.1%升至2026年3月的6.8%，但S28未附沙特央行的原始储备结构数据。〔S28〕
- 文章称，中国在波斯湾地区的基础设施投资已超过700亿美元，并将其与人民币能源贸易的发展联系起来，但未提供投资统计的时间范围及具体项目清单。〔S28〕
- S33虽然以石油人民币结算进展为调研主题，但主要有效正文发表于2025年，没有提供能够进一步确认2026年人民币石油结算规模的新统计数据。〔S33〕

### 人民币国际化的可能方向
- 来源1认为，人民币石油结算的战略价值主要在于扩大货币选择权、降低制裁风险和减少对美元支付渠道的依赖，而不一定是全面取代美元。〔S28〕
- 来源1认为，成为单一全球储备货币可能带来汇率升值、出口竞争力变化和承担国际储备货币责任等成本。〔S28〕
- 来源1预测，到2028年海湾国家对亚洲的石油出口中，人民币计价及结算的比例可能进一步提高，但没有给出可验证的具体目标比例。〔S28〕
- 来源1预期未来国际石油贸易可能形成美元、人民币、欧元及数字货币并存的多元化结算格局。〔S28〕
- S33来源1建议建立金砖国家大宗商品人民币定价联盟，并推动数字货币桥等支付基础设施建设；该内容属于政策建议，并非已经建立的国际定价机制。〔S33〕
- S33来源1认为，到2030年人民币在全球支付中的占比可能达到20%，但这一预测覆盖整体支付市场，不代表人民币石油结算份额。〔S33〕

### 研究中的关键统计口径
- 石油交易使用人民币支付，不一定意味着石油合同使用人民币定价。
- 油轮数量占比、原油运输量占比和石油交易金额占比分别反映不同指标，不能相互替代。
- 人民币跨境支付规模、石油贸易结算比例和人民币在各国央行外汇储备中的占比，需要分别统计。
- 数字人民币、人民币跨境清算机制和多边央行数字货币桥应作为不同的支付工具及基础设施研究。
- CIPS全部业务处理金额、能源类交易金额、石油贸易结算金额和国际石油贸易人民币结算比例，应分别统计，不能将支付系统整体业务增长直接等同于人民币石油结算增长。〔S33〕
- 人民币原油期货交易规模、实物石油贸易合同定价货币及最终支付货币属于不同指标，需要分别核实。〔S33〕

- [[人民币跨境支付系统CIPS]]：为人民币跨境支付和清算提供基础设施，是观察人民币能源结算发展的重要对象。〔S33〕
- [[美国经济制裁与长臂管辖]]：金融制裁风险被相关来源视为俄罗斯、伊朗等国家发展替代性货币结算机制的重要动力。〔S28〕〔S33〕

## 不同说法
- S28来源1的标题宣称石油美元即将终结，但正文同时承认美元金融市场具有深度、流动性和网络效应优势，并认为未来更可能出现多种货币并存的结算格局。标题判断明显强于正文论证。〔S28〕
- 来源1一处称伊朗实行人民币结算优先规则，另一处称必须使用人民币结算才允许船只通行；优先使用与强制使用属于不同政策，需要核实官方规定。〔S28〕
- 来源1强调人民币能源结算正在扩大，来源2则指出同期美元指数突破100关口，说明人民币能源结算的发展与美元短期走强可能同时存在。〔S28〕
- S33来源2称，俄罗斯、伊朗对华石油交易人民币结算比例达到65%以上。〔S33〕
- S28来源1称，俄罗斯卢克石油已将对华原油出口结算货币全部切换为人民币；这一说法针对特定企业，与俄罗斯或伊朗全国对华石油贸易的整体结算比例不是同一统计口径。〔S28〕
- S33来源2强调人民币及CIPS在能源贸易中的竞争优势，S33来源1则认为美元在大宗商品贸易中仍具有相对优势，说明替代性结算渠道的发展尚不能证明国际石油定价权已经转移。〔S33〕
