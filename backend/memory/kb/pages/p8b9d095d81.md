# 良渚文化
位于长江下游太湖东南地区，在中华文明起源过程中率先发展出早期国家政体的区域考古学文化。〔S13〕

## 要点

### 历史地位
- 良渚文化属于中华文明探源工程所划分的古国时代第二阶段，该阶段整体时间范围为距今5300—4300年。〔S13〕
- 良渚文化早期与中期交界时，良渚早期国家正式形成。〔S13〕
- 项目执行专家组将良渚文化与长江中游屈家岭—石家河文化区视为率先发展出早期国家政体的区域。〔S13〕
- 良渚文化是研究中华文明早期国家形成、社会复杂化及资源组织能力的重要案例。〔S13〕

### 社会组织与经济基础
- 良渚文化的聚落等级分化、公共资源配置及人力调配复杂程度，相较古国时代第一阶段发生了质的变化。〔S13〕
- 稻作农业是这一时期长江流域社会发展的关键经济支撑。〔S13〕
- 良渚文化与长江中游部分遗址在大型水利工程、水管理体系方面存在趋同现象。〔S13〕
- 聚落等级与公共资源调配能力的发展，是项目组判断良渚已经形成早期国家的重要依据。〔S13〕

### 宗教与意识形态
- 项目执行专家组提出，良渚文化可能存在较为发达的一神教信仰，但这一判断仍具有推测性质。〔S13〕
- 同一时期，江汉平原及澧阳平原尚未发现能够支持类似宗教信仰判断的迹象。〔S13〕
- 不同区域早期文明在意识形态方面存在不同的发展路径。〔S13〕

### 跨区域交流
- 良渚遗址存在远距离物品交流现象。〔S13〕
- 同一时期的焦家遗址也存在远距离物品交流，反映区域社会活动对地缘空间的扩张与突破。〔S13〕
- 良渚所处的长江下游文明与长江中游区域文明在社会复杂化、水利管理和早期国家发展方面具有可比较性。〔S13〕

## 时间线
- 距今5300—4300年：良渚文化对应古国时代第二阶段。〔S13〕
- 良渚文化早中期之交：良渚早期国家正式形成。〔S13〕
- 2020—2024年：良渚被纳入中华文明探源工程第五阶段29处遗址的田野考古及多学科研究范围。〔S13〕
- 2026-06-25：良渚博物院发布中华文明探源工程最新研究成果与认识。〔S13〕
- 2026-06-26：中国社会科学院考古研究所发布相关研究成果，明确良渚早期国家的形成及其文明发展地位。〔S13〕
