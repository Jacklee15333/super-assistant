# AI时代SaaS商业模式与竞争壁垒
AI智能体正在改变企业软件的使用方式、收费模式及竞争壁垒，传统SaaS企业需要重新评估自身的商业价值与盈利能力。〔S37〕

## 要点

### 一、传统SaaS面临的市场冲击
- 据2026年3月13日雷峰网报道，2026年初约两个月内，北美软件股市值蒸发超过1.6万亿美元。〔S37〕
- 2026年1月底，Anthropic推出能够自主操作电脑、执行办公任务的Claude Cowork，引发市场对传统企业软件长期商业价值的担忧。〔S37〕
- 投资人Daniel认为，此轮SaaS股价下跌主要源于市场对未来商业模式的预期变化，而非企业当期财务表现不及预期。〔S37〕
- 当AI智能体能够绕过图形用户界面直接操作软件时，传统流程化软件可能逐渐成为智能体调用的功能模块，削弱原有软件厂商的定价能力。〔S37〕
- 致趣百川联合创始人兼CEO何润认为，中国SaaS企业的市销率（PS）估值体系此前已经受到严重冲击，北美SaaS企业也开始面临类似压力，企业需要更加重视实际盈利能力。〔S37〕
- 何润观察到，不少北美SaaS企业的净收入留存率（NDR）已经回落至100%左右，认为这一指标继续下降将进一步冲击传统估值逻辑。〔S37〕

### 二、传统软件竞争壁垒受到的挑战

| 原有竞争壁垒 | AI带来的挑战 |
| --- | --- |
| 客户转换成本 | AI原生软件可能以更低成本和更好的使用体验争夺存量客户〔S37〕 |
| 网络效应 | 传统SaaS依靠网络效应建立的竞争优势受到挑战〔S37〕 |
| 图形用户界面（GUI） | AI能够通过自然语言理解用户需求并执行软件操作〔S37〕 |
| 功能数量 | 部分复杂软件功能可能被AI Skills替代或整合〔S37〕 |
| 业务流程入口 | AI智能体可能接管用户与企业软件之间的交互入口〔S37〕 |

- 部分AI Native企业软件并未创造全新的商业需求，而是通过更高效的技术架构争夺传统软件企业已经拥有的客户和市场预算。〔S37〕
- 单纯依靠增加功能、改善操作界面和提高软件开发效率建立竞争优势，可能变得越来越困难。〔S37〕

### 三、仍可能长期存在的商业壁垒

| 商业壁垒 | 形成原因 |
| --- | --- |
| 企业经营数据 | 客户长期使用软件过程中积累的数据形成迁移和替换障碍〔S37〕 |
| 客户关系 | 长期服务形成的客户信任及合作关系难以快速复制〔S37〕 |
| 品牌认同 | 企业客户对已有供应商的品牌认可具有商业价值〔S37〕 |
| 行业知识（Know-how） | 对特定行业业务规则、经营流程和实际需求的理解需要长期积累〔S37〕 |
| 业务流程耦合 | 软件与企业内部经营流程深度结合，提高替换难度〔S37〕 |
| 系统集成能力 | 企业软件需要与数据库、工厂系统及其他内部系统完成复杂对接〔S37〕 |
| 专业交付能力 | 数据对接、实施部署、员工培训和持续服务仍需要专业能力〔S37〕 |

- 何润将企业长期沉淀在SaaS系统中的经营数据形成的壁垒称为“数据半透膜”。〔S37〕
- Daniel认为，与客户业务流程深度耦合、长期沉淀的行业知识及持续服务关系，是企业软件仍然具有长期商业价值的重要原因。〔S37〕
- 吴昊认为，即使AI大幅降低软件开发成本，企业对业务理解、复杂系统交付及系统集成的需求仍然存在。〔S37〕

### 四、收费模式可能发生变化
- 圆桌讨论的三位嘉宾均认为，传统SaaS按员工账户数量或软件坐席数量收费的商业模式，在AI时代可能面临较大挑战。〔S37〕
- 吴昊举例说明，如果一家拥有10,000名员工的企业因AI应用将员工数量减少至8,000名，在其他条件不变的情况下，按员工坐席收费的软件厂商收入可能减少20%。〔S37〕
- 上述数字属于假设案例，不是已经发生的企业裁员或软件收入下降案例。〔S37〕
- 嘉宾提出，未来企业软件可能逐渐转向按照Token使用量或实际业务结果收费。〔S37〕
- Daniel提醒，如果软件厂商采用按模型调用量收费的模式，部分利润可能向基础模型供应商转移，领先模型厂商仍可能具有较强的定价能力。〔S37〕

### 五、AI对软件开发行业的影响
- 吴昊认为，AI不会消除社会专业分工，软件开发人员的工作可能从基础编码向架构设计、系统结构和客户需求理解转移。〔S37〕
- 软件开发成本下降可能进一步扩大社会对软件的需求，因此开发效率提升并不必然导致软件行业整体萎缩。〔S37〕
- 企业级软件的长期竞争力可能更多取决于业务理解、系统集成和专业交付，而不是单纯编写代码的能力。〔S37〕

### 六、传统软件企业商业化观察案例
- 吴昊在圆桌讨论中提到，Salesforce虽然持续强调AI业务，但其观察认为，2025年财报中AI相关收入占比可能仍只有百分之几。〔S37〕
- 吴昊称，Salesforce在2025年全年的股价跌幅约为30%。〔S37〕
- 上述数据来自行业人士在媒体圆桌讨论中的陈述，S37未提供相应财报原文或完整股价统计依据，不能直接作为经过独立核实的经营数据。〔S37〕

## 不同说法

### AI是否会消除传统软件企业的商业价值
- Daniel认为，AI智能体可能削弱传统软件厂商对业务入口的控制及定价能力，但企业软件仍可依靠业务流程、行业知识和客户服务关系保留长期价值。〔S37〕
- 何润认为，传统SaaS的转换成本和网络效应正在受到挑战，但企业经营数据及长期客户关系仍是重要竞争资产。〔S37〕
- 吴昊相对乐观，认为AI提高开发效率可能进一步扩大软件需求，专业分工及复杂交付能力不会因此消失。〔S37〕

上述判断的主要差异在于对传统软件商业模式受到冲击的程度，以及未来软件市场需求增长空间的预期，均属于行业人士的分析判断。〔S37〕
