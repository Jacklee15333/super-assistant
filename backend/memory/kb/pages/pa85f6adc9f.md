# 美国经济制裁与长臂管辖
美国通过国内立法、行政命令、金融限制、贸易禁运及域外司法管辖等手段，对其他国家、企业和个人实施经济与政治压力。〔S32〕

## 要点

### 法律与制度工具
中国外交部于2022年6月发布《美国对华认知中的谬误和事实真相》，其中列举了美国实施经济制裁与长臂管辖的相关法律、政策工具及案例。〔S32〕
美国相关法律包括：
- 《国际紧急经济权力法》。〔S32〕
- 《全球马格尼茨基人权问责法》。〔S32〕
- 《以制裁反击美国敌人法》。〔S32〕
- 针对古巴的《托里切利法》。〔S32〕
- 针对古巴的《赫尔姆斯—伯顿法》。〔S32〕

美国还通过行政命令对特定国家、组织及个人实施制裁，并通过最低联系原则、效果原则等法律规则扩大国内法的域外适用范围。〔S32〕

### 制裁规模
- 据中国外交部2022年发布的材料，特朗普第一届政府累计实施超过3900项制裁措施，平均每天约3项。〔S32〕
- 截至2021财年，美国净制裁实体及个人数量达到9421个，较2000财年增长933%。〔S32〕
- 上述3900项属于一定时期内实施的制裁措施数量，9421个属于被制裁实体及个人数量，两者统计口径不同，不能直接相加或比较。〔S32〕

### 古巴制裁案例
- 截至2022年，美国针对古巴的贸易禁运、经济封锁及金融制裁已经持续60多年。〔S32〕
- 美国通过禁运政策及《托里切利法》《赫尔姆斯—伯顿法》等国内立法构建针对古巴的制裁体系。〔S32〕
- 据中国外交部2022年发布的材料，相关制裁已使古巴蒙受超过1000亿美元的直接经济损失。〔S32〕

### 伊朗制裁案例
- 美国自20世纪70年代末开始对伊朗实施长期封锁与制裁。〔S32〕
- 2018年5月，美国政府单方面退出伊朗核问题全面协议，随后恢复并增加对伊朗的制裁措施。〔S32〕
- 据中国外交部发布的材料，相关制裁导致多国企业停止与伊朗合作，部分外国石油企业撤出伊朗，并对伊朗制造业、经济增长、物价及货币价值产生负面影响。〔S32〕
- 美国还对白俄罗斯、叙利亚、津巴布韦、朝鲜和委内瑞拉等国家实施制裁或施压政策。〔S32〕

### 对中国的经济与技术限制
- 美国通过市场准入限制、芯片及操作系统供应限制等方式对华为实施限制措施，并推动其他国家限制华为参与当地5G网络建设。〔S32〕
- 美国依据301调查，先后三轮对价值约3600亿美元的中国输美商品加征高额关税。〔S32〕
- 2021年9月，美国政府宣布针对钕铁硼永磁材料是否影响美国国家安全启动232调查。〔S32〕
- 美国出台《维吾尔强迫劳动预防法案》，涉及新疆棉花、番茄、太阳能光伏等产业的对美贸易。〔S32〕
- 贸易关税、出口管制、进口限制、金融制裁及司法长臂管辖属于不同政策工具，研究时应分别考察其法律依据及实际影响。

### 制裁政策的争议
- 中国外交部认为，美国利用金融优势、技术优势及国内法律实施单边制裁和长臂管辖，损害相关国家的主权、经济发展及民众生活。〔S32〕
- 美国塔夫茨大学教授、布鲁金斯学会高级研究员丹尼尔·德雷兹纳于2021年9月在《外交》杂志发表文章，批评美国历届政府过度依赖制裁解决外交问题，并指出其政策效果及人道主义代价值得反思。〔S32〕

## 时间线
- 20世纪70年代末：美国开始对伊朗实施长期封锁与制裁。〔S32〕
- 2018-05：美国退出伊朗核问题全面协议，随后恢复并新增对伊朗的制裁措施。〔S32〕
- 2021-09：美国宣布针对钕铁硼永磁材料启动232调查。〔S32〕
- 2021-09：丹尼尔·德雷兹纳在《外交》杂志发表文章，批评美国过度依赖经济制裁。〔S32〕
- 2021财年：美国净制裁实体及个人数量达到9421个，较2000财年增长933%。〔S32〕
- 2022-06：中国外交部发布《美国对华认知中的谬误和事实真相》，系统阐述对美国经济制裁、长臂管辖及对华限制政策的批评。〔S32〕
