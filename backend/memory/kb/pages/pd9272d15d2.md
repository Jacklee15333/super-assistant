# 低空经济真实市场交易与数据口径
低空经济真实市场核实要求区分产业规模估算、客户注册数量、采购预算、挂牌价格、实际成交金额及经营净利润，避免将产业热度误认为商业需求。〔S56〕

## 要点

### 四个市场核实维度
S56报告从市场规模、客户、购买力和利润四个主要维度调查低空经济，并补充公开市场交易及设备使用数据。〔S56〕

| 调查维度 | 核心问题 | 当前证据及缺口 |
| --- | --- | --- |
| 市场规模 | 行业实际发生了多少交易 | 2025年产业规模估算为7151.2亿元，实际成交总额待核实〔S56〕 |
| 客户 | 有多少人或机构实际付费 | 已有注册用户及运营主体数据，年度付费客户数量待核实〔S56〕 |
| 购买力 | 客户实际愿意支付多少钱 | 已获得部分采购、中标、挂牌及收费样本，年均实际消费额待核实〔S56〕 |
| 利润 | 经营者最终能够赚多少钱 | 已获得部分上市公司财务数据，小型服务商利润率待核实〔S56〕 |

### 市场规模与客户统计的边界
- 产业规模、制造业产值、企业营业收入、投资金额及实际成交总额属于不同统计口径，不能直接混用。〔S56〕
- 无人机注册用户数量属于存量统计，并不是当年实际购买设备或服务的客户数量。〔S56〕
- 无人机注册保有量不等于年度新增销量。〔S56〕
- 取得运营合格证的单位数量代表相关运营主体规模，而不是实际付费客户数量。〔S56〕
- 无人机累计飞行时长包含非付费飞行，不能直接换算为商业作业收入。〔S56〕
- 2026年前三季度全国居民人均可支配收入为34230元，该数字只能作为居民购买力背景，不能作为无人机消费金额。〔S56〕

### 政府采购市场调查
- 2026年11月26日21时47分，S56所用交易平台爬虫完成相关数据采集。〔S56〕
- 中国政府采购网2026年5月30日至11月26日以「低空经济」为关键词的搜索结果中，采购公告为248条，中标公告为66条。〔S56〕
- 上述数量属于关键词搜索结果，可能存在重复公告、无关项目及漏检项目，并非已经完成去重的独立订单数量。〔S56〕
- 政府采购预算与中标金额混合抽样3条记录所得中位数为266万元，但样本较少，且存在异常日期记录可能影响计算的问题。〔S56〕
- 爬虫数据中出现了日期为2026年12月17日、预算4000万元的芜湖低空经济测试验证基地公告，该日期晚于采集时间和报告截止时间，因此被排除出有效交易证据。〔S56〕
- 由于无法确认上述异常记录是否参与中位数计算，266万元的样本中位数也需要谨慎使用。〔S56〕
- 不能使用少量金额样本的中位数乘以采购公告数量或中标公告数量，推算全国低空经济成交总额。〔S56〕
- 全国低空经济政府采购实际成交总额，截至S56报告完成时仍未核实。〔S56〕

### 平台成交数据与电商数据
- 2026年11月猪八戒网部分航拍商品搜索快照显示成交量为0单，但其累计统计周期不明。〔S56〕
- 商品存在挂牌报价，只能证明有人提供相关商品或服务，不能证明存在对应价格的实际订单。〔S56〕
- 2026年11月26日，1688无人机及配件数据因登录限制和抓取超时，未能获得可靠成交额及销量。〔S56〕
- 同日，京东无人机及配件数据因页面空壳及登录限制，未能获得可靠成交额及销量。〔S56〕
- 电商数据抓取失败不代表商品没有销量，也不能将无法获取的成交金额记为零。〔S56〕
- 猪八戒网及大疆官方商城的部分价格仅来自搜索快照，尚未完成实时订单页面核实。〔S56〕

- S56报告对低空经济整体给出偏向「话多钱少」的判断，具体含义是已验证商业成交、持续盈利及普通人创业机会尚不足以支撑产业宣传热度，而不是认定整个产业没有真实市场。〔S56〕

### 数据质量与证据核实原则
- 政府部门官方统计可以支持其明确统计口径内的结论，但不能自动转换为其他商业指标。〔S56〕
- 政府中标公告及合同公告适合用于核实具体采购需求及交易金额，但需要按项目编号去重，并区分预算与实际成交。〔S56〕
- 上市公司年度报告能够支持企业营业收入及利润分析，但代表企业的盈利能力不能直接外推至小型创业者。〔S56〕
- 行业研究报告可以提供产业规模参考及结构分析，但需要区分事前预测、事后估算及实际交易统计。〔S56〕
- 平台挂牌报价只能作为收费参考，真实购买力需要通过实际成交记录进一步验证。〔S56〕
- 自动采集数据需要检查日期异常、重复记录、无关搜索结果及数据缺失问题。〔S56〕
- S56所用资料①包含相关制造业、上市公司财务汇总及新闻监测数据，但缺少原始数据页面网址，因此没有被作为低空经济专项市场规模证据。〔S56〕
- 资料②包含搜狗输入法、电子邮箱帮助中心、Obsidian教程及PPT模板等无关搜索结果，已全部剔除，不采用其中任何数字。〔S56〕
- 资料③属于交易平台爬虫样本，是本次采购调查的优先证据，但不是完整交易数据库。〔S56〕
- 中国民航局统计公报因原报告预设的证据分类限制被归入「行业报告」，其实质仍然是政府部门官方统计，而非商业咨询机构估算。〔S56〕

### 进一步核实真实市场的方法

| 待调查数据 | 调查渠道 | 核实方法 |
| --- | --- | --- |
| 全国实际年度成交额 | 中国民航局、国家统计局 | 查询专项统计，区分产值、营收、投资额及实际交易额〔S56〕 |
| 无人机年度真实销量 | 淘宝、京东、大疆商城 | 按型号记录价格、销量、评价及销售周期〔S56〕 |
| 配件进货成本及毛利 | 1688 | 比较电池、桨叶、电机及维修配件的批发价与零售价〔S56〕 |
| 航拍实际成交价格 | 猪八戒网、闲鱼 | 查看真实交易记录，区分挂牌价与最终成交价〔S56〕 |
| 政府采购实际金额 | 中国政府采购网 | 汇总中标公告及合同公告，按项目编号去重〔S56〕 |
| 地方企业采购金额 | 全国公共资源交易平台 | 搜索具体无人机作业及服务采购项目〔S56〕 |
| 实际付费客户数量 | 当地农业农村局、合作社、产业园 | 调查客户数量、外包频率及年度预算〔S56〕 |
| 小型服务商利润率 | 当地飞防公司、无人机维修店 | 核实营业收入、耗材、人工、折旧、获客及税费〔S56〕 |
| 培训真实需求 | 正规无人机培训机构 | 核实开班、缴费人数、退款及获客成本〔S56〕 |
| 当地经营与合规条件 | 民用无人驾驶航空器综合管理平台 | 核实经营资质、适飞空域及当地运营条件〔S56〕 |

政府采购调查不应只使用「低空经济」作为关键词，因为已经投入实际使用的业务往往直接以具体采购需求命名。〔S56〕
S56报告建议使用以下关键词分别检索：无人机植保、无人机飞防服务、无人机巡检服务、无人机航拍服务、无人机测绘、无人机维修、无人机培训、无人机实训设备、无人机租赁。〔S56〕

### 决定小型创业可行性的关键数据
相对于全国低空经济产业规模及未来增长预测，S56报告认为以下四项数据对于普通创业者更为重要：
- 本地实际付费客户数量。〔S56〕
- 客户购买及复购频率。〔S56〕
- 实际成交客单价。〔S56〕
- 小型经营者扣除全部经营成本后的净利率。〔S56〕

## 不同说法

### 产业规模与实际成交额
- 赛迪顾问新版报告估算2025年中国低空经济产业规模为7151.2亿元。〔S56〕
- 其他行业报告及早期预测曾提出8591.7亿元和1.5万亿元等不同规模数字。〔S56〕
- S56报告未找到全国低空经济2025年度实际成交总额的统一统计，因此上述产业规模数字均不能直接认定为真实交易金额。〔S56〕

### 政府采购金额样本的可靠性
- 原始爬虫数据给出了266万元的政府采购预算与中标金额混合样本中位数。〔S56〕
- 后续核实发现其中存在日期晚于采集时间的4000万元预算公告，且无法确认该异常记录是否影响中位数计算，因此该中位数不能作为可靠的全国采购客单价。〔S56〕

### 零成交与数据缺失
- 猪八戒网部分航拍服务商品搜索快照显示成交量为0单，但累计周期不明。〔S56〕
- 1688及京东未取得可靠销量与成交额，原因是抓取及访问限制，并非平台已经确认成交量为零。〔S56〕
- 两种情形分别属于有限的可见成交记录与数据获取失败，不能混为一谈。〔S56〕
