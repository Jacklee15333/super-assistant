# 刑事辩护策略与数罪并罚风险
刑事辩护应当以事实、证据和法律为基础，评估不同辩护方案的整体法律后果，避免局部有利的策略造成最终结果恶化。〔S40〕

## 要点

### 罪名切分与整体量刑
- 减少涉案金额、改变罪名、减少犯罪事实、降低单罪刑期、缩短最终执行刑期以及实现无罪认定，是不同层次的刑事辩护目标，不能简单等同。〔S40〕
- 贪污罪涉及特定主体利用职务便利非法占有公共财物等行为；职务侵占罪涉及公司、企业或者其他单位工作人员利用职务便利非法占有本单位财物等行为。〔S40〕
- 数罪并罚是指一个人被认定犯有数罪时，依法分别确定相应刑罚，再依照法定规则决定执行刑罚。〔S40〕
- 刑事律师阮思乔认为，当涉案金额达到特别高的水平时，贪污罪与职务侵占罪的实际量刑可能趋于接近，改变部分行为的罪名未必能够获得显著的减刑效果。〔S40〕
- 如果将原本按照单一罪名处理的行为切分为两个独立罪名，可能产生数罪并罚风险，使罪名调整带来的量刑优势被抵消，甚至导致最终执行刑期增加。〔S40〕
- 罪名切分是否成立，需要结合犯罪主体资格、财产性质、具体行为、行为发生时间、主观目的、适用法律和案件证据综合判断。〔S40〕

### 辩护方案的整体评估
- 在提出重大辩护策略之前，应当审查犯罪构成、主体资格、资金性质、实际用途、证据充分性、数罪认定、量刑情节及相关程序问题。〔S40〕
- 如果案件存在无罪或者部分事实不构成犯罪的辩护空间，不应未经充分审查便接受有罪前提，仅讨论如何在不同罪名之间进行切分。〔S40〕
- 律师不仅需要判断法律定性是否正确，还需要推演定性变化对涉案金额、量刑档次、罪名数量及最终执行刑罚的连锁影响。〔S40〕
- 阮思乔要求律师在提出意见之前至少先思考三步，避免专业表达先于充分的法律分析和后果评估。〔S40〕

### 当事人选择律师与审查辩护方案
- 律师的学历、执业年限、专业背景和表达能力可以作为参考，但不能替代对具体辩护方案及其潜在后果的审查。〔S40〕
- 当事人及家属可以围绕以下九个问题审查重大辩护方案：〔S40〕
- 方案的事实依据和法律依据是什么？〔S40〕
- 是否以承认部分犯罪事实为前提？〔S40〕
- 改变罪名是否会增加新的罪名？〔S40〕
- 是否存在数罪并罚或其他不利量刑风险？〔S40〕
- 原方案与新方案的整体量刑结果有何区别？〔S40〕
- 是否存在无罪、部分无罪或者其他更有利的辩护空间？〔S40〕
- 方案成立需要哪些关键证据，现有证据是否充分？〔S40〕
- 如果方案未被采纳，最坏的结果是什么？〔S40〕
- 是否有必要获取另一位专业刑事律师的独立意见？〔S40〕
- 对于涉案金额巨大、可能面临长期监禁的案件，获取独立的专业意见具有重要的风险控制价值。〔S40〕

## 不同说法
- 作者观点：在特别巨大的涉案金额下，贪污罪与职务侵占罪的刑期可能非常接近，切分罪名可能造成更加不利的数罪并罚结果。〔S40〕
- 资料点评：上述观点属于作者的实务判断，存在一定程度的简化，不能据此认定单罪处理一定优于数罪并罚，也不能认定具体案件中的罪名切分必然增加刑期。〔S40〕
- 作者使用「一加一有可能大于二」形容局部优化导致整体恶化的风险，这是策略层面的比喻，并非严格的法律计算公式，不意味着数罪并罚后的有期徒刑可以任意超过各罪刑期之和。〔S40〕
