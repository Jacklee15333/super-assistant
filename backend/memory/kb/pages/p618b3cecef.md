# 数字身份冒用与亲友安全核实
数字身份冒用是他人未经授权使用个人账号或身份信息进行活动的行为，亲友安全核实需要区分账号活动与本人真实状态。〔S49〕

## 要点

### 一、数字身份不等于真实身份
- 收到微信文字消息，只能说明有人正在使用相关账号，不能单独证明回复者就是账号本人。〔S49〕
- 朋友圈持续更新、社交账号在线及正常文字交流，并不能充分证明账号持有人的人身安全。〔S49〕
- 当真实见面、语音交流及视频交流长期中断时，不能仅依靠社交媒体活动判断亲友的安全状况。〔S49〕

### 二、基于个人行为基线识别异常
[[行为基线分析与确认偏误]]可以用于比较亲友当前通信行为与过去长期形成的稳定习惯，发现值得进一步核实的变化。〔S49〕

| 异常维度 | 需要关注的表现 |
| --- | --- |
| 称呼习惯 | 突然使用过去很少使用的亲属称呼或伴侣昵称。〔S49〕 |
| 语言习惯 | 文字表达方式与过去长期形成的沟通习惯存在明显差异。〔S49〕 |
| 情感反应 | 对重要亲友、宠物及家庭事件的反应与以往明显不同。〔S49〕 |
| 联系方式 | 原本经常通话或见面，后来长期只能通过文字联系。〔S49〕 |
| 社会活动 | 连续缺席生日、节日及其他重要家庭活动。〔S49〕 |
| 职业信息 | 亲友所掌握的工作情况与实际职业状态存在矛盾。〔S49〕 |
| 行程信息 | 声称的出差、旅游或迁居安排长期无法得到独立核实。〔S49〕 |
| 综合变化 | 多种通信和生活异常持续存在，且缺乏可信解释。〔S49〕 |

上述异常不能单独作为身份冒用或犯罪发生的证据，但可以成为启动进一步安全核实的依据。〔S49〕

### 三、为什么异常容易被忽略
- 单独一次措辞变化、未接电话或临时失约，可能存在普通生活中的合理解释。〔S49〕
- 不同亲友掌握的信息可能不完整，难以及时发现彼此掌握的信息存在矛盾。〔S49〕
- 社交账号持续活动容易让亲友误以为与本人仍然保持正常联系。〔S49〕
- 在亲友已经相信当事人正在外地生活或工作的情况下，缺少见面机会可能不会立即引起警觉。〔S49〕
- 事后能够汇总的异常信息，不代表亲友在事件发生期间就具备同样完整的信息，因此不应简单指责亲友未能及时发现异常。〔S49〕

### 四、亲友联系异常时的安全核实流程
1. 发现亲友长期无法直接联系、通信习惯明显改变或连续失约时，重视这些异常是否持续累积。〔S49〕
2. 尝试通过实时语音、视频或其他正常联系方式直接与本人交流。〔S49〕
3. 联系其他亲友、同事等可信任的人员，独立核实其工作、生活及安全状况。〔S49〕
4. 如果仍然无法确认本人安全，或者已经存在明确的人身危险信号，应及时向警方求助。〔S49〕
5. 不独自进入可能存在危险的环境，也不因仍能收到文字消息而放弃进一步核实。〔S49〕

在中国境内遇到紧急人身安全风险，可以拨打110报警。〔S49〕

### 五、数字账号与个人财产保护
数字身份安全不仅涉及通信真实性，也涉及个人账户、信用额度及财务信息的安全。〔S49〕
- 妥善保管身份证、银行卡及重要账号信息。〔S49〕
- 不随意向他人提供支付密码及短信验证码。〔S49〕
- 开启银行账户和信用卡的大额交易提醒。〔S49〕
- 定期检查个人征信、借贷记录及账户交易情况。〔S49〕
- 在亲密关系中保留个人账户及必要的财务自主权。〔S49〕

### 六、代表性案例
在[[上海朱晓东杀妻藏尸案]]中，杨俪萍遇害后，其亲友在三个多月内仍然能够收到来自她微信账号的消息，却无法与其本人进行正常的实时交流。〔S49〕
亲友曾发现称呼习惯改变、对重要事件的情感反应异常、家庭活动持续缺席及职业信息不一致等问题，但未能及时确认本人安全状况。〔S49〕
案件最终于2017年2月1日朱晓东自首后曝光，说明数字层面的联系持续存在，并不意味着真实的人际接触及人身安全能够得到确认。〔S49〕
该案例的安全启示是，应当将账号活动、身份真实性及本人安全状态视为不同的核实对象。〔S49〕

## 关联
- [[上海朱晓东杀妻藏尸案]]：数字身份冒用导致亲友长期无法确认受害者真实状态的代表性案例。〔S49〕
- [[行为基线分析与确认偏误]]：通过比较长期通信习惯识别变化，同时保留多种解释，避免错误归因。
- [[亲密关系中的强制控制与社会支持网络]]：独立社会关系和真实人际接触有助于发现异常及获得外部支持。〔S49〕
- [[亲密关系信任危机与财产风险管理]]：个人身份信息、支付账号及信用额度需要建立独立安全边界。〔S49〕
- [[举证责任与事实核查]]：区分账号活动、身份确认及真实安全状态，避免用不足的证据支持确定性结论。
