# 新能源汽车下游服务与创业机会
围绕存量新能源汽车及车队的实际使用需求，提供商品销售、安装配套、车辆检测、清洁美容及运营维护等服务，尽量避免承担整车制造、经销和公共充电站建设的重资产风险。〔S20〕

## 要点

### 一、市场基础与商业逻辑
- 2025年，全国新能源乘用车新车零售量为1280.9万辆，新能源二手车交易量约为160万辆。〔S20〕
- 截至2026年6月底，全国新能源汽车保有量达到4897万辆，为汽车用品、充电配套及售后服务提供了潜在客户基础。〔S20〕
- 2025年，新能源品牌经销商售后业务毛利贡献占比为37.1%，高于新车销售的26.5%，但这两个指标均不是业务毛利率。〔S20〕
- 2025年，全国汽车经销商亏损比例达到55.7%，说明汽车市场规模庞大并不代表整车销售容易盈利。〔S20〕
- 普通创业者更值得研究车辆售出后持续产生的消费需求，而不是直接承担整车生产、库存及销售风险。〔S20〕
- 目前尚缺乏新能源汽车小型服务商的真实成交价格、获客成本及净利率数据，因此不能认定任何一个细分方向已经具备稳定盈利能力。〔S20〕

### 三、专车专用汽车用品
产品与客户
- 可研究的产品包括专车专用脚垫、后备箱垫、遮阳帘、收纳配件、充电枪保护套等。〔S20〕
- 主要客户为已经购买新能源汽车的私人车主。〔S20〕
- 可通过电商平台、小区车友群及当地车友俱乐部销售，不必承担整车库存风险。〔S20〕

经营验证
- 建议先确定具体热销车型，再调查对应的汽车用品需求、商品价格及供应商，不宜直接大量囤货。〔S20〕
- 截至2026年11月26日，1688及京东相关商品的真实成交价格、销量、进货成本和利润率均未得到有效核实。〔S20〕
- 现阶段应通过具体商品的成交记录、进货报价和小批量销售验证商业可行性。〔S20〕

### 四、家用充电桩安装及配套服务
服务内容
- 可从安装对接、现场勘查、配套材料供应、充电桩立柱安装及物业协调等需求切入。〔S20〕
- 主要客户是拥有固定车位并需要安装家用充电桩的新能源汽车车主。〔S20〕
- 涉及施工能力及资质要求的工作，应由符合资质要求的人员承担。〔S20〕
- 对资金有限的创业者，报告建议先与有资质的安装商合作获取订单，而非直接投资建设公共充电站。〔S20〕

公开服务报价
截至2026年11月26日，小鹏汽车官网家用充电桩安装服务规则列出的部分增项收费如下。〔S20〕

| 服务项目 | 公开报价 |
| --- | --- |
| 充电桩立柱，含安装 | 300元/个〔S20〕 |
| 硬化路面开挖及修复 | 150元/米〔S20〕 |

- 上述价格为单一汽车品牌公开收费标准，不代表行业平均成交价格，也不代表安装人员最终获得的净收入。〔S20〕
- 实际经营需要分别核算设备费、材料费、人工费、安装费及其他交付成本。〔S20〕
- 家用充电桩安装的实际客单价、订单数量和服务商净利率仍待核实。〔S20〕

### 五、新能源二手车检测与评估
市场基础
- 2025年，全国新能源二手车交易量约160万辆，该数据由新华社援引中国汽车流通协会发布。〔S20〕
- 新能源二手车买家除关注车辆事故、泡水及行驶里程外，还关注电池衰减、电池健康度及维修记录。〔S20〕
- 电池检测、车辆状态检测及评估报告可能形成独立付费服务。〔S20〕

公开参考报价
2026年，电车省心站公开网页提供了以下检测服务参考报价。〔S20〕

| 服务内容 | 参考报价 |
| --- | --- |
| 基础电池检测 | 500—800元〔S20〕 |
| 深度车辆检测 | 1000—1500元〔S20〕 |
| 完整车辆评估报告 | 1500—2500元〔S20〕 |

- 上述报价来源并非官方行业统计，也未提供真实订单凭证，属于低可信度询价参考，不能直接作为真实成交价格。〔S20〕
- 电池检测业务涉及专业技术能力、车辆数据获取权限及检测结果可靠性，不能仅凭公开报价判断进入门槛和盈利能力。〔S20〕
- 新能源二手车的实际成交价格、检测服务购买比例及第三方检测机构真实订单量仍待核实。〔S20〕

### 六、企业和政府车队配套服务
- 潜在客户包括网约车公司、物流企业、汽车租赁公司及拥有新能源公务车辆的政府单位。〔S20〕
- 可延伸的服务包括车辆清洁、用品集中采购、日常维护、充电设备维护及车辆调度。〔S20〕
- 企业和机构客户可能形成持续订单，但账期、资质、投标竞争及履约要求通常比个人零售更加复杂。〔S20〕
- 政府采购记录已经显示新能源执法车辆采购、车辆租赁和充电设备采购等具体需求。〔S20〕
- 普通创业者可以优先调查当地车队的配套业务，而不必直接承担整车采购及大规模车辆租赁项目。〔S20〕
- 相关采购案例与证据限制见[[新能源汽车政府采购与车队需求]]。〔S20〕

### 七、月赚1万元的经营测算方法
报告提出通过公开参考报价、实际变动成本及每月固定成本，倒推实现目标经营利润所需的订单数量。〔S20〕
计算公式：
- 每单边际收益＝每单实际收费－每单实际变动成本。〔S20〕
- 每月所需订单数＝（目标月利润＋每月固定成本）÷每单边际收益，计算结果向上取整。〔S20〕
- 按每位客户购买一次计算，订单数量对应所需客户数量，未计入的其他成本还应额外扣除。〔S20〕
- 例如，基础电池检测收费500元，即使完全不计算成本，每月也需要20单才能达到1万元营业收入；实际获得1万元经营净收益所需订单量还会更高。〔S20〕

可用于初步测算的公开参考收费档位：

| 服务项目 | 每单参考收费 |
| --- | --- |
| 充电桩立柱安装 | 300元〔S20〕 |
| 基础电池检测 | 500元或800元〔S20〕 |
| 深度车辆检测 | 1000元〔S20〕 |
| 车辆评估 | 1500元或2500元〔S20〕 |

- 上述收费只能作为经营测算输入，不能直接作为市场利润预测。〔S20〕
- 每单实际变动成本、每月固定成本、真实订单数量及实际利润率均需要通过经营调查获得。〔S20〕
- 不能将营业额等同于利润，也不能直接套用乘用车或电池上市公司的毛利率测算个人小店收益。〔S20〕

- 2026-11：汽车用品、清洁美容、家充安装配套及二手车检测被列为优先调研方向。〔S20〕
