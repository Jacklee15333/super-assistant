# 人工智能产业发展与商业化趋势
截至2026年11月26日，S10研究报告判断，人工智能产业正在从技术能力竞争进入商业价值验证阶段，预计2027—2029年产业竞争将更加重视完成真实业务的成本、质量和稳定性。〔S10〕

## 要点

### 一、人工智能产业的五个层级

| 产业层级 | 代表企业及产品 | 核心竞争力 | 小团队进入难度 |
| --- | --- | --- | --- |
| 算力基础设施 | NVIDIA、AMD、谷歌TPU、国产AI芯片厂商 | 芯片、能源、数据中心 | 极高〔S10〕 |
| 基础大模型 | OpenAI、Anthropic、Google、DeepSeek、通义千问 | 算力、人才、训练数据 | 极高〔S10〕 |
| AI应用入口 | ChatGPT、Claude、Gemini、豆包 | 用户规模、分发渠道、产品生态 | 高〔S10〕 |
| AI应用及智能体 | 编程助手、企业自动化、行业Agent | 行业经验、业务流程、执行能力 | 中〔S10〕 |
| AI配套服务 | 数据治理、系统集成、成本优化、安全评估 | 专业能力、客户关系、交付质量 | 低至中〔S10〕 |

- 谷歌的科研、自研芯片、搜索、云计算和办公生态能够形成相互支持的竞争体系。〔S10〕
- 微软、OpenAI、Anthropic等企业正在争夺企业软件、编程工具和工作入口。〔S10〕
- 报告判断，随着产业竞争维度增加，单次模型能力排行榜的商业参考价值将相对下降。〔S10〕
- 普通人和小团队更适合进入AI应用及配套服务层，而非与大型企业直接竞争算力基础设施和基础模型。〔S10〕

### 二、产业规模及商业化关键数据
以下数据来自S10报告所引用的研究机构、媒体及企业官方资料。

| 指标 | 数据 | 原始来源或统计口径 |
| --- | --- | --- |
| 中国生成式AI用户规模 | 超过7亿人，普及率超过50% | 2026年上半年，CNNIC、新华社〔S10〕 |
| 2026年企业生成式AI部署支出 | 1,768亿美元，约为上年的5.4倍 | Menlo Ventures市场规模估算〔S10〕 |
| 企业级AI规模化应用比例 | 44%，上年为38% | 麦肯锡2026年受访者调查〔S10〕 |
| AI对企业息税前利润产生贡献的比例 | 37% | 麦肯锡2026年受访者调查〔S10〕 |
| 开源模型使用量份额 | 从11%上升至19% | Menlo Ventures研究报告〔S10〕 |
| ChatGPT高用量Pro套餐 | 500美元/月 | OpenAI官方帮助中心〔S10〕 |

- Menlo Ventures的数据属于市场研究估算，麦肯锡的数据属于问卷调查结果，均不能直接视为经过审计的全行业经营数据。〔S10〕
- 报告认为，企业AI使用率与实际盈利改善之间的差距，反映出实施、改造、培训、维护和运营服务的潜在商业需求。〔S10〕

### 三、基础模型逐渐商品化
- 随着模型能力提高，普通任务不一定需要最先进的模型，企业可以根据任务复杂程度选择不同性能和价格的模型。〔S10〕
- 开源模型使用量份额从11%上升至19%，被报告视为低成本、可替换模型获得更多使用机会的信号。〔S10〕
- 报告预测，2027年多模型组合将成为常见方案，2028—2029年标准化AI功能将面临进一步的价格竞争，趋势确定性评估为高。〔S10〕
- 单纯为大模型增加一个用户界面难以形成长期竞争优势，客户资源、行业知识、历史数据及业务流程将成为重要竞争要素。〔S10〕

### 四、AI单位价格与实际使用成本
- Token是模型处理信息的计量单位，单个Token的价格与企业完成任务所需的实际支出不是同一个概念。〔S10〕
- 智能体反复规划、调用工具、多轮推理、检查结果和重复执行，会增加Token消耗量。〔S10〕
- AI产业可能出现单位推理价格持续下降、使用量快速增加、企业总账单反而上升的现象。〔S10〕
- 麦肯锡2026年调查显示，约20%的受访者表示AI运行成本已经限制其所在组织对AI的使用。〔S10〕
- 企业应重点关注完成一项合格任务的总成本、任务成功率及人工干预成本，而非仅比较模型API报价。〔S10〕
- 报告预测，AI成本管理需求将在2027年开始明显增长，2028—2029年可能逐渐形成较成熟的服务市场，趋势确定性评估为高。〔S10〕

### 五、资本市场估值与实际盈利能力
S10以Anthropic上市为观察前沿大模型企业商业模式的重要案例，并称已通过公司公告、SEC披露及媒体报道核实上市事项。〔S10〕

| 指标 | 报告所载数据 |
| --- | --- |
| 上市日期 | 2026年11月19日〔S10〕 |
| 上市地点 | 纳斯达克〔S10〕 |
| 股票代码 | ANT〔S10〕 |
| 首次公开发行规模 | 813亿美元，不含后续超额配售〔S10〕 |
| 最终公开发行总额 | 935亿美元，含超额配售〔S10〕 |
| 计入同步私募融资后的发行交易总额 | 约1,195亿美元，扣除发行费用前，含原股东出售股份所得〔S10〕 |

- 初始公开发行规模、含超额配售的最终公开发行总额、计入同步私募后的交易总额及公司实际获得的净融资额属于不同统计口径，不应混用。〔S10〕
- 笔记中涉及的万亿美元估值、净融资额及基础设施承诺金额仍需进一步核对。〔S10〕
- 即使融资规模和市场估值很高，也不能直接证明AI企业已经拥有可持续盈利的商业模式。〔S10〕
- 判断前沿模型企业商业模式是否成立，需要进一步观察营收、毛利率、亏损、现金流及算力支出。〔S10〕

### 六、AI成为新的商业流量入口
- AI可能逐渐承担商品信息搜集、价格比较、产品推荐及协助交易等功能，改变传统搜索引擎和电商平台的获客方式。〔S10〕
- S10记载，OpenAI于2026年11月推出Business Agent商业代理功能，并将符合条件的企业范围扩展至美国以外的电商及在线服务企业。〔S10〕
- S10记载，OpenAI于2026年11月13日公布ChatGPT Wallet。〔S10〕
- GEO即生成式引擎优化，主要关注如何让AI准确理解、引用和推荐企业的商品及服务，与传统SEO搜索引擎优化形成新的商业服务方向。〔S10〕
- 报告预测，2027年属于AI商业流量入口的探索期，2028—2029年可能成为部分商品和服务的重要获客渠道，趋势确定性评估为中。〔S10〕
- 现阶段尚不能保证AI推荐能够为商家带来稳定订单，曝光、推荐与实际成交之间仍需要商业验证。〔S10〕

### 七、中国AI应用及服务出海
- 2026年11月26日，商务部等8部门印发《服务贸易发展“十五五”规划》，提出有序推动云计算、大模型等AI相关服务出海，培育人工智能服务贸易新业态。〔S10〕
- 中国团队可以尝试利用国产模型、软件开发能力及供应链优势，为海外企业提供AI自动化、多语言客服、商品营销及垂直行业软件服务。〔S10〕
- 报告预计相关政策将在2027—2030年持续推进，2027—2028年适合小团队验证海外客户需求，商业趋势确定性评估为中。〔S10〕
- 政策支持不等于企业能够盈利，实际商业结果仍取决于产品质量、获客能力、数据跨境及当地合规要求。〔S10〕

### 八、AI向物理世界延伸
- 多模态模型、世界模型及机器人技术的发展，可能推动AI从处理文字、图片和代码扩展至理解真实环境、操作设备及辅助工业生产。〔S10〕
- 斯坦福大学《2026 AI Index Report》将机器人及人工智能技术性能列为重点研究方向。〔S10〕
- 报告预测，2027—2028年工业质检、仓储、巡检等结构化场景更容易取得商业化进展。〔S10〕
- 2029年及以后，通用机器人可能进入更多商业场景，但具体普及时间仍待核实。〔S10〕
- AI向物理世界延伸的趋势确定性评估为中，通用家庭机器人在三年内大规模普及的确定性评估为低。〔S10〕
- 普通创业者更适合关注机器视觉、行业数据采集、设备维护、机器人部署和培训等配套服务。〔S10〕

## 不同说法

### Token价格与AI使用成本
- 原收藏笔记中的判断倾向于认为Token会越来越贵。〔S10〕
- S10研究报告对此作出修正，认为更可能出现Token单价下降、使用量增加、总账单上升的情况。〔S10〕
- 判断AI使用成本时，需要区分单位价格、调用数量、任务成功率和实际交付成本。〔S10〕

### Anthropic上市与融资规模
- S10前文将Anthropic上市、813亿美元IPO募资及万亿美元估值等笔记信息列为需要核实的事项。〔S10〕
- S10后续补充称，上市事实及发行规模已经通过官方公告等资料核实，但万亿美元估值、实际净融资额和基础设施承诺金额仍需进一步核对。〔S10〕
- 813亿美元、935亿美元及约1,195亿美元分别对应不同发行统计口径，不属于相互矛盾的融资数据。〔S10〕
