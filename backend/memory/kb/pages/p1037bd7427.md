# 优必选
优必选是中国人形机器人企业，2025年全尺寸具身智能人形机器人及解决方案收入约8.21亿元，相关业务毛利率54.6%，但公司整体净亏损约7.90亿元。〔S19〕

## 要点

### 一、机器人业务销售情况
- 优必选2025年度报告披露，全尺寸具身智能人形机器人及解决方案收入约8.21亿元。〔S19〕
- 2025年全尺寸具身智能人形机器人销量为1079台。〔S19〕
- 8.21亿元包含相关解决方案收入，不是单纯的整机销售金额，因此不能直接用该收入除以1079台，作为纯整机实际销售均价。〔S19〕
- 上述销售和收入数据属于已经披露的企业经营结果，可以用于判断机构客户对机器人及其配套解决方案存在真实购买需求。〔S19〕

### 二、产品毛利率与公司亏损
- 2025年优必选全尺寸人形机器人业务毛利率为54.6%。〔S19〕
- 2025年公司整体净亏损约7.90亿元。〔S19〕
- 根据年度报告净亏损与营业收入计算，公司整体净利率约为-39.5%。〔S19〕
- 业务毛利率与公司整体净利率覆盖的业务和成本范围不同，不能直接把54.6%当作公司最终盈利水平。〔S19〕
- 优必选的经营数据表明，人形机器人相关业务即使具有较高毛利率，公司仍可能因研发、工程、销售、售后和运营等成本而出现整体亏损。〔S19〕

### 三、市场验证意义
- 优必选2025年已经形成机器人整机销量及相关解决方案收入，说明具身智能商业化不只体现为产品发布或市场关注度。〔S19〕
- 公司整体亏损表明，整机及解决方案的销售收入不能直接代表企业盈利能力。〔S19〕
- 评估人形机器人企业时，需要分别考察实际交付数量、整机收入、解决方案收入、毛利率、净利润及经营成本。〔S19〕
- 优必选与[[宇树科技]]的经营结果存在较大差异，不能用单一头部企业数据推算全行业利润水平。〔S19〕

## 时间线
- 2025：优必选全尺寸具身智能人形机器人销量达到1079台。〔S19〕
- 2025：全尺寸具身智能人形机器人及解决方案实现收入约8.21亿元，相关业务毛利率54.6%。〔S19〕
- 2025：公司整体净亏损约7.90亿元，整体净利率约-39.5%。〔S19〕
