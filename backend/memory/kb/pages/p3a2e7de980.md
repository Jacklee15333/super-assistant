# 中华文明探源工程
通过考古实证与多学科研究，探索中华文明起源、形成及早期发展过程的重大科研项目。〔S13〕

## 要点

### 项目规模与研究进展
- 项目于2001年启动预研究，2025年通过绩效评价验收，历经25年。〔S13〕
- 第五阶段（2020—2024年）围绕良渚、陶寺、石峁、二里头等29处遗址开展田野考古和多学科合作研究。〔S13〕
- 项目涉及的多个遗址先后获评“全国考古十大发现”及“中国考古新发现”，部分项目入选“考古中国”重大成果。〔S13〕

### 学术起源与历史背景
- 探究中华文明的源头，是中国近代考古学自诞生以来承担的重要历史使命。〔S22〕
- 1926年，李济主持山西夏县西阴村考古发掘，据资料记载，这是中国学者首次自主开展的田野考古实践，其重要目标是寻找夏文化的实物证据。〔S22〕
- 王国维主张遵循“从已知到未知”的研究路径，先夯实商周文明的考古基础，再向更早的夏文化追溯。〔S22〕
- 1928年，中央研究院历史语言研究所成立，并将殷墟科学发掘作为成立后的首要任务。〔S22〕
- [[殷墟]]的考古研究将历史学、语言学、考古学及动物研究等多学科力量结合起来，并通过甲骨文、青铜器、宫殿遗址和王陵等实物证据验证历史文献。〔S22〕
- 20世纪50年代以来，郑州二里岗遗址、郑州小双桥遗址和安阳洹北商城等考古发现，逐渐建立起从早商、中商到晚商的文化发展序列。〔S22〕
- 1959年，徐旭生依据历史文献寻找夏文化遗存，在河南偃师发现[[二里头遗址]]，推动夏文化考古研究进入新的阶段。〔S22〕
- 二里头遗址通过碳十四测年与地层学分析，被确定在新石器时代龙山文化与二里岗早商文化之间，为研究商代之前的文明发展提供了重要实物依据。〔S22〕

### 研究方法与技术突破
- 采用贝叶斯统计和核密度估计法分析测年结果，并结合考古遗存背景，提高关键历史节点的年代测定精度。〔S13〕
- 对牛河梁第一地点（女神庙）、石峁及碧村等北方石城遗迹、三星堆祭祀坑的年代测定取得新进展，突破既往年代预估。〔S13〕
- 对中原腹心地区新石器时代重大环境事件及二里头遗址开展更加精细的年代研究。〔S13〕
- 综合运用聚落布局、墓葬等级、水利设施、农业经济、手工业、军事权力和远距离物资交流等考古证据，分析史前社会复杂化及早期国家形成过程。〔S13〕
- 中国文明探源研究具有将考古实物与历史文献相互验证的学术传统，殷墟发掘及其后续商文化研究是这一方法的重要实践。〔S22〕
- 碳十四测年和地层学分析可以相互补充，帮助研究人员建立不同考古学文化之间的年代先后关系，二里头遗址研究是相关方法的应用案例。〔S22〕

### 核心研究成果
- 将中华文明起源与早期发展的关键阶段划分为古国时代和王朝时代，其中古国时代进一步划分为三个阶段。〔S13〕
- 研究认为，不同地区的文明具有各自的发展路径，早期和晚期形成的古国不存在简单的高低之分或直接继承关系。〔S13〕
- 不同区域之间存在物质文化、农业与手工业技术、动植物物种、贵重资源及高等级手工业产品的交流与传承。〔S13〕
- 项目执行专家组认为，良渚文化及长江中游部分文化区域率先发展出早期国家政体。〔S13〕

## 时间线
- 1926：李济主持山西夏县西阴村考古发掘，探索夏文化实物证据。〔S22〕
- 1928：中央研究院历史语言研究所成立，开展殷墟科学发掘。〔S22〕
- 1949年以后：殷墟考古工作持续推进，研究范围逐渐向商文明之前的历史及其文化源头扩展。〔S22〕
- 20世纪50年代：郑州二里岗遗址的发现推动早商文明研究。〔S22〕
- 1959：徐旭生发现偃师二里头遗址。〔S22〕
- 1996：西阴村遗址被国务院公布为全国重点文物保护单位。〔S22〕
- 2001：启动中华文明探源研究预研究。〔S13〕
- 2020—2024：开展第五阶段研究，涉及29处遗址。〔S13〕
- 2025：项目通过绩效评价验收。〔S13〕
- 2025-09-19：良渚博物院发布《亲历者口述中华文明探源工程（上）》，回顾中国近代考古学及中华文明探源研究的历史脉络。〔S22〕
- 2026-06-25：良渚博物院网站发布《中华文明探源工程的新成果与新认识》。〔S13〕
- 2026-06-26：中国社会科学院考古研究所网站发布项目执行专家组撰写的《中华文明探源工程的新成果与新认识》。〔S13〕
