# 豆包
字节跳动旗下的多模态人工智能助手，正在从对话问答工具向专业办公和智能体协作平台发展。〔S12〕

## 要点

### 产品定位与基础功能
- 豆包以字节跳动自研的[[豆包大模型]]为技术底座，支持文字、图片、语音等多模态交互。〔S12〕
- 产品覆盖网页端、Windows、macOS、iOS及安卓平台，支持跨设备同步对话记录。〔S12〕
- 资料所列官方网页版入口为 www.doubao.com。〔S12〕
- 支持上传PDF、Word、Excel、PPT等文件，进行内容摘要、文档解读、数据分析和要点提取。〔S12〕
- 支持智能写作、翻译、语音对话、AI播客、图像生成、图片编辑、视频生成及编程辅助。〔S12〕

### AI搜索与深度研究
- 据第三方介绍页面，豆包的AI搜索结合大模型推理、互联网检索和多来源信息整理，并提供来源链接供用户核验。〔S12〕
- 深入研究功能能够自动执行资料检索、信息整理、分析和报告生成，支持以可视化网页或文档形式呈现研究结果。〔S12〕
- 来源1宣称深入研究功能可在5至30分钟内生成带有引用来源的研究报告，但实际研究质量和来源准确性尚未得到独立验证。〔S12〕
- 本次S12主动研究原定主题为美伊冲突与霍尔木兹海峡，但抓取结果大量混入豆包产品介绍，说明自动检索结果仍需要进行主题相关性筛选。〔S12〕

### 智能体与办公自动化
- 据来源2介绍，豆包依托扣子（Coze）平台构建智能体生态，支持通过可视化界面创建包含插件和工作流的智能体。〔S12〕
- 2026年豆包工作推出技能、连接器、工作伙伴三类能力，支持多个智能体并行处理复杂任务。〔S12〕
- 连接器据称能够连接飞书、钉钉、邮箱等第三方服务，读取和写入业务数据。〔S12〕
- 豆包专业版主打办公任务Agent，据称支持操作本地电脑和浏览器、定时任务、多步骤自动执行以及Office办公能力。〔S12〕
- 编程功能支持代码生成、调试、重构及可视化开发，并可引入GitHub代码仓库作为项目上下文。〔S12〕
- 会议记录功能据称支持长达60分钟的会议录制，能够区分发言人、提取待办事项、责任人和截止时间，并导出Word或Excel文档。〔S12〕

### 商业模式
- 据来源2介绍，豆包面向普通用户的搜索问答、写作、图像生成及语音对话等核心功能采取免费策略。〔S12〕
- 据来源1报道，2026年6月24日豆包专业版开放订阅，标准套餐连续包月68元起，另设200元/月和500元/月档位。〔S12〕
- 专业版主要面向软件开发、数据分析、专业设计及深度办公等场景。〔S12〕
- 来源2称专业版也将提供一定的免费使用额度，但未提供具体额度。〔S12〕

### 实际应用案例：手机供应链事实核查
- 在[[华为手机射频元器件直播争议]]中，主播现场使用豆包查询华为某款手机是否使用美国博通（Broadcom）的5G射频滤波元器件。〔S43〕
- 文字稿将待查询的手机型号记录为Mate 90 Pro Max典藏版，但这一名称可能存在语音识别错误，尚未核实。〔S43〕
- 直播中朗读的豆包回答称，相关手机未使用美国博通的射频滤波元器件，并将其归因于2020年美国出口管制、国产射频供应链发展及华为自主设计的射频架构。〔S43〕
- 豆包回答中还涉及Broadcom（博通）、Skyworks（思佳讯）、Qorvo（威讯联合半导体）及国产厂商配套，并使用了全去美化的表述。〔S43〕
- 连麦者听完豆包回答后，部分接受主播的反驳，说明AI回答在该次公共讨论中成为影响参与者判断的工具。〔S43〕
- 现有视频笔记未提供足以独立验证该回答的专业拆机报告、原始供应商资料及芯片型号，因此不能据此确认豆包的技术结论正确。〔S43〕
- 资料没有确认此次查询所使用的豆包模型版本，也没有明确记录是否启用了联网检索及深度研究功能。〔S43〕

### 事实查询的可靠性与使用边界
- 大语言模型可能生成看似专业、完整和自信但实际存在错误的信息，也可能混淆产品型号、政策时间、元器件类别和供应商关系。〔S43〕
- 在事实核查场景中，应当要求豆包提供原始资料链接、发布时间及支持结论的具体证据，而不是只提供肯定或否定判断。〔S43〕
- 查询之前应当明确可验证命题，避免用范围过大的问题替代具体事实核查。〔S43〕
- 针对手机供应链问题，应当优先核实产品型号及版本，区分不同射频元器件，寻找实际拆机报告和供应商资料。〔S43〕
- 不应仅凭美国出口管制政策推断某款手机的实际元器件来源。〔S43〕
- 应当要求豆包同时寻找支持和反驳待验证主张的证据，区分已证实事实、合理推测及无法确认的信息。〔S43〕
- 豆包等AI工具可以辅助查证，但未经原始资料核实的回答不能作为最终事实证据，对人类陈述与AI陈述应当使用同样严格的证据标准。〔S43〕

### 资料可信度
- S12中有关豆包的详细信息主要来自奇想AI站和AI工具箱两个第三方导航网站，并非豆包官方发布页面。〔S12〕
- 产品价格、性能指标、免费政策、功能上线及下线安排均应视为第三方转述，尚需通过官方公告核实。〔S12〕
- S43中的豆包使用案例来自直播切片及其视频文字稿，属于实际使用过程的间接记录，而非豆包官方技术说明或经过控制的产品性能测试。〔S43〕
- 由于S43未完成独立事实核验，不能依据此次案例直接评价豆包整体事实准确率，也不能认定其具体回答已经被证实为正确或错误。〔S43〕

## 不同说法
- 专业版上线状态：来源1称豆包专业版已于2026年6月24日正式开放订阅。〔S12〕来源2仍使用计划推出或即将推出的表述，两者可能存在信息更新时间差异，需核实官方公告。〔S12〕

- 事实核查中的证明作用：S43视频中的主播将豆包回答作为反驳连麦者的依据，连麦者部分接受其回答；资料整理者则认为，没有实际拆机报告及原始供应链证据支持的AI回答不能作为最终事实证明。〔S43〕
