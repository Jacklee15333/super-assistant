# 上海朱晓东杀妻藏尸案
2016年发生于上海市虹口区的一起有预谋的故意杀人案件，也是研究亲密关系控制、经济侵占、社会支持网络失效和数字身份冒用的重要案例。〔S49〕

## 要点

### 一、主要人物及家庭背景
- 杨俪萍，1987年出生于上海，家中独生女，毕业于上海师范大学中文系，曾担任小学语文教师兼班主任，其公开课《尊严》成为学校的教学范本。〔S49〕
- 朱晓东，与杨俪萍同龄，10岁时父母离异，曾与母亲居住在30多平方米的老房子里，接受过职业教育，后来担任百货商场陈列员。〔S49〕
- 据视频介绍，朱晓东月收入约4000—5000元，约为杨俪萍收入的一半。〔S49〕
- 杨敢连是杨俪萍的父亲，案发后持续为女儿寻求司法公正。〔S49〕
- 杨俪萍原本具有稳定职业、独立收入和较好的家庭支持，说明学历、职业能力及家庭条件并不能自动保证一个人免受亲密关系中的欺骗与控制。〔S49〕

### 二、婚恋关系中的欺骗与控制
- 两人于2012年相识，朱晓东曾失联约一年，重新出现后声称自己患过脑部肿瘤，并曾独自前往西藏生活，该经历未经证实。〔S49〕
- 2015年2月，朱晓东大量删除杨俪萍社交账号中的男性好友，并经常跟随她参加同学聚会及探望父母，限制其独立社交空间。〔S49〕
- 杨俪萍曾多次替朱晓东偿还信用卡债务，并攒钱购买价值5000多元的手表送给他。〔S49〕
- 婚前家庭聚会上，朱晓东曾表示别人不能打骂杨俪萍，只有自己可以骂她，表现出具有支配意味的伴侣观念。〔S49〕
- 女方承担约10万元婚房装修费用，双方婚礼仅摆6桌酒席。〔S49〕
- 婚后朱晓东被发现出轨，曾写下保证书承诺改变，但保证书包含共同死亡意味的威胁性内容，此后仍继续与其他女性交往。〔S49〕
- 2016年6月30日，杨俪萍通过朋友圈透露，朱晓东以观察宠物为由在家中安装摄像头，同时能够监视她的活动。〔S49〕

### 三、虚假职业承诺与独立性受损
- 2016年8月，两人曾准备办理离婚，但最终没有离婚，具体原因存在不同说法。〔S49〕
- 朱晓东随后虚构公司将提拔自己、派往香港培训并将月薪提高至2万元的计划，促使杨俪萍辞去稳定的教师工作。〔S49〕
- 杨俪萍于2016年9月14日提交辞职申请，10月14日正式离职，其校长曾承诺她未来遇到困难时可以返回学校工作。〔S49〕
- 杨俪萍未向父母告知准备离婚、辞职等重大事项，客观上减少了亲友提供帮助及独立核实信息的机会。〔S49〕
- 2016年9月19日，杨俪萍在朋友圈表示丈夫近期对自己特别好，反而让她感到恐慌。〔S49〕

### 四、犯罪事实与财产侵占
- 2016年10月17日，杨俪萍在上海遇害，朱晓东随后隐瞒其死亡事实，法医认定杨俪萍死因为机械性窒息。〔S49〕
- 朱晓东侵占杨俪萍支付宝账户内的4.5万元，并透支其信用卡10余万元，法院认定相关资金合计近15万元。〔S49〕
- 案发后，朱晓东使用相关资金旅游、购物及进行个人消费，其29岁生日时曾在上海外滩一家餐厅消费约5000元。〔S49〕
- 朱晓东长期冒用妻子的数字身份与亲友保持联系，导致家人在三个多月内未能得知杨俪萍已经遇害。〔S49〕
- 亲友曾发现文字称呼、语言习惯、情感反应及家庭活动参与情况出现异常，但当时掌握的信息不足以确认真实情况。〔S49〕

### 五、司法认定与量刑
- 上海市第二中级人民法院一审以故意杀人罪判处朱晓东死刑，剥夺政治权利终身。〔S49〕
- 上海市高级人民法院二审认定朱晓东系有预谋地杀人，驳回上诉，维持原判。〔S49〕
- 朱晓东具有主动投案的情节，但法院综合犯罪性质、犯罪情节及社会危害程度，最终仍判处死刑。〔S49〕
- 本案说明自首属于可以考虑的从宽处罚情节，并不意味着必然获得从轻处罚或免除死刑。〔S49〕

### 六、案件的社会警示
- 反复欺骗、社交控制、经济索取、隐私侵犯、死亡威胁和职业独立性受损等风险同时存在时，应当重视其累积影响。〔S49〕
- 单一异常行为不足以预测一个人未来是否会实施恶性犯罪，不能将收入、学历、家庭背景或生活爱好直接视为犯罪倾向的证据。〔S49〕
- 受害者的善良、信任及原谅不能成为减轻犯罪人责任的理由，也不应成为指责受害者的依据。〔S49〕
- 杨俪萍生前曾在《尊严》公开课上希望学生成为自立、自强、有尊严的人，视频以此强调独立人格与个人尊严的重要性。〔S49〕

- [[数字身份冒用与亲友安全核实]]：本案说明社交账号正常活动不能证明账号本人平安。〔S49〕

- [[择偶条件匹配与婚前风险评估]]：涉及婚前危险信号、个人经历核实及长期行为观察。〔S49〕

## 不同说法
- 是否存在预谋：朱晓东主张案件源于夫妻临时争吵；上海高院二审认定其系有预谋地杀人。〔S49〕
- 杨俪萍辞职原因：朱晓东声称妻子厌恶学校工作；视频笔记依据相关案件材料指出，其辞职与朱晓东虚构的赴港工作计划有关。〔S49〕
- 未能办理离婚的原因：朱晓东声称杨俪萍曾以自杀相威胁，但这属于其单方面陈述，资料未提供充分的独立证据。〔S49〕
- 时间统计口径：视频采用107天描述案发至自首的时间跨度，部分媒体采用105天描述藏尸时间，法院公开通报使用三个多月的表述，引用时宜同时注明2016年10月17日至2017年2月1日的日期区间。〔S49〕
- 具体犯罪动机：视频作者推测朱晓东既希望摆脱婚姻约束，又不愿放弃妻子提供的经济利益，但这一解释属于作者推断，不应等同于司法认定。〔S49〕
