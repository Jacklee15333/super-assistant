# 豆包大模型
字节跳动自研的人工智能基础模型体系，为豆包助手、智能体应用及模型服务提供技术支持。〔S12〕

## 要点

### 模型能力
- 据第三方介绍页面，豆包1.6支持256K上下文窗口，并能够结合模型推理与实时搜索处理复杂问题。〔S12〕
- Seed-2.0重点优化长链推理和智能体编排能力，支持信息检索、内容摘要、深度分析、工具调用及报告生成等连续任务。〔S12〕
- Doubao-Seed-Code面向代码生成、调试和重构等软件开发场景。〔S12〕
- 据来源1报道，豆包2.1 Pro在2026年6月23日火山引擎FORCE大会亮相。〔S12〕
- 来源1称豆包2.1 Pro在测试中能够连续运行18小时完成芯片设计RTL任务，但未提供完整测试条件和独立评估结果。〔S12〕
- 来源1称其Agent能力在3D虚拟城市场景中支持500多个智能体同时协作。〔S12〕

### 模型价格与市场规模
- 据来源1报道，豆包2.1 Pro的输入价格为6元人民币/百万Token。〔S12〕
- 据来源1转述，截至2026年6月，豆包大模型日均Token调用量超过180万亿，过去一年增长超过10倍。〔S12〕
- 来源1援引IDC数据称，火山引擎在中国公有云MaaS（模型即服务）市场的份额达到49.5%，排名第一，但未附IDC原始报告。〔S12〕

### 相关多模态模型
- Seedance 2.0面向视频生成，据称支持复杂交互和运动场景生成。〔S12〕
- Seedream 5.0面向图像生成，引入实时检索增强能力，用于获取资讯辅助图片创作。〔S12〕
- SeedEdit面向图像编辑，支持通过自然语言指令进行局部修改、背景替换及颜色调整。〔S12〕
- 据来源1报道，Seedance 2.5于2026年6月的火山引擎FORCE大会预告，计划支持最长30秒的单段视频生成及50个全模态参考素材。〔S12〕
- 同场预览的AI版权商业化平台据称已接入周星驰经典电影授权范本，当日创作量超过10万次。〔S12〕

### 资料可信度
- 上述模型能力、技术参数、调用规模、市场份额和价格均来自S12收录的第三方AI导航网站，尚未通过官方技术报告、原始统计报告或独立测试核实。〔S12〕
- S12未提供完整的模型价格表、测试基准、推理成本、收入数据或盈利情况，不能仅凭调用量判断实际商业收益。〔S12〕
