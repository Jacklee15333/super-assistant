# AI Skill（技能）与可复用工作流
AI Skill是将经过验证的提示词、专业知识、工作规范、脚本和参考资料封装成可重复调用的能力，使AI能够按照稳定的方法完成同类任务，并通过按需加载提高复杂工作流程的可维护性。〔S54〕

## 要点

### 一、Skill的本质：把一次性提示词变成可复用的工作能力
- Prompt（提示词）是用户向AI提出的具体任务指令，例如制作PPT时指定背景颜色、字体颜色、页面结构和排版方式。〔S54〕
- 当用户反复执行同一类任务时，可以将经过验证的提示词、操作规范和执行流程封装成Skill，避免每次重新输入相同要求。〔S54〕
- Skill的核心价值不是创造一种完全不同于提示词的新能力，而是把一次性指令沉淀为可以反复调用的标准化工作方法。〔S54〕
- Skill可以理解为AI的SOP（Standard Operating Procedure，标准作业程序），使AI能够按照预先设定的步骤和质量要求完成工作。〔S54〕
- Skill能够将个人经验、专业知识和工作习惯转化为可以长期积累和持续改进的数字化工作资产。〔S54〕

### 二、按需加载与渐进式披露
- Skill的重要特点之一是On-demand Loading（按需加载），即根据当前任务需要读取相应的指令、文件和辅助资源，而不是一次性加载全部内容。〔S54〕
- 一个完整的Skill可能包含大量提示词、Python脚本、HTML文档、参考资料、模板和辅助文件。〔S54〕
- 如果将所有资源直接放入普通提示词，可能增加上下文长度和Token消耗，也可能让无关信息干扰当前任务。〔S54〕
- 采用按需加载方式时，可以先读取基础工作说明，再根据任务复杂程度读取具体规范、参考资料或者执行脚本。〔S54〕
- Progressive Disclosure（渐进式披露）是指先提供完成当前任务所需的基础信息，在任务深入时再加载更具体的资源。〔S54〕
- 按需加载有助于节省上下文空间、降低不必要的Token消耗并提高资源管理效率，但实际效果取决于Skill设计和AI执行能力。〔S54〕

### 三、Skill可以包含多种资源，不只是提示词
一个成熟的Skill可以围绕特定工作任务组织多种资源。〔S54〕

| 资源类型 | 主要作用 |
| --- | --- |
| SKILL.md | 保存核心任务说明、执行流程和调用规则〔S54〕 |
| references | 保存专业知识、配色规范、字体要求和操作说明〔S54〕 |
| scripts | 保存Python等程序脚本，辅助执行具体任务〔S54〕 |
| assets | 保存PPT模板、图片和其他素材〔S54〕 |
| examples | 保存优秀案例和参考样本〔S54〕 |
| 检查清单 | 保存输出标准、常见错误和质量检查要求〔S54〕 |

- 上述目录结构是根据视频原理整理的示例，并非视频展示的实际文件目录。〔S54〕
- 通过将工作要求、参考资料和执行工具分离，可以在不重写整套Skill的情况下，单独更新某项规范或辅助资源。〔S54〕

### 四、适合建立Skill的工作场景
- 视频笔记：保存笔记结构、分类标签、语音识别纠错规则和质量检查标准。〔S54〕
- PPT制作：保存品牌配色、字体规范、排版规则、图表脚本和演示文稿模板。〔S54〕
- 商业研究：保存研究框架、数据核查方法、分析维度和报告输出格式。〔S54〕
- 文章写作：保存文章结构、语言风格、引用规范和审核标准。〔S54〕
- 数据分析：保存数据清洗流程、分析方法、图表规范和结果解释要求。〔S54〕
- 会议纪要：保存会议内容分类、决策提取、行动事项整理和责任人记录规则。〔S54〕
- 邮件处理：保存邮件分类、回复语气、重点提取和跟进规则。〔S54〕

### 五、从提示词思维转向工作流思维
普通AI使用者通常关注如何向AI提出一个问题，而工作流思维关注如何让AI稳定、持续地完成某一类工作。〔S54〕

| 遇到的问题 | 优先解决方式 |
| --- | --- |
| AI不理解工作要求 | 优化Prompt〔S54〕 |
| AI每次都需要重新解释工作流程 | 建立Skill〔S54〕 |
| AI输出风格和质量不稳定 | 完善Skill及质量标准〔S54〕 |
| AI缺少最新实际数据 | 接入连接器或数据工具〔S54〕 |
| AI无法读取外部系统 | 检查连接器和访问权限〔S54〕 |
| AI无法执行外部操作 | 检查工具能力和授权〔S54〕 |
| AI无法完成复杂多步骤任务 | 组合Skill、连接器和工作流〔S54〕 |
| 多种相关能力分散，使用不方便 | 考虑使用或构建插件〔S54〕 |

### 六、旅游规划工作流案例
视频以北京自驾旅游规划说明如何把Skill和外部工具组合起来。〔S54〕
一个可复用的旅游规划工作流可以分为以下步骤：
1. 收集用户需求，包括出行日期、人数、预算、交通方式和旅行偏好。〔S54〕
2. 加载旅游规划Skill，明确规划步骤、路线原则和输出格式。〔S54〕
3. 通过地图连接器获取路线、距离和景点信息，并通过其他相应服务获取天气、住宿及餐饮信息。〔S54〕
4. 由AI整合信息，比较路线、安排时间、评估预算并检查行程冲突。〔S54〕
5. 输出完整旅游方案，包括每日行程、路线、住宿、餐饮、预算和注意事项。〔S54〕

- 这套工作流建立后，可以通过替换目的地、日期和预算等输入参数，重复完成不同城市的旅游规划。〔S54〕
- 实际天气、酒店库存、餐厅信息及预订操作能力取决于所接入的服务和对应授权。〔S54〕

### 七、建立个人Skill库
- 对于经常使用AI的人，可以将已经验证有效的工作方法逐步沉淀为个人Skill库。〔S54〕
- 每次发现更有效的提示词、更合理的执行步骤或者更好的输出结构，都可以更新对应Skill。〔S54〕
- Skill库可以按照任务类型组织，例如视频笔记、文章写作、PPT制作、行业研究、会议纪要、邮件处理、代码开发和数据分析。〔S54〕
- Skill的长期价值在于保存专业知识、工作流程和判断标准，而不是简单收藏某条提示词。〔S54〕
- 模型和工具可能不断升级，但已经沉淀的业务经验和工作方法经过必要调整后仍然具有复用价值。〔S54〕

### 八、Skill与AI模型的关系
可以用员工培训的方式理解两者的区别。〔S54〕
- AI Model相当于大脑，负责理解、推理、分析和生成内容。〔S54〕
- Skill相当于专业操作手册，告诉AI某项工作应该遵循什么流程、方法和标准。〔S54〕
- AI模型提供通用能力，Skill则将通用能力组织成面向具体任务的专业工作方法。〔S54〕

## 关联
- [[AI智能体与企业应用]]：Skill是AI智能体执行连续业务任务时可以使用的工作规范和可复用能力。〔S54〕
- [[AI连接器与外部工具集成]]：Skill负责工作方法，连接器负责获取外部数据和调用第三方应用，两者可以组合成完整工作流。〔S54〕
- [[AI插件与专项任务能力组合]]：插件可以将多个Skill和连接器组织起来，为特定领域提供综合能力。〔S54〕

## 不同说法
- 视频为了方便普通用户理解，将Skill概括为提示词的封装。〔S54〕
- 视频同时指出，成熟Skill还可以包含Python脚本、HTML文档、参考资料、模板和其他辅助文件，因此不宜将Skill严格理解为只有提示词文本。〔S54〕
- 按需加载有助于控制上下文和资源使用，但并不意味着任何Skill都必然提高模型性能，实际效果还取决于设计质量和执行能力。〔S54〕
