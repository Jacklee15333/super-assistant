# 人民币跨境支付系统CIPS
CIPS是支持人民币跨境支付与清算的金融基础设施，其业务规模、参与机构、支付效率及国际覆盖范围是观察人民币国际化的重要指标。〔S33〕

## 要点

### 系统定位与战略价值
- CIPS通过支持跨境人民币支付与清算，为国际贸易和金融交易提供人民币资金结算渠道。〔S33〕
- S33来源2认为，CIPS的发展有助于减少部分跨境交易对传统美元支付渠道的依赖，并推动人民币在国际贸易中的使用。〔S33〕
- CIPS与[[人民币石油结算]]、大宗商品贸易、本币贸易结算及数字人民币跨境应用存在潜在协同关系。〔S33〕
- S33来源2将CIPS与SWIFT之间的关系描述为国际支付体系竞争，但其论述存在将金融报文传输、资金清算和最终支付结算混合比较的问题。〔S33〕
- CIPS的业务增长可以作为研究人民币跨境使用情况的参考，但不能单独证明人民币已经获得国际储备货币或大宗商品定价主导权。〔S33〕

### 业务规模与增长速度
以下数字主要来自2025年8月2日搜狐号自媒体文章，S33未附CIPS官方统计报告或原始业务数据，相关数字应作为待核实线索。〔S33〕
- S33来源2称，2024年CIPS处理的人民币跨境交易金额达到175.49万亿元人民币，约合25.4万亿美元。〔S33〕
- 文章称，CIPS业务量增速连续两年超过40%。〔S33〕
- 文章称，截至2024年，CIPS已经接入全球约1500家金融机构，覆盖128个国家，但未区分直接参与机构、间接参与机构和实际业务覆盖地区。〔S33〕
- 文章称，中国跨境人民币结算业务中有82%不经过SWIFT系统，而由CIPS闭环完成，但未提供统计口径和原始数据。〔S33〕
- 文章称，SWIFT统计的人民币国际支付占比为2.88%，排名全球第六，低于加元和日元，但未明确对应月份。〔S33〕
- 文章将CIPS全年约25.4万亿美元的业务处理金额与SWIFT统计的2980亿美元进行比较，得出前者约为后者85倍的结论；由于未明确后者的统计周期及业务范围，该倍数不能直接用于衡量两个系统的市场份额。〔S33〕

### 支付机制、效率与成本
- S33来源2提到CIPS采用实时全额结算机制（RTGS），并认为这一机制能够提高跨境资金结算效率。〔S33〕
- 文章称，CIPS平均业务处理时间约为30秒，相当于SWIFT处理时间的四分之一，但未提供双方采用相同测试条件的证据。〔S33〕
- 文章称，CIPS直接参与行架构可以减少部分中间银行处理环节，进而降低跨境支付成本。〔S33〕
- 文章以单笔100万美元跨境支付为例，声称交易成本可以下降0.3%，但未提供原始收费标准、银行费用结构或实际交易账单。〔S33〕
- 系统内部报文处理时间、银行资金结算时间及企业账户最终到账时间应分别衡量，不能将不同环节的处理速度直接进行比较。〔S33〕

### 大宗商品及国际贸易应用案例
以下案例均为S33来源2的报道内容，尚未获得企业、银行或相关国家官方披露的独立验证。〔S33〕
- 巴西淡水河谷：文章称，该企业将部分对华铁矿石贸易结算由美元切换为人民币，通过CIPS支付后，到账时间由两天缩短至40分钟。〔S33〕
- 沙特阿美：文章称，其对华原油出口中约12%采用人民币及CIPS结算。〔S33〕
- 能源贸易：文章称，俄罗斯和伊朗对华石油交易中的人民币结算比例达到65%以上，CIPS能源类交易金额一年增长67%。〔S33〕
- 中俄贸易：文章称，人民币在中俄贸易结算中的占比由2019年的3%增长至2024年的67%。〔S33〕
- 跨境电商：文章称，义支付依靠CIPS支付成本优势取得中东市场19.1%的份额，但未说明具体市场范围、统计指标和数据来源。〔S33〕
- 东盟贸易：文章称，2025年上半年东盟区域贸易中的人民币结算占比超过30%。〔S33〕
- RCEP区域贸易：文章称，RCEP成员国相关CIPS清算占比达到31%，三年提升13%，但未明确分母及13%是相对增幅还是百分点变化。〔S33〕
- 中巴贸易：文章称，中国与巴西续签1900亿元人民币货币互换协议，并称大豆贸易全面采用本币结算；两项说法均需查阅官方协议和实际贸易数据。〔S33〕

### 国际金融机构参与
- S33来源3称，英国大型银行汇丰控股正式接入CIPS，并将其视为人民币国际支付体系影响力扩大的表现。〔S33〕
- S33来源3提供的正文不完整，未注明汇丰接入CIPS的具体时间、参与主体、参与方式及实际业务规模。〔S33〕
- 金融机构接入支付清算系统与其全面改变交易货币、资产配置及储备货币选择属于不同层面的变化，不能仅凭接入行为判断美元国际地位发生逆转。〔S33〕

### 与金融制裁及替代支付系统的关系
- S33来源2将CIPS视为部分国家降低对传统跨境支付渠道依赖的重要工具。〔S33〕
- 文章称，CIPS已经与俄罗斯金融报文传输系统SPFS、伊朗SEPAM系统实现报文互操作，但未提供官方技术协议、系统运营文件及实际业务记录。〔S33〕
- 文章认为，上述系统互联能够提高相关国家应对金融制裁的能力，但未充分分析次级制裁、交易对手合规要求及参与银行面临的风险。〔S33〕
- 使用替代性人民币支付渠道并不等同于交易主体已经免受所有金融制裁；研究相关问题时需要结合[[美国经济制裁与长臂管辖]]及具体交易的法律关系。〔S33〕

### 与数字人民币及多边央行数字货币桥的协同
以下技术应用及数据主要来自S33来源2，缺乏官方技术文件和完整统计支持。〔S33〕
- 文章称，沙特和阿联酋通过多边央行数字货币桥与CIPS实现秒级跨境支付。〔S33〕
- 文章称，数字人民币跨境试点覆盖23个国家，交易金额突破1200亿元人民币，并支持8秒到账。〔S33〕
- 文章称，数字人民币通过智能合约自动执行反洗钱规则，将交易追溯时间由传统系统的72小时缩短至15分钟。〔S33〕
- 文章称，在RCEP区域贸易中，智能合约可以自动触发关税支付和物流追踪，甚至实现人工干预归零；该说法缺少实际项目及业务覆盖范围说明。〔S33〕
- 文章称，量子通信卫星与CIPS主干网络融合，并预计2025年实现抗量子破解加密；资料未提供技术实施结果，该预测不能视为已完成的技术升级。〔S33〕
- 文章称，香港发行了全球首只离岸人民币稳定币并与CIPS直接连接，但未提供发行主体、监管许可、产品名称及系统接入文件。〔S33〕

### 研究中的关键统计口径
- CIPS业务处理总额、跨境人民币实际收付金额、国际贸易人民币结算金额及人民币全球支付占比分别衡量不同市场活动，不应相互替代。
- CIPS直接参与机构数量、间接参与机构数量及实际提供服务的金融机构数量需要分别统计。
- 支付系统业务规模应统一统计周期、币种、业务类型及计算方法后再进行比较。
- 人民币国际支付份额、国际贸易计价份额、全球外汇储备份额及国际债务货币份额，需要分别作为人民币国际化指标研究。
- CIPS、数字人民币、多边央行数字货币桥、人民币稳定币及其他国家金融报文系统，应区分各自功能、运营主体及实际互联关系。

## 关联

- [[美国经济制裁与长臂管辖]]：部分国家发展替代性跨境支付渠道的动力，与降低金融制裁风险有关。〔S33〕

## 不同说法

### 关于CIPS业务规模与SWIFT支付份额
- S33来源2认为，SWIFT公布的人民币国际支付份额低估了人民币实际国际使用规模，并以CIPS业务金额为SWIFT相关统计金额85倍作为依据。〔S33〕
- 同一文章未证明两项金额具有相同统计周期、币种范围、业务类型及清算口径，因此85倍的比较结论尚不能成立为严格的市场份额比较。〔S33〕

### 关于CIPS能否取代SWIFT
- S33来源2将CIPS描述为能够构建独立于SWIFT体系之外的人民币国际金融基础设施，并强调其效率和成本优势。〔S33〕
- S33来源1则认为，美元在复杂跨境交易和大宗商品贸易中仍具有相对优势，国际支付体系的变化更可能是渐进式、区域化和多元化的。〔S33〕
- S33没有提供足以证明CIPS已经全面替代SWIFT金融报文网络，或能够完全脱离现有国际银行合作体系运行的证据。〔S33〕

### 关于支付体系发展与美元国际地位
- S33来源2认为，CIPS业务快速增长正在挑战美元国际主导地位。〔S33〕
- S33来源3以汇丰接入CIPS及美国财政部长耶伦在会议中徽章意外掉落的事件，渲染美元国际地位面临危机，但后一事件不具有衡量货币信用或金融实力的经济统计意义。〔S33〕
- S33来源1认为，美元国际地位虽然面临结构性挑战，但短期内仍难以被单一货币全面取代。〔S33〕
