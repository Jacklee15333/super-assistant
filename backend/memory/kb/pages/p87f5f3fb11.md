# 举证责任与事实核查
举证责任与事实核查是通过明确概念、限定命题、检验证据、检查逻辑及主动纠错，提高事实判断可靠性的方法。〔S43〕

## 要点

### 谁主张，谁举证
- 提出事实性主张的一方，应当首先提供能够支持该主张的证据，而不是要求质疑者证明自己的说法错误。〔S43〕
- 口头陈述、个人印象和坚定的表达语气不能代替证据，重复一个结论也不等于证明该结论。〔S43〕
- 举证责任应当与主张的具体范围相匹配，涉及整个行业的普遍性结论，需要比单个产品的事实判断更充分的证据。〔S43〕
- 没有足够证据证明一个说法成立，不代表该说法一定错误，也不代表该说法已经成立；证据不足时，应当保留判断。〔S43〕
- 举证责任不意味着质疑者无须核实信息，而是不能要求他人在缺乏证据的情况下默认原始主张成立。〔S43〕

### 区分不同性质的信息
- 事实主张：能够通过客观资料、原始文件或实际观察进行验证的陈述。〔S43〕
- 推测：根据有限信息提出的可能性判断，需要明确其不确定性。〔S43〕
- 个人评价：基于个人价值观、评价标准或经验形成的判断。〔S43〕
- 转述信息：来自其他信息发布者、但尚未完成独立核实的说法。〔S43〕
- 未知事项：当前缺乏足够信息，无法得出可靠结论的问题。〔S43〕
- 不能将个人相信某件事情、曾经听说某种观点或对某个行业的笼统印象，直接等同于已经证实的客观事实。〔S43〕

### 概念定义与可验证命题
- 讨论之前应当明确关键概念的定义和评价标准，避免不同参与者使用同一个词语却讨论不同问题。〔S43〕
- 对复杂问题，应当逐步缩小研究范围，将宏观判断拆解成可以通过具体证据验证的小问题。〔S43〕
- 国产手机是否使用外国零部件、华为是否实现全部核心技术自主研发、华为某款手机是否使用博通射频滤波器，是三个不同的事实命题，不能相互替代。〔S43〕
- 应当记录讨论者最初提出的事实主张，避免通过不断改变定义、扩大讨论范围或提出新问题，跳过原本尚未得到证明的命题。〔S43〕
- 不断改变论证目标或转移讨论对象，与逻辑学中的移动球门（Moving the Goalposts）、转移话题（Red Herring）等论证问题有关。〔S43〕

### 逻辑一致性检验
- 当一个人的两个判断之间存在明显张力时，应当检查是否缺少必要的中间条件、事实依据或因果解释。〔S43〕
- 逻辑自洽是判断可靠性的重要条件，但逻辑上存在某种可能性，不等于现实中已经发生相应事实。〔S43〕
- 例如，出口管制与外国元器件继续供货之间的关系，需要结合具体管制范围、许可证、库存及供应渠道分析，不能仅凭逻辑推演得出具体产品的供应链结论。〔S43〕

### 证据分级
针对手机供应链等技术问题，S43提出以下参考证据等级：
- 第一层，直接技术证据：实际芯片标识、专业拆机报告、可验证的采购记录。〔S43〕
- 第二层，原始公开文件：监管部门文件、企业正式公告、经过核实的供应商资料。〔S43〕
- 第三层，专业分析：独立研究机构、专业媒体及行业专家提供的有来源分析。〔S43〕
- 第四层，普通网络信息：自媒体报道、论坛讨论及社交平台爆料。〔S43〕
- 第五层，未经核实的判断：没有来源的AI回答、个人印象、传闻与猜测。〔S43〕
- 上述分级属于示意性参考，并非固定的量化评分体系，实际证据价值还需要结合真实性、适用范围、时效性、独立性及与待验证命题的相关程度判断。〔S43〕
- 证据数量不能代替证据质量，应当优先寻找能够直接支持或反驳当前命题的材料。〔S43〕

### AI辅助事实核查
- 大语言模型可能产生幻觉，以专业、完整且自信的表达方式输出错误信息，也可能混淆产品型号、公司名称、政策时间及供应商关系。〔S43〕
- [[豆包]]等AI工具可以提高信息检索和整理效率，但没有原始资料支持的AI回答只能作为调查线索，不能直接作为最终事实证据。〔S43〕
- 使用AI进行事实核查时，应当要求提供原始资料链接、发布时间、关键证据内容，并区分已经证实的事实、合理推测和无法确认的信息。〔S43〕
- 应当同时寻找支持与反驳待验证主张的证据，避免将AI变成为既有立场寻找支持材料的工具。〔S43〕
- 当可靠证据不足时，应当允许AI明确回答无法确认，而不是强制要求其给出肯定或否定结论。〔S43〕

### 认知不足与言论责任
- 知识水平有限可以解释错误产生的原因，但不能自动免除公开传播信息时的核实与纠正责任。〔S43〕
- 应当区分诚实的事实错误、未经证实的猜测、故意编造事实以及法律意义上的造谣，不能因为某人暂时无法证明自己的主张，就直接认定其故意造谣。〔S43〕
- 是否需要公开道歉，应当结合言论性质、传播范围、实际影响及当事人是否主动纠正等因素判断。〔S43〕
- 发现此前公开表达的事实主张缺乏依据时，可以收回原有确定性判断，而不必在证据不足的情况下接受对方的全部结论。〔S43〕
- 认知失调（Cognitive Dissonance）、面子压力和自我防御可能阻碍个人修正原有观点，但不能仅凭一次争论确定当事人的真实心理动机。〔S43〕
- 人身贬低和攻击性语言可能使事实讨论转变为立场与面子之争，不利于参与者接受新的证据。〔S43〕

### 独立思考与统一证据标准
- 支持某个品牌不意味着必须接受有关该品牌的全部正面信息，质疑某个品牌也不意味着可以传播未经核实的负面信息。〔S43〕
- 对符合自身立场的信息与不符合自身立场的信息，应当采用同样严格的证据标准。〔S43〕
- 成熟的认知能力不仅体现在获取知识和形成判断，也体现在发现错误后重新核实证据、调整结论和主动澄清。〔S43〕

### 信息传播前自检
- 是否准确理解所讨论的概念和判断标准。〔S43〕
- 是否区分了事实、推测和个人评价。〔S43〕
- 是否掌握具体且可靠的信息来源。〔S43〕
- 是否核实时间、数字、品牌和产品型号。〔S43〕
- 结论是否超出了现有证据能够支持的范围。〔S43〕
- 是否认真考虑过反面证据。〔S43〕
- 是否因为个人立场或品牌偏好而降低判断标准。〔S43〕
- 如果发现错误，是否愿意在适当范围内主动纠正。〔S43〕

## 待跟进
- 研究公共讨论中的举证责任与司法程序中的法律举证责任有何区别。
- 建立适用于科技、经济、历史和国际政治研究的证据评价体系。
- 研究事实错误、失实传播、故意造谣及法律责任之间的具体边界。
- 建立知识库内部的事实、推测、争议及已纠正信息分类机制。
- 研究如何降低AI迎合用户既有观点及生成虚假来源的风险。
- 观察公开纠错的传播范围是否能够覆盖原始错误信息的受众。
