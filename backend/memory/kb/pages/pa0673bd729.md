# 德赛西威
德赛西威是智能驾驶领域的重要汽车电子供应商，其公开经营数据反映了智能驾驶业务规模扩张、产品降价、毛利率下降及客户集中等商业特征。〔S18〕

## 要点

### 智能驾驶业务规模
- 根据2025年年度报告，德赛西威2025年智能驾驶业务营业收入达到97亿元，包含公司境内外相关业务收入。〔S18〕
- 根据2026年半年度报告，2026年上半年智能驾驶业务营业收入为39.18亿元。〔S18〕
- 德赛西威除智能驾驶业务外，还拥有智能座舱等其他业务，因此公司整体财务数据不能直接作为智能驾驶业务的独立财务数据。〔S18〕

### 产品价格
- 2024年智能驾驶产品平均售价为856元/件。〔S18〕
- 2025年智能驾驶产品平均售价下降至651元/件。〔S18〕
- 2024—2025年，智能驾驶产品平均售价下降约23.95%。〔S18〕
- 上述价格为企业供货产品的平均售价，并非消费者购买整套智能驾驶系统的价格，也不是小型供应商能够直接取得的订单价格。〔S18〕

### 盈利能力
- 2024年智能驾驶业务毛利率为19.9%。〔S18〕
- 2025年智能驾驶业务毛利率下降至16.36%，约为16.4%。〔S18〕
- 2025年公司整体净利率为7.6%，该数据包含智能座舱等其他业务，并非智能驾驶业务独立净利率。〔S18〕
- 智能驾驶业务收入增长的同时，产品平均售价及毛利率下降，反映汽车电子供应商面临较大的价格竞争压力。〔S18〕

### 客户结构
- 截至2025年底，公司全部产品覆盖全球超过80家整车厂，该数量并非仅指智能驾驶业务客户。〔S18〕
- 2025年前五大客户贡献公司55.53%的销售收入，表明公司业务具有较明显的大客户集中现象。〔S18〕
- 对缺少整车厂供应链资源的小型创业者而言，报告建议优先研究已进入汽车供应链的企业及其配套服务需求，而不是直接向大型整车厂销售核心产品。〔S18〕

### 商业研究价值
- 德赛西威的智能驾驶业务规模、平均售价及毛利率可以作为观察[[中国智能驾驶市场]]产业竞争状况的具体企业样本。〔S18〕
- 公司整体7.6%的净利率可以用于创业经营压力测试，但不能直接假定小型智能驾驶服务商能够取得相同利润率。〔S18〕
- 以7.6%的参考净利率计算，每月实现1万元净利润需要约13.16万元营业收入。〔S18〕

## 时间线
- 2024年：智能驾驶产品平均售价为856元/件，智能驾驶业务毛利率为19.9%。〔S18〕
- 2025年：智能驾驶业务营业收入达到97亿元，产品平均售价下降至651元/件，业务毛利率下降至16.36%。〔S18〕
- 2025年：公司整体净利率为7.6%，前五大客户贡献55.53%的销售收入。〔S18〕
- 2025年末：公司全部产品覆盖全球超过80家整车厂。〔S18〕
- 2026年上半年：智能驾驶业务营业收入达到39.18亿元。〔S18〕
- 2026-08：公司半年度报告披露2026年上半年智能驾驶业务经营数据。〔S18〕
