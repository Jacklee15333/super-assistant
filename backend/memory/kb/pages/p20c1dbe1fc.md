# 成人职场英语与商务英语培训
将英语教学能力转化为面向成年职场人士、外贸业务员及企业客户的实用型教育服务。〔S14〕

## 要点

### 一、市场定位
- 相比泛英语教育，报告建议聚焦外贸业务员在实际工作中遇到的英语沟通问题，设计4～8周的结果导向型课程。〔S14〕
- 成人学员的主要付费动机是提高工作效率、改善商务沟通能力及获得职业发展机会，而不只是学习英语本身。〔S14〕
- 教育、知识付费与在线教育最近7天的新闻数量分别为1,227条和712条，但新闻热度不能证明成人商务英语培训的真实市场规模。〔S14〕
- 成人商务英语培训的权威细分市场规模、平均成交价格及个人教师平均利润，目前缺少足够可靠的数据。〔S14〕
- 报告将个性化学习、数字化教学、AI辅助教学及具体学习成果视为值得关注的教育产品发展方向。〔S14〕

### 二、目标客户
- 英文商务邮件写作能力不足的外贸业务员。〔S14〕
- 具备英语考试基础，但缺乏英文会议表达能力的职场人士。〔S14〕
- 需要处理海外客户询盘的跨境业务销售人员。〔S14〕
- 希望从国内销售转向海外业务的职场人士。〔S14〕
- 有员工商务英语培训需求的外贸企业。〔S14〕

### 三、上海成人语言培训经营合规要求
根据S14援引的《上海市成人语言类培训机构设置标准》及《上海市成人培训机构设立与管理实施办法》：
- 面向18周岁以上自然人开展的外国语言培训属于成人语言培训管理范围。〔S14〕
- 成人语言培训机构需要取得所在区教育行政部门颁发的办学许可。〔S14〕
- 线下培训场所建筑面积不得少于200平方米。〔S14〕
- 线上培训涉及服务器、ICP备案或相关电信业务许可、网络安全等级保护等要求。〔S14〕
- 中文教学人员需要具备与项目相匹配的能力证明，包括相应教师资格证、外国语言文学相关学历或学位、翻译系列职称或上海认可的行业培训证书等。〔S14〕
- 成人培训机构不得以教育咨询、企业管理咨询等名义开展实际培训业务。〔S14〕
- 报告提醒，不应将个人微信收费、线上一对一教学、社群训练营或教育咨询作为规避办学许可要求的方式。〔S14〕

以上为S14转述的政策要求，实际经营前仍需核实最新规定及具体业务适用范围。〔S14〕

### 四、轻资产经营方式
- 优先与取得相应成人语言培训许可的机构合作，由机构负责招生、合同、收费及办学管理，个人负责课程研发、教学和反馈。〔S14〕
- 个人是否具备授课资格，需要结合自身学历、资格证书及相关能力证明进行核实。〔S14〕
- 如果暂不具备授课条件，可以先提供课程设计、教学材料开发及企业学习内容供应，再由合规机构和符合条件的教师完成实际培训。〔S14〕
- 不建议创业初期独立开办成人英语培训学校。〔S14〕

### 五、课程产品设计
推荐首个产品为《外贸业务员商务英语实战训练营》。〔S14〕

| 项目 | 设计方案 |
| --- | --- |
| 培训周期 | 4周〔S14〕 |
| 每班人数 | 6～8人〔S14〕 |
| 授课频率 | 每周1次〔S14〕 |
| 单次课时 | 90分钟〔S14〕 |
| 核心内容 | 开发信、询盘回复、产品介绍、视频会议〔S14〕 |
| 配套服务 | 每周练习、作业批改、常见错误分析〔S14〕 |
| 交付结果 | 完成一套常见外贸场景的英语沟通练习〔S14〕 |

其他可开发课程包括：
- 8周职场英语邮件写作训练。〔S14〕
- 6周外贸业务常用英文表达训练。〔S14〕
- 30天英文会议表达训练。〔S14〕
- 12次常见商务场景口语训练。〔S14〕

### 六、收费与合作分成

| 服务 | 建议测试报价 |
| --- | --- |
| 4周基础课程 | 每班4,000～6,000元〔S14〕 |
| 8周进阶课程 | 每班7,000～10,000元〔S14〕 |
| 企业定制课程 | 根据课时、人数和内容另行报价〔S14〕 |

- 建议个人获得课程收入的60%～70%，具体合作分成需要与培训机构协商。〔S14〕
- 上述报价是建议测试价格，不是上海成人英语培训市场的统一收费标准或已验证成交均价。〔S14〕
- 初期应通过4周小班课程验证付费需求，而不是提前制作大量录播课程。〔S14〕

### 八、收入预测
假设个人取得课程收入的65%，合作机构取得35%，另行扣除部分直接成本。〔S14〕

| 情景 | 月度成交 | 月营业额 | 预计现金贡献 |
| --- | --- | --- | --- |
| 保守 | 1个班×4,000元 | 4,000元 | 约2,300元〔S14〕 |
| 一般 | 2个班×5,500元 | 11,000元 | 约6,600元〔S14〕 |
| 乐观 | 4个班×7,000元 | 28,000元 | 约16,600元〔S14〕 |

- 现金贡献未扣除个人劳动报酬及所得税等费用，不能直接视为净利润。〔S14〕
- 乐观情景要求每周稳定投入15～25小时，并且合作机构能够持续招生，不应作为第一季度的默认收入。〔S14〕
- 报告评估该方向匹配度为88分，预计回本周期1～3个月，风险等级为中等，尚未经过实际经营验证。〔S14〕

### 九、首次商业验证
- 访谈10位外贸业务员，了解其工作中最困难的英语沟通场景。〔S14〕
- 联系5家上海成人语言培训机构，了解商务英语课程合作需求。〔S14〕
- 制作一节90分钟免费试讲样课，主题为《外贸英文询盘回复的10个常见错误》。〔S14〕
- 初步目标是找到至少一家愿意讨论合作的合规机构，并获得真实学员的试学意愿。〔S14〕
- 如果缺少成人教学案例，应通过试讲和学员反馈持续优化课程。〔S14〕
- 通过记录学员训练前后的表现开发进阶课程，但不得夸大就业、升职或其他职业发展效果。〔S14〕

### 十、AI辅助教学
- 使用AI生成口语练习题、整理错题、辅助备课及分析学员学习进度。〔S14〕
- AI作为教师的效率工具，而非完全代替教学判断和人工审核。〔S14〕
