# 70岁企业家参与地方事务职务犯罪案例
一起涉及企业家私人垫资、地方事务资金管理、职务犯罪认定及刑事辩护策略风险的律师口述案例。〔S40〕

## 要点

### 当事人背景与案件经过
- 当事人为一名70岁男性，早年在房地产、金融等行业积累了大量个人财富，据作者介绍，其商业成功与善于把握行业发展趋势有关。〔S40〕
- 当事人在获得财富及社会认可之后，希望进一步实现个人情怀和社会价值，受当地邀请担任某地方负责人。〔S40〕
- 参与地方事务期间，当事人为了推动相关工作，使用个人财产进行垫资。〔S40〕
- 随着资金需求扩大，其个人及家庭财产逐渐无法承担持续投入，开始向朋友和过去的上下游客户借款。〔S40〕
- 据视频披露，当事人对外借款累计超过1亿元。〔S40〕
- 当事人后来从相关单位取得资金，用于归还此前向朋友等人借入的款项，但相关资金往来缺乏规范的财务手续及完整证据链。〔S40〕
- 据家属向律师反映，当事人数亿元家财散尽，并被判处15年有期徒刑。〔S40〕

### 资金流转与争议形成
1. 使用私人财富为地方事务垫资。〔S40〕
2. 随着资金需求扩大，向朋友及过去的上下游客户筹集超过1亿元借款。〔S40〕
3. 将借入资金投入地方事务。〔S40〕
4. 从相关单位取得资金，偿还此前的借款。〔S40〕
5. 借款、资金投入、财务入账、审批及后续还款之间缺乏充分的证据支持。〔S40〕
6. 相关取款行为产生贪污罪、职务侵占罪等刑事定性争议。〔S40〕

### 律师提出的辩护方案
- 视频作者阮思乔是一名从事经济犯罪及职务犯罪刑事辩护的律师。〔S40〕
- 作者所在律所一名代号为「老丁」的年轻律师具有较高学历、多年从业经验，并接触过职务犯罪案件。〔S40〕
- 老丁发现当事人在正式上任之前已经参与部分地方工作，提出以正式上任时间作为划分相关行为的节点。〔S40〕
- 老丁建议将上任前的相关行为按照职务侵占罪方向辩护，将上任后的相关行为按照可能涉及贪污罪的方向处理。〔S40〕
- 这一方案试图通过调整部分行为的罪名，减少贪污罪所对应的涉案金额和处罚风险。〔S40〕
- 阮思乔认为，该方案可能忽略巨额涉案金额下两个罪名量刑趋近及数罪并罚带来的不利影响。〔S40〕
- 视频没有说明老丁提出的方案是否实际实施，也没有证明该方案与当事人15年刑期之间存在因果关系。〔S40〕

### 信息边界
- 视频没有公布当事人的真实姓名、具体地方、正式职务、案号、裁判文书、各罪名对应的涉案金额及判决依据。〔S40〕
- 当事人的财富损失、借款金额及获刑情况来自作者和家属的叙述，不能直接视为经过独立核实的司法事实。〔S40〕
- 资料未能证明当事人是否具有非法占有目的，也无法确认其是否遭遇错误裁判。〔S40〕
- 视频虽然带有「无罪辩护」标签，但主要讨论罪名切分与量刑风险，没有完整论证当事人是否具备无罪辩护条件。〔S40〕
