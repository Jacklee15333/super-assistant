# 中国AI算力市场
中国AI算力市场已经形成数百亿元规模，企业、开发者、高校、科研机构及政府等客户存在真实采购需求，但不同机构的市场统计口径差异较大，基础设施投入和行业利润压力也较高。〔S17〕

## 要点

### 一、市场规模与统计口径
2025年中国AI算力相关市场已经达到数百亿元规模，但IDC、中国信通院及上市公司统计的数据范围不同，不能直接相加，也不能将上市公司全部营业收入当作算力市场收入。〔S17〕

| 统计机构或口径 | 2025年市场规模 | 统计范围 |
| --- | --- | --- |
| IDC智算云基础设施服务市场 | 486.7亿元 | GPU实例、专属集群及相关存储，不含上层应用软件〔S17〕 |
| IDC广义AI云市场 | 684亿元 | AI云服务市场〔S17〕 |
| 中国信通院企业级AI云服务市场 | 800亿元 | 企业级AI云服务〔S17〕 |
| 中国信通院广义智能算力服务市场 | 超过1300亿元 | 包含云电脑等消费级业务〔S17〕 |

- IDC测算，2025年中国智算云基础设施服务市场规模为486.7亿元。〔S17〕
- 中国信通院测算，2025年中国广义智能算力服务市场规模超过1300亿元。〔S17〕
- 上述市场数字属于不同统计口径，不能简单相加，也不能将较宽泛的智能算力服务市场全部理解为GPU租赁市场。〔S17〕
- 对于研究GPU出租、算力基础设施及相关技术服务的小商家，IDC统计的486.7亿元智算云基础设施服务市场比上市公司概念板块总营收更有参考价值，但仍然不是小商家可以直接获得的订单规模。〔S17〕

### 二、2026年市场增长与竞争格局
- IDC于2026年11月23日发布的市场跟踪报告显示，2026年上半年中国智算云基础设施服务市场规模达到430.3亿元。〔S17〕
- IDC数据显示，2026年上半年中国智算云市场同比增长97.7%。〔S17〕
- 2026年上半年中国AI云计算服务市场中，阿里巴巴市场份额为32.3%，前三大厂商合计占61.3%。〔S17〕
- 市场规模增长较快，但底层算力服务的收入明显向头部厂商集中，中小服务商需要寻找细分客户和差异化服务。〔S17〕

### 三、真实客户与购买需求
AI算力的主要买家包括科技企业、AI开发者、高校、科研机构、政府部门和医院。〔S17〕

| 客户或交易类型 | 已知数据 | 数据性质 |
| --- | --- | --- |
| AutoDL平台累计注册用户 | 超过100万人 | 累计注册，不等于付费用户〔S17〕 |
| AutoDL累计服务企业 | 超过10000家 | 累计服务企业，不等于年度付费企业〔S17〕 |
| AutoDL累计服务普通高校 | 700余所 | 累计服务数量〔S17〕 |
| 全国年度实际付费企业及个人数量 | 待核实 | 缺少统一统计〔S17〕 |
| 全国中小企业年度平均算力支出 | 待核实 | 缺少真实账单和订单数据〔S17〕 |

真实需求的证据主要包括：
- 专业算力租赁平台已经积累大量注册用户、企业客户及高校客户。〔S17〕
- 政府采购平台存在持续的算力相关采购公告和中标公告。〔S17〕
- 上市公司已经披露独立核算的AI算力云服务收入。〔S17〕
- 个人开发者可以按小时租用GPU，不必购买整套服务器。〔S17〕

需要注意，注册用户、累计服务客户、年度付费客户和实际成交金额是不同指标，不能相互替代。〔S17〕

### 四、政府采购与机构交易
2026年5月30日至11月26日，中国政府采购网算力关键词检索得到1184条采购公告和326条中标公告。〔S17〕
这些数量是关键词检索结果，未完成去重，可能包含重复公告、重新招标、配套项目及非AI专用算力项目，不能视为独立客户数量。〔S17〕
部分采购项目如下：

| 项目 | 金额 | 性质 |
| --- | --- | --- |
| 湖北经济学院云金融算力底座项目 | 475万元 | 采购预算〔S17〕 |
| 重庆市巴南区人民医院人工智能算力项目 | 99万元 | 采购预算〔S17〕 |
| 清华大学GPU算力服务器采购 | 195万元 | 采购预算〔S17〕 |
| 算力网威胁情报能力增强与配套服务项目 | 78.5万元 | 中标金额，非纯算力租赁〔S17〕 |
| 全国海关信息中心智能算力技术服务多年期项目 | 6598.66万元 | 多年期项目中标金额，来源为第三方转录公告〔S17〕 |

- 机构采购的金额明显高于个人小时租赁，但采购预算、中标金额、合同金额和实际收到的现金不是同一概念。〔S17〕
- 多年期合同不能直接全部计入当年收入。〔S17〕
- 本次政府采购抽样将预算金额和中标金额混合计算，得到的约102万元中位数不具备可靠的实际成交客单价代表性。〔S17〕

### 五、上市公司经营数据与利润水平
AI算力市场有真实商业收入，但行业规模增长并不代表所有企业都能获得较高净利润。〔S17〕

| 指标 | 数据 | 统计范围 |
| --- | --- | --- |
| AI算力概念上市公司毛利率中位数 | 19.6% | 2025年〔S17〕 |
| AI算力概念上市公司合计归母净利率 | 2.6% | 2025年〔S17〕 |
| AI算力概念上市公司营收同比增长 | 4.5% | 2026年前三季度〔S17〕 |
| AI算力概念上市公司净利润同比增长 | -8.2% | 2026年前三季度〔S17〕 |
| AI算力概念上市公司全部业务营收 | 1.43万亿元 | 2025年〔S17〕 |
| AI算力概念上市公司全部业务营收 | 1.09万亿元 | 2026年前三季度〔S17〕 |

上述上市公司收入包含通信、工程建设、服务器销售等其他业务，不能视为AI算力专项收入。〔S17〕
青云科技提供了更直接的算力业务样本：
- 2025年AI算力云服务实际确认营业收入4336.16万元。〔S17〕
- 2025年AI算力云服务第一大客户年度确认收入3193.27万元。〔S17〕
- 2025年AI算力云服务专项业务毛利率为31.62%。〔S17〕
- 2025年青云科技全公司净利润为-6562.21万元。〔S17〕

这组数据说明，专业算力服务可以形成实际收入，部分企业客户也具有较强采购能力，但单个大客户收入较高并不意味着公司整体盈利。〔S17〕
行业利润可能受到设备折旧、电费、融资成本、价格竞争、设备闲置及客户拖欠货款等因素影响。〔S17〕

### 七、市场数据的主要局限
目前仍然缺少以下关键数据：
- 全国AI算力年度独立付费客户数量。〔S17〕
- 全国纯GPU租赁业务全年实际成交总额。〔S17〕
- 全国中小企业年度实际算力支出。〔S17〕
- 小型GPU出租商的真实净利润率及设备利用率。〔S17〕
- AI部署、调试和运维服务的实际成交客单价。〔S17〕
- 政府算力采购年度实际成交总额及去重客户数量。〔S17〕

数据质量方面还存在以下问题：
- 1688和京东的数据抓取没有成功，不能据此推断没有真实成交。〔S17〕
- 政府采购网部分原始页面访问受限，部分金额数据未能逐条复核。〔S17〕
- 政府采购样本中出现2026年12月7日和12月21日的公告日期，晚于本次调研日期2026年11月26日，因此不作为已发生交易证据。〔S17〕
- 行业媒体重复引用同一份研究报告，不应当被视为多个独立数据来源。〔S17〕

## 时间线
- 2025年：中国智算云基础设施服务市场规模为486.7亿元，广义智能算力服务市场规模超过1300亿元。〔S17〕
- 2026-04：全国信息通信研究机构发布《智能算力服务研究报告（2026年）》，提供中国智能算力服务市场相关测算。〔S17〕
- 2026-11-23：IDC发布2026年上半年智算云市场跟踪报告，公布430.3亿元市场规模及97.7%的同比增速。〔S17〕
- 2026-11-26：完成AI算力市场、政府采购、GPU租赁报价和电商商品价格的交叉核实，确认市场存在真实需求，但全国付费客户总数和小商家净利润率仍缺少充分证据。〔S17〕

## 关联
- [[人工智能产业发展与商业化趋势]]：AI算力是人工智能产业的重要基础设施，市场竞争正在从单纯资源供应向更完整的云服务能力发展。〔S17〕
- [[AI智能体与企业应用]]：企业智能体的模型运行、推理和部署需要算力资源支持。〔S17〕
- [[AI创业机会与商业验证]]：算力部署、运维和采购代理可以作为AI创业的细分服务方向。〔S17〕
- [[AI算力轻资产技术服务]]：围绕算力资源提供环境部署、调试、运维和成本优化服务。〔S17〕
- [[人工智能服务交易与政府采购]]：政府算力采购是观察机构真实需求及项目预算的重要渠道。〔S17〕
- [[AI轻资产服务成本与利润测算]]：算力服务需要分别测算资源费用、设备折旧、人工成本、获客成本和实际净利润。〔S17〕
