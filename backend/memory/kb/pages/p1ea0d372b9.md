# 南京涉黑团伙与瑞银员工资金侵占案
一起据视频记载涉及犯罪所得、跨境资金委托、银行员工侵占客户资产及相关人员刑事责任的案件，反映非法利益合作中的信任和法律风险。〔S46〕

## 要点

### 涉及人员与犯罪背景
- 视频所述案件发生在南京，涉及一对经营多个洗浴中心的夫妇。〔S46〕
- 夫妇姓名在语音识别稿中记为余权利、罗小杰，准确姓名尚待司法文件核实。〔S46〕
- 视频称相关经营者涉及非法色情交易，并获得其他人员提供的保护。〔S46〕
- 视频称其相关非法收入累计约9亿元人民币，但该金额的统计范围及司法认定情况尚待确认。〔S46〕
- 涉及银行人员被视频记为孙建荣，身份为瑞银集团香港副总监，其准确职务及任职情况待核实。〔S46〕

### 委托资金与资产侵占
- 据视频记载，2014年相关夫妇委托孙建荣处理1.3亿元人民币资金，涉及跨境资金转移。〔S46〕
- 视频称其中约1.24亿元人民币被孙建荣侵吞。〔S46〕
- 视频将本案描述为银行内部人员利用犯罪客户面临的法律风险侵占其资产的案例，但具体犯罪手段及相关人员真实动机尚待核实。〔S46〕
- 相关夫妇在资金遭到侵占后选择报警。〔S46〕
- 案件反映非法利益合作中的参与者同样可能面临欺诈、资产侵占及合作关系破裂等风险。〔S46〕

### 刑事责任
根据S46视频文字稿：
- 孙建荣据称因洗钱等相关犯罪行为被判处10年有期徒刑，具体罪名尚待核实。〔S46〕
- 余权利、罗小杰夫妇据称因组织色情交易相关犯罪被判处15年有期徒刑，准确罪名及各自刑期需要查阅裁判文书确认。〔S46〕
- 视频称案件还牵出了其他涉嫌充当保护伞的人员。〔S46〕
- S46未提供法院名称、案件编号、正式判决书及具体裁判日期，因此上述人员身份、犯罪事实及判决信息均属于尚待独立核实的视频转述。〔S46〕

### 信任机制与法律风险
- 非法利益合作并不意味着参与者之间具有稳定的信任关系，合作双方也可能发生利益冲突。〔S46〕
- 犯罪所得的来源问题与非法合作过程中发生的资产侵占问题，需要分别考察相关法律责任。〔S46〕
- 银行员工的职务身份及金融机构的品牌声誉不能单独证明某项资金委托业务具有合法性和安全性。〔S46〕
- 个人员工涉嫌犯罪与金融机构整体参与犯罪属于不同性质的事实命题，不能仅凭员工身份推定瑞银集团管理层参与相关犯罪。〔S46〕
- 分析本案需要区分原始犯罪行为、资金委托行为、资产侵占行为及相关金融机构内部管理责任。〔S46〕

## 时间线
- 2014年：据视频记载，相关涉黑团伙经营者委托瑞银香港员工处理1.3亿元人民币资金，随后发生约1.24亿元人民币资金被侵吞的事件。〔S46〕
- 此后（具体日期未提供）：相关夫妇报警，案件进入司法处理程序，并据称牵出其他涉嫌充当保护伞的人员。〔S46〕
- 判决时间未确认：视频称孙建荣被判处10年有期徒刑，相关夫妇被判处15年有期徒刑。〔S46〕
