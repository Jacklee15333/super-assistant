# AI融脸与个人肖像权益保护
生成式AI降低了人物形象复制和再创作的成本，使普通人的外貌、个人风格及原创内容也可能成为商业化利用的素材。〔S51〕

## 要点

### 一、AI漫剧融脸案例
- 据博主苍述描述，一名女生在小红书发布个人照片后，因为外貌具有吸引力而获得较多评论及互动。〔S51〕
- 后来有人发现该女生的面部特征出现在多个AI漫剧的女主角形象中。〔S51〕
- 据作者叙述，该女生经过追踪，发现相关制作团队利用AI将其外貌特征融入生成式人物形象。〔S51〕
- 作者将这种利用现实人物面部特征生成其他人物形象的方式称为「融脸」。〔S51〕
- 作者认为，相关团队可能试图利用具有吸引力的外貌特征提升作品流量及商业价值。〔S51〕
- 该案例未提供当事人姓名、具体漫剧名称、制作团队信息、授权记录及独立验证材料。〔S51〕

### 二、个人外貌成为商业内容素材
- 作者认为，可能被AI内容制作团队关注的人不一定具有传统意义上的高颜值，只要拥有鲜明外貌特征、独特个人风格或者较强的用户互动能力，就可能被视为具有流量价值的素材。〔S51〕
- AI内容复制风险不仅涉及产品创意，也可能涉及普通人的面部特征、审美风格、声音、原创作品及身份表达。〔S51〕
- 个人在社交平台上获得的点赞、评论和互动，在作者所描述的竞争机制中可能成为内容商业价值受到关注的信号。〔S51〕
- AI内容制作能力与规模化经营流程结合后，可能使制作团队更容易利用已经表现出流量潜力的内容素材。〔S51〕

### 三、个人肖像与原创内容的日常保护
以下为S51资料整理者在视频观点基础上提出的防护建议。〔S51〕
- 定期检查社交媒体隐私设置，了解个人内容的公开范围。〔S51〕
- 根据实际分享需求，减少不必要的高清正脸照片、敏感个人信息及能够关联真实身份的资料公开。〔S51〕
- 对重要原创作品保留原始文件、项目源文件、创作过程及发布时间记录。〔S51〕
- 保存涉及内容创作、授权及商业合作的相关沟通记录，以便在发生争议时证明作品来源和授权情况。〔S51〕

### 四、发现疑似未经授权使用后的处理
- 保存相关作品页面、作品链接、账号信息及截图等证据。〔S51〕
- 保留本人原始照片、视频、声音资料或原创作品，用于核实素材来源。〔S51〕
- 根据具体情况通过平台投诉、协商或合法法律途径处理争议。〔S51〕
- 判断是否构成侵权，需要综合考虑具体使用方式、人物可识别程度、授权情况及适用法律。〔S51〕
- AI生成相似人物形象并不必然构成侵权，不能仅凭外貌相似就直接认定制作方实施了违法行为。〔S51〕

### 五、AI内容产业的原创权益问题
- S51资料认为，如果市场持续奖励复制效率，却不能充分保护原创成果，可能削弱个人投入原创内容生产的积极性。〔S51〕
- 内容生产者除提高创作效率外，也需要积累原创素材、创作过程记录、个人品牌及稳定的用户信任关系。〔S51〕
- AI内容生产中的合法模仿、正常市场竞争与侵犯个人肖像或知识产权的行为，需要根据具体情况加以区分。〔S51〕
