# 人工智能服务交易与政府采购
通过接单平台、政府采购公告和电商交易记录，研究人工智能服务的实际购买需求、价格水平和交易规模。〔S16〕

## 要点

### 接单平台报价样本
2026年11月26日，研究报告采用猪八戒网人工智能服务搜索首页的94个挂牌报价样本，抓取结果尚未独立复现。〔S16〕

| 指标 | 金额 | 出处 |
| --- | --- | --- |
| 最低挂牌报价 | 50元 | 〔S16〕 |
| 下四分位数 | 110元 | 〔S16〕 |
| 中位数 | 500元 | 〔S16〕 |
| 上四分位数 | 1800元 | 〔S16〕 |
| 最高挂牌报价 | 16888元 | 〔S16〕 |

- 样本中间50%的挂牌报价位于110～1800元之间，中位数为500元。〔S16〕
- 上述价格属于卖家挂牌报价，不代表买家实际支付金额，也不能反映各价格区间的真实成交量。〔S16〕
- 94个首页挂牌样本不是94笔实际成交订单。〔S16〕
- 人工智能接单服务的实际成交总额、真实客单价、成交率及退款率仍待核实。〔S16〕

### 政府及事业单位采购
- 2026年5月30日至11月26日，中国政府采购网以人工智能为关键词的爬虫记录显示，采购公告数量为3379条，中标公告数量为928条，两项数据均未去重。〔S16〕
- 采购公告和中标公告数量不能直接视为独立采购项目数量或独立客户数量，也不能直接据此计算成交率。〔S16〕
- 爬虫资料记录了宁波市海曙区人民医院人工智能建设项目中标金额160万元，研究报告查到了原始招标公告，但因网站读取限制未能独立确认中标金额。〔S16〕
- 爬虫资料记录了东莞市机电工程学校人工智能实训基地项目中标金额250万元，尚未独立核实原始中标公告。〔S16〕
- 原始采购金额样本同时混合预算金额和中标金额，并出现2026年12月2日、12月7日两条晚于报告统计截止日期的异常记录。〔S16〕
- 因日期异常及金额统计口径混杂，报告不采用原始样本计算出的149万元中位数作为有效购买力证据。〔S16〕
- 截至2026年11月26日，人工智能政府采购实际中标总金额尚未完成逐条核实与汇总。〔S16〕

### 电商平台交易情况
- 研究资料虽然提及1688、京东、什么值得买等平台，但没有提供这些平台有效的人工智能相关商品销量或成交额。〔S16〕
- 目前不能根据已有资料判断人工智能相关商品在电商平台的真实市场规模。〔S16〕

### 交易证据核实原则
- 调查平台接单市场时，应重点查看实际支付金额、成交记录、订单评价、退款情况及商家竞争程度，而不是只看挂牌报价。〔S16〕
- 调查机构采购时，应重点核实中标公告、合同公告、采购清单及合同金额，区分采购预算与实际中标金额。〔S16〕
- 不应以未经去重的公告数量乘以金额样本中位数推算整体采购市场规模。〔S16〕
- 政府及事业单位采购市场与普通个人能够进入的小型服务接单市场需要分别研究。〔S16〕
