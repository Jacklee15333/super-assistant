# 新华字典第13版带货视频纠错争议
一起围绕《新华字典》第13版带货视频出现知识错误、后续澄清未能阻断原视频传播，以及批评者是否需要道歉而展开的自媒体争议。〔S39〕

## 要点

### 一、资料来源与证据边界
- 资料来自抖音博主严老爹的视频《回复某人要求我道歉的视频，两个任务：1，明确义务；2，明确我和你不一样》。〔S39〕
- 视频链接：[https://www.douyin.com/video/7711910144112872166](https://www.douyin.com/video/7711910144112872166?utm_source=chatgpt.com) 。〔S39〕
- 视频笔记提取时间为2026年11月26日20:16。〔S39〕
- 现有资料主要依据严老爹的单方陈述及AI整理笔记，未对争议双方的原始视频、商业合同和全部相关说法进行独立核实。〔S39〕
- 原资料没有明确标注6月19日、6月20日及10月18日所属年份，因此不擅自补充年份。〔S39〕

### 二、争议起因
- 据严老爹陈述，另一位抖音博主于6月19日发布《新华字典》第13版带货视频。〔S39〕
- 对方因文案准备匆忙、看错行，将有关「玩弄女性」的内容错误解读为改成了「玩弄手机」。〔S39〕
- 据严老爹转述，对方表示自己在6月19日当天已经发现错误，并于6月20日发布道歉及澄清视频。〔S39〕
- 错误视频与澄清视频之间还间隔了一期有关鲁迅的视频，原错误视频没有类似上下集的明确提示。〔S39〕
- 据严老爹陈述，原错误视频在接近半年的时间里没有被删除。〔S39〕
- 对方解释保留错误视频是为了提高自己的犯错成本，通过永久公开错误警示自己。〔S39〕

### 三、争议的发展
- 严老爹称，自己于11月制作有关《新华字典》改版升级的内容时，通过搜索发现了6月19日发布的错误视频，该视频仍出现在靠前的搜索结果中。〔S39〕
- 严老爹自述，自己完整观看了原视频及随后一期讲鲁迅的视频，并截取原视频中的错误片段进行批评。〔S39〕
- 对方及其部分粉丝认为严老爹没有了解完整经过，存在断章取义、扣帽子及攻击行为，要求严老爹道歉。〔S39〕
- 严老爹拒绝道歉，认为自己指出的是原视频中真实存在的具体错误，没有改变原意，也没有义务遍历对方账号的全部视频。〔S39〕
- 严老爹称，引用对方视频时使用了较厚的马赛克隐藏身份，也没有主动公开对方的抖音账号名称。〔S39〕
- 据严老爹陈述，对方在回应视频中直接报出了他的账号名称，并将有关他的讨论与造谣传谣、阴谋论等内容并列。〔S39〕

### 四、关于《新华字典》第13版修订的分歧
- 对方在带货视频中使用了「这个国家级大瓜，终于有后续了」以及「上面对网友的反馈真的听劝」等表述。〔S39〕
- 严老爹不认同将字典修订过度娱乐化，也认为涉及中国社会科学院语言研究所、相关辞书研究机构或商务印书馆时，应直接说明具体机构名称，而不是含糊地称为「上面」。〔S39〕
- 视频讨论了「累赘」的例句由「孩子是累赘」调整为「行李是累赘」的情况。〔S39〕
- 严老爹认为该调整体现了辞书编纂受到舆论压力后的妥协，并可能反映汉语表意空间受到压缩。〔S39〕
- S39资料点评认为，仅凭这一例句不足以认定辞书修订受到不合理舆论裹挟，仍需结合辞书编纂原则、语言使用习惯、例句教育功能及实际修订资料进行研究。〔S39〕

### 五、严老爹自述的创作与商业实践
以下内容属于严老爹在回应视频中的自述，尚未获得独立验证。〔S39〕
- 在《新华字典》第13版面世前约半年，严老爹将自己制作的一整套汉语知识视频无偿授权给新华字典APP及相关线上平台使用，双方签订了正式书面合同，授权费为0元。〔S39〕
- 上述授权距离此次回应视频约一年，严老爹称此前没有主动公开宣传这项合作。〔S39〕
- 10月18日曾免费发布一期好书推荐视频，事前没有联系书籍作者，也没有要求经济回报。〔S39〕
- 自述只在抖音接过一次二手车APP商业推广，采用《变形金刚》中的汽车人作为创意主题。〔S39〕
- 自述曾因视频核心内容存在明显错误，删除已经获得大量播放或获得「抖音精选」标签的作品。〔S39〕
- 自述课程、语言文化沙龙、英语纠音及英语口语沙龙均不收费，没有设置付费专属会员。〔S39〕
- 曾接受其他博主对其「西班牙语是足球世界语言」说法的纠正，并表示感谢。〔S39〕
- 曾通过1898年和1932年的历史书证回应另一位博主对日语发音问题的质疑，但现有文字稿无法准确还原相关外语原文及部分书证名称。〔S39〕

### 七、争议的核心问题
- 信息发布者是否有责任保证原错误视频的后续观众能够接触到更正信息。〔S39〕
- 公开批评者是否应进一步核查对方已经发布的澄清内容。〔S39〕
- 保留错误视频以警示自己，是否可以与阻止错误信息继续传播同时实现。〔S39〕
- 商业推广者应如何承担产品信息错误可能造成的品牌商誉损失。〔S39〕
- 支持知识产品与保持对产品具体内容的独立判断是否能够兼容。〔S39〕
- 双方争议不应成为粉丝相互骚扰或实施网络攻击的理由。〔S39〕

## 不同说法
- 对方认为严老爹没有了解其已经发布澄清视频的完整经过，因此存在断章取义及攻击行为，应当道歉。〔S39〕
- 严老爹认为原视频是一条可以独立传播的作品，自己完整观看并准确引用了该视频，只指出具体错误，不构成断章取义。〔S39〕
- 对方认为长期保留错误视频能够提高自身犯错成本，起到自我警示作用。〔S39〕
- 严老爹认为保留错误视频会使错误继续传播，既然主动选择保留错误，就应承担未来不断有人指出错误的后果。〔S39〕
- 严老爹强调免费知识贡献与商业带货在行为动机及责任理念上的差异。〔S39〕
- S39资料点评认为，免费传播不必然意味着更高的专业水平或道德标准，收费也不意味着缺乏责任感，应以内容质量、商业透明度、承诺兑现和实际纠错行为进行比较。〔S39〕
