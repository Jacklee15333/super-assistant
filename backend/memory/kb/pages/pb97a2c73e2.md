# AI智能体与企业应用
AI智能体是能够根据用户目标执行连续工作任务的人工智能应用，其企业价值取决于业务执行能力、数据质量、任务成功率、安全机制及实际交付成本。〔S10〕

## 要点

### 一、从回答问题转向完成工作
- AI正在从单纯回答问题的聊天工具，转变为能够读取资料、调用软件、编写代码、生成报告、处理订单和执行连续任务的生产工具。〔S10〕
- 智能体可以承担客户寻找、询盘整理、报价单制作、合同检查、售后处理和经营报告生成等工作。〔S10〕
- 典型的人机协作方式是由用户提供目标，AI负责执行，人负责审核关键结果。〔S10〕
- 报告认为，AI可能逐渐分走原本属于传统软件和人工外包的预算，企业未来可能更加重视软件实际完成的工作量，而非功能数量。〔S10〕

### 四、企业知识库与数据治理
- 企业AI应用的难点正在从模型是否能够回答问题，转向能否访问正确数据、遵守业务规则、稳定运行并避免严重错误。〔S10〕
- 企业知识库建设可以整理产品文档、客户问答、历史案例、售后记录、培训资料及业务操作流程。〔S10〕
- 报告提出，可以通过整理企业过去五年的相关资料，建立可持续更新、具备来源引用及权限控制能力的知识库。〔S10〕
- 知识库的核心商业价值不仅是提供聊天问答，还包括数据治理、信息可追溯性、持续更新和实际业务支持。〔S10〕
- 数据质量差、商业机密泄露及AI错误回答是企业知识库建设的主要风险。〔S10〕

### 五、模型调用与成本优化
- 企业应根据任务难度选择不同模型，简单任务使用低价模型，复杂任务使用高性能模型。〔S10〕
- 智能体运行中的重复调用、过长上下文、任务失败和反复推理可能造成额外支出。〔S10〕
- 缓存、小模型替代及自动模型路由是报告提出的成本优化方向。〔S10〕
- 成本优化需要同时关注输出质量、任务成功率和实际节省金额，避免因过度压缩模型成本导致业务结果恶化。〔S10〕
- 企业评价AI系统时，应以完成合格任务所需的综合成本作为重要指标。〔S10〕

#### 算力基础设施与资源采购
- 企业AI应用除了模型调用费用，还需要考虑GPU实例、专属集群及相关存储等基础设施成本。〔S17〕
- IDC测算，2025年中国智算云基础设施服务市场规模为486.7亿元，该统计包含GPU实例、专属集群及相关存储，不含上层应用软件。〔S17〕
- IDC数据显示，2026年上半年中国智算云基础设施服务市场规模为430.3亿元，同比增长97.7%。〔S17〕
- 2026年11月查询到的RTX 4090公开租赁报价为0.98～1.88元/小时，这属于平台挂牌价格，并不等于所有GPU任务的实际成本。〔S17〕
- 对于没有稳定算力需求的小型企业，可以考虑按需租用GPU资源，而不是一开始购买昂贵设备。〔S17〕
- 小型服务商可以由客户直接向算力平台支付资源费用，再收取模型部署、环境配置、调试及运维服务费用，以降低设备闲置风险。〔S17〕
- 算力服务的实际成本还需要考虑设备折旧、电费、网络、平台费用及资源利用率，不能只比较显卡的小时租赁报价。〔S17〕

### 六、AI编程与企业软件开发
- AI编程工具降低了网站、内部管理系统、数据分析平台及自动化工具的开发门槛，使懂业务的人更容易参与软件开发。〔S10〕
- 麦肯锡2026年调查显示，32%的受访者表示，其所在组织因为能够利用AI编程工具自行开发，已经放弃购买至少一种软件产品或功能。〔S10〕
- 报告认为，程序员的价值将更多体现在系统架构、业务理解、代码安全和交付质量方面。〔S10〕
- 软件开发成本下降并不意味着获客成本、售后维护成本和系统安全成本会同步下降。〔S10〕
- 报告预测，2027年可能出现大量小型定制软件，2028—2029年部分传统通用软件的收费模式可能受到挑战，趋势确定性评估为高。〔S10〕

### 七、智能体安全、测试与运行监控
- 随着AI获得更多业务操作权限，数据保护、权限控制、运行监控及人工审核将成为企业AI应用的重要基础设施。〔S10〕
- AgentOps是报告关注的智能体运行与运维方向，相关服务涉及智能体测试、评估及持续监控。〔S10〕
- 企业可以建立真实业务测试案例，检测错误回答、越权操作、任务失败及异常费用。〔S10〕
- 智能体安全服务的风险包括客户付费意愿不明确、安全责任不清晰以及测试覆盖不足。〔S10〕
- 完全无人监管的金融、医疗及法律AI服务具有较高错误成本，并涉及专业资质、责任和监管问题，报告不建议普通创业者进入此类高风险业务。〔S10〕
