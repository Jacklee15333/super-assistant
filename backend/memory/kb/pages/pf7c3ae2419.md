# 自媒体内容创作者责任与信息纠错
自媒体创作者不仅需要对发布内容的准确性负责，还需要关注错误信息的持续传播、引用他人内容的公平性以及面对公众批评时的责任。〔S39〕

## 要点

### 一、信息发布者与接收者的义务边界
- 信息发布者应尽可能保证内容准确、完整、清晰，发现错误后应主动采取有效的纠错措施，而不是将寻找正确解释的责任全部转嫁给观众。〔S39〕
- 普通观众没有遍历一个账号全部历史作品的义务，也没有主动寻找每一期视频后续澄清内容的无限责任。〔S39〕
- 观众仍应具备基本的信息判断能力，不能将创作者承担主要发布责任理解为接收者完全不需要核实信息。〔S39〕
- 公开批评他人的创作者承担着不同于普通观众的信息核查责任，尤其当批评可能影响他人声誉时，应合理核实重要后续信息。〔S39〕
- 判断信息传递是否有效，不应只看发布者是否已经作出解释，还应看目标受众能否合理获得正确信息。〔S39〕

### 二、数字内容的非线性传播机制
- 短视频平台的内容传播不同于按照时间顺序展开的现实事件，用户可能通过算法推荐、搜索结果、社交转发和视频切片独立接触某一期旧视频。〔S39〕
- 原始视频与后续澄清视频可能拥有完全不同的受众，发布澄清视频并不意味着原视频的观众已经获得更正信息。〔S39〕
- 已经确认存在错误的视频如果长期保留，且缺少明显的更正提示，就可能不断向新的观众传播错误信息。〔S39〕
- 数字内容具有可管理、可修改和可删除的特点，创作者能够通过技术和运营措施降低错误信息继续传播的风险。〔S39〕
- [[新华字典第13版带货视频纠错争议]]体现了原始错误视频与后续澄清视频相互分离所产生的传播责任问题。〔S39〕

### 三、引用、剪辑与断章取义的区别
- 截取他人视频片段本身不必然构成断章取义，关键在于是否准确保留原意和必要语境。〔S39〕
- 如果通过删减关键内容、改变原意或制造误导性关联，使观众形成与原内容不符的认识，就可能构成误导性引用。〔S39〕
- 对他人作品进行公开批评时，应尽量围绕具体表述、原始材料、时间及相关证据展开。〔S39〕
- 应区分对某项知识错误的批评、对个人动机的推测以及对人格的攻击，不能仅凭一项错误就否定一个人的全部能力。〔S39〕

### 四、内容发布前的质量审核机制
S39资料根据视频作者描述的制作流程，归纳出以下内容审核环节。〔S39〕

| 审核环节 | 检查内容 |
| --- | --- |
| 选题 | 核心观点是否明确，是否具有真实的信息价值。〔S39〕 |
| 资料 | 数据、书籍、新闻、引用及案例是否具有可靠来源。〔S39〕 |
| 文案 | 是否存在看错行、错别字、概念混淆等问题。〔S39〕 |
| 专业知识 | 专业术语、机构名称、人名及发音是否准确。〔S39〕 |
| 拍摄 | 吐字、语调、拾音、画面及表达是否合适。〔S39〕 |
| 剪辑 | 是否改变原意或丢失必要语境。〔S39〕 |
| 字幕 | 字幕是否与实际表达一致。〔S39〕 |
| 标题 | 是否夸大事实、制造误导或过度情绪化。〔S39〕 |
| 商业信息 | 产品名称、版本、功能及宣传内容是否准确。〔S39〕 |
| 最终审核 | 从陌生观众的角度完整观看成品。〔S39〕 |

- 涉及专业知识、重大争议和商业合作的内容，适合在发布前进行二次审核。〔S39〕

### 五、错误信息的分级处理机制
S39资料提出，不同严重程度的错误可以采用不同的纠错方式，而不必将所有错误一概而论。〔S39〕

| 错误等级 | 典型情况 | 建议处理方式 |
| --- | --- | --- |
| 轻微错误 | 不影响理解的错别字、口误 | 修改字幕、补充说明。〔S39〕 |
| 一般错误 | 局部数据、名称或时间不准确 | 在原内容显著位置标注更正。〔S39〕 |
| 重大错误 | 核心观点建立在错误事实上 | 下架或删除，修改后重新发布。〔S39〕 |
| 商业错误 | 产品功能、版本或性能介绍错误 | 暂停传播、联系合作方、纠正并重发。〔S39〕 |
| 高风险错误 | 可能造成健康、财产或公共安全损失 | 立即阻断错误传播，尽可能通知受影响的人。〔S39〕 |

- 删除并非唯一有效的纠错方式，保留原始记录并增加醒目的更正声明，也可能有利于透明度和公众追溯。〔S39〕
- 置顶更正评论、增加明确的澄清入口、修改原内容以及必要时下架，都是资料提出的纠错措施。〔S39〕
- 纠错的核心目标是降低新增误导，而不是仅仅证明创作者已经表达歉意。〔S39〕

### 六、短期流量与长期信誉
- 视频作者严老爹自述，即使作品已经获得几十万至上百万播放量，或者获得「抖音精选」标签，只要发现核心内容存在明显错误，也会删除、修改并重新发布。〔S39〕
- 已经投入的制作成本及取得的流量，不应成为继续保留重大错误内容的理由，这一问题可以借助沉没成本概念理解。〔S39〕
- 从长期经营角度看，观众信任、专业认可及持续关注比单条爆款视频更具有长期资产价值。〔S39〕

### 七、面对公众批评的处理原则

| 批评类型 | 建议处理方式 |
| --- | --- |
| 真实存在的知识错误 | 核实、接受、纠正、感谢。〔S39〕 |
| 专业知识分歧 | 查阅资料、展示证据、解释逻辑。〔S39〕 |
| 合理的价值观差异 | 表达立场，允许不同意见存在。〔S39〕 |
| 对内容产生误解 | 补充必要语境，澄清实际意思。〔S39〕 |
| 无实质伤害的情绪化评价 | 视情况忽略，避免无效争论。〔S39〕 |
| 恶意造谣、骚扰及严重人身攻击 | 保存证据，使用平台治理及必要的合法维权渠道。〔S39〕 |

- 严老爹主张博主和媒体开放评论区，不应通过精选评论或关闭评论的方式过滤所有不利意见。〔S39〕
- 创作者公开承诺欢迎批评之后，应当在批评真正出现时保持言行一致，而不是只接受对自己有利的反馈。〔S39〕
- 内容创作者应避免动员粉丝攻击争议对象，必要时可以隐藏不影响论证的个人身份信息，并明确提醒观众不要骚扰他人。〔S39〕

### 八、责任原则在其他领域的应用
- 工作通知、邮件及公开声明同样存在原始错误信息与后续更正信息相互分离的问题。〔S39〕
- 承诺欢迎员工提出不同意见、对产品质量负责或者接受公开监督，意味着在相关原则对自身利益不利时仍需承担相应责任。〔S39〕
- 判断一个人是否真正认同某项原则，可以观察其实际行为是否与公开承诺一致。〔S39〕

## 不同说法
- 严老爹认为，普通观众没有查阅对方全部历史视频的义务，只要引用的单期视频没有被曲解，就可以指出其中的错误。〔S39〕
- S39资料点评认为，普通观众没有无限追溯义务，并不意味着进行公开批评的创作者完全没有核实重要后续信息的责任，尤其应考虑对方是否已经公开纠错。〔S39〕
- 严老爹倾向于删除核心内容存在重大错误的视频，以阻止错误继续传播。〔S39〕
- S39资料分析认为，在能够有效提示观众的前提下，保留原始内容及更正记录也可能具有透明度和追溯价值。〔S39〕
