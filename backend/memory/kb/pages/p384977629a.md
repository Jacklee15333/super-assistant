# 中华文明起源与早期发展
根据中华文明探源工程的研究，中华文明经历了区域文明分别发展、古国形成及王朝背景下文明一体化的发展过程。〔S13〕

## 要点

### 文明起源的阶段划分
中华文明探源工程认为，大约从距今5800年开始，黄河中下游、长江中下游及西辽河流域相继出现明显的社会分化，进入文明起源的加速阶段。〔S13〕

| 历史阶段 | 时间范围 | 主要代表文化 |
| --- | --- | --- |
| 古国时代第一阶段 | 距今5800—5300年 | 仰韶文化中期、大汶口文化早期、红山文化中期、崧泽文化、大溪文化、油子岭文化〔S13〕 |
| 古国时代第二阶段 | 距今5300—4300年 | 仰韶文化晚期至庙底沟二期文化、大汶口文化中晚期、红山文化晚期、良渚文化、屈家岭—石家河文化、马家窑文化〔S13〕 |
| 古国时代第三阶段 | 距今4300—3800年 | 各地龙山时代考古学文化、石峁文化、宝墩文化、肖家屋脊文化、钱山漾文化等〔S13〕 |
| 王朝时代 | 距今3800—2200年 | 二里头文化至秦统一之前的时期〔S13〕 |

### 古国时代第一阶段：社会复杂化加速
- 牛河梁遗址群第一地点发现前后9座台基，为重新认识女神庙区域的性质与布局提供了新证据。〔S13〕
- 凌家滩遗址确认存在多重环壕、复杂公共空间，以及高等级贵族墓地周围的祭祀遗存。〔S13〕
- 中心聚落开始整合普通村落，聚落群内部及聚落群之间出现新的政治因素。〔S13〕
- 黄河、长江及西辽河流域的玉石器呈现不同特点，反映各区域不同的社会分化模式与文明发展路径。〔S13〕
- 长江中下游均发现占地面积超过或达到100万平方米的中心聚落。〔S13〕
- 大型聚落出现水坝、引水渠、环壕等外围水利设施，内部也存在复杂的水管理系统。〔S13〕
- 水利管理系统的发展与农业生产密切相关，稻作农业在生业经济中的占比明显提升。〔S13〕
- 大型聚落与水利系统的修建体现了区域组织和调动人力能力的提升。〔S13〕

### 古国时代第二阶段：早期国家形成
- 社会整合由聚落群内部扩大至聚落群之间，甚至整个考古学文化区域。〔S13〕
- 大型都邑和区域中心出现，反映出人群聚集与资源整合能力的增强。〔S13〕
- 不同区域依据自身条件形成不同的生业经济策略和社会发展模式。〔S13〕
- 稻作农业逐渐成为长江流域社会发展的关键经济支撑。〔S13〕
- 长江下游良渚文化及长江中游屈家岭—石家河文化区的聚落等级、公共资源及人力调配复杂程度显著提升，率先发展出早期国家政体。〔S13〕
- 良渚文化早期与中期交界时，良渚早期国家正式形成。〔S13〕
- 黄河流域双槐树、焦家遗址出现由多重环壕构成的复杂城邑。〔S13〕
- 焦家、岗上遗址发现反映复杂社会等级的墓葬，部分墓葬建于专门堆筑的人工土台上。〔S13〕
- 黄河流域大型公共设施增多，社会等级分化及军事权力更加明显，但是否已经形成国家政体，项目组认为尚无法确认。〔S13〕
- 焦家、良渚等遗址存在远距离物品交流，体现出社会活动对地缘空间限制的突破。〔S13〕

### 古国时代第三阶段：区域文明兴衰与中原崛起
- 西辽河流域红山文化全面衰落，长江中下游部分地区的社会发展逐渐衰落并陷入停滞。〔S13〕
- 大部分石家河文化城址逐渐荒废，肖家屋脊文化仅在个别遗址呈现若干文明发展特征。〔S13〕
- 四川盆地西部边缘成为这一时期长江流域文化发展最为发达的区域，以宝墩、高山等遗址为代表，出现密集筑城现象。〔S13〕
- 三星堆遗址宝墩文化堆积分布面积达到500万平方米，是当时长江流域乃至全中国规模最大的聚落。〔S13〕
- 黄河中游地区大型都城不断出现，国家形态开始显现，逐渐形成以中原为中心的历史发展趋势。〔S13〕

### 王朝时代：文明一体化
- 王朝时代大体为距今3800—2200年，对应考古学上的二里头文化至秦统一之前的时期。〔S13〕
- 这一阶段的主要特征是王朝背景下的文明一体化发展。〔S13〕

### 多区域文明发展与交流
- 不同区域古国在各自社会基础上发展起来，不存在简单的文明高低之分。〔S13〕
- 不同地区古国之间没有直接的继承关系，但存在物质文化、农业技术、手工业技术、动植物物种及贵重资源的交流与传承。〔S13〕
- 早期区域文明的发展并非同步进行，不同地区经历了各自的兴盛、衰落及社会转型过程。〔S13〕

### 早期国家判定的考古证据
根据项目执行专家组的研究，值得关注的考古证据包括：〔S13〕
- 聚落规模、聚落等级及区域整合程度。〔S13〕
- 贵族墓葬、社会等级与资源分配差异。〔S13〕
- 大型公共工程、水利设施及人力组织能力。〔S13〕
- 农业经济及稳定的社会生产体系。〔S13〕
- 军事权力、政治因素及公共资源调配能力。〔S13〕
- 宗教信仰、祭祀活动及意识形态。〔S13〕
- 远距离物资交流及跨区域社会联系。〔S13〕

上述内容是资料中涉及的考古分析维度，并非资料明确列出的完整、统一的国家判定标准。

## 时间线
- 距今约5800年：黄河中下游、长江中下游及西辽河流域相继进入文明起源加速阶段。〔S13〕
- 距今5800—5300年：古国时代第一阶段，社会复杂化及聚落整合加速。〔S13〕
- 距今5300—4300年：古国时代第二阶段，良渚及长江中游部分区域率先形成早期国家。〔S13〕
- 距今4300—3800年：古国时代第三阶段，部分区域文明衰落，中原地区逐渐崛起。〔S13〕
- 距今3800—2200年：王朝时代，中华文明进入王朝背景下的一体化发展阶段。〔S13〕
- 2026-06：中华文明探源工程项目执行专家组公布新的阶段划分及相关研究成果。〔S13〕

## 待跟进
- 中国考古学界与西方考古学界对文明、早期国家的具体判定标准有何异同。
- 文字、冶金技术、城市、社会分层与公共权力在不同文明判定体系中的地位。
- 中华早期文明与古埃及、两河流域、印度河流域早期文明的年代及社会结构对比。
- 良渚、陶寺、石峁、二里头在政治组织、经济基础、宗教体系及军事能力方面的具体差异。
- 良渚、红山及石家河等区域文明衰落的原因，以及环境变化与社会发展的关系。
- 中原地区逐渐成为文明发展中心的具体机制及考古证据。
- 社会复杂化与真正形成国家政体之间的判定边界。
