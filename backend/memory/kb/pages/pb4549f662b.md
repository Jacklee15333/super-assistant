# 侵害后的二次伤害与社会支持
侵害后的二次伤害是受害者因外界的质疑、指责、羞辱及隐私侵犯而承受的额外伤害，可靠的社会支持网络能够降低求助障碍、减少孤立感并帮助恢复行动能力。〔S55〕

## 要点

### 一、二次伤害的形成机制
- 二次伤害（Secondary Victimization），也称二次受害，是指受害者在遭遇侵害后，又因为外界的指责、质疑、羞辱及否定等反应而承受额外伤害。〔S55〕
- 许多受害者并非不愿意寻求帮助，而是担心说出经历后遭到嘲笑、指责、怀疑或不被相信。〔S55〕
- 典型的受害者归责包括追问受害者为什么前往某个地方、为什么没有提前拒绝、为什么没有反抗、为什么与对方见面，以及为什么现在才说出来。〔S55〕
- 外界的否定和责备可能加重受害者的羞耻感、孤立感、自我怀疑及心理压力，影响其寻求医疗、心理及法律帮助的意愿。〔S55〕
- 保护受害者不仅意味着制止原有侵害，也意味着避免在其寻求帮助和恢复生活的过程中再次施加伤害。〔S55〕

### 二、羞耻感与维权障碍
- 遭遇性骚扰及其他侵害后，部分受害者可能因为羞耻感、缺乏证据、担心外界评价或认为事情不够严重而选择沉默。〔S55〕
- 视频认为，受害者长期沉默可能使有关部门难以掌握重复侵害行为的完整情况，也可能使受害者无法及时获得所需帮助。〔S55〕
- 作家蒋方舟分享了自己遭遇性骚扰后报警的经历，并认为身边存在一个能够提供理解和支持的小环境，是自己能够克服羞耻感的重要原因。〔S55〕
- 能够让人放心说出真实遭遇的人际环境，有助于将已有的安全知识和维权认知转化为实际求助行为。〔S55〕

### 三、建立一至两个可靠的社会支持关系
- 视频提出，长期自保的关键不在于拥有庞大的社交圈，而在于拥有一至两个真正可信赖、能够提供情绪支持和实际帮助的人。〔S55〕
- 当个人遭遇侵害、陷入恐惧或不知道如何处理问题时，可靠的支持者能够认真倾听，而不是立即质疑、责备或要求其独立证明自己的遭遇。〔S55〕
- 支持者可以根据实际需要提供陪同报警、陪同就医、确认行踪、整理信息、联系家人及寻找专业资源等帮助。〔S55〕
- 可信赖的人际支持能够减少危机中的孤立感，并帮助个人逐步恢复判断和行动能力。〔S55〕
- 自我保护不意味着必须独自解决所有问题，知道什么时候求助、向谁求助，本身也是一种重要的生存能力。〔S55〕

### 四、可靠支持者的判断标准
- 尊重个人隐私，不轻易传播他人的私人经历，也不擅自公开他人的身份和遭遇。〔S55〕
- 遇到紧急情况时，能够优先关注当事人的人身安全、情绪状态及实际需求。〔S55〕
- 不习惯性地通过指责、贬低、否定或羞辱等方式回应他人的困难。〔S55〕
- 在必要时能够提供实际帮助，而不仅仅是提出空泛的意见。〔S55〕
- 尊重当事人的自主决定，不以提供帮助为由要求对方交出全部隐私、行动自由或个人决策权。〔S55〕

### 五、如何帮助遭遇侵害的亲友
- 首先确认对方当前是否安全，是否需要紧急医疗、报警或其他外部帮助。〔S55〕
- 认真倾听对方的经历，不急于追问其为什么没有提前防范、为什么没有及时反抗或为什么没有更早求助。〔S55〕
- 询问当事人目前需要什么帮助，并在尊重其意愿的前提下提供情绪支持、陪同报警、就医或联系专业机构等服务。〔S55〕
- 不擅自将当事人的经历发布到网络上，也不应未经允许向无关人员传播其私人信息，以免造成新的隐私风险和心理压力。〔S55〕
- 支持受害者与依法核实事件事实并不矛盾，可以先提供安全和情绪支持，再由相关专业人员开展调查及判断。〔S55〕

### 六、建立多层次紧急支持网络
- 不应等到真正遭遇危险时，才开始考虑能够向谁求助，可以提前确定紧急联系人及其能够提供的帮助类型。〔S55〕
- 私人支持层可以由可信赖的朋友、家人及其他稳定的人际关系构成，主要提供情绪支持、行踪确认和实际协助。〔S55〕
- 专业支持层可以包括报警渠道、医疗机构、法律援助机构及心理支持资源。〔S55〕
- 日常联系机制可以包括必要的行踪报备、约定返程后的确认信息，以及出现异常失联时的应急联系方式。〔S55〕
- 长期安全保障应当来自多层次的社会支持，而不是完全依赖某一个伴侣、朋友或家庭成员。〔S55〕
- 缺乏社会支持可能增加个人求助的困难，但不能因此认为社会关系较少或处于孤立状态的受害者应当为侵害承担责任。〔S55〕

### 七、社会支持在自我保护体系中的作用
- 视频将稳定、可信赖的人际环境视为整个自我保护体系的底层支撑，因为安全知识只有在个人敢于行动并能够获得帮助时，才能真正发挥作用。〔S55〕
- 事前社会支持能够通过行踪确认和紧急联系机制提高异常情况被发现的可能性。〔S55〕
- 事后社会支持能够通过情绪接纳、陪同报警、医疗帮助及信息整理，降低当事人的求助障碍。〔S55〕
- 长期社会支持的价值在于帮助个人减少孤立、恢复行动能力和维持自主判断，而不是替代个人作出所有决定。〔S55〕

- [[侵害后的报警求助与证据保全]]：二次伤害及羞耻感可能阻碍报警，而可靠的支持者能够帮助当事人获得医疗与法律资源。〔S55〕

- [[普通人应对恶意与人际边界管理]]：选择可靠的人际关系、保护隐私及避免持续接受外界贬低，有助于维护个人边界。〔S55〕
