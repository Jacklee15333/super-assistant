# 个人认知与学习画像
根据成长库形成的阶段性观察，描述个人的认知倾向、学习习惯和价值判断方式。〔S4〕

## 要点
- 机制导向：不仅关注事件的表面结果，更重视背后的利益分配、制度约束、行为动机和因果关系。〔S4〕
- 评价标准一致性：关注同类事件是否因国家、品牌或人物身份不同而受到不同评价，重视判断尺度的统一。〔S4〕
- 实证导向：相比企业家的个人光环和宣传叙事，更重视技术指标、比赛成绩、工程能力及商业可持续性。〔S4〕
- 审视权威：关注学术造假、名人履历争议及知识付费乱象，不倾向于将身份地位直接等同于观点正确。〔S4〕
- 长期学习意识：不仅收集即时新闻，也围绕同一问题进行跨领域研究，尝试将零散信息转化为系统知识。〔S4〕
- 独立判断：希望建立一套不被舆论、权威和商业叙事轻易左右的认知体系。〔S4〕
- 行动意识：关注理性判断与现实行动之间的关系，重视认清问题后的行动能力，而非单纯的情绪宣泄。〔S4〕
- 持续积累历史、经济、社会心理学和传播学案例，训练逻辑辨析、事实核查及复杂社会现象的归因能力。〔S4〕
- 上述画像来自小助对成长库内容的分析，收藏内容及其作者立场不能直接等同于个人真实立场。〔S4〕
