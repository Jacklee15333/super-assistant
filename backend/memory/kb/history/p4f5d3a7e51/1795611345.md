# 个人关注与专题研究方向
汇总个人长期关注的领域、具体研究对象及正在使用的研究方法。〔S4〕

## 要点

### 国际地缘政治与利益博弈
- 重点关注美伊谈判、霍尔木兹海峡能源安全、巴以冲突、日本军事化风险及中俄关系。〔S4〕
- 重视国家利益、外交筹码及国际关系背后的利益博弈。〔S4〕
- 正在研究美伊谈判与霍尔木兹海峡能源博弈，关注能源运输、军事威慑、外交谈判与国家战略之间的关系。〔S4〕

### 中国科技与产业国际竞争力
- 持续关注中美可回收火箭技术、SpaceX星舰试飞、歼-10CE、宇树科技载人机甲及张雪机车的国际赛事表现。〔S4〕
- 正在研究中美可回收火箭的技术差距，主要比较指标包括回收成功率、单箭复用次数和单位载荷发射成本。〔S4〕
- 重视实际技术指标、比赛成绩、工程能力和商业可持续性，而非单纯依赖企业宣传或人物影响力进行评价。〔S4〕

### 媒体叙事与舆论操纵
- 关注选择性报道、框架效应、概念偷换、双重评价标准及认知偏误。〔S4〕
- 关注资本利益和流量机制对信息传播的影响。〔S4〕
- 正在研究国际媒体对中美同类科技成就及技术事故的报道差异，并积累识别选择性报道和框架效应的方法。〔S4〕

### 历史叙事与文化自主性
- 关注中国历史的真实性及传统文化传承。〔S4〕
- 关注东西方文明评价体系，以及全球化与中国自主发展之间的关系。〔S4〕

### 社会信任与公共道德
- 关注虚假热点、慈善乱象、网络暴力和地域歧视。〔S4〕
- 关注公众善意被反复消耗的社会机制，以及社会信任与独立思考、现实行动之间的关系。〔S4〕

### 商业利益与制度规则
- 关注世界杯转播权谈判、平台限流及企业海外投资安全。〔S4〕
- 关注学术监督、高校公共资源管理、学术造假、名人履历争议及知识付费乱象。〔S4〕

### 研究方法
- 使用可量化指标进行技术实力的横向比较。〔S4〕
- 从利益结构、制度约束、行为动机及因果关系等角度分析事件。〔S4〕
- 通过比较不同媒体对同类事件的报道，研究评价标准和叙事框架的差异。〔S4〕
- 积累历史、经济、社会心理学和传播学案例，开展跨领域研究，训练事实核查、逻辑辨析及归因能力。〔S4〕
