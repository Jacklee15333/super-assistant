# 人民币石油结算
人民币石油结算通过扩大人民币在国际能源贸易中的使用，为能源进口国和出口国提供美元之外的货币选择。〔S28〕

## 要点
发展动力
- 中国庞大的原油进口需求被来源1视为推动人民币进入国际能源贸易的重要经济基础。〔S28〕
- 俄罗斯、伊朗受到美国制裁及美元支付体系限制，被来源1视为具有使用人民币等替代结算货币的现实动力。〔S28〕
- 来源1认为，能源出口国采用多种结算货币，有助于分散对单一货币及其金融政策的依赖。〔S28〕

人民币能源交易与支付基础设施
- 来源1称，2023年中国石油通过上海石油天然气交易中心完成首笔数字人民币石油交易。〔S28〕
- 来源1提到，沙特参与多边央行数字货币桥项目，该项目被文章视为发展替代性跨境支付渠道的重要探索。〔S28〕
- 来源1称，阿联酋等海湾国家正在建设人民币清算机制，并逐步扩大人民币在对华能源贸易中的使用。〔S28〕
- 上述支付基础设施及交易案例反映的是人民币跨境支付应用的探索，不能直接证明人民币已经取得国际石油定价主导权。〔S28〕

2026年人民币石油结算的相关报道
以下信息主要来自2026年4月3日网易号自媒体文章，资料未附官方公告、完整统计表或企业原始披露，应作为待核实线索保存。〔S28〕
- 文章称，2026年3月霍尔木兹海峡32%的油轮使用人民币结算，较2023年增长约6倍，但未说明统计样本、交易金额和结算范围。〔S28〕
- 文章称，伊朗开始实施人民币结算优先的港口通行规则，并将人民币结算与船舶通行条件挂钩。〔S28〕
- 文章称，中国石化、印度信实工业调整了相关结算策略，俄罗斯卢克石油将对华原油出口的结算货币全部切换为人民币。〔S28〕
- 文章称，伊朗约90%的石油出口流向中国，因此具有推动人民币能源结算的动力。〔S28〕
- 文章称，沙特外汇储备中人民币的占比由2022年的1.1%升至2026年3月的6.8%，但S28未附沙特央行的原始储备结构数据。〔S28〕
- 文章称，中国在波斯湾地区的基础设施投资已超过700亿美元，并将其与人民币能源贸易的发展联系起来，但未提供投资统计的时间范围及具体项目清单。〔S28〕

人民币国际化的可能方向
- 来源1认为，人民币石油结算的战略价值主要在于扩大货币选择权、降低制裁风险和减少对美元支付渠道的依赖，而不一定是全面取代美元。〔S28〕
- 来源1认为，成为单一全球储备货币可能带来汇率升值、出口竞争力变化和承担国际储备货币责任等成本。〔S28〕
- 来源1预测，到2028年海湾国家对亚洲的石油出口中，人民币计价及结算的比例可能进一步提高，但没有给出可验证的具体目标比例。〔S28〕
- 来源1预期未来国际石油贸易可能形成美元、人民币、欧元及数字货币并存的多元化结算格局。〔S28〕

研究中的关键统计口径
- 石油交易使用人民币支付，不一定意味着石油合同使用人民币定价。
- 油轮数量占比、原油运输量占比和石油交易金额占比分别反映不同指标，不能相互替代。
- 人民币跨境支付规模、石油贸易结算比例和人民币在各国央行外汇储备中的占比，需要分别统计。
- 数字人民币、人民币跨境清算机制和多边央行数字货币桥应作为不同的支付工具及基础设施研究。

## 关联
- [[霍尔木兹海峡能源运输风险]]：能源运输安全、通航政策与国际能源贸易结算方式可能相互影响。〔S28〕
- [[石油美元体系与美元国际地位]]：人民币能源结算为传统美元石油结算提供替代选择，但不等同于美元国际货币地位被全面取代。〔S28〕

## 不同说法
- S28来源1的标题宣称石油美元即将终结，但正文同时承认美元金融市场具有深度、流动性和网络效应优势，并认为未来更可能出现多种货币并存的结算格局。标题判断明显强于正文论证。〔S28〕
- 来源1一处称伊朗实行人民币结算优先规则，另一处称必须使用人民币结算才允许船只通行；优先使用与强制使用属于不同政策，需要核实官方规定。〔S28〕
- 来源1强调人民币能源结算正在扩大，来源2则指出同期美元指数突破100关口，说明人民币能源结算的发展与美元短期走强可能同时存在。〔S28〕
