## 背景与主题
过去半个多世纪，全球半导体产业主要沿着摩尔定律（Moore’s Law）指引的方向发展，通过不断缩小晶体管尺寸、提高晶体管集成密度，推动芯片性能提升。但随着先进制程逐渐接近物理极限，研发成本、设备成本和生产成本不断攀升，传统技术路线面临越来越大的挑战。
与此同时，美国对华为及中国半导体产业实施技术和供应链限制，使中国企业获取部分先进芯片制造技术和设备的难度进一步增加。
在这一背景下，华为提出“韬定律”，尝试将芯片性能提升的重点从单纯追求几何尺寸缩小，转向缩短信号传输时间、优化系统架构和提升整体集成效率。
视频作者对这一技术路线持高度肯定的态度，认为它不仅具有技术和经济价值，也是中国企业突破外部技术限制、寻找自主创新路径的重要体现，并对国内部分质疑华为的舆论表达了强烈不满。

## 核心观点

### 1. 摩尔定律正在遭遇物理极限和经济成本的双重瓶颈
传统半导体产业的发展逻辑，是通过几何缩微（Geometric Scaling）不断缩小晶体管尺寸，在有限的芯片面积内集成更多晶体管，从而提升计算能力。视频列举了从14纳米、7纳米到5纳米、3纳米的制程演进过程，说明过去几十年行业基本沿着同一条技术路线前进。但随着晶体管关键结构逐渐接近原子尺度，量子隧穿、漏电、发热、制造精度等问题变得更加突出，继续缩小尺寸的难度越来越大。另一方面，每一代先进制程的突破，都可能涉及光刻机、刻蚀机、厂房、材料及配套工艺的升级，需要投入极其庞大的资金。作者认为，当一条技术路线的边际收益不断下降，而投入成本持续增加时，就有必要寻找新的发展方向，而不是继续沿着原有道路硬拼。

### 2. 韬定律的核心：从几何缩微转向时间缩微
摩尔定律主要关注晶体管集成数量的增长，而韬定律将缩短信号传播和任务执行时间作为技术演进的核心目标。
华为提出的韬定律，正式名称为韬（τ）定律（Tau Scaling Law，时间缩微定律），其核心思想是系统性降低电子系统各个层级的特征时间常数τ。传统路径主要通过缩小器件尺寸、提高集成密度来改善性能，而新路径则可以通过缩短互连距离、优化电路结构、提升数据传输效率、逻辑折叠等方式实现性能增长。视频作者将其概括为“不再单纯追求把芯片做得更小，而是让信号跑得更快”。需要注意的是，这里的“更快”主要指降低信号传播时延和任务完成时间，并不是改变电磁信号传播的物理极限。2026年5月25日，华为半导体业务部总裁何庭波在上海举行的国际电路与系统研讨会（IEEE ISCAS 2026）上正式发表了这一技术演进原则。

### 3. 用城市交通理解芯片：不再只缩小城市，而是重新设计交通网络
为了让普通人理解复杂的芯片技术，作者将芯片比作一座城市，将芯片内部的信号传输比作城市中的交通运输。过去的办法相当于不断缩小城市面积，让各个建筑之间的距离越来越短，从而减少出行所需的时间，但城市不可能无限缩小。韬定律所代表的思路，则类似于在城市中建设高架桥、地下快速路和立体交通网络，让交通不再局限于同一个平面。对应到芯片技术，就是通过三维集成（3D Integration）、逻辑折叠（Logic Folding）等技术，将部分原本需要在平面上进行的长距离信号传输，转化为更短的互连路径。作者借此强调，提高效率不一定要压缩空间，也可以通过重新组织空间和优化连接方式实现。

### 4. 韬定律有望降低对先进制程和昂贵制造设备的依赖
作者认为，韬定律最直接的经济价值就是节省成本，因为如果芯片性能的提升不再完全依赖制程升级，就可以提高现有产线和设备的利用价值。视频举例称，已有的14纳米、7纳米产线可能继续发挥作用，并通过系统设计、立体堆叠等手段，获得原本需要更先进制程才能实现的部分性能表现。相比于重新建设先进晶圆厂、购置新设备、开发新材料和工艺，这种路径有机会减少部分资本开支，同时降低对特定海外先进设备的依赖。不过，三维集成本身也会产生先进封装、混合键合、散热、良率控制等方面的新成本，并不是完全没有技术门槛。尤其需要区分，利用成熟制程实现接近先进制程的某些性能指标，不等于将14纳米或7纳米的实际制造工艺直接升级成5纳米工艺。

### 5. 华为不是停留在理论和PPT阶段，而是已经积累了六年的产业实践
视频中最值得关注的一组数据，是华为已经基于相关技术思路进行了六年实践，并成功设计和量产了381款芯片。作者强调，这些芯片并非只应用于单一产品，而是覆盖了手机、人工智能、服务器、汽车、通信基站等多个领域。按照华为公开披露的信息，这些实践的时间范围为2020年5月至2026年5月，涉及移动设备、AI、汽车、工业和基础设施等市场。

### 6. 美国的供应链限制促使华为寻找不同于传统路线的突破口
视频将韬定律放在中美科技竞争和全球半导体供应链分工的大背景下进行分析，认为美国能够实施技术限制，与先进芯片产业高度依赖跨国协作有关。半导体产业涉及芯片设计软件、知识产权、光刻设备、制造设备、材料、晶圆制造和先进封装等多个环节，其中部分关键技术和设备集中在少数国家和企业手中。如果华为完全沿着原有先进制程路线发展，就可能持续受到部分关键设备和技术获取条件的限制。韬定律提供的另一种思路，是将研发资源更多地投入芯片设计、互连优化、封装集成和系统协同等方向，尽可能利用能够获取的制造资源实现性能提升。作者将这种策略理解为从被动追赶转向主动寻找新赛道，但这种技术路线仍需要产业链共同发展，并不意味着所有外部技术限制都已失去作用。

### 7. 芯片产业的竞争可能从单纯的制程竞争转向系统级竞争
作者在视频中提到，有外部人士认为华为将竞争的战场从“拼纳米”转变为“拼系统”，并将其评价为一种非常高明的战略。传统芯片竞争中，制程节点通常被视为衡量技术先进性的重要指标，但对于最终用户而言，真正影响体验的是任务完成速度、功耗、成本、系统稳定性以及整体性能。如果一家公司能够通过架构设计、存储优化、高速互连、先进封装和软硬件协同实现更高的系统效率，就可能在某些应用场景中弥补制造制程方面的差距。特别是在AI计算和服务器领域，单颗芯片的性能只是决定整个计算系统效率的因素之一，芯片之间的数据通信和系统资源调度同样重要。因此，韬定律的战略价值不仅是提出某项具体技术，还在于尝试改变产业衡量技术进步的方式。

### 8. 国内外媒体的关注与网络争议，反映出技术问题被赋予了更多情绪和立场
视频开头提到，一位未具名博主在多个平台发布有关韬定律的内容后，遭到了大量网友的批评和围攻，这也是作者制作这段视频的直接原因。作者列举了路透社（Reuters）、彭博社（Bloomberg）、国际投行以及学术界人士，并提到人民日报、新华社、侠客岛等国内媒体，试图说明韬定律已经受到广泛关注。作者不理解为什么部分国内网友对华为的技术创新持否定态度，并认为部分反对意见可能源于对华为的既有偏见，而非对技术本身的分析。不过，视频没有提供相关博主的姓名、具体评论内容，也没有给出其转述的国际投行评价的完整出处，因此无法据此判断所有质疑者的动机。实际上，路透社的报道既认可这一路径具有潜在价值，也保留了其能否真正成为重大技术突破的疑问，这说明受到国际关注、获得积极评价与形成行业共识，是三个不同层次的概念。

### 9. 创新的重要价值在于重新定义问题，而不只是沿着旧路径追赶
视频最后将华为的技术选择上升到思维方式和创新哲学的层面，认为当一条道路走不通时，不应该只想着如何突破眼前障碍，还应该思考能否改变实现目标的方式。作者用“东方智慧是换路的”来概括这一思想，并借用水和“道”的意象，强调顺势而为、灵活变化、绕开障碍的重要性。在这个案例中，真正的目标是提高芯片与电子系统的性能，而缩小晶体管尺寸只是实现目标的手段之一，两者不能混为一谈。即使三维堆叠、先进封装、高速互连等技术在国际上早已有研究和应用，将这些技术系统性组织起来并形成新的工程优化框架，仍然可能具有创新价值。不过，将不同技术选择简单归因于中西方文化和思维方式的差异，容易忽略全球半导体产业长期以来在多种技术路线上的共同探索。

### 二、摩尔定律与韬定律的核心区别

| 对比维度 | 摩尔定律主导的传统路线 | 韬定律提出的新路线 |
| --- | --- | --- |
| 英文名称 | Moore’s Law | Tau Scaling Law |
| 核心方向 | 几何缩微 | 时间缩微 |
| 主要关注指标 | 晶体管数量、集成密度 | 特征时间常数、系统时延 |
| 主要技术思路 | 缩小器件尺寸 | 缩短关键路径、优化互连和系统 |
| 性能提升方式 | 更先进的制造工艺与更高集成度 | 多层级工程优化与系统协同 |
| 城市交通比喻 | 缩小城市、缩短距离 | 建设高架桥、地下快速路 |
| 关键技术 | 光刻、晶体管结构、先进制程等 | 逻辑折叠、三维集成、高速互连等 |

### 四、关键技术术语

| 技术术语 | 中文解释 |
| --- | --- |
| Moore’s Law（摩尔定律） | 对集成电路晶体管数量长期增长趋势的经验性总结 |
| Tau Scaling Law（韬定律） | 以降低多层级电子系统特征时间常数为目标的技术演进原则 |
| Geometric Scaling（几何缩微） | 通过缩小器件及相关结构尺寸推动技术进步 |
| Time Scaling（时间缩微） | 通过降低传播时延和任务响应时间提升电子系统性能 |
| Transistor（晶体管） | 现代芯片中实现开关、放大及逻辑运算的基础电子器件 |
| Logic Folding（逻辑折叠） | 通过立体化逻辑布局等方式缩短关键互连路径的技术 |
| 3D Integration（三维集成） | 在垂直方向上集成多个器件层或芯片层 |
| Advanced Packaging（先进封装） | 通过高密度互连、多芯片集成等方式提升芯片整体能力 |
| Hybrid Bonding（混合键合） | 实现高密度、短距离层间连接的一类键合技术 |
| Latency（时延） | 信号传播、数据传输或任务完成所需要的时间 |
| System-level Optimization（系统级优化） | 从计算、存储、通信、软件和硬件等多个层面提高整体效率 |

## 值得记住的点 / 行动建议
视频没有提出具体的个人操作步骤，以下是从作者的技术解读和创新思路中提炼出的可迁移方法。

### 1. 遇到难以突破的瓶颈时，首先区分目标和手段
华为案例中最值得学习的地方，是重新思考什么才是真正需要解决的问题。
半导体产业最终要实现的是更高的计算能力、更短的响应时间、更低的功耗以及合理的成本，而不是单纯追求一个更小的纳米数字。
如果把过去行之有效的技术手段误认为最终目标，就可能陷入路径依赖，即使原有方法越来越昂贵、越来越难以实施，也仍然坚持使用。
这一思路可以应用到很多领域：

| 场景 | 容易陷入的路径依赖 | 可以重新思考的方向 |
| --- | --- | --- |
| 企业经营 | 不断增加销售人员 | 提高客户转化率、复购率 |
| 工作效率 | 延长工作时间 | 优化流程、消除重复劳动 |
| 学习知识 | 不断增加学习时长 | 提高理解深度和知识调用效率 |
| 软件开发 | 不断升级服务器 | 优化算法、缓存和系统架构 |
| 创业竞争 | 模仿行业头部企业 | 寻找尚未被满足的细分需求 |
| 产品研发 | 不断堆叠硬件参数 | 改善用户实际体验 |

遇到瓶颈时，可以先问自己：我现在究竟是在解决问题，还是在执着于某一种解决问题的方法？

### 2. 当局部优化接近极限时，尝试从整个系统寻找突破口
一个系统的性能并不完全由某一个部件决定。
对于芯片而言，即使计算单元速度很快，如果数据需要花费大量时间在计算单元、存储单元和其他芯片之间传输，整体性能依然可能受到限制。
因此，不应该只盯着单项技术参数，而应该识别整个系统中最影响结果的瓶颈，并针对瓶颈实施优化。
例如，一家公司经营效率低下，不一定是员工不够努力，也可能是审批流程过长、部门之间信息不畅、目标反复变化或者资源分配不合理。
从系统角度解决问题，往往比单纯要求某个环节更加努力更有效。

### 3. 重视资源利用效率，而不是盲目追求最高配置
视频反复强调已有产线能够继续发挥作用，这背后体现的是一种提高存量资源利用效率的思路。
现实中，很多个人和企业面对发展问题时，首先想到的是增加投入、购买设备、扩大团队或者升级配置，而不是充分挖掘现有资源的潜力。
如果能够通过重新组合资源、改变工作流程、优化产品架构，以较低成本获得接近的结果，那么这种创新就可能拥有更好的经济性。
在实际决策中，应当比较不同方案的完整成本，包括前期投资、维护成本、使用寿命、实际收益、实施风险及后续扩展能力，而不能只比较单项性能指标。

### 4. 评价技术创新，要区分概念、原型、量产和商业价值
视频作者特别强调华为六年时间和381款量产芯片的实践经历，这提醒我们：判断一项技术是否真正有价值，不能只看发布会上的描述，还应考察其实际应用程度。
可以使用以下框架来判断一项新技术的发展阶段。
01

概念提出
是否明确说明要解决什么问题？

02

理论与实验验证
是否有论文、实验结果和可解释的技术原理？

03

工程原型
是否能够制造出具备预期功能的实际产品？

04

规模化量产
是否具备稳定良率、可靠性和生产能力？

05

商业应用
是否有真实客户、使用需求和经济价值？

06

产业普及
是否能够被更多企业采用，并形成可持续的产业生态？

华为披露的381款芯片，是评估相关技术实践的重要信息，但对最新技术方案的性能和经济性，仍然需要根据具体产品、测试数据以及后续商业表现进行判断。

### 5. 不要把技术领先程度简单等同于制程数字
对于普通消费者而言，购买手机、电脑等电子产品时，没有必要将芯片采用多少纳米制程作为唯一判断标准。
制程先进性确实会影响集成密度、功耗和性能潜力，但最终产品表现还受到处理器架构、缓存设计、软件优化、散热能力、功耗管理等因素的影响。
例如，两款采用不同制程的手机芯片，在某些应用中的实际流畅度、续航时间和持续性能，未必完全按照制程数字排序。
同样，在AI计算领域，也不能只比较单颗芯片的理论算力，还应关注计算集群规模、通信带宽、存储容量、实际任务吞吐量及单位能耗下的有效计算能力。

### 6. 面对外部限制，寻找替代路径可能比正面竞争更有效
如果竞争对手在某个领域拥有数十年的技术积累、庞大的资本投入和成熟的供应链，那么直接在对方最有优势的维度进行竞争，成本可能非常高。
华为案例启发我们，可以尝试寻找其他技术维度，通过自身擅长的能力重新组合资源，建立差异化竞争优势。
对于创业者、小企业或者资源有限的个人来说，也不一定要复制领先者的发展路径。
与其在资金、规模、品牌知名度等方面与大企业直接竞争，不如寻找特定细分市场、独特需求、效率优势或服务差异化机会。
其本质是：目标可以相同，但实现目标的路径不必相同。

### 7. 对创新既要保持开放，也要保留科学质疑
支持一家企业的技术创新，并不意味着必须无条件接受其所有宣传和预测；同样，对新技术提出合理疑问，也不代表否定企业的全部研发成果。
面对韬定律这样的新技术原则，应重点关注以下几个问题：
- 是否提出了明确、可测量、可验证的技术目标？
- 相比已有三维集成和先进封装方案，具体创新在哪里？
- 芯片实际性能、功耗、面积、成本和良率发生了怎样的变化？
- 是否能够在不同类型的芯片和电子系统中持续发挥作用？
- 长期技术路线图是否能够兑现？
- 是否能够形成开放、可扩展的产业生态？

真正有价值的技术讨论，应当围绕这些可以通过数据和工程实践验证的问题展开，而不是仅仅讨论支持谁、反对谁。
