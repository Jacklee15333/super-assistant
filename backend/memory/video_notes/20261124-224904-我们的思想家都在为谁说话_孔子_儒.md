## 核心观点

### 1. 争论的起点：孔子和老子是否始终站在统治者的立场思考问题？
视频开头被引用的国学研究者认为，中国最伟大的两位思想家——孔子和老子，都是从如何成为一个好的统治者出发来思考社会问题的。
他认为，孔子所关注的核心概念是“君子”，“君子”早期具有君主之子、贵族阶层成员等身份含义，到了孔子那里逐渐演变成道德伦理意义上的人格标准，但仍然没有完全脱离统治阶层的视角。孔子强调礼制、仁爱以及“君君、臣臣、父父、子子”的社会关系，本质上是在告诉统治者如何成为一个仁慈、有道德、能够治理好国家的人。
而老子所倡导的“无为而治”，在这位研究者看来，同样是对统治者提出要求，只不过他所理解的好统治者应减少对人民的干预，给予人民更多自主权与自由。
因此，即使孔子和老子都主张保护人民、善待人民，他们的思考位置仍然属于统治者，而不是普通百姓，这就是他所说的“朝廷式占位”。
按照这一逻辑，传统知识分子往往希望通过劝说统治者改善治理，而不是直接从人民自身的权利、利益和主体性出发构建思想体系。

### 2. 作者的根本反驳：儒家思想的底层逻辑是天道与人性，而不是统治权力
视频作者认为，把孔子和老子的思想简单理解为如何帮助统治者治理国家，是对儒家和道家思想的表面化解读。
在作者看来，无论是孔子还是老子，其真正研究的对象都是“天道”，而儒家最底层的核心思想可以概括为“人性即是天道”。作者引用《论语·公冶长》中子贡的话：“夫子之文章，可得而闻也；夫子之言性与天道，不可得而闻也。”
他将这段话解释为，孔子的言行、教导以及外在的礼仪规范比较容易被人理解，但关于人性和天道的深层哲学，并不是普通人能够轻易领悟的。孔子因此需要通过言传身教、日常实践和逐步教化，让人们慢慢体会这些思想，而不是仅仅传授一套抽象的哲学理论。
作者认为，如果只看到儒家对君臣关系、父子关系和社会秩序的规定，却没有看到其背后对人类本性的理解，就容易误以为儒家是一套单纯服务于政治统治的规则体系。
不过，“人性即是天道”是视频作者对儒家思想的个人概括，并非孔子在《论语》中的直接原话。

### 3. 仁义孝信不是外界强加的道德规范，而是人类本性的自然表现
作者认为，人本来就具有善良、同情、正义、诚实以及关爱亲人的倾向，这些品质并不是孔子发明出来并要求所有人遵守的。
视频通过多个具体事例说明这一观点：

| 人的自然反应 | 对应的儒家道德概念 |
| --- | --- |
| 看到孩子在井边面临危险，会下意识伸手救助 | 仁 |
| 看到不公平、不正义的事情，会本能地产生愤怒 | 义 |
| 在没有外部压力的情况下，愿意诚实守信 | 信 |
| 对父母、兄弟具有天然的亲近、关爱和恭敬之情 | 孝、悌 |
| 不喜欢混乱，希望生活具有一定秩序 | 对礼与秩序的内在需求 |

其中，孩子在井边遇险的例子，与《孟子·公孙丑上》中著名的“孺子将入于井”思想实验相呼应，其核心是人看到他人遭遇危险时，会产生自发的恻隐之心，而不一定是为了获得利益、名声或社会认可。
作者认为，这些道德品质属于天赋予人的本源属性，只不过随着成长，人可能受到环境、利益、自私欲望等因素的干扰，逐渐偏离原来的本性。
因此，在作者的理解框架中，儒家教育不是凭空制造道德，而是帮助人恢复原本具有的道德能力。
道德不是从外部植入的东西，而是需要从人的内部重新发现的东西。 这是理解整段视频的重要前提。

### 4. 孔子向统治者传播思想，不代表孔子的思想是为了统治者服务
针对孔子为什么经常向君主和统治阶层传播自己的思想，作者提出了一个重要区分：思想的传播对象，不等于思想所代表的利益立场。
作者认为，在孔子所处的历史环境下，他不可能逐一向所有普通百姓讲授自己的思想，因此，通过影响统治者，再由统治者自上而下地进行社会教化，是一种现实的思想传播路径。
孔子之所以希望统治者修身、行仁、遵循礼仪，并不是单纯为了帮助他们巩固权力，而是为了要求掌握权力的人遵守比权力本身更高的道德原则。
按照作者的理解，统治者并不是因为拥有权力，所以天然正确；恰恰相反，统治者必须顺应天道、遵循人性、具备仁德，才有资格承担治理社会的责任。
因此，孔子向统治者提出道德要求，可以被理解为对权力的约束，而不是无条件地为权力辩护。
这一观点试图把“通过统治者实践思想”和“站在统治者立场构建思想”区分开来，但两者之间究竟存在怎样的历史联系，仍然需要结合孔子的政治思想与当时的社会制度进一步讨论。

### 5. 社会秩序并不必然意味着压迫，因为人本身就需要稳定与秩序
作者不认同把儒家强调的社会秩序直接等同于对人性的束缚，认为人类本身就不喜欢长期处于混乱、不稳定和不可预测的环境中。
他甚至以动物世界为例，指出动物也存在领地意识和一定的群体秩序，从而说明秩序并非完全由人类社会的政治权力人为创造。
对于人类而言，稳定的生活环境、相对明确的社会关系以及可以预期的行为规则，有助于生存、繁衍与发展，这也是社会需要秩序的原因。
按照作者的逻辑，孔子倡导礼制的目的并不是单纯追求社会“维稳”，而是通过建立符合人性的社会关系，让社会进入相对和谐的状态。
因此，他认为仁义礼智信并不是圣人随意设计出来的条条框框，而是试图将人内在的道德倾向转化为现实生活中的行为方式。
但这里仍然需要区分两个问题：人类普遍需要一定的社会秩序，并不意味着任何一种具体的等级制度、礼仪规范和权力关系都天然合理。

### 6. 黑格尔对儒家的理解，以及中西方思想传播中的语言障碍
视频作者提到德国哲学家黑格尔（Georg Wilhelm Friedrich Hegel），认为黑格尔及部分西方思想家主要看到了儒家的伦理规范和社会秩序，却没有深入理解其背后的人性哲学与天道观。
作者认为，如果将儒家的“君君、臣臣、父父、子子”仅仅理解为规定每个人社会身份和行为义务的一套规则，就很容易得出儒家限制个人自由、束缚人性的结论。
但在作者看来，仁义礼智信只是内在道德本性的外在表现，理解儒家不能止步于这些规范本身，而应继续追问这些规范试图实现怎样的人格状态。
他进一步将这种理解差异归因于中西方语言、文字和文化背景的不同，认为通过表音文字翻译中国传统哲学概念时，可能无法充分传达其中深层的文化内涵。
作者甚至提出，中国人往往能够较为准确地理解外国思想，甚至进一步丰富其内涵，而外国人理解中国思想时却容易停留在表面。
这一判断体现了作者对中国传统哲学独特性的强调，但跨文化误读并非单向存在，语言类型也不能单独决定一个人理解哲学思想的深度。

### 7. 孝道不是孔子发明的，而是人对父母亲情的自然延伸
作者特别回应了当代社会中批评孝道、反对儒家伦理的现象，认为有些人把孝道误解成了传统社会强行施加给子女的义务。
在他看来，人对父母的亲近、关爱和尊敬，本来就是人类具有的自然情感，即使没有孔子、没有儒家思想，人们也可能产生这些行为。
作者举例说，外国文化中虽然不一定存在与中国传统“孝道”完全对应的概念，但外国人同样会爱自己的父母、尊敬自己的长辈，这说明关爱父母并不是儒家文化独有的道德发明。
孔子的作用，是把人类本来就存在的亲情和道德情感加以总结、提炼，并通过教育帮助人们重新认识这些情感，而不是凭空制定一套要求子女服从父母的规则。
因此，作者甚至认为，一些人对孝道的全面否定，实际上是在否定自己原本具有的善良本性。
不过，这一论证主要是在为自然亲情和合理的孝道辩护，并没有充分回应现实中以孝道为名进行道德绑架、要求子女无条件服从父母等问题，而后者也是当代孝道争议的重要来源。

### 8. 孔子的最高修身境界，是从遵守外部规则走向内在的道德自觉
作者引用孔子在《论语·为政》中的名言“从心所欲，不逾矩”，用来说明儒家修身思想的最终目的并不是让人永远受到规矩约束。
孔子这句话的完整语境是“七十而从心所欲，不逾矩”，意思是经过长期的学习、反思和人格修养之后，一个人可以按照自己的内心意愿行事，却自然不会超越合理的行为规范。
在作者看来，这说明孔子已经真正回归了人的本来面目，他的内心意愿与道德原则达到了统一，因此不再需要依靠外在的强制力来约束自己。
普通人可能需要通过规则提醒自己不要欺骗、伤害别人，但真正具有道德自觉的人，不需要反复克制自己才做到诚实和善良，因为这些行为已经成为其人格的一部分。
由此，作者试图说明，儒家的最高境界不是压抑自我，而是让个人的内在自由与道德秩序实现协调。
这一思想可以理解为从“他律”到“自律”，再到“道德自觉”的过程：最初需要外部规则进行引导，最终则能够依靠内在的判断和人格修养自主行动。

### 9. 王阳明的“致良知”与孔子的修身思想一脉相承，但作者不认同程朱理学的教条化倾向
视频作者进一步提到明代思想家王阳明，认为王阳明所倡导的“致良知”，与自己所理解的孔子思想具有高度一致性。
所谓“良知”，在这一思想框架中，并不是通过外部教育从零开始获得的知识，而是人自身原本具有的辨别善恶、认识是非的道德能力。
作者借用生活中常见的说法“你良心发现了”，形象地解释这一逻辑：之所以叫“发现”，是因为良心本来就存在，只不过此前可能被自私、利益或者其他外部因素遮蔽了。
因此，无论是孔子的修身，还是王阳明的致良知，按照作者的理解，其核心都是帮助人清除遮蔽、恢复本心，而不是把某种外在规范强行植入人的内心。
与此同时，作者明确表示，自己的理解并不是程朱理学，也不认同通常被概括为“存天理，灭人欲”的思想表达，认为程朱理学过于死板和教条，并强调孔子从未提出过“灭人欲”这一主张。
这说明作者并不是无条件接受儒家历史发展过程中形成的所有学说，而是试图区分孔子的原始思想、后世儒学的不同发展路径，以及后来可能出现的教条化解释。

### 10. 对传统文化、历史和国家的情感，被作者视为尚未受到污染的本性
视频最后，作者将关于人性、天道和良知的讨论延伸到了当代社会的文化认同与爱国情感。
他提到，有些人会直接表达“我就是爱国，你爱咋咋地”，并且在看到自己认为属于抹黑国家历史、攻击传统孝道的言论时产生愤怒。
作者认为，这些情绪反映了一个人仍然保有对自身文化、家庭、国家以及共同体的自然情感，没有完全被自私、冷漠等后天因素所污染。
按照作者建立的思想体系，对不公正现象的愤怒属于“义”的表现，而对家庭和文化共同体的关爱，也可以被理解为人的本性在不同社会关系中的延伸。
因此，他鼓励具有这些情感的人继续保持，不要因为外界对传统文化的批评而轻易否定自身的道德感受。
不过，从自然亲情、恻隐之心推导到具体的国家认同和历史判断，中间仍然存在需要论证的环节；真诚的情感值得尊重，但情感的强烈程度本身并不能证明某个具体观点一定正确。

视频开头的国学研究者将其理解为统治视角下的社会秩序，而视频作者则强调，这些规范应建立在符合人性与道德原则的基础上。
③《孟子·公孙丑上》：关于恻隐之心
今人乍见孺子将入于井，皆有怵惕恻隐之心。

孟子借助孩子即将掉入井中的情境，说明人可能在没有进行利益计算之前，就已经产生了惊惧、同情和救助他人的冲动。
这一案例是视频中“善良源于人的本性”最具代表性的思想依据。
与此相关的孟子“四端”思想是：

| 人的内在道德倾向 | 对应的道德品质 |
| --- | --- |
| 恻隐之心 | 仁之端 |
| 羞恶之心 | 义之端 |
| 辞让之心 | 礼之端 |
| 是非之心 | 智之端 |

“四端”是与视频主题相关的经典背景补充，并非作者在视频中完整列举的内容。
④《论语·为政》：关于孔子的人生修养阶段
吾十有五而志于学，三十而立，四十而不惑，五十而知天命，六十而耳顺，七十而从心所欲，不逾矩。

其中包含了孔子对自身人生修养过程的总结：

| 年龄 | 修养阶段 |
| --- | --- |
| 15岁 | 志于学 |
| 30岁 | 而立 |
| 40岁 | 不惑 |
| 50岁 | 知天命 |
| 60岁 | 耳顺 |
| 70岁 | 从心所欲，不逾矩 |

视频重点引用的是最后一个阶段，完整年龄序列为帮助理解经典语境而补充。
作者认为，七十岁时的孔子已经实现了内在意愿和道德原则的高度统一，因此能够自由行动而不违反合理的规范。

## 金句摘录
以下摘录保留视频原话的主要表达，仅对明显的语音识别错误、标点和个别口语进行校正。

### 1. 关于儒家的思想根源
“无论孔子还是老子，研究的都是天道。孔子或者说是儒家，最底层的核心思想是，人性即是天道。”

这句话是作者全部论证的理论起点，也是他反驳“朝廷式占位”观点的核心依据。

### 2. 关于善良与道德本性
“人本来就是善的。看到一个孩子在井边有危险，不用思考，他就会去拉住他，人本来就是这个样子的。”

作者强调，真正的善良往往并不来自外部要求或者利益计算，而可能来自人内在的道德直觉。

### 3. 关于道德与统治权力的关系
“孔子不是站在统治者的角度，思考如何维稳，而是站在天道与人性本身的角度，告诉统治者，你只有顺应天道，修身行仁，才配统治，天下才会安宁。”

作者将儒家的仁德要求理解为对统治权力施加的道德约束，而不是单纯为权力提供合法性。

### 4. 关于规则与恢复本性
“事实上儒家所有的条条框框，在你看来是束缚，其实都是在让你回归本来的样子。”

这句话集中体现了作者对于儒家礼仪、伦理和道德规范的理解：规范是修身的手段，而不是最终目的。

### 5. 关于良知的存在
“有的时候我们开玩笑说，你良心发现了。这就是说你本来就有良心，你现在发现了。”

作者使用一个非常日常的表达解释王阳明的“致良知”，将抽象的心学思想转化为普通人能够理解的生活经验。

### 6. 关于孔子与后世儒学的区别
“我这不是什么程朱理学，这只是我个人的理解。我也不喜欢灭人欲，程朱理学太死板教条，孔子也从来没说过要灭人欲。”

这句话说明作者并不是笼统地维护所有儒家思想，而是在儒家内部进行区分，强调自己对孔子思想的理解不同于后世的某些理学解释。

## 值得记住的点 / 行动建议
视频本身主要是哲学观点辩论，并没有提供系统性的行动清单。以下是从作者的论述中提炼出的实践启发，同时补充必要的判断边界。

### 1. 区分一个人的说话对象、思考立场与实际利益取向
判断一个思想家究竟在为谁说话，不能仅仅看他在向谁传播思想。
孔子向统治者讲仁政、礼制与修身，并不能单凭这一事实就认定他只为统治者服务；同样，也不能仅仅因为他要求统治者善待人民，就认定他的全部思想都代表普通百姓的利益。
在阅读政治思想、商业观点、社会评论或者历史人物言论时，可以分别思考：他说话的对象是谁、他所关心的问题是什么、他的主张由谁执行、最终受益者是谁，以及他的思想在现实中会产生什么影响。
这种分析方式比简单判断某人属于哪个阶层、站在哪个阵营更有深度，也能避免将传播方式与价值立场混为一谈。

### 2. 理解思想体系时，不要只记住表面的规则，更要追问背后的原理
作者对传统儒学研究者最大的批评，就是只看到了礼仪、等级、君臣关系等外在规范，却忽略了这些规范背后的哲学目的。
学习一个思想体系时，应当区分它的底层假设、核心价值、实现方法和现实表现。
以儒家为例，人性与道德是哲学层面，仁义礼智信是价值层面，修身与教化是实践层面，而君臣父子关系及社会制度则属于具体的社会应用层面。
不同层次之间存在联系，却不能简单地画等号；尤其不能把某个历史时期的具体制度直接视为整个思想体系的唯一内涵。
这种方法也适用于学习现代管理学、经济学、心理学和其他哲学流派：不要只记住别人要求你怎么做，而要弄明白他为什么认为应该这么做。

### 3. 将道德修养从被动遵守规则转化为主动的内在选择
作者对“从心所欲，不逾矩”的解释，提供了一种理解自律和人格成长的方式。
一个人真正的修养，并不一定体现为他能够背诵多少道德规范，而在于没有人监督、没有奖惩机制、甚至可以通过不道德行为获得利益时，他依然愿意选择正确的行为。
例如，在没有人发现的情况下是否仍然愿意诚实，在自己的利益与他人的权益发生冲突时是否能够考虑公平，以及在拥有权力后是否仍然尊重别人。
可以通过日常反省来培养这种能力：回顾自己一天中的重要决定，思考自己是出于恐惧、利益、虚荣、社会压力，还是出于真正认可的价值原则而行动。
长期而言，值得追求的不只是表面的守规矩，而是让正确的行为逐渐成为稳定的人格习惯。

### 4. 善用“良知”进行自我反省，但不要把所有直觉都当成真理
王阳明的“致良知”以及作者所说的“良心发现”，提醒我们，人不一定需要等到别人批评之后，才开始认识自己的错误。
当自己做出某种选择时，如果内心已经意识到这个行为可能伤害别人、违背承诺或者不符合公平原则，就值得认真对待这种道德上的不安。
可以进一步追问：如果这件事情发生在我身上，我是否愿意接受？如果我没有利益牵涉，我还会做出同样的判断吗？如果所有人都这样做，后果是否可以接受？
不过，人的直觉同样可能受到偏见、群体认同、情绪和成长环境影响，因此道德直觉不能完全替代理性分析、事实核查和对他人处境的理解。
真正有价值的良知，应当能够经得起反思，而不仅仅是对自己原有立场的确认。

### 5. 区分自然亲情、合理孝道与无条件服从
作者用外国人同样关爱父母的例子说明，亲情具有跨文化的普遍基础，这一点有助于避免将所有孝道观念都理解为封建压迫。
在现实生活中，合理的孝道可以体现在关心父母的健康、尊重父母的人格、在能力范围内提供照顾、保持沟通，以及对父母曾经付出的关怀给予回应。
但关爱父母并不意味着必须放弃自己的职业选择、婚姻自由、财务独立和个人生活边界，也不意味着需要接受伤害或者不合理的要求。
批评愚孝、道德绑架以及绝对服从，与否定亲情本身，是两件不同的事情。
更成熟的家庭伦理，应当在亲情、责任、尊重、自主权和相互理解之间建立平衡，而不是在盲目服从与彻底否定传统之间进行二选一。

### 6. 理解社会需要秩序，但不要把秩序本身当成最高价值
作者强调，人类需要相对稳定的社会环境才能生存和发展，这是理解社会规则必要性的一个重要角度。
没有基本的公共秩序，人与人之间难以建立信任，合作成本会增加，普通人的生活也会面临更多不确定性。
但评价一套秩序是否合理，除了考虑它能否维持稳定，还应该考虑它是否公平、是否尊重个人权利、是否能够约束掌握权力的人，以及是否允许纠错和改进。
如果一种秩序只要求弱势群体服从，却不要求强势群体承担相应责任，那么即使它能够维持某种稳定，也不一定符合正义原则。
因此，真正值得追求的不是单纯的秩序，而是兼顾稳定、公平、尊严与自由的合理秩序。

### 7. 阅读传统文化时，要区分原始思想、后世发展与现实应用
视频作者明确表示不喜欢程朱理学中的某些观念，这一点提示我们，儒家不是一个两千多年始终保持不变、内部完全统一的思想体系。
孔子、孟子、荀子、程颢、程颐、朱熹、王阳明等人虽然都与儒学有关，但他们对于人性、天理、欲望、知识和道德修养的理解存在明显差异。
例如，孟子强调性善，荀子强调人的自然欲求需要礼义教化，王阳明强调心与良知，而程朱理学则有自己关于天理、格物和修养的系统论述。
因此，不能把某个后世思想家的观点直接归到孔子身上，也不能因为历史上某种制度借用了儒家名义，就认定那种制度完整代表了儒家的全部精神。
同样，也不能因为孔子的思想具有积极的道德内涵，就否认后世儒家规范曾经产生的负面社会影响。

### 8. 直接阅读经典原文，避免完全依赖二手解读
视频中的许多争议，都涉及如何理解“君子”“天道”“仁”“礼”“良知”等概念。
不同思想者可能基于不同的价值立场，对同一段经典作出截然不同的解释；仅仅观看一个国学博主或者听取某位专家的总结，并不足以完整理解这些思想。
如果希望进一步研究这次争论，可以按照以下顺序阅读：

| 推荐阅读 | 重点关注的问题 |
| --- | --- |
| 《论语》 | 孔子的仁、礼、君子、修身及政治伦理 |
| 《孟子》 | 性善论、四端、仁政、民本思想 |
| 《荀子》 | 性恶论、礼义教化，以及对人性的不同理解 |
| 《道德经》 | 天道、自然、无为而治、统治者的行为边界 |
| 《大学》 | 修身、齐家、治国、平天下之间的逻辑 |
| 《中庸》 | 天命、性、道、教之间的关系 |
| 《传习录》 | 王阳明的致良知、知行合一与心学思想 |

尤其建议对照阅读孟子与荀子，因为两者对人性的不同解释，能够帮助读者跳出视频中相对单一的性善论框架。
另外，孟子的“民为贵，社稷次之，君为轻”，以及《论语》中“君使臣以礼，臣事君以忠”等内容，也可以作为进一步研究儒家究竟如何理解人民、统治者及其相互责任的材料。

### 9. 保持文化认同，但不要将文化批评等同于道德败坏
作者鼓励人们保持对自身文化、国家历史和传统伦理的自然感情，这种文化归属感可以为个人提供身份认同、精神支持和价值来源。
但是，一个人认同自己的文化，并不意味着必须认为这种文化中的所有传统、制度和历史事件都是正确的。
同样，一个人批评某些传统习俗、历史制度或者思想观念，也不意味着他必然缺乏良知、不爱自己的国家，或者受到了所谓的思想污染。
遇到涉及历史和文化的争议时，应当区分事实判断、价值判断和情感表达，首先核查对方所说的事实是否准确，再判断其论证是否合理。
健康而有韧性的文化认同，不仅能够发现自身文化的优点，也能够正视其历史局限，并通过反思促进文化的发展。

## 我的点评
第一，视频最有价值的地方，是区分了思想的传播对象与思想的价值立场，并提醒我们不能仅凭儒家具有政治治理功能，就否认其在人格修养、道德哲学和社会伦理方面的丰富内涵。
第二，作者通过恻隐之心、自然亲情、良心发现和“从心所欲，不逾矩”等案例，将抽象的传统哲学转化成日常生活经验，对于理解孟子的性善论和王阳明的心学具有一定启发意义。
第三，作者把“人性本善”“人性即是天道”作为孔子、老子乃至整个儒家思想的统一基础，存在一定的过度概括，因为孔子在《论语》中并未系统提出孟子式的性善论，荀子也持不同的人性观，而道家的天道观与儒家的道德人性观并不能直接等同。
第四，视频强调孔子思想的道德理想，却没有充分讨论儒家伦理在历史政治实践中可能兼具约束权力与维护等级秩序的双重功能，而其对程朱理学“灭人欲”的理解，也需要区分正常的人类需求与理学所批评的过度私欲。
第五，作者将黑格尔对儒家的理解主要归因于语言障碍，并把部分传统文化批评者视为本性受到污染的人，这些判断缺乏充分论证，也容易将思想分歧转化为对不同意见者的道德评价。
第六，对普通人而言，最值得吸收的是儒家关于内在道德自觉、修身、责任与良知的积极思想，同时保持独立思考，既不因为传统文化曾经被权力利用就全盘否定它，也不因为它具有深厚的哲学价值就拒绝对其历史局限进行反思。

好的统治者就是保护人民的自由的统治者，自主的统治者，这是中国最伟大的思想家，孔子 老子。都是从政权的角度来思考问题的，都是把自己内心，摆在统治者的位置来思考问题的，所以这个就是占位的问题。但这个占位，和我们的传统的思维方法，它的占位永远是朝廷式占位，它是占着朝廷教徒考的问题。这种占位传统就是统治者，好的自治分子是希望政府成为一个好的统治者，这么一个占位。但它还是占着统治者，它最多是对着统治者的耳朵说，您如果这么去保护人民的权利，你的power就。

说老子孔子都是站在统治者，站在朝廷的角度去占位的，我个人认为，他就不懂儒家，事实上。无论孔子还是老子研究的都是天道，孔子或者说是儒家，最底层的核心思想是，人性即是天道。子贡曰，夫子之文章可得而文也，夫子之言性与天道不可得而文也，就是说性与天道，不是孔子不说。而是普通人理解不了，所以孔子只能言传神教，慢慢的去渗透，性与天道，就是说人本来就是善的。表现出来的那就是人，看到一个孩子在景边有危险，不用思考，他就会去拉住他，人本来就是这个样子的。

人本来看到不公的事就会愤怒，表现出来的就是义，人本来就是诚实的，表现出来的就是信。人本来对父母兄弟就是亲和公敬的，那表现出来的就是孝弟，这是天赋予人的本源属性。然后因为后天的干扰污染，才让人变得懒惰自私，所以说孔子老子是站在统治者的角度。说话，就是没有真正理解儒家道家的思想本源，人本来就是要有秩序的，就不喜欢混乱，就算是动物的世界。他也是有秩序和领地的，对吧，而孔子之所以要向统治者推销自己的思想，是因为他不可能向每个普通老百姓去讲述。只能通过说服统治者，然后自上而下的去教化民众，所以孔子是真正的知行合一，而无论孔子还是老子。

都不是站在统治者的角度说话，而是天道，现在很多人包括黑格尔都说，儒家就是孔子建立了一套君君臣臣的规矩。束缚人性，对吧，错了，人意理智性只是外在的表现形式，是圣人在洗涤污染，让人回归本性。而黑格尔看到了儒家，因为语言翻译的原因，他只能看到一些条条框框，所以他会认为这不就是一套束缚人的规矩吗。说到这，我又不得不说一句，大家有没有觉得我们理解外国的思想，基本都很精准，甚至还能美化。对吧，而老外理解我们的思想，事物往往都是相差甚远，这就是语言的差距，表音文字翻译。

我们的思想触及不了深度根源灵魂，所以有很多东西他们学不来，学也是个思不想，对吧。那说回来，所以说孔子不是站在统治者的角度，思考如何维稳，而是站在天道与人性本人的角度。告诉统治者，你只有顺应天道，修身行人，才配统治，天下才会安宁，因为人本来就喜欢，也需要稳定。需要秩序，这样才能繁衍发展，还有就是现在有太多的人，对我们的孝道口诛笔吧，骂儒家。那其实是在骂你自己，因为你本来对父母就是孝顺的，天生的，就好比老外，他没有孝道这一说。对吧，但是他们也会爱父母去敬意我，这不就是这个道理吗，人本来就是这个样子的，不是孔子逼着你给你立的规矩。

孔子只是帮你把自私的被污染的心，重新找回来，同理那些职人也是被污染了，对吧，事实上儒家所有的条条框框。在你看来是束缚，其实都是在让你回归本来的样子，这就是人性，即是天道，所以孔子说，其实从心所欲不欲举。就是他真正回到了本来的样子，怎么做怎么对。

他不会认为那些是束缚，后来王阳明的治良之也是这个逻辑，都是一脉相承的，所以有的时候我们开玩笑说。你良心发现了，这就是说你本来就有良心，你现在发现了，对吧，所以我说有些人骂的根本就不是儒家。圣人不会那么肤浅的，另外我要说一点就是，我这不是什么成竹理学，这只是我个人的理解。我也不喜欢灭人欲，成竹理学太死板教条，孔子也从来没说过要灭人欲，所以我认为这位国学大师。根本就没懂儒家，更是看低了孔子，还有我要说，就是我看到很多人说，我就是爱国，你爱咋咋地。

看到抹黑我们历史，攻击孝道的人，我就愤怒，那是因为你还保持着人的本源本性，你没有被污染。你本来就是这个样子的，这就是天道，应该继续保持下去。
