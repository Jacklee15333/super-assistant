## 一句话概括
真正高明的销售，不是每天想着如何把商品推销出去，而是把商品变成有趣、有料、有价值的内容载体，通过传播快乐、获取关注、建立用户关系、占领消费者心智，让人们在真正产生购买需求时，自然而然地想到你，从而实现「不卖而卖」。

## 背景与主题
这段视频围绕销售、短视频内容创作、个人IP打造和流量变现展开，作者分享了一个自己认为是「不传之秘」的销售方法：从自己的职业定位中，把“卖”这个字去掉。
无论是卖鞋、卖衣服、卖伞，还是卖书，都不要把自己的全部注意力放在如何推销商品上，而应该思考如何围绕商品创造有趣的内容。
作者以雨伞为例，并引用网络创作者手工耿制作「无用发明」的案例，说明打破商品原有的功能限制，反而能够获得更多的关注和流量。
这种销售方法的本质，是把商业活动从以成交为中心，转变为以内容、情绪价值、用户关系和需求为中心，先建立长期联系，再寻找合适的商业变现机会。

## 核心观点

### 1. 从职业定位中去掉「卖」字，打破销售的思维限制
作者提出了一个看起来非常简单，却具有深层商业逻辑的方法：把「卖」这个字从自己的字眼里面扣出去。
- 我是卖伞的——去掉「卖」，只剩下伞。
- 我是卖书的——去掉「卖」，只剩下书。
- 我是卖衣服的——去掉「卖」，只剩下衣服。

当一个人把自己定位成销售人员时，他所有的行为都会不自觉地围绕成交展开，例如介绍商品功能、强调价格优势、展示商品质量、催促消费者下单。但是，当他不再把自己局限为销售人员时，商品就不再仅仅是需要出售的库存，也可以成为创作素材、娱乐道具、知识载体和人与人之间建立联系的媒介。去掉「卖」字，实际上就是去掉对短期成交的过度执着，释放自己的创造力。作者认为，只有摆脱这种思维限制，才有可能发现传统销售之外的更多商业机会。

### 2. 人们并不反感商品，而是反感被推销
作者在视频中提出了一个很直接的反问：「你就是卖东西，你就是个推销员，你一出来，谁愿意看你？」
在短视频平台上，用户打开软件的初衷通常是娱乐、学习、放松、获取信息，而不是随时准备购物。如果创作者一出现，就开始介绍商品、宣传优惠、推荐购买，那么即使商品本身不错，也很容易引起用户的防御心理。相比之下，如果创作者能够提供快乐、知识、新鲜感或者情绪价值，用户就拥有了主动观看的理由。这意味着，商家真正需要解决的第一个问题并不是如何成交，而是如何让别人愿意停下来关注自己。
先让别人愿意看你，才有机会让别人认识你、信任你，最终购买你的商品。

### 3. 不再执着于销售之后，商品就有了无限的内容创作空间
作者用雨伞举了一个具体例子：正常情况下，雨伞是用来挡雨的，但如果自己不再时刻想着卖伞，就可以把伞拆掉、改造，甚至反过来用它接雨。
从传统销售角度看，这种行为似乎没有意义，因为它既没有强调雨伞的质量，也没有介绍雨伞的实用性，甚至违背了商品原本的使用目的。但是，从内容传播的角度看，这种反常识的操作能够制造好奇心、意外感和娱乐效果，让观众产生观看兴趣。一把原本只能围绕防雨功能进行宣传的雨伞，因此可以衍生出实验、搞笑、创意改造、生活段子等大量内容。作者强调，当你不再要求每一条内容都必须服务于销售时，你的创作边界就会大幅拓宽。

### 4. 手工耿的「无用发明」证明了趣味本身就是一种价值

手工耿与「无用发明」
通过反常识、脑洞大开、看似没有实际用途的发明，创造娱乐价值和内容吸引力。

作者专门提到了网络创作者手工耿（Handy Geng），指出他经常发明各种看似没有实际用途的东西，却依然有很多人愿意观看。
这个案例揭示了商品的实用价值与内容的传播价值之间的区别：一个东西即使没有实际用途，也可能因为足够有趣而吸引大量关注。观众观看这些内容，并不一定是为了购买发明出来的东西，而是为了满足自己的好奇心、获得快乐，或者欣赏创作者的脑洞。因此，商家不必把自己的内容全部限制在商品功能、产品参数和使用说明之中，而可以借助商品创造独立的娱乐价值。只要商品能够持续出现在有趣的内容中，就有机会在不强行推销的情况下，实现长期的品牌曝光。

### 5. 从提供商品价值，升级为提供情绪价值
作者建议，卖伞的人可以专门拍摄与伞有关的有趣视频，卖书的人也可以围绕书籍创作各种有料、好玩的内容和段子。
这样一来，用户关注你的原因，就不再是自己刚好需要购买某种商品，而是因为你能够给他带来快乐。当用户形成持续观看的习惯时，甚至会主动好奇：「这哥们今天又犯什么病了？可以看一看。」这说明用户的注意力已经从商品本身，延伸到了创作者的人格、创意和内容风格上。相比于单纯的商品买卖关系，这种基于兴趣和情绪价值建立的联系，具有更强的持续性，也更容易形成个人IP。
商品需求不是每天都有，但人们对快乐、娱乐和新鲜感的需求却经常存在。

### 6. 不卖东西的内容，反而能够积累更多商业流量
作者认为，当你的内容有趣、有料、好玩，不再让别人感受到强烈的推销意图时，人们就不会反感你，这样的内容也更有机会获得流量。
传统销售的局限在于，它往往只能吸引当下有购买需求的人，而这部分人在全部潜在用户中只是一个子集。例如，一个晴天不需要买伞的人，通常不会主动观看雨伞促销广告，却可能愿意看一个关于雨伞的搞笑实验。通过内容创作，商家有机会提前接触那些暂时没有购买需求、但未来可能成为消费者的人。这相当于将原本发生在购买时刻的营销行为，转移到了更早、更广泛的日常生活场景中。
短视频营销的目标，因此不必局限于当场成交，还可以是提前获得注意力、积累潜在客户和建立品牌认知。

### 7. 提前占领消费者心智，在需求产生时自然完成转化
作者强调，虽然你平时没有刻意卖伞，但观众一直知道你是卖伞的，当他真正需要雨伞的时候，自然就有可能想起你。
这里涉及一个重要的营销概念：心智占领（Mental Availability，即品牌在相关购买场景中被消费者想起的可能性）。人们产生购买需求时，往往会优先想到那些自己已经认识、熟悉或者拥有一定好感的商家，而不是每次都从零开始寻找。通过持续发布与雨伞相关的内容，创作者实际上是在消费者心中建立「这个人—雨伞」之间的关联。作者的策略并不是消除商业属性，而是避免过早索取商业回报，先在用户心中建立稳定的位置。

### 「不卖而卖」的商业转化路径

### 8. 在消费者最需要的时候销售，而不是任何时候都销售
视频中给出了一个非常具体的变现场景：平时围绕雨伞拍摄各种有趣的短视频，等到下雨的时候，再开一场直播卖伞。
平时不下雨的时候，消费者对雨伞的购买需求可能并不强烈，此时过度宣传很容易变成无效营销。但是到了下雨的时候，消费者的真实需求开始出现，雨伞的实用价值也变得更加明显。如果此前已经通过短视频积累了一批粉丝，并且让大家知道自己是卖伞的，那么此时进行销售就具备了更好的转化条件。这种做法将流量积累与商业转化分开，在不同的阶段完成不同的目标。
平时做内容，需求出现时做销售；平时积累关系，关键时刻实现变现。

### 9. 销售的最高境界，是外在没有销售感，内在却拥有商业逻辑
视频最后，作者借用武侠小说中的剑术境界来比喻销售高手的状态：「手中无剑，心中有剑。」
所谓「手中无剑」，指的是在外在表现上不时刻推销商品，不刻意向用户施加购买压力，也不把每次交流都变成一次交易。所谓「心中有剑」，则是指创作者内心始终清楚自己的商业定位、经营目标、产品属性和最终的变现方式。作者并不是主张彻底放弃销售，而是主张把销售融入内容、信任、关系和需求之中，让它变得自然。真正成熟的商业思维，是既拥有商业目标，又不让商业目标破坏自己为用户创造的价值。
这就是作者所说的「不卖而卖」——在方法上去销售化，在结果上实现商业化。

## 值得记住的点 / 行动建议
以下既包括作者直接提出的方法，也包括基于视频核心思想延伸出的具体执行建议。

### 10. 改变自己的职业定位，从销售者变成价值创造者
不要总是问自己：「我今天应该怎么把商品卖出去？」而应该问：「我今天可以利用这个商品，为别人创造什么价值？」
重新定义自己所从事的行业，可以打开完全不同的内容创作方向。

| 原来的定位 | 可以尝试的新定位 |
| --- | --- |
| 卖书的 | 知识分享者、读书博主 |
| 卖衣服的 | 穿搭博主、审美分享者 |
| 卖伞的 | 创意实验博主、生活观察者 |
| 卖鞋的 | 鞋类测评博主、运动知识分享者 |
| 卖家具的 | 家居设计与生活方式博主 |
| 卖茶叶的 | 茶文化传播者 |
| 卖厨具的 | 美食创作者 |
| 卖电脑的 | 科技知识分享者 |
| 卖护肤品的 | 护肤知识分享者 |
| 卖课程的 | 专业知识传播者 |

不要把自己定义为一个单纯出售商品的人，而是成为能够围绕某个领域持续创造价值的人。

### 11. 做内容之前，先思考用户为什么愿意看
每次准备拍摄视频、写文章、发布社交媒体内容之前，都可以用下面几个问题检验自己的选题：
- 如果用户完全不想买我的商品，他还愿意看这条内容吗？
- 我的内容能不能给别人带来快乐？
- 有没有能够让人感到意外的地方？
- 有没有别人不知道的知识？
- 有没有让人产生共鸣的生活场景？
- 用户看完之后，有没有分享给朋友的理由？
- 去掉商品购买链接之后，这条内容是否依然有价值？

尤其是最后一个问题，非常适合判断一条内容究竟是纯粹的广告，还是具有独立价值的作品。

### 12. 打破商品的传统用途，寻找反常识的内容选题
作者提出用雨伞接雨，本质上就是一种逆向思维（Reverse Thinking）。
如果商品通常被用来做某件事，那么就可以思考它是否能够被用来做完全相反的事，或者放进一个意想不到的场景中。

### 13. 将流量内容与成交内容适当分开

流量型内容

成交型内容

直播、促销、商品推荐

流量型内容负责吸引陌生用户，信任型内容负责建立专业形象，成交型内容负责实现商业回报。
不必机械地遵守上述比例，可以根据行业特征、商品利润、用户反馈和实际销售效果进行调整。

### 14. 理解用户的需求周期，在正确的时间进行销售
视频中下雨时卖伞的案例，可以延伸到非常多的商业场景。

| 商品或服务 | 潜在的销售时机 |
| --- | --- |
| 雨伞 | 雨季、降雨天气 |
| 空调 | 高温天气、夏季到来前 |
| 羽绒服 | 降温、寒潮来临前 |
| 鲜花 | 情人节、母亲节、纪念日 |
| 行李箱 | 旅游旺季、长假前 |
| 健身课程 | 新年、夏季前 |
| 学习用品 | 开学季 |
| 报税服务 | 报税季 |
| 月饼 | 中秋节前 |
| 求职辅导 | 招聘季、毕业季 |

优秀的销售并不是不断制造购买压力，而是能够识别消费者的需求何时产生，并提前做好内容、商品和渠道方面的准备。

### 15. 让用户形成「某种需求就想到你」的条件反射
做个人IP（Personal Brand，个人品牌）不只是为了获得更多粉丝，更重要的是让粉丝知道你究竟代表什么。
例如：
- 想买书，就想到某个读书博主。
- 想学英语，就想到某个英语老师。
- 想买电脑，就想到某个科技测评博主。
- 想了解投资，就想到某个专业财经创作者。
- 想买雨伞，就想到那个经常用雨伞做各种奇怪实验的人。

这种关联来自长期稳定的内容输出，而不是一次偶然的爆款视频。
如果一个账号虽然经常发布搞笑视频，却没有建立明确的行业认知，那么即使积累了大量粉丝，也可能很难实现商业变现。
流量的数量很重要，但流量与商业定位之间的相关性同样重要。

### 16. 把每一次内容创作都视为积累长期商业资产
传统交易通常在消费者完成购买之后才产生价值，而内容营销可以在消费者尚未购买之前，就开始积累具有潜在商业价值的资产。
