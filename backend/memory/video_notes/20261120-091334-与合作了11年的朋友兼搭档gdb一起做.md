两人已经保持了长达11年的朋友兼事业搭档关系，共同经历了 OpenAI 从早期创业到大型人工智能企业的发展过程。Greg 早期每周花费100个小时编写代码，如今则负责公司内部部分难度最高、影响最深远的业务。
作者从长期合作伙伴的角度，高度评价了 Greg 的技术能力、领导力、坚定意志以及对 OpenAI 使命的长期投入，甚至认为没有 Greg 就不会有今天的 OpenAI。
这条推文不仅是一份对合作伙伴的公开致敬，也体现了创始团队、核心人才和共同使命对于一家前沿科技公司的重要性。

## 核心观点

### 1. 长达11年的合作关系，是共同事业的重要基础
作者首先强调，Greg 不仅是自己的事业搭档，也是相识并合作了11年的朋友。两人之间的关系并非单纯建立在商业利益之上，而是经过长期共同工作形成的信任与默契。
对于 OpenAI 这种技术不确定性高、发展速度快、面临复杂商业决策的企业而言，核心团队之间的长期信任具有重要价值。稳定的合作关系能够降低内部沟通成本，也有利于团队在面对重大挑战时保持战略方向的一致性。
这种经过时间检验的合作伙伴关系，是一家科技公司难以通过资金直接购买的组织资产。

### 2. Greg 从一线程序员成长为核心业务领导者
作者提到，在 OpenAI 成立初期，Greg 每周花费100个小时编写代码，而现在已经开始领导公司部分最困难、最具重大影响的业务。
这体现了他的角色随着企业发展而发生的变化：从直接参与技术开发，逐渐转向承担更复杂的组织与业务责任。创业初期，公司需要核心成员亲自解决技术和产品问题；随着组织规模扩大，则需要具备统筹资源、协调团队和处理复杂决策的能力。
Greg 的经历说明，技术型创始人并不一定只能担任技术专家，也可以随着企业成长不断拓展自身的能力边界。

### 3. OpenAI 的早期发展离不开核心成员的高强度投入
推文中最具体的数字是 Greg 早期每周编写代码长达100个小时。这个数字反映了作者眼中 Greg 在 OpenAI 创业阶段的投入程度。
前沿人工智能研发需要解决大量尚未形成成熟答案的技术问题，早期团队不仅需要技术能力，也需要持续投入时间和精力。Greg 并非仅仅以管理者或联合创始人的身份参与公司，而是直接承担了大量技术建设工作。
不过，每周100小时属于作者对其早期工作状态的描述，并不意味着超长工作时间本身就是创业成功的必要条件，更不应将其简单推广为普遍适用的工作方式。

### 4. 真正优秀的领导者需要兼具能力与坚定意志
作者使用了两个具有代表性的形容词评价 Greg：
- Brilliant（才华出众、极具智慧）
- Fiercely determined（意志极其坚定、拥有强烈决心）

这两个特征分别对应解决复杂问题的能力，以及面对困难持续推进工作的意志。对于前沿科技企业而言，仅有技术能力并不足以保证长期成功，因为企业还需要面对组织扩张、资源分配、商业化和技术发展不确定性等挑战。
作者认为 Greg 同时具备优秀的能力和坚定的行动意志，并希望通过 DealBook 活动让外界看到这些特质。

### 5. 企业发展过程中，岗位职责可以变化，但核心使命应保持稳定
作者特别强调，尽管 Greg 在 OpenAI 内部的角色发生了巨大变化，但有一件事始终没有改变，那就是他对公司使命的非凡承诺。
从早期编写代码，到如今负责重大业务，Greg 的工作内容、责任范围以及解决问题的方式都在变化，但作者认为其行动背后的核心目标保持一致。
这揭示了一种值得关注的组织发展逻辑：企业不能要求核心成员永远从事相同的工作，却可以通过共同使命保持长期战略方向的一致性。
具体工作可以变化，能力结构可以升级，但驱动行动的核心目标应当具有连续性。

### 6. 核心人才可能对一家企业具有决定性影响
作者明确表示，如果没有 Greg，OpenAI 就不会存在。这是整条推文中对 Greg 个人贡献最强烈的评价。
这句话反映出，在作者看来，Greg 并非普通意义上的高管或技术负责人，而是参与构建 OpenAI 的关键人物。尤其是在企业发展的早期阶段，少数核心成员的技术判断、行动能力和资源组织能力，可能对公司的生存与发展产生长期影响。
当然，这属于作者基于个人合作经历作出的高度评价，而不是能够通过独立数据严格证明的反事实结论。OpenAI 的发展同样离不开其他创始成员、研究人员、工程师、投资者以及整个组织的共同努力。

### 7. 人工智能的发展不仅是技术问题，也是领导力与价值观问题
作者最后将 Greg 的贡献从 OpenAI 公司内部进一步延伸到了全世界的人工智能发展道路。
他认为，如果没有 Greg，世界迈向人工智能未来的道路可能会更加糟糕。这说明作者不仅认可 Greg 在技术和商业层面的贡献，也认为他的使命感、领导能力以及决策方式对人工智能的发展方向具有积极意义。
人工智能未来如何发展，不仅取决于模型能力、算力和算法，也取决于掌握这些技术的人如何作出决策、如何设置组织目标以及如何处理商业利益与社会责任之间的关系。
不过，这种对人工智能未来的评价具有明显的主观性，不能仅凭这条推文就证明 Greg 的实际决策一定产生了更好的社会结果。

## 值得记住的点 / 行动建议

### 1. 选择长期合作伙伴时，不要只看当下的能力
寻找创业伙伴或长期事业搭档时，除了考察对方现有的专业能力，还应该关注其可靠性、价值观、责任意识以及面对困难时的表现。
短期利益能够促成合作，但真正长期的合作往往需要共同目标、信任积累和相互认可。尤其在创业过程中，团队成员能否共同应对不确定性，有时比初始能力差距更加重要。

### 2. 技术人员需要主动拓展自己的能力边界
Greg 从早期编写代码转变为核心业务领导者的经历，对技术从业者具有一定启发。
如果希望获得长期职业发展，不能只停留在完成具体技术任务的层面，还应该逐步培养产品理解、业务判断、项目管理、资源协调和组织领导能力。
理想的成长路径可以概括为：
解决技术问题 → 独立承担项目 → 解决业务问题 → 协调组织资源 → 推动战略目标实现。
掌握技术是一种重要基础，但能够将技术转化为组织成果，则是更高层次的能力。

### 3. 不要把岗位职责等同于自己的长期价值
一个人在组织中的具体职责可能随着企业发展而不断变化。
创业阶段需要亲自开发产品，成长阶段可能需要管理团队，成熟阶段则可能需要参与战略决策。真正值得积累的并不是某个固定职位，而是持续解决更复杂问题的能力。
在职业发展过程中，可以定期思考：自己目前解决的问题是否越来越重要？能够创造的价值是否越来越大？是否具备承担下一阶段责任的能力？

### 4. 重视使命感，但不要盲目崇拜超长工作时间
Greg 每周100小时的早期工作经历，可以作为理解其投入程度的案例，但不应成为普通人的工作时间标准。
长期事业需要的不仅是投入，还需要健康、判断力、学习效率和可持续的行动能力。真正值得学习的是对重要目标的专注，以及在关键时期主动承担责任的态度，而不是机械复制工作时长。
高强度投入可以是一种阶段性选择，可持续的价值创造才是长期目标。

### 5. 研究AI企业时，除了模型和产品，也要关注核心团队
了解 OpenAI 等前沿人工智能公司时，不能只关注模型发布、用户数量、融资规模和算力资源。
核心团队的技术背景、领导能力、职责分工、战略判断和价值观，同样可能对公司的长期发展产生重要影响。
对于关注AI行业的人而言，可以建立更加完整的企业观察框架：

| 观察维度 | 重点关注内容 |
| --- | --- |
| 技术能力 | 模型性能、算法创新、研发效率 |
| 基础设施 | 算力、芯片、数据中心 |
| 商业能力 | 产品应用、客户需求、收入模式 |
| 核心人才 | 创始团队、技术负责人、领导能力 |
| 组织能力 | 团队协作、资源配置、战略执行 |
| 使命与治理 | AI安全、发展方向、社会责任 |

这样能够避免仅凭单次产品发布或者短期市场热度判断一家公司的长期竞争力。

### 6. 区分企业高管的公开评价与可验证的客观事实
这条推文具有明显的个人情感表达和公开致敬性质，同时也可能发挥强化企业核心团队形象的作用。
阅读此类企业高管发言时，应当区分三个层面的信息：具体经历与数字、作者对人物能力的评价，以及作者对未来发展的主观判断。
例如，11年的合作经历和每周100小时的工作描述属于原文提供的具体信息；而“没有 Greg 就没有 OpenAI”和“世界会走向更糟糕的AI未来”，则属于作者的个人判断。
理解这种区别，有助于更加理性地分析企业动态，避免将人物评价直接等同于客观事实。

## 我的点评
这条推文虽然篇幅很短，但揭示了前沿科技公司发展过程中一个容易被忽略的因素：核心人才及其长期合作关系所形成的组织能力。Greg 从一线技术开发者成长为关键业务领导者，也体现了技术型人才通过持续学习和承担责任实现能力升级的可能性。作者对共同使命的强调具有合理性，因为长期技术研发确实需要相对稳定的目标与组织信任。但是，关于 Greg 对 OpenAI 存续和全世界人工智能未来的决定性贡献，仍然属于带有个人情感色彩的评价，不宜将复杂的集体成就完全归功于某一个人。每周100小时的工作经历也不应该被过度美化，持续超负荷工作未必有利于长期创新。对于普通人而言，最值得学习的是长期合作、专业能力积累、责任边界拓展以及持续创造价值，而不是盲目崇拜成功人士的工作强度。
