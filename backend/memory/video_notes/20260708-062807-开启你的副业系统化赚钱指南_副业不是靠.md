## 一句话概括
真正有增长潜力的副业，不是依靠增加劳动时间来换取收入，而是通过系统化地整理个人经验、将技能产品化、将工具模板化，以及公开记录个人成长过程（Build in Public），构建能够重复销售、持续积累、降低边际成本的个人商业系统，从而逐渐摆脱单纯依靠时间换钱的生存模式。

## 背景与主题
这段视频围绕普通人应该如何开启副业、构建个人产品以及提高个人赚钱能力展开，作者结合自己直播时与社区成员的交流，分享了对副业、创业和个人成长的理解。针对很多人抱怨投入产出比不匹配、没有经验可以分享、不知道如何开始副业等问题，作者提出了两套具体方法：一是盘点已有的经验、技能和工具使用能力，并将其转化为可销售的产品；二是从自己未来想要实现的目标出发，通过学习、实践、验证和公开输出，逐步创造新的产品。
作者特别强调 Build in Public（公开构建、公开记录成长与创作过程），认为即使普通人目前没有成熟的技能和经验，也可以通过解决自身问题的过程，为其他有相同需求的人创造价值。视频后半部分进一步延伸到上班与创业的区别、普通人长期从事低技术含量工作的局限，以及创业实践对个人视野、知识密度和思维方式的提升。
作者的根本立场是：副业不仅是一种增加收入的手段，更应该成为个人积累资产、提升认知、降低自身可替代性、改变长期收入结构的方式。

## 核心观点

### 1. 做副业不能单纯依靠勤奋，否则只是在给自己增加一份工作
作者开篇就提出一个非常鲜明的观点：“做副业一定不是靠勤奋，越勤奋越穷，因为那相当于你不过就是多打了一份工而已。”
他反对的并不是勤奋本身，而是没有复利效应、缺少积累价值、只能通过不断投入时间才能获得收入的劳动模式。如果一个人白天上班八小时，晚上再花几个小时从事另一项同样依靠时间换钱的工作，那么虽然短期收入可能增加，但本质上的收入结构没有发生变化。一旦停止工作，收入也会随之停止，作者将这种情况概括为“口停手停”，结合上下文可以理解为“手停口停”。
普通兼职和系统化副业的核心区别，在于后者能够将某一次劳动形成的成果保留下来，并在未来持续创造收益。例如，一次性制作完成的教程、电子书、PPT模板、AI提示词工具，可以反复销售给不同的用户，而不必每次从头制作。副业真正应该追求的，不是工作量的增加，而是单位劳动所能创造的长期价值的增加。

### 2. 主动寻找投入与产出不对称的机会，而不是执着于一分耕耘一分收获
作者提到，自己在当天直播时，有一位社区成员留言抱怨投入产出比不匹配。对此，作者反而认为，一个人真正应该寻找的，就是投入与产出不匹配的事情，只不过应该努力让产出大于投入，而不是长期让投入大于产出。
如果永远是“一分耕耘，一分收获”，意味着只要不继续耕耘，就不再有任何收获，这种收入模式很难产生规模效应。如果已经发现自己处于“十分耕耘，一分收获”的状态，就应该停下来审视所选择的方向、方法和环境，而不是继续机械地增加投入。作者用种地进行了形象的比喻：“既然你已经知道这个地是十分耕耘一分收获了，那你为什么不换个地种呢？”
这一观点背后的商业逻辑，是寻找具有杠杆效应、可复制性和复利效应的机会，让同样的时间投入能够服务更多的人，并形成长期资产。对于普通人而言，选择做什么、以什么方式做，往往比单纯延长工作时间更加重要。

### 3. 副业的第一个起点，是盘点自己过去的所有经验
作者提出的第一种副业方法，是将自己过去所有有价值的经历、解决问题的方法、做事经验，以及曾经帮助过自己的技巧全部记录下来。即使某些经验在自己看来非常微小、简单甚至不值钱，也不要轻易否定它们，因为其他人可能正处在相应的需求阶段。
视频中举了一个非常具体的例子：很多十六七岁的小男孩满脸青春痘，如果一个人曾经通过某种方法改善了自己的青春痘问题，那么这段经验对现在的自己可能已经不重要，但对于正在受到青春痘困扰的青少年而言，却可能具有很大的价值。这个例子说明，经验的价值并不完全取决于拥有者如何看待它，更取决于接受者是否存在现实需求。
因此，普通人不必等到自己成为行业专家，才开始分享知识或制作产品，而应该先系统梳理自己的生活经历、职业经历、学习过程以及解决困难的方法。你已经解决的问题，可能恰好是别人现在面对的难题；你已经习以为常的能力，可能恰好是别人愿意付费获得的能力。
需要注意的是，青春痘案例主要用于说明经验的需求差异，个人健康经验并不一定适用于每个人，分享时应区分个人经历与经过专业验证的医学建议。

### 4. 不要直接出售经验本身，而要出售经验的副本
作者反复强调：“有经验，不卖经验，卖副本。”这里的“副本”指的是将个人经验转化为可以脱离本人、能够独立传播与重复使用的内容或产品，例如文章、电子书、操作手册、教程、视频课程、方法清单等。
如果一个人每次都通过一对一交流来出售自己的经验，那么收入依然受到个人时间的限制，因为每增加一名客户，就必须增加相应的服务时间。但如果将同样的经验整理成一份清晰、完整、可重复使用的产品，那么就有可能通过一次制作服务多名用户。这种产品的复制成本通常远低于第一次制作的成本，并且可以在后续不断更新、优化和增加售价。
作者建议先将自己的经验公开分享出去，通过 Build in Public（公开构建）的方式让更多人看到，并观察是否获得反馈，即使某个经验没有引起关注，也不意味着遭受了很大的损失。这种低成本试错方式，可以帮助普通人逐渐筛选出真正具有需求和商业价值的经验，从而避免一开始就投入大量资金制作没人需要的产品。

### 5. 将个人技能产品化，用工具解决其他人不会解决的问题
除了出售经验的副本，作者提出的第二个具体方向是将个人技能制作成产品或工具，让其他人能够直接使用。技能产品化的关键不在于展示自己有多厉害，而在于把自己熟悉的操作流程变成别人使用起来简单、方便、有效的解决方案。
作者分享了自己社区中已经发生的真实案例：他经常在社区成员面前演示自己如何使用 AI（人工智能）整理知识、处理内容以及获得新的洞见，但由于这些操作对自己而言非常简单，所以没有专门讲解其中的具体步骤。随后，社区中的一些成员将录音转文字、利用 AI 根据内容提炼洞见等操作所需的提示词（Prompt），整理制作成了一个小型产品。
按照文字稿中的说法，这个小产品的售价大约是 10.24元，即十块两毛四，而且已经有人开始购买。作者认为，虽然这个金额并不大，但这是一个良好的开端，因为它证明某项技能被封装成产品以后，确实可能存在真实的付费需求。
这一案例体现了一个重要的商业规律：用户并不一定愿意花大量时间研究一项技术，但可能愿意为能够帮助自己节省时间、简化操作、降低学习门槛的产品付费。

### 6. 工具使用过程中产生的模板，也是可以销售的数字化资产
作者提出的第三个具体方向，是将自己在研究和使用各种工具时积累的模板整理出来，并将其作为商品对外销售。很多人虽然没有意识到自己掌握了什么独特的技能，但在日常工作和学习中，事实上已经积累了大量具有复用价值的工作流程。
例如，有些人经常需要使用 PPT（PowerPoint，演示文稿软件）进行工作汇报，但不知道怎样制作美观、专业的演示文稿，因此会购买成熟的 PPT 模板。有些人经常需要撰写商务邮件，却不知道如何组织语言、表达需求和提高沟通效率，因此可以使用不同场景下的邮件模板。作者还特别提到了 Notion（笔记与知识管理工具）模板，这同样属于可以重复销售的数字产品。
这些产品本身未必涉及非常高深的技术，但能够帮助用户减少重复劳动、降低试错成本、提高工作效率，因此具备潜在商业价值。模板化的本质，是将已经验证过的工作方法进行标准化，使其他人不必重新经历你曾经经历过的摸索过程。

### 7. 即使没有经验，也可以从未来三个月、六个月或一年的个人目标出发创造产品
很多人认为自己没有经验、没有技能，也没有任何东西值得分享，因此不知道如何开启副业。针对这种情况，作者提出了第二种更具操作性的方法：不要过早制定过于遥远和宏大的计划，而是明确自己未来三个月、六个月、一年想完成什么事情，然后把实现这个目标的过程变成产品。
视频给出的例子包括减肥和赚钱，如果自己想要减肥，可以尝试研究并撰写一本关于如何减肥的书；如果自己想学习赚钱，可以尝试研究并撰写一本关于如何赚钱的书。当有人质疑“我现在自己还不会赚钱，怎么能写一本教别人赚钱的书”时，作者回答说，正因为你还不会，才需要通过写书来推动自己系统地学习和实践。
他的真正意思并不是让没有能力的人直接包装自己、出售未经验证的知识，而是将产品的制作过程作为一种倒逼自己学习、研究和实践的机制。通过给自己设置一个必须完成的成果目标，原本零散的学习就会逐渐转化为有方向、有体系、有实践反馈的成长过程。
即使最终没有成功出版书籍，只要已经完成了研究、实践、验证和知识整理，个人也有可能获得新的能力、内容资产和商业机会。

### 8. 产品必须经过“理论—实践—数据—理论修正”的完整验证过程
为了回应“自己不会赚钱却写赚钱的书，会不会误导别人”的质疑，作者进一步解释了产品应当如何真正创造价值。首先，需要系统研究市场上已经存在的赚钱方法，梳理不同方法背后的理论、条件和实施路径；其次，不能只停留在知识整理阶段，而必须亲自实践，检验这些方法究竟是否有效。
例如，当研究到一种赚钱方式时，自己应该尝试按照相应的方法去执行，记录实际挣到了多少钱、投入了什么、遇到了哪些问题，以及最终的结果是否符合原来的理论预期。完成实践以后，还应该重新回到理论层面，根据真实情况修正自己的认识，并总结出新的方法和适用条件。
作者强调，最终形成的书籍或产品应该做到“有理论、有案例、有实操、有数据、有方法”，而不是简单拼凑别人已经讲过的知识。一个方法、两个方法、三个方法不断积累下来，最终即使没有正式出版，也已经完成了一套真实的商业实践与能力训练。
这一过程实际上构成了一个知识生产闭环：学习已有知识 → 提出假设 → 亲自实践 → 收集数据 → 总结经验 → 修正理论 → 形成产品。

### 9. 每天用半小时到一小时构建自己的产品，通过持续公开输出形成长期积累
作者建议普通人从现在开始，每天至少抽出半小时到一个小时，踏踏实实地构建自己的产品，不要一开始就追求规模，而应该把产品“做小、做好、做完整”。这里强调的不是短期内投入大量时间，而是每天围绕同一个方向持续推进，最终让个人努力沉淀为完整的成果。
作者还以自己的输出习惯作为例子，提到每天写1000字、每天拍摄一条短视频，并鼓励听众找到自己的方向后持续行动。他认为，大部分人不仅缺少学习与思考的习惯，而且即使开始行动，也往往会在坚持到一半时选择退出。
为了说明坚持本身所带来的竞争优势，作者给出了一组带有个人判断性质的比例：90%的人不学习、不思考；剩余的人中又有90%不会有效思考；再剩下的人中还有60%会半途而废。这些比例没有提供统计来源，但表达的核心意思是，在长期学习、有效思考和持续执行三个方面同时做到的人，可能远比表面上的竞争者数量少。
持续进行 Build in Public，不仅可以形成越来越多的公开内容和产品素材，还可以获得真实反馈、建立个人信任，并逐步积累潜在用户。

### 10. 创业和副业的真正价值，还在于改变认知结构、提升个人能力和降低可替代性
视频后半部分，作者将副业的话题延伸到普通人应该选择上班还是创业。他坦言，如果一个与自己没有特殊关系的人询问应该创业还是上班，自己可能会建议对方去上班，因为创业存在失败风险；但如果是自己的弟妹、子侄询问相同的问题，他反而会强烈鼓励对方尝试创业。
作者认为，很多人长期收入不高的原因，一方面是眼界不够开阔，不知道外部世界存在什么机会；另一方面是每天重复大量缺少技术含量的工作，导致个人能力长期无法发生质变。他用“干5年和干5个月”进行对比，认为某些高度重复性的岗位除了熟练度、人情世故有所增加之外，核心能力并没有明显提升。
当一个人的工作很容易被其他人替代时，他就更容易在职场中缺少议价能力，并担心领导不满意、给自己穿小鞋，因此不得不花费大量精力处理人际关系。与之相比，作者认为，在不让自己承担过度债务的前提下尝试创业，即使失败，也可能提升个人视野、知识密度、思维方式、行动力以及接触不同人群和机会的能力。
因此，副业和创业的意义不应该只用短期盈利衡量，还应该关注是否形成了新的技能、资产、认知和选择权。不过，这并不意味着所有上班经历都缺少成长价值，真正需要警惕的是长期处于没有学习、没有积累、没有能力提升的工作状态。

| Prompt | 提示词，用于指导AI完成特定任务，可以整理成数字产品 |

| 经验副本 | 将个人知识和实践经验转化为可以反复传播、销售的内容载体 |

其中，Build in Public 是贯穿整段视频的核心概念。产品化、标准化、边际成本、复利效应等概念，则有助于进一步解释作者提出的方法背后的商业逻辑。

### 五、值得关注的具体案例
案例一：青春痘改善经验
曾经受到青春痘困扰的人，在找到适合自己的解决方法以后，可能不再认为这段经历有什么价值。但是对于正在经历同样问题的十六七岁青少年而言，这些经验可能非常重要。
案例说明：经验具有情境价值，同一种经验在不同人群、不同人生阶段中的价值存在差异。
案例二：AI提示词小产品
作者经常在社区中演示如何使用AI整理知识、处理录音和提炼洞见，但没有专门讲解具体操作。社区成员发现这一需求后，将操作流程和提示词整理成售价约10.24元的小产品，并获得了实际购买。
案例说明：商业机会可能就隐藏在专家认为过于简单、不值得详细讲解的操作中。用户愿意购买的，往往不是技术本身，而是一个经过整理、能够快速产生结果的使用方案。
案例三：PPT、邮件和Notion模板
对于熟练使用工具的人而言，制作一份工作汇报、设计一封商务邮件或者搭建一个知识管理系统并不困难。但对于不熟悉这些工具的人而言，直接使用现成模板可以显著减少学习时间和操作成本。
案例说明：重复性的工作需求，可以通过模板化形成可重复销售的数字商品。
案例四：通过写一本赚钱的书倒逼自己学习赚钱
一个目前不懂赚钱的人，可以先确定自己要完成一本关于赚钱方法的书，再系统研究市场上的方法、亲自实践、记录实际收入和失败经历，并最终形成自己的理论与案例。
案例说明：产品不一定要等到个人能力完全成熟以后才开始构建，也可以在能力成长的过程中逐渐完成，但最终交付的内容必须诚实反映经过验证的结果。
案例五：普通员工工作5年与5个月的区别
作者认为，有些岗位每天重复相同的低技术含量工作，即使工作5年，与工作5个月相比，核心能力也没有明显区别。这会导致员工可替代性较高，缺少在职场上的议价能力。
案例说明：工作年限并不必然等于能力积累，只有能够持续产生新知识、新技能、新资源和新成果的工作，才更可能提高个人长期价值。

## 金句摘录
以下摘录保留原话的主要表达，仅对语音识别中的明显错字、重复词和标点进行适当修正。
**1. 关于副业的本质**
“做副业一定不是靠勤奋，越勤奋越穷，因为那相当于你不过就是多打了一份工而已。”

重点：勤奋应该服务于能够积累长期价值的方向，而不是无限增加出售时间的数量。
**2. 关于投入产出比与方向选择**
“既然你已经知道这个地是十分耕耘一分收获了，那你为什么不换个地种呢？”

重点：发现方向错误以后，改变策略和环境可能比继续坚持更加重要。
**3. 关于个人能力的商业化**
“有经验，不卖经验，卖副本；有技能，不卖技能，把技能做成产品往外销售。”

重点：将个人能力封装成能够独立交付、重复使用的产品，逐渐减少收入对个人时间的依赖。
**4. 关于构建产品的正确方法**
“有理论，有案例，有实操，有数据，有方法，就去写这样的书。”

重点：真正有价值的知识产品应该建立在理论研究与真实实践的基础上，而不是对既有信息的简单搬运。
**5. 关于从零开始的执行策略**
“从现在开始，每天至少抽出半个小时、一个小时，踏踏实实地去构建你自己的产品，一点一点完成，把它做小、做好、做完整。”

重点：缩小产品范围，保持持续执行，优先形成完整、可使用的成果。
**6. 关于持续成长**
“想想你未来三个月、六个月、一年，你要干什么事，然后从现在开始，每天前进一点点，Build in Public。”

其中 Build in Public 意为“公开构建”，即将自己的成长、探索、实践和产品开发过程持续对外分享。

## 值得记住的点 / 行动建议

### 1. 重新理解副业：从赚取额外收入转向构建个人资产
开始副业之前，首先应该问自己：正在做的事情究竟是在增加劳动收入，还是在积累能够持续创造收益的资产？
两者并不完全冲突，但是需要有意识地区分。

| 对比维度 | 单纯兼职模式 | 系统化副业模式 |
| --- | --- | --- |
| 收入来源 | 工作时间 | 产品及其创造的价值 |
| 增加收入的方式 | 增加工作量 | 增加销量、提高产品价值 |
| 是否依赖本人持续参与 | 高度依赖 | 可以逐步降低依赖 |
| 停止工作后的收入 | 通常停止 | 可能继续产生收入 |
| 成果能否复用 | 相对有限 | 可以反复使用和销售 |
| 长期积累 | 工资、熟练度 | 产品、品牌、用户、内容、方法 |
| 前期收益 | 相对直接 | 不确定，可能较低 |
| 长期增长空间 | 受时间限制 | 有机会通过规模化突破限制 |
