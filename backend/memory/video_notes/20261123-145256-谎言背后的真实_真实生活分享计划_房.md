### 2. 2022—2023年美联储连续11次加息，是美元流动性周期发生转向的重要节点
作者将2022年和2023年视为美元潮汐转向的重要阶段。

这里的基点需要理解清楚：
- 25个基点 = 0.25个百分点。
- 50个基点 = 0.50个百分点。
- 75个基点 = 0.75个百分点。

美联储加息并不是简单地把一个数字调高，而是提高美元资金的使用成本。此前可以用较低成本获得的美元融资，随着政策利率提高，逐渐变得昂贵。
当美元利率持续走高时，美元资产对全球投资者的吸引力可能增强，部分国际资本会重新考虑资金配置，寻求更高的美元资产收益。
与此同时，依赖美元融资的企业、国家和金融机构需要承担更高的利息支出，原本依靠低利率维持的债务结构可能出现压力。
作者想表达的是：2022—2023年的11次加息不是孤立的货币政策事件，而是全球美元流动性环境从宽松转向紧缩的重要分水岭。

### 3. 美元潮汐的核心逻辑，是先通过宽松释放流动性，再通过紧缩改变全球资本的流向
作者将2020年、2021年和2022年前后的美元流动性环境概括为一个宽松周期。
在这一阶段，全球能够以相对低廉的成本获得美元资金，融资条件较为宽松。视频用比较形象的说法描述这种状态：

这里的意思是，宽松货币环境使得资金供应充足，融资成本较低，企业和投资者可以较容易地借到钱，用于投资、扩张和资产配置。
但当美元潮汐开始转向，美联储连续加息，原本充裕而廉价的美元资金开始变得昂贵。资金不再像以前一样容易获得，全球经济体和企业需要重新适应高融资成本。
作者认为，这种宽松与紧缩之间的周期性变化，实际上会改变全球资产的价格和资本的流向。
在宽松阶段，资金可能流向新兴市场、房地产、股票、大宗商品和各类投资项目；而在紧缩阶段，美元融资成本提高，部分资本可能回流美元资产，依赖外部融资的市场则面临更大的压力。
因此，作者所说的美元潮汐，本质上是一种观察全球资本周期的分析框架：不能只看美国国内的利率，还要看美国货币政策变化对全球资金流动产生的连锁反应。

例如，CPI反映的是一篮子消费品和服务价格的整体变化，但不同家庭的消费结构存在差异。对于住房支出占比较高的家庭来说，住房成本的变化可能比整体CPI更重要；对于食品和能源消费占比较高的家庭来说，食品、汽油和电费的上涨可能带来更直接的压力。
此外，不同统计指标的计算口径也不一样。CPI、核心CPI、PCE物价指数分别有不同的统计范围和用途，不能简单混为一谈。

不过，质疑统计指标与认定统计数据造假是两回事。要证明某项数据失真，需要具体分析统计口径、原始数据、权重和计算方法，而不能仅凭生活感受作出结论。

## 值得记住的点 / 行动建议

### 9. 看宏观经济，不要只看一个数字，要追溯数字背后的形成过程
看到美国房贷利率达到7.35%，不要只停留在“利率很高”这个结论上。
应该继续追问：
- 为什么会达到7.35%？
- 美联储过去几年采取了什么货币政策？
- 10年期和30年期国债收益率发生了什么变化？
- 银行的融资成本和贷款利差发生了什么变化？
- 为什么这些变化会传导到普通家庭？
- 这种影响会持续多久？

例如，房贷利率上升并不只是房地产行业的问题，它可能同时反映美元融资环境、长期利率预期和金融市场风险溢价的变化。
可操作的方法：每次看到一个宏观经济新闻，都尝试从结果倒推原因，再从原因推导影响。

### 10. 建立美元潮汐分析框架，持续观察美国货币政策和全球资本流向
理解美元潮汐，不能只看美联储是否加息或降息。
建议持续关注以下指标：

| 观察指标 | 重点关注的问题 |
| --- | --- |
| 美联储政策利率 | 美元短期资金成本是上升还是下降？ |
| 美国10年期国债收益率 | 长期利率预期如何变化？ |
| 美国30年期国债收益率 | 长期融资成本是否持续走高？ |
| 美元指数（DXY） | 美元相对于其他主要货币是否走强？ |
| 美国国债拍卖情况 | 市场对美国国债的需求是否稳定？ |
| 国际资本流动 | 资金是在流入还是流出新兴市场？ |
| 全球企业融资成本 | 企业偿还债务和获得新融资是否更加困难？ |
| 大宗商品价格 | 全球经济预期及美元定价资产是否发生变化？ |

这些指标放在一起看，才能更好地理解美元流动性变化究竟对全球经济产生了什么影响。

### 11. 特别注意宏观经济的滞后效应，不要把今天的结果误认为今天的原因
这是整段视频最值得实际应用的分析方法之一。
宏观政策往往不会立刻反映到所有经济主体身上。
例如：
- 美联储加息后，金融市场可能很快调整利率预期。
- 银行可能逐步调整贷款定价。
- 新购房者可能立即面对更高的贷款成本。
- 企业可能在下一轮融资或债务到期时才真正感受到压力。
- 家庭可能在购房、续贷和消费支出中逐渐体现利率变化的影响。

因此，在分析某个经济现象时，应该同时考虑三个时间维度：
**1. 过去： 哪些政策和市场变化埋下了问题？**
**2. 现在： 哪些影响已经显现？**
**3. 未来： 哪些影响还在传导过程中，可能尚未完全体现？**

这比简单地根据当天公布的数据判断经济好坏，更有分析价值。

### 12. 不要只看CPI headline，要同时观察其他通胀和生活成本指标
作者提出对CPI的质疑，值得转化为一种更严谨的数据阅读习惯。
建议至少区分以下指标：
- Headline CPI： 整体消费者价格指数，包含食品、能源等项目。
- Core CPI： 核心消费者价格指数，通常剔除食品和能源。
- PCE Price Index： 个人消费支出价格指数，是美联储重点关注的通胀指标之一。
- Core PCE： 核心个人消费支出价格指数。
- Shelter Inflation： 住房相关价格变化。
- Wage Growth： 工资增长速度。

为什么要同时观察？
因为整体通胀下降，不代表每个家庭的生活成本都在下降；通胀率下降，也不代表此前上涨的价格已经回到原来的水平。
例如，某项商品价格从100上涨到120，之后涨幅放缓至2%，并不意味着价格重新回到100，而是价格仍然在较高水平继续上涨。
重要区别：通胀率下降不等于物价下降。
因此，分析美国普通家庭的真实经济压力时，应该把通胀、住房、工资、消费和债务负担结合起来。

### 13. 分析美国债务问题时，要同时考虑债务规模、利息成本和经济增长能力
视频特别提到美国40多万亿美元的债务规模。
但判断一个国家的债务风险，不能只看债务总额。
至少需要同时观察四个方面：
第一，债务规模。
债务总额是否持续扩大，增长速度是否超过经济增长速度。
第二，利息支出。
美国政府需要支付多少利息？利息支出占财政收入和财政支出的比例是多少？
第三，债务期限结构。
短期债务和长期债务的比例如何？未来是否有大量债务需要集中再融资？
第四，经济增长能力。
经济增长、税收收入和生产率能否支撑不断增加的债务负担？
尤其需要理解一个问题：美联储加息会提高新发行债务和到期再融资债务的融资成本，但不会让所有存量长期固定利率国债的利息立即同步上涨。
因此，债务压力也存在时间上的滞后性。

### 14. 对地缘政治事件，要区分战略目标、实际成本和最终收益
视频将2025年关税政策和2026年地缘政治博弈联系起来，提醒观众不要只看国际新闻中的表面胜负。
分析一场地缘政治博弈，可以从三个层次入手：
- 战略目标： 一个国家究竟想得到什么？是资源、市场、金融控制力，还是安全和政治影响力？
- 实际成本： 为达到目标付出了多少财政、军事、外交和经济成本？
- 最终收益： 这些成本最终有没有转化为可以持续获得的利益？

例如，某项关税政策可能在短期内对其他国家形成压力，但也可能提高本国进口成本，引发贸易摩擦和供应链调整。
因此，不能只看政策是否出台，更要看政策实施之后的实际结果。

### 15. 对金融危机预测保持警惕，建立自己的风险验证体系
视频提出了“多重危机叠加”和“黑色星期五”的风险判断，但没有完整展示所有风险变量。
因此，观众可以把它作为研究方向，而不是直接当作投资结论。
建议建立一个风险观察清单：
- 美国国债收益率是否持续异常上升？
- 美国政府利息支出是否快速增加？
- 国债拍卖是否出现需求不足？
- 美国银行体系是否出现明显流动性压力？
- 企业债券信用利差是否扩大？
- 房地产市场交易和融资是否持续收缩？
- 就业、消费和企业投资是否同步走弱？
- 美联储是否面临通胀与经济衰退之间的政策两难？

如果多个指标同时恶化，才更有理由判断系统性风险正在积累。
最重要的是：不要因为某个博主提出了危机预测，就直接推导出某个时间点一定会发生金融崩盘。要让数据来验证判断。
