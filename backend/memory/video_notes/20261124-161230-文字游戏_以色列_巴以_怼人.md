## 核心观点

### 1. 切换新闻叙事中的主体，可以改变公众对战争性质的判断
原博主认为，一些自媒体在报道针对以色列的军事行动时，会使用具体武装组织的名称，而在报道以色列反击时，则改用国家或地区名称，以此强化以色列侵犯他国主权的印象。例如，胡塞武装发动袭击时称为“胡塞武装”，遭到反击时则称为“以色列进攻主权国家也门”；哈马斯发动袭击时称为“哈马斯”，遭到反击时则称为“以色列攻击巴勒斯坦”。类似的表达方式还出现在黎巴嫩真主党、塔利班和沙姆解放组织相关的报道中。原博主认为，这种叙事方式虽然可能没有直接捏造事实，却通过改变描述对象，将武装组织的行为与国家及普通民众的处境进行不对称呈现。其核心逻辑在于：同一个事件采用不同的叙事框架，可能让受众产生完全不同的道德判断。

### 2. 报道遭受打击的国家和平民，不一定构成偷换概念
视频作者反驳称，使用武装组织名称描述发动军事行动的一方，同时使用国家名称描述遭受打击的地区，在逻辑上并不必然矛盾。以也门为例，胡塞武装是军事行动的参与者，但以色列打击的机场、港口等设施位于也门境内，受到军事行动影响的普通民众也可能是也门公民。因此，报道“以色列打击也门境内目标”与“以色列打击胡塞武装”，可以是对同一事件不同层面的描述。视频作者进一步指出，胡塞武装打击以色列境内目标，同样可以被描述为对以色列的打击。由此可见，真正需要判断的不是报道是否使用了国家名称，而是它是否准确区分了军事行动实施者、军事打击对象、受影响地区以及平民受害者。

### 3. 判断战争责任不能只截取某一次军事行动，而应关注冲突的历史背景
视频作者认为，原博主将胡塞武装、哈马斯等组织的军事行动作为叙事起点，却没有充分交代此前的巴以冲突以及加沙地区长期存在的人道主义问题。作者将胡塞武装针对以色列的军事行动解释为对加沙局势的回应，并将其评价为具有正义性。谈及加沙时，作者还列举了断水、断电、粮食供应受阻等问题，并引用“世界上最大的露天监狱”这一具有强烈批判性的比喻。作者试图说明，如果只报道某一次袭击，而不说明此前发生了什么，就可能使公众对冲突的起因和责任形成片面认识。不过，理解历史背景与认定具体军事行动是否合法是两个不同的问题，历史上的压迫、封锁或不公正待遇，并不自动赋予任何一方攻击平民的合法权利。

### 4. 平民伤亡不能因为军事行动以反恐或自卫为名而被忽略
视频作者着重批评了将军事行动简单概括为“打击恐怖组织”或“军事反击”的叙事方式，认为这种表述容易掩盖战争对普通民众造成的实际伤害。作者以加沙为例，提到学校、医院、避难所等设施遭到破坏，以及妇女、儿童等非战斗人员的伤亡。文字稿中给出的数字包括加沙超过7万人死亡、超过17万人受伤，并另称妇女和儿童相关伤亡数字超过3.8万人，但没有交代具体统计日期、来源和口径。作者还提到以色列在黎巴嫩的军事行动对居民楼、建筑设施及平民造成的影响，强调不能因为军事行动的名义目标是某个武装组织，就忽略其附带的人道主义后果。其核心观点是：军事行动的正当性不能仅由其宣称的目标决定，还必须考虑实际采用的手段和造成的后果。

### 5. 美国在阿富汗等地的反恐战争，同样需要接受人道主义审视
视频作者将讨论范围从以色列扩大到美国，反驳原博主关于塔利班与阿富汗战争的论述。原博主认为，将美国打击塔利班描述为轰炸阿富汗，是媒体利用主体切换进行负面叙事的例子；视频作者则认为，美国以反恐为名发动的军事行动确实造成了大量平民伤亡，不能将相关报道一概归为对美国的污名化。作者援引美国布朗大学（Brown University）的研究统计，称阿富汗战争造成7万多名平民直接死亡，整个反恐战争造成40多万名平民死亡，但文字稿未明确具体报告及统计范围。此外，作者还提到美国以反恐为名进入叙利亚并造成平民死亡的问题。这部分论述旨在说明，无论行动主体是国家军队还是非国家武装组织，都不应因为其政治身份或宣称的军事目的而免于对战争行为的审查。

### 6. 国际人道法中的区分原则，是保护战争中平民的基本规则
视频作者提出，讨论军事行动是否合法，不能只围绕“谁先打谁”展开，还必须考虑国际人道法（International Humanitarian Law，IHL）中的区分原则（Principle of Distinction）。区分原则要求交战各方区分平民与战斗人员、民用物体与军事目标，不能故意将平民和民用物体作为攻击对象。作者以住宅、医院及基础设施为例，强调这些设施不能仅仅因为位于敌方控制区域，就被视为当然合法的军事打击对象。需要进一步补充的是，某些民用物体在满足严格法律条件时可能构成军事目标，医院等医疗设施则享有特别保护，即便涉及军事用途也必须遵守相应的法律要求。这项原则的根本意义在于：战争并不是对暴力行为的无限授权，即使交战一方拥有合法的自卫理由，也必须遵守保护平民的战争规则。

### 7. 比例原则意味着合法军事目标也不能成为无限扩大伤害的理由
除了区分原则，视频作者还强调了比例原则（Principle of Proportionality）。比例原则要求，即使攻击对象属于合法军事目标，也不得发动预期会造成相对于具体和直接军事利益而言过度的附带平民伤亡或民用物体损害的攻击。也就是说，存在军事目标并不意味着交战方可以不受限制地使用武力，更不能简单地以打击武装人员为由否定对平民伤害的审查。视频作者将这一原则视为现代文明的底线，并以此反驳只强调反恐、自卫或报复理由的战争叙事。不过，比例原则并不是比较交战双方的死亡人数，也不是仅凭事后伤亡数字就能判断某次攻击违法，而需要结合攻击前能够掌握的信息、预期军事利益及可预见的平民损害进行具体分析。

### 8. 局部事实不等于完整真相，但“真相”也不能脱离可验证的事实
原博主提出了一句贯穿整段争论的话：“您看到的是事实，它不是真相。”这句话意在说明，媒体可以通过选择性呈现真实事件，构建具有误导性的整体叙事，即每一个单独的信息可能属实，但组合之后形成的认知未必全面。视频作者对此提出反驳，认为原博主不能一边否定经过国际媒体交叉验证的信息，一边宣称自己掌握了真正的真相。这场争论实际上涉及一个重要的传播学问题：事实是否真实、事实是否完整，以及对事实的解释是否合理，是三个不同层次的问题。比较可靠的认识方式不是简单地相信某一方宣称的“真相”，而是通过多来源核查、还原时间线、区分事实与推论，逐步建立对事件的完整理解。

### 9. 选择性同情、双重标准和立场先行，会使公共讨论失去理性
视频最后，作者将矛头指向为国家军事行动进行辩护的部分自媒体，认为他们通过选择性强调以色列、美国受到的伤害，淡化其军事行动造成的平民伤亡，将施暴者重新包装为受害者。作者进一步指责此类传播行为是在美化暴力、滋养邪恶，并怀疑部分自媒体可能受到利益驱动，但视频并未提供证据证明其所指对象存在收受资金或接受宣传指令的行为。与此同时，视频作者自身也使用了大量讽刺、人身攻击和情绪化政治标签，将复杂的国际冲突高度道德化。虽然这种表达具有较强的情绪动员能力，却可能使讨论从核实事实和分析战争责任，转变为对不同立场者进行人格攻击。真正值得重视的问题是：如果评价战争的标准随着行为主体的变化而变化，那么无论站在哪一方，都可能陷入自己所批评的双重标准。

## 金句摘录
以下摘录自视频文字稿，对明显的语音识别错误和口语断句进行了适当修正。
**1. 关于事实与真相的关系（原博主）**
“您当然也会批评他们，但是您看到的是事实，它不是真相。”

值得思考的是，事实可能是真实的，但选择哪些事实、忽略哪些事实，以及如何组织事实，都可能影响最终形成的整体认识。
**2. 关于媒体叙事主体的切换（视频作者）**
“说以色列受伤害的时候，就把国家换成了组织；说以色列施暴的时候，就把组织换成了国家，以增加以色列被冤枉的效果。”

作者借此反驳原博主的论证方式，认为对方实际上也在利用国家与组织之间的主体转换塑造舆论。
**3. 关于平民保护（视频作者）**
“区分原则，就是打仗只能打战斗员和军事目标，绝对不能把平民和民用目标，比如住宅、医院、基础设施当目标。”

这是视频中具有知识价值的国际人道法论述，但具体适用条件仍需要结合正式法律规则理解。
**4. 关于军事行动的限制（视频作者）**
“比例原则就是，就算你打的确实是一个合法的军事目标，也不能为了打它而造成过分的平民伤亡。”

合法的军事目标并不意味着任何攻击手段都是合法的。
**5. 关于现代文明的底线（视频作者）**
“这是国际法明文规定的，这才是现代文明的底线。”

作者借此强调，战争行为仍然受到法律与人道主义规则的约束。
**6. 关于信息来源的选择（视频作者）**
“只看以色列单方面的信息，那些国际媒体经过交叉验证的信息，一概都不听不信。”

这句话虽然是在批评特定立场者，但同样可以用于提醒任何一方：不能只接受符合自己预设立场的信息。

## 值得记住的点 / 行动建议

### 1. 看国际新闻时，首先检查新闻标题中的行为主体
新闻标题不只是对事件的概括，也会影响读者对责任归属的第一印象。国家、政府、军队、武装组织和普通民众并不是可以随意互换的概念。
阅读相关新闻时，可以主动检查：
- 谁实施了军事行动？
- 谁是实际军事打击对象？
- 行动发生在哪个国家或地区？
- 哪些人实际受到了伤害？
- 标题中的主体和正文中的主体是否一致？
- 报道有没有将某个组织的行为归咎于整个民族或国家？

例如，下面几种表述描述的重点并不相同：

| 表述 | 突出的重点 |
| --- | --- |
| 以色列打击胡塞武装 | 军事行动的针对对象 |
| 以色列打击也门境内目标 | 军事行动发生的地理范围 |
| 以色列军事行动造成也门平民伤亡 | 军事行动的人道主义后果 |
| 以色列侵犯也门主权 | 对军事行动作出的法律或政治评价 |

前三种表述在特定情况下可以同时成立，而第四种涉及进一步的法律判断，不能仅凭前面的事实自动得出。

### 2. 学会区分事实、叙事、评价与指控
这是理解此类政治评论视频最有用的思维工具之一。
第一层：客观事实
什么时间、什么地方发生了什么事件？有哪些可以核实的损害？

第二层：叙事框架
媒体从哪个时间点开始讲述？强调哪一方的行为？省略了什么背景？

第三层：法律与道德评价
行为是否符合国际法？是否具有正当性？判断依据是什么？

第四层：动机推测与政治指控
是否存在蓄意操纵舆论、利益输送或宣传活动？是否有独立证据？

越往后，通常越需要额外的证据和论证。
例如，某次军事行动造成平民伤亡可能是可核查的事实，但认定该行动构成战争罪需要进一步的法律分析，而指控某位博主收钱为交战方进行宣传，则需要资金往来或其他独立证据。
不能将这几个层次混为一谈。

### 3. 判断战争责任时，建立完整的事件时间线
很多国际政治争论的关键，并不是双方完全不认可相同的事实，而是双方选择了不同的叙事起点。
一方可能从某次袭击开始讲述，另一方则从此前的封锁、军事占领、历史冲突或其他政治事件开始讲述。双方都可能提供真实的信息，却得出截然不同的结论。
因此，在分析复杂冲突时，应当尽可能了解：
- 长期历史背景；
- 冲突爆发前的政治与社会条件；
- 近期冲突升级的直接原因；
- 各方军事行动之间的因果联系；
- 冲突持续过程中发生的人道主义问题；
- 国际社会和相关机构的调查、评价及调停行动。

同时也要避免另一种错误：历史背景可以解释某种行为为何发生，但不能自动证明该行为在法律和道德上是正当的。

### 4. 将发动战争的合法性与战争行为的合法性分开判断
视频虽然没有系统介绍这一法律框架，但其讨论实际上涉及国际法中的两个重要领域。

| 法律概念 | 主要讨论的问题 |
| --- | --- |
| Jus ad Bellum（诉诸战争权或使用武力的法律规则） | 一方是否拥有合法使用武力的依据 |
| Jus in Bello（战时法或国际人道法） | 在武装冲突中可以采取哪些行为、必须遵守哪些限制 |

例如，即便一方具备合法自卫的依据，也不代表其所有军事行动都是合法的；同样，即便某一方发动战争的行为违法，其平民也不能因此成为合法的攻击对象。
这种区分能够帮助普通人避免两个常见的逻辑错误：
“因为一方是自卫，所以它做什么都是合理的。”
“因为一方过去遭受过不公正待遇，所以它采取的任何反抗手段都是正当的。”
战争的原因、战争的目标与战争的手段，应当分别接受审查。

### 5. 对所有交战方采用同一套平民保护标准
反对双重标准最有效的方式，不是简单改变自己的政治立场，而是建立一套不依赖行为主体身份的评价规则。
无论行为主体是以色列军队、美国军队、哈马斯、胡塞武装，还是真主党，都应当审视其具体行为是否违反国际人道法，以及是否履行保护平民的义务。
可以采用一个简单的思维检验方法，即主体互换测试：
假设性质相同的行为不是由自己支持的一方实施，而是由自己反对的一方实施，自己的评价是否会发生改变？
如果会发生明显变化，就需要重新检查自己的判断是否基于证据和规则，还是基于政治身份与情感立场。

### 6. 引用战争伤亡数字之前，必须核查统计口径
战争伤亡数据能够帮助公众理解战争的严重程度，但数字也是政治传播中非常容易被误用的内容。
视频中提及的7万、17万、3.8万、40万等数字，如果要用于文章写作、学术研究或者公开讨论，应当先找到对应的原始报告。
战争伤亡数据核查清单

0/8

是否找到数字的原始出处
是否确认统计截止日期
是否区分死亡人数与受伤人数
是否区分平民与战斗人员
是否区分直接死亡与间接死亡
是否确认地理范围及统计时间跨度
是否有其他独立机构进行交叉验证
是否避免将存在重叠的数据重复相加

特别是在援引布朗大学（Brown University）的战争代价项目（Costs of War Project）时，应优先查阅原始研究，而不是仅使用短视频中的二手转述。

### 7. 建立多来源交叉验证的信息获取习惯
视频双方都涉及对信息来源可信度的质疑，因此普通人不应该把获取国际新闻的渠道局限在某个自媒体账号或者某一政治立场的媒体。
在核实国际冲突相关信息时，可以参考以下不同类型的信息来源：

| 信息来源 | 主要参考价值 |
| --- | --- |
| 联合国人道主义事务协调厅（OCHA） | 人道主义局势及相关统计 |
| 红十字国际委员会（ICRC） | 国际人道法及战争中的平民保护 |
| 世界卫生组织（WHO） | 医疗系统、公共卫生及医疗设施相关信息 |
| 国际法院（ICJ） | 国家间争端及相关国际法问题 |
| 国际刑事法院（ICC） | 涉及个人刑事责任的国际司法程序 |
| 布朗大学战争代价项目 | 战争伤亡、经济成本及社会影响研究 |
| 路透社（Reuters） | 国际新闻及现场信息 |
| 美联社（Associated Press） | 国际新闻及多来源采访报道 |
| 冲突各方的官方声明 | 了解各方公开立场，但需独立核查 |

不同机构承担的职能不同，不能将媒体报道、学术研究、政府声明和法院裁决视为同等性质的证据。
还需要注意，多家媒体报道同一条消息，并不一定意味着完成了独立交叉验证，因为它们可能引用的是同一个原始消息来源。

### 8. 警惕情绪化表达代替事实论证
视频后半部分使用了较多侮辱性词汇、人身攻击和高度情绪化的政治评价，并提出关于自媒体收钱进行宣传的指控。
这些表达方式容易增强视频的传播效果，也容易使拥有相同立场的观众产生情绪共鸣，但并不能增加论证本身的可靠性。
面对这种评论内容时，应该主动剥离其中的情绪成分：
- 去掉侮辱性词汇之后，作者还剩下哪些实质性论点？
- 这些论点有没有事实和证据支持？
- 作者有没有准确转述对方的观点？
- 是否存在未经证明的动机推测？
- 作者自己有没有犯下其所批评的逻辑错误？

真正高质量的批评，应当针对论点、证据、推理过程和事实错误，而不是仅仅针对提出观点的人。

### 9. 不要把政治立场当成判断事实真假的依据
这一视频最值得延伸思考的地方，在于双方都试图揭露对方的选择性叙事，却也都可能受到自身政治立场的影响。
现实中，一个人可以同时承认：
以色列平民遭受袭击值得谴责，巴勒斯坦平民遭受伤害也值得关注；可以反对针对平民的武装袭击，同时批评国家军队造成的过度平民损害；可以理解冲突背后的历史原因，同时反对不符合国际人道法的军事行为。
这些立场并不必然互相矛盾。
成熟的独立思考不是必须在所有问题上选择一个阵营，而是能够依据一致的事实标准、法律标准和道德标准，对每一项具体行为作出相对独立的判断。

## 我的点评
这段视频最有价值的部分，是将战争舆论中的主体切换、选择性叙事、平民伤亡及国际人道法放在同一个讨论框架中，提醒人们不能只关注军事行动的名义目标，而忽视实际的人道主义后果。作者强调的区分原则和比例原则具有重要的知识价值，但具体军事行为是否违法仍需根据证据、攻击条件及正式法律规则进行个案判断。原博主关于局部事实可能被组合成误导性叙事的提醒本身也有道理，只是这种标准必须平等地适用于所有政治立场和媒体来源。视频作者的不足在于，部分伤亡数据缺乏完整出处，对某些武装行动正当性的判断过于绝对，并使用未经证实的利益指控和大量人身攻击，削弱了论证的严谨性。对普通人而言，与其直接接受其中任何一方的政治结论，不如学习如何区分事实与评价、核查数据来源、还原事件背景，以及识别媒体叙事中的双重标准。衡量一个观点是否可靠，最重要的不是它支持谁，而是它是否拥有充分的证据、严密的逻辑和能够一致适用的判断标准。
