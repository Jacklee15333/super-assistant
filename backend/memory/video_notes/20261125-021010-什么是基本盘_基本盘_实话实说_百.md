## 核心观点

### 1. 网络语境中的“基本盘”已经从中性概念演变为群体嘲讽标签
作者首先通过抖音搜索展示了部分网络观点对“基本盘”的定义，其中包括关注宏大叙事和国家叙事，却不关心自身生活和身边的人；习惯反驳他人、转移话题、缺乏逻辑与同理心；生活不如意却渴望赚大钱；容易受到片面信息影响、轻信缺乏根据的说法等。搜索结果本身也注明，这只是部分观点的总结，不能代表所有被称为“基本盘”的人。作者认为，这些描述将政治立场、心理性格、认知能力和经济状况强行绑定在一起，本质上是在对特定人群进行负面刻画。
在作者看来，现实中的网络使用标准其实没有那么复杂：凡是在网上表达对国家的支持、认同国家立场或者公开表达爱国情感的人，都可能被某些网民划入“基本盘”。因此，他认为这个词在特定网络圈层中已经不再是单纯的社会分析概念，而成为一种带有轻蔑、嘲讽和身份区隔意味的称呼。其背后的问题是，人们不再针对某个具体观点展开讨论，而是先给表达观点的人贴上标签，再通过标签否定其判断能力。

### 2. “基本盘”的本质是一个系统赖以维持的核心支持力量
作者试图将“基本盘”重新拉回其相对中性的含义，并给出自己的定义：“所谓的基本盘，就是这个系统的核心支持力量。”按照这一理解，无论是一个国家、政治组织、企业还是其他社会系统，都需要具有相对稳定认同和支持意愿的人群，才能维持自身的长期运行。
在视频中，作者将国家称为“这个家”，把认同国家、愿意支持国家的人视为维系这个共同体的重要力量。他认为，这类人的价值不应该仅仅以个人财富、消费能力、学历或者网络表达能力来衡量，而应该考虑他们对社会整体的认同与贡献。在作者的论述中，“基本盘”不仅不是一个应该感到羞耻的身份，反而代表着社会的稳定性、凝聚力和共同体意识。
不过，需要区分的是，广义上的“基本盘”指稳定的核心支持群体，并不天然意味着这一群体在道德、认知或实际贡献上一定优于其他人，这一点属于作者进一步赋予该概念的价值判断。

### 3. 消费品牌被部分网民用来表达身份认同和文化优越感
作者列举了三个非常具体的消费选择：手机使用苹果（Apple），汽车选择特斯拉（Tesla），购物选择山姆会员商店（Sam’s Club）。在作者看来，部分消费者对这些国外品牌的偏好，已经超出了产品性能、质量、价格和服务等正常消费决策的范畴，而变成了一种身份表达和文化立场展示。
例如，作者认为某些人高度认可特斯拉，却将其他电动汽车贬低为“几块电池绑四个轱辘”，这种评价并不是基于统一的技术标准，而是由品牌来源和预设立场决定的。他试图说明，部分人可能借助国外品牌建立自己比普通消费者更有见识、更理性、更高级的心理优越感。
这一观点涉及消费行为中的身份认同、品牌崇拜和象征性消费问题，但视频并未提供证据证明使用这些品牌的人普遍具有某种政治立场。因此，更准确的理解是：作者批评的是将品牌选择上升为文化优劣和政治身份判断的现象，而不是品牌本身的实际产品价值。

### 4. 对国内外科技成就采用不同评价标准，是作者重点批评的认知现象
作者以埃隆·马斯克（Elon Musk）的火箭项目和中国航空航天事业为例，指出部分网络评论可能对国内外科技成就存在明显不同的评价标准。在他描述的现象中，马斯克的火箭成功发射会被称为“人类之光”，即使试验失败，也能够被解释为积累经验、推动进步，甚至被评价为另一种成功；而中国的航空航天成就，却可能遭到“拇指按按钮训练五年”“宇航员得坐轮椅”等嘲讽。
作者还批评了另一种网络说法，即现代人使用的物品、身上穿的东西都是西方发明的，而中国取得的科技进步则被简单归结为抄袭。这种论述背后的核心问题，是评价标准是否会随着评价对象的国别和身份而发生变化。
如果国外技术失败可以被理解为探索成本，那么国内技术失败原则上也应该得到同样的分析；如果国内技术创新需要接受原创性和技术价值的检验，那么国外技术也应接受相同标准的检验。作者借此强调，应避免先决定自己喜欢或厌恶谁，再为不同对象寻找完全不同的解释方式。

### 5. 国际政治讨论中的双重标准，体现了立场先于事实的判断方式
作者进一步将这种评价方式延伸到国际政治和军事冲突领域，并列举了美国对外军事行动、加沙冲突、巴勒斯坦人的反抗、以色列对卡塔尔的袭击，以及胡塞武装针对以色列的行动等案例。
按照作者的描述，部分网民将美国的对外军事行动解释为传播文明，将以色列的军事行动解释为反恐或“定点清除”，却将巴勒斯坦人和胡塞武装的相关行动一概归类为恐怖袭击或恐怖主义。作者认为，这种叙述方式的问题在于，并非首先根据具体行动的性质、攻击对象、造成的后果以及国际法规则作出判断，而是先根据实施行动的一方属于哪个阵营，再决定使用什么样的道德评价和政治术语。
其背后的逻辑是，同一种行为可能因为实施者的身份不同而被赋予截然不同的名称，从而影响公众对事件正当性的判断。作者由此批评一种他认为普遍存在的现象：凡是中国支持的对象就反对，凡是与中国关系友好的国家或组织就加以抹黑。
需要注意的是，这些国际冲突涉及复杂的历史背景、国际法规则与具体事实，不能仅凭视频中的概括就判断每一项军事行动是否合法，也不能把所有持不同意见的人归为同一阵营。

### 6. “山河四省”“鸿蒙四省”等网络称呼反映了地域、品牌与政治身份的标签化
作者提到，近期网络上出现了将“山河四省”称为“基本盘大省”的说法，还出现了“鸿蒙四省”“鸿蒙思维”“鸿蒙问题”“在华为店接生”等带有讽刺意味的表达。其中，“山河四省”通常指山东、山西、河南、河北四个省份，而“鸿蒙”则是华为（Huawei）旗下的操作系统 HarmonyOS（鸿蒙操作系统）。
作者认为，这些说法试图把一个人的出生地域、消费习惯、国产品牌偏好、科技产品选择和政治价值观绑定起来，并通过这种绑定划分所谓的高认知与低认知人群。在这种舆论逻辑下，一个人支持国产科技品牌、生活在特定省份或者表达国家认同，都可能被当作判断其思想水平的依据。
作者对此提出强烈反感，认为“给人泼脏水、扣帽子、做分类”是其所批评群体的重要特征。这实际上涉及地域歧视、群体刻板印象、消费鄙视链和网络身份政治等多个问题：当群体标签代替具体事实时，正常的社会讨论就容易演变为不同身份群体之间的相互攻击。

### 7. 财富水平不能直接证明一个人的认知水平、道德品质或社会价值
视频后半段讨论了“边角料更容易赚到钱，而基本盘普遍比较穷”的网络说法，作者没有直接否认这种说法，而是试图从财富积累方式和道德约束角度重新解释它。他认为，一些人之所以能够获得更多财富，可能并非因为认知能力更强，而是因为更善于钻营、利用关系、调动社会资源，或者在赚钱过程中具有更少的道德约束。
作者使用了“好人发不了财”“良心坏了的人，他才会有那么多手段去赚钱”等措辞，并指出某些人口头上反对人情往来，私下却可能更加依赖人脉关系和利益交换。他进一步提到，富裕群体和超级富豪所拥有的资源、人脉和社会关系，往往是普通人难以想象的。
作者想要反驳的核心逻辑是：**赚到更多钱，不等于拥有更高的认知、更优秀的人格或更正确的政治判断。**不过，视频从这一合理提醒进一步推导出富人普遍存在不干净的原始积累等结论，属于缺乏充分证据的过度概括，不能视为已经得到证实的社会规律。

### 8. 经济利益、资源关系与个人政治立场之间可能存在关联
作者进一步提出，当国家收紧某些政策，或者国家与某些外部利益关联方发生矛盾时，部分依赖这些资源、关系和利益网络的人，可能会因为自身利益受到影响而改变立场。
在他的解释框架中，一个人的政治态度并不总是完全来自独立思考和抽象价值观，也可能受到资产来源、商业利益、社会关系和经济依赖的影响。例如，当政策调整影响既有财富积累模式、经营空间或者特殊利益时，直接受到影响的人可能对相关政策表达不满。
这一观点实际上涉及政治经济学中利益结构与政治偏好之间的关系，即人们所处的经济位置和资源依赖可能影响其对公共政策的看法。但作者将这种可能性直接延伸为对特定群体忠诚度的否定，甚至以“屁股是歪的”等表述进行道德评判，就超出了现有论据能够支持的范围。
理解利益因素有助于分析一个人的观点形成过程，但不能因此认定所有反对某项政策的人都存在不当利益关系，因为政策批评也可能来自专业判断、公共利益考虑或者不同的价值取向。

### 9. 作者强调共同体归属感与建设性参与的重要性
在视频结尾，作者再次回到“基本盘”的定义，强调“基本盘是撑起这个家的主流”。他认为，真正有价值的社会成员不仅应该享受社会发展所带来的成果，也应该对共同体具有责任意识，并在社会面临困难时愿意承担相应责任。
与此相对，作者将其所称的“边角料”描述为不愿意伸手帮助、只在旁边袖手旁观、看热闹和发表负面评论的人。他还直接批评了被称为“老陈”的对象，声称对方在国内和国外都处于边缘位置，却仍然将自己视为更加深刻和清醒的人。
这里反映出作者对“归属感”“社会贡献”和“自我优越感”之间关系的理解：他认为，单纯依靠否定原有共同体或者认同其他共同体，并不必然能够获得新的社会地位和真正的归属。不过，视频针对“老陈”的个人经历指控并没有提供证据，同时，对国家的认同、对具体政策的批评以及对社会问题的关注也并非必然相互矛盾，建设性的批评同样可能是一种社会参与方式。

## 值得记住的点 / 行动建议
以下内容结合作者的论述提炼，同时将其中具有普遍价值的部分转化为更加客观、可操作的思考方法。

### 1. 区分一个词的原始含义与它在网络中的情绪含义
遇到“基本盘”“边角料”等具有明显立场色彩的网络词汇时，不要立即接受使用者赋予它的全部含义。
首先判断这个词原本描述的是什么，其次判断它在当前语境中是否已经成为一种攻击性标签，最后再分析被贴标签的人究竟表达了什么观点、采取了什么行为。
例如，“基本盘”原本可以用于描述政党的稳定支持者、企业的核心客户、品牌的忠实消费者或某个组织的稳定成员，并不是天然具有贬义的词汇。
掌握这种分析方式，可以避免被网络语言预先设定的价值判断所影响。

### 2. 使用统一的评价标准，识别自己和他人的双重标准
判断一种观点是否合理，可以使用“交换评价对象”的方法。

| 原有判断 | 可以提出的反向问题 |
| --- | --- |
| 国外火箭试验失败是探索成本 | 国内火箭试验失败是否也应考虑技术探索价值？ |
| 国内企业借鉴国外技术就是抄袭 | 国外企业借鉴其他国家技术时，是否采用同样的标准？ |
| 国外品牌质量好，所以消费者认知高 | 国产品牌质量好，是否也能得出同样的结论？ |
| 某一方的军事行动属于自卫 | 另一方实施类似行动时，判断标准是否一致？ |
| 有钱人一定更加聪明 | 聪明但收入较低的人是否构成反例？ |
| 穷人一定更加善良 | 经济状况能否直接证明一个人的道德品质？ |

这种方法的重点不是证明哪一方永远正确，而是检查自己的判断是否因为对象的国籍、品牌、身份或政治立场而发生不合理的变化。

### 3. 不要通过消费品牌判断一个人的思想水平和国家认同
一个人购买苹果手机、特斯拉汽车或者在山姆购物，可能只是因为产品生态、驾驶体验、价格、服务质量或者个人习惯。
同样，一个人购买华为手机、支持国产新能源汽车，也可能只是基于实际需求、产品性能和个人偏好。
更理性的消费决策应该关注产品的实际质量、安全性、技术能力、使用成本、售后服务以及是否符合自身需求，而不是将品牌选择变成身份优越感的证明。
买什么产品是消费选择，不应该自动成为判断一个人政治立场、道德水平或者认知能力的依据。

### 4. 将科技进步视为需要长期积累的过程，而不是简单的阵营竞争
在评价航空航天、新能源汽车、操作系统等科技领域时，应该尽量了解技术原理、研发难度、试验过程、产业链能力、产品成熟度和实际应用价值。
科技创新通常包括基础研究、技术借鉴、工程试验、失败复盘、产品迭代和商业化等多个阶段，因此一次试验失败不一定意味着整个技术路线失败，一次成功也不意味着所有问题已经解决。
面对国外科技进步，可以认可其真实贡献；面对国内科技进步，也可以根据相同的标准进行评价，同时保留对不足之处的批评。
既不因为技术来自国外就无条件崇拜，也不因为技术来自国内就无条件肯定，才能形成更稳定、更接近事实的科技判断。

### 5. 分析国际事件时，先判断具体行为，再判断政治立场
面对国际军事冲突和政治争议，不应该仅仅根据某个国家或组织与本国的关系，决定其行为是否正确。
更具参考价值的分析维度包括事件的历史背景、行为实施者、行为对象、是否伤害平民、军事行动是否具有合法依据、是否符合国际人道法，以及不同消息来源是否能够相互印证。
尤其需要警惕“文明”“反恐”“自卫”“侵略”“定点清除”等具有强烈政治和道德含义的词汇，因为使用这些词汇本身并不能证明相关行为的合法性。
评价具体行动，并不意味着必须对实施该行动的国家或组织进行整体支持或整体否定。

### 6. 警惕地域歧视、品牌鄙视链和群体刻板印象
“山河四省”“鸿蒙四省”等标签可能在传播过程中不断被附加政治、文化、经济和认知层面的含义，从而使原本复杂多样的人群被简化成单一形象。
判断一个人的能力和品质，需要了解其真实行为、知识水平、生活经历、价值判断以及与他人相处的方式，而不是根据籍贯或所使用的手机品牌得出结论。
当别人试图通过地域、学历、收入、职业、品牌等标签迅速判断某个人时，可以追问：这种判断是否存在可靠的统计依据？是否忽略了群体内部的大量差异？是否仅仅是在借助少数案例强化已有偏见？
对标签化的最佳反击不是创造另一个相反的贬义标签，而是重新将讨论拉回具体的人和具体的事实。

### 7. 正确认识财富、认知、道德与社会资源之间的关系
作者关于财富问题的论述虽然存在明显的情绪化和过度概括，但其中有一个值得保留的观点：财富水平不是衡量一个人全部价值的指标。
个人财富受到许多因素共同影响，包括家庭背景、教育机会、行业选择、专业能力、劳动付出、商业模式、社会资源、资本规模、风险承担、时代机遇和运气，以及经营行为是否符合法律和道德规范。
富有的人不一定更加聪明或更加善良，收入较低的人也不一定更加愚蠢或更加高尚。
普通人在追求财富的过程中，应该关注合法经营、长期信誉、专业能力、真实价值创造和可持续的收入来源，而不是将突破道德底线误认为赚钱的必要条件，也不要因现实收入差距而产生不必要的自卑或道德优越感。

### 8. 从利益结构理解观点，但不要陷入动机揣测
当某个人对一项政策、一家企业或者一个国家发表强烈评价时，了解其职业背景、利益关系、资源来源和社会处境，有时可以帮助理解其观点形成的原因。
例如，一项政策的调整可能给不同职业、行业和资产持有者带来不同影响，因此不同群体对同一项政策产生不同评价并不奇怪。
但是，利益相关并不等于观点错误，没有直接利益关系也不等于观点正确。判断一个观点最终仍然需要回到事实、逻辑、证据和实际后果，而不能仅凭对发言者动机的猜测决定其观点是否成立。
这能够避免陷入一种常见的逻辑错误：不去反驳一个人说了什么，而是通过质疑他为什么这样说，直接否定其全部论述。

### 9. 国家认同与独立思考并不冲突
关心国家发展、科技进步、社会稳定和公共利益，与关注自己的工作、收入、家庭、身体健康和现实生活，并不是相互排斥的关系。
一个人可以对国家具有认同感，同时对具体政策和现实问题提出批评；也可以认可国外先进的技术、制度经验和优秀产品，同时积极支持国内的发展。
更加成熟的共同体意识，不是无条件地肯定所有事情，也不是通过否定一切来证明自己清醒，而是能够区分整体认同与具体判断。
在能力范围内做好本职工作、维护公共秩序、尊重他人、遵守法律、提升专业能力，并对社会问题提出建设性意见，都是具有实际意义的社会参与方式。

### 10. 识别网络论战中常见的认知陷阱
这段视频本身也可以作为观察网络论战方式的案例，其中涉及多个值得警惕的思维现象。

| 认知陷阱 | 具体含义 | 在本视频中的表现 |
| --- | --- | --- |
| 确认偏误 | 更愿意接受符合已有观点的信息 | 选择性肯定自己支持的一方 |
| 双重标准 | 对相似行为采用不同评价尺度 | 对国内外科技失败的不同解释 |
| 过度概括 | 从少量案例推导整个群体的特征 | 将富裕群体与不道德积累直接关联 |
| 群体刻板印象 | 根据群体身份推断个人特征 | 通过地域、消费品牌判断认知 |
| 人身攻击 | 攻击发言者而非具体观点 | 使用“基本盘”“边角料”等贬义标签 |
| 虚假二分 | 将复杂问题压缩为两个对立选项 | 将社会成员简单划分为两个阵营 |
| 动机归因 | 通过推测他人动机否定其观点 | 将政策批评直接归结为既得利益受损 |
| 内群体偏好 | 更容易认可自己所属群体 | 对己方行为采取更加宽容的解释 |
| 外群体同质化 | 认为另一个群体的成员都差不多 | 将不同消费习惯和政治观点归为同一类人 |

这些认知问题不只可能出现在作者所批评的群体中，也可能出现在作者自身的论述中。
真正具有独立思考能力的人，需要用同一套逻辑标准审视自己认同和不认同的观点，而不是只在反驳他人时才强调理性。

## 我的点评
这段视频比较值得认同的地方，在于它指出了中文互联网中存在的消费鄙视链、地域标签化、财富崇拜、科技评价双重标准，以及通过贬低他人建立自我优越感等问题，并尝试恢复“基本盘”作为核心支持力量的中性含义。作者关于财富不能直接证明认知水平、品牌不能直接证明个人价值、国内外科技成就应该接受统一评价标准的思考，具有一定的现实意义。
但是，视频最明显的逻辑矛盾是，作者一方面反对别人扣帽子、做分类和制造群体刻板印象，另一方面又使用“边角料”这一贬义标签，将国外品牌消费者、富裕群体、政策批评者和持不同政治观点的人联系起来，在一定程度上重复了自己所批评的思维方式。尤其是关于“好人发不了财”“超级富豪的原始积累不干净”等判断，没有统计数据、具体案例或者充分证据支持，容易将复杂的财富形成机制简化为道德对立。
此外，爱国并不等于无条件赞同，批评也不等于否定国家，支持国外优秀技术与支持国内发展同样不必然冲突。对于普通人来说，这段视频最大的参考价值，不是帮助自己选择成为哪一个阵营的成员，而是提醒自己避免用身份标签代替事实、用情绪代替逻辑、用立场代替证据，并且始终对自己和他人采用一致的判断标准。
