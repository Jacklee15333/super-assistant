## 核心观点

### 1. 《三十六计》是特定战争环境下的生存策略，而非日常社会交往的道德准则
被反驳的律师认为，《三十六计》将瞒天过海、笑里藏刀等尔虞我诈的行为包装成智慧，导致社会陷入永无止境的猜疑链。视频作者则强调，《三十六计》是后世总结的战场实用策略，其应用环境是生死存亡、敌我对抗以及国家安全受到威胁的战争场景。在这种环境中，隐瞒意图、迷惑敌人、出其不意等做法，是为了赢得战争、降低损失、保存自身力量，而不是鼓励普通人在生活中欺骗他人。
作者认为，不能脱离一个思想或策略产生的历史背景和适用条件，直接用它来解释当代社会的道德问题。战争中的策略合理性与和平社会中的道德正当性，是两个不同层面的问题；掌握谋略不等于推崇欺诈，懂得防范他人也不意味着必须主动伤害他人。

### 2. 现代社会确实存在信任危机，但不能简单将其归咎于古代文化
律师在视频中描述了一种相互防备的社会状态：商家研究声东击西的营销套路，消费者研究各种避坑指南，每一场交易都像心理战，每一次合作都仿佛需要暗度陈仓。作为一名自称从业十多年的律师，她还表示，经常在后台看到粉丝留言中透露出的防御心理和相互试探，这种现象让她感到心凉。
视频作者并未直接否认现代商业活动中存在虚假宣传、消费陷阱、利益算计等问题，而是反对将这些问题与《三十六计》建立简单的因果关系。作者认为，只要商业活动存在竞争、利益分配和信息差，就可能产生相互防范甚至欺骗的行为，这并非中国社会独有的现象。
从因果逻辑来看，社会存在欺诈现象，与社会拥有一部讲述军事谋略的古代著作，并不能直接证明两者之间存在决定性的因果关系。发现社会问题是一回事，准确解释社会问题为什么产生，则是另一回事。

### 3. 不能只挑选传统文化中的负面材料，而忽视大量重信守诺的历史传统
作者批评了一种选择性评价中国传统文化的现象：提起中医就强调负面争议，提起中国历史就只讨论残酷、黑暗的一面，提起传统文化就想到太监文化、裹小脚、磕头等体现封建压迫的内容。在作者看来，如果长期采用这种筛选方式，就容易将中国历史整体塑造成愚昧、黑暗、顺从、缺乏独立人格的历史。
为了反驳《三十六计》代表中国人尔虞我诈的观点，作者列举了退避三舍、赵氏孤儿、《刺客列传》等历史典故与文学记载，并提到从周公时代开始就存在关于“信”的道德观念。作者还提及2026年的一组现实人物互信互助的案例，试图说明重视承诺、彼此帮助的行为并未随着时代发展而消失，不过文字稿中的具体人名存在识别错误，无法准确确认。
这一观点背后的逻辑是，中国传统文化内部本身就存在丰富且多元的价值体系，既包含军事谋略，也包含诚信、仁义、守诺、责任和牺牲。不能用一种思想、一部著作或几个负面历史现象，概括整个文明的文化底色。

### 4. 商业竞争、资本逐利和信息不对称，是解释现代商业信任问题的重要因素
作者认为，与其将现代商业中的欺诈行为归咎于《三十六计》，不如关注现代商业体系中真实存在的利益驱动机制。视频列举了一系列相关现象和概念，包括现代营销学、消费者心理学、价格歧视、饥饿营销、信息不对称、品牌洗脑、金融割韭菜、市场垄断、关税壁垒以及贸易霸凌等。
在这些现象中，企业可能利用自身掌握的信息、资源和市场地位，影响消费者的购买决策，甚至通过不透明的规则获取更多利益。与此同时，消费者为了避免承担损失，会主动研究产品测评、避坑指南、合同条款以及各种营销套路，从而形成商家与消费者之间不断升级的防御关系。
作者强调，无论在哪个国家，只要发展商业，就必然伴随着竞争与利益算计，因此商业中的诚信问题不能被简单定义为某个民族的文化缺陷。不过，价格歧视、营销、品牌建设等商业手段本身并不必然构成欺诈，需要进一步区分正常商业行为与违法违规、操纵性或损害消费者权益的行为。

### 5. 西方历史同样存在大量欺诈、掠夺和利益算计，信任问题并非中国独有
为了反驳尔虞我诈是中国传统谋略文化所导致的说法，作者将视角扩展至西方商业史、殖民史和国际政治。视频提到大航海时代及其后的殖民扩张，认为一些殖民者曾接受当地原住民的帮助，随后却通过武力和掠夺损害当地居民的利益。
作者还列举了鸦片贸易、黑奴贸易、华尔街房地产金融问题、石油美元体系、长臂管辖、退出国际组织或协议、撕毁承诺，以及一边谈判一边采取军事行动等现象。通过这些例子，作者试图说明西方历史中同样存在利用信息差、实力差距、规则优势和利益算计损害他人的行为。
作者由此质问：如果西方社会也存在大量商业诈骗和失信行为，而西方社会并不是以《三十六计》作为传统文化基础，那么为什么能够将中国的信任危机主要归咎于《三十六计》？这一论证能够提示信任问题具有跨文化、跨社会的普遍性，但作者进一步将美西方概括为尔虞我诈的“祖师爷”和“集大成者”，则属于带有鲜明立场的评价，并不能仅凭视频所列举的案例得到充分证明。

### 6. 不能用简单的文化归因方式解释躺平、内卷等复杂社会现象
作者通过一系列反问，将对《三十六计》的批评延伸到其他传统思想与现代社会问题之间的关系。如果今天很多人选择躺平，是否就应该归咎于老子所提出的“无为”思想？如果今天一些人不愿意努力、不追求上进，是否就应该把责任推给《道德经》中的相关论述？
同样，如果今天社会竞争激烈、工作压力巨大、内卷现象严重，难道就应该归咎于古人所推崇的“天道酬勤”？作者借助这种类比，指出从古代思想中随意选取一句话，再将其与现代社会问题建立因果关系，实际上很容易得出荒谬或者片面的结论。
躺平、内卷和社会信任下降等现象，都可能受到经济环境、就业压力、资源分配、竞争机制、社会保障、技术变化以及个人价值观等多种因素共同影响。传统思想可能影响现代人的行为，但不能因为两者之间存在某种表面联系，就认定传统思想是现代社会问题的根源。

### 7. 科技进步和物质繁荣不一定能够提高人的幸福感，资本与消费主义可能带来新的压力
视频作者进一步讨论了消费主义、现代营销体系和资本逐利对个人生活的影响，认为这些因素可能比古代军事谋略更值得关注。作者指出，科技发展原本应该提高生产效率、减轻人们的负担，但现实中很多人并没有因为科技进步而活得更加轻松。
手机和电脑虽然为生活提供了巨大便利，却没有必然让人的人生变得更有意义、更充实；相反，有些人刷了一整天手机之后，会感到内心空虚甚至焦虑。作者还感叹现代生活的时间流逝越来越快，人在持续的信息刺激、工作竞争和消费需求中，不知不觉就度过了几十年。
这一段讨论实际上触及了技术效率提升与个体幸福感之间的矛盾：如果效率提升带来的收益没有转化为更多的休息时间、生活自主权和精神满足，那么技术进步就可能同时伴随着更快的工作节奏、更高的消费欲望以及更严重的注意力消耗。作者因此希望人们将批判的重点放在现实生活中的结构性压力，而不是将所有问题都归咎于传统文化。

### 8. 评价中国的发展成就，需要结合历史起点、发展阶段和现实条件
作者认为，中国目前仍然是一个发展中国家，却经常被直接拿来与世界上唯一的超级大国进行比较，而这种比较如果忽略历史发展起点和资源条件，就容易失去公平性。视频强调，中国曾经处于十分贫穷、落后的发展状态，而今天已经成长为能够与多个西方发达国家展开竞争的经济体。
在作者看来，从贫穷落后到取得今天的发展成就，本身就体现了社会发展能力、民族韧性以及长期努力所积累的成果。作者进一步提出，如果类似的经济与社会发展成就发生在西方国家，一些人可能会给予高度赞扬，而当这些成就发生在中国时，却容易被忽视，甚至受到更加苛刻的批评。
这一观点反映出作者对评价标准不一致的担忧，即不能只看某个国家当前还存在多少问题，而忽略其历史起点、发展速度和已经取得的进步。但承认发展成就与正视现实问题并不冲突，发展中国家的身份也不应成为回避具体制度、市场治理或社会诚信问题的理由。

### 9. 反对以偏概全和文化污名化，主张建立更加完整的民族与文化认知
视频最后将讨论上升到了文化认同与民族认同的层面，认为如果有人不断从中国历史中寻找负面现象，并用这些现象否定整个民族的文化基础，就是一种极端片面的历史观。作者认为，《三十六计》体现的是古人在复杂环境中分析局势、制定策略、应对风险的能力，而不能被直接定义为中国社会尔虞我诈的思想根源。
作者还强调，一些人对西方文化及商业体系中的负面影响缺乏同等程度的批判，却对本国传统文化采取更加严苛的评价标准，这在他看来反映了独立思考能力的不足。整段视频因此不仅是在为《三十六计》辩护，也是在反对作者所认定的文化自我贬低和选择性历史叙事。
不过，视频后半段使用了大量情绪化表达、人身攻击和群体标签，在一定程度上削弱了前面关于因果关系和历史语境的理性论证。真正成熟的文化自信，应当既有能力认识自身文化的价值，也有能力坦然面对传统文化中确实存在的问题，而不需要通过否定其他文明来证明自身的优越性。

## 值得记住的点 / 行动建议
以下建议既包括作者明确表达的主张，也包括从视频争论中进一步提炼出的可操作思考方法。

### 1. 理解任何思想，都要先弄清楚它产生的背景和适用边界
不要脱离历史环境、现实条件和使用目的评价一种思想是否正确。《三十六计》适用于军事对抗，并不意味着其中每一个计谋都适合应用于家庭、朋友、商业伙伴或者普通社会交往。
同一种策略，在不同环境中的道德评价可能完全不同。例如，军事行动中隐藏真实计划可以保护己方人员，但商家在销售过程中故意隐瞒产品缺陷，就可能构成对消费者权益的侵害。
以后遇到类似思想时，可以先问自己四个问题：
- 它是在什么历史环境下产生的？
- 它原本是为了解决什么问题？
- 它适用于哪些对象和场景？
- 将其应用于现代生活，会不会超出原本的适用范围？

不要把局部场景中的有效策略，当成适用于所有社会关系的人生哲学。

### 2. 区分相关性与因果关系，警惕对复杂问题的单一归因
一个社会存在《三十六计》，同时也存在商业欺诈，并不能直接证明商业欺诈是由《三十六计》造成的。同样，社会中有人躺平，不代表他们受到老子“无为”思想的影响；社会中有人内卷，也不意味着“天道酬勤”是内卷的根源。
面对复杂社会问题，应该从多个维度寻找解释，包括经济利益、竞争机制、法律约束、监管效率、信息透明度、社会环境、文化观念以及个人行为选择。
一个非常实用的判断方法是进行反事实检验：如果一个没有《三十六计》传统的社会，同样存在商业诈骗和信任危机，那么《三十六计》显然不是此类问题产生的必要条件。
当然，这也不能证明文化完全没有影响，而是意味着要证明具体文化因素的影响程度，还需要更充分的证据。

### 3. 不要用少数典型案例概括整个民族、国家或文化
当有人列举几个负面的历史事件，并试图用这些事件证明某个民族缺乏诚信、某种文化本质上落后时，应当警惕以偏概全。
中国历史上既有军事谋略、宫廷斗争和权力算计，也有诚信、仁义、舍生取义、重信守诺的传统；西方历史上同样既有殖民掠夺、商业欺诈，也有契约精神、商业信用、法治建设和社会合作的发展。
评价任何一个文明，都应当主动寻找能够支持和反驳自己观点的材料，而不是只收集符合既有立场的案例。
判断一个人的历史观是否客观，不仅要看他展示了哪些事实，还要看他忽略了哪些事实，以及他的结论是否超过了证据能够支持的范围。

### 4. 面对商业信任问题，优先关注利益机制，而不是给人贴文化标签
普通人在消费、签订合同、开展合作或者参与商业活动时，与其猜测对方是否信奉某种谋略，不如直接分析交易结构。

| 需要关注的因素 | 具体做法 |
| --- | --- |
| 对方的利益来源 | 弄清楚对方通过什么方式赚钱 |
| 信息是否透明 | 核实产品参数、收费规则、合同条款和附加条件 |
| 承诺是否可信 | 查看历史履约记录、第三方评价和可验证材料 |
| 违约成本 | 判断对方失信之后需要承担什么责任 |
| 维权渠道 | 提前了解售后、退款、投诉及法律救济方式 |
| 风险分配 | 明确交易失败后由谁承担损失 |
| 合作期限 | 判断对方追求一次性利益，还是重视长期关系 |

现实中的可信任关系，通常不只是依赖对方的个人道德，也依赖透明的规则、合理的激励机制、明确的责任以及足够的违约成本。
与其不断学习怎样识别别人的计谋，不如尽量选择信息透明、责任明确、双方利益一致的交易环境。

### 5. 建立有边界的信任，而不是在盲目信任和完全不信任之间二选一
视频中的律师提到，社会中许多人在交往时表现出明显的防御和试探心理。这种现象值得重视，因为如果每个人都默认对方会欺骗自己，整个社会的合作成本就会不断上升。
但解决信任危机也不意味着要求所有人无条件相信陌生人。更加现实的做法是建立分层次、可验证、能够逐步积累的信任机制。
例如，第一次合作可以从小额交易开始，经过多次稳定履约之后再扩大合作规模；涉及重大金额或长期责任时，可以通过书面合同、分阶段付款、第三方保障等方式降低风险。
这样既能够保护自身利益，也不会因为对风险的过度恐惧而完全放弃与他人合作的可能性。
成熟的信任不是毫无防备，而是在合理防范风险的同时，仍然保留与他人建立长期合作关系的能力。

### 6. 对营销套路和消费主义保持警惕，避免被人为制造的需求支配
作者提到饥饿营销、品牌宣传、消费者心理学和资本逐利，这些概念对于普通人的消费决策具有一定现实意义。
当商家使用限时优惠、库存告急、即将涨价、身份象征、从众心理等方式刺激购买时，可以主动区分真实需求与营销刺激。
具体可以采用以下方法：
- 购买非必需品之前设置24小时至72小时的冷静期。
- 不仅比较折扣比例，还要比较历史价格、实际成交价和同类产品价格。
- 将产品的功能价值与品牌带来的身份认同分开考虑。
- 不因为“别人都在买”或“错过就没有了”而仓促消费。
- 在付费之前确认退款条件、售后服务和长期使用成本。
- 定期复盘自己的消费记录，识别冲动消费、闲置消费和重复消费。

商业营销并不天然有害，但消费者应该保留独立判断的能力，而不是完全按照商家设定的购买节奏行动。

### 7. 重新审视科技工具与个人幸福感之间的关系
作者关于手机、电脑以及现代人精神空虚的讨论，值得从个人生活管理的角度进一步思考。
技术能够帮助人们节约时间，但如果节约下来的时间全部被更多工作、更多信息和更多娱乐刺激占据，那么技术效率提高并不一定能够改善生活质量。
可以尝试减少无目的的信息浏览，关闭非必要通知，为短视频和社交媒体设置使用时间上限，并将节约下来的时间投入阅读、运动、深度思考、现实社交和真正有意义的活动。
每天除了考虑自己完成了多少任务，也可以考虑自己是否拥有足够的自主时间、是否进行了有质量的交流、是否获得了真实的休息。
衡量技术是否真正改善生活，不仅要看它让人完成了多少事情，更要看它是否让人拥有更多自由、选择权和精神满足。

### 8. 比较不同国家的发展水平时，要使用一致的评价标准
视频作者强调中国的发展阶段和历史起点，这提示我们在进行国际比较时，需要避免只看某一个时间点的绝对差距。
更加完整的比较应该同时考虑：
- 历史发展起点。
- 人口规模与人口结构。
- 人均经济发展水平。
- 基础设施与产业发展程度。
- 教育、医疗和社会保障水平。
- 不同发展阶段面临的主要问题。
- 长期增长趋势及已经取得的进步。
- 仍然存在的制度、经济和社会问题。

既不能因为一个国家仍然存在问题，就否定它已经取得的全部成就，也不能因为它取得了显著成就，就认为所有现实问题都不应该受到批评。
评价标准一致，比预先决定哪个国家更值得赞扬或批评更重要。

### 9. 文化自信不应该建立在文化自我否定或对其他文化的全盘否定之上
作者希望人们认识中国传统文化中的正面价值，而不是将所有社会问题归咎于自身的历史和文化。这种反对文化污名化的意识具有一定合理性，但同样需要警惕走向另一个极端，即认为自身传统文化不存在问题，或者其他文明只能用欺诈、掠夺和利益算计来概括。
真正具有独立思考能力的人，可以同时承认中国传统文化中的智慧与局限，也可以同时认识西方文明中的有益成果与历史问题。
对《三十六计》这样的传统著作，可以吸收其中关于形势判断、风险识别、资源调配、灵活应变和战略思考的价值，同时避免将敌我对抗的思维无限扩大到普通人际关系之中。
学习传统文化的目的，不应该只是证明古人正确或者某个民族更加优秀，而应该是帮助现代人更好地理解世界、解决现实问题和完善自身行为。

### 10. 在网络争论中，重点分析论证质量，而不是被情绪和立场牵着走
这段视频本身也可以作为训练批判性思维的案例：双方虽然立场不同，但都在尝试使用具体社会现象支持自己的判断，同时也都存在论证可能超出证据范围的问题。
观看类似评论视频时，可以将内容拆分成四个层次：

| 层次 | 应该如何判断 |
| --- | --- |
| 事实 | 具体发生了什么，是否有证据支持 |
| 解释 | 作者认为事情为什么发生，是否存在其他解释 |
| 价值判断 | 作者赞成或反对什么，依据是什么 |
| 情绪表达 | 愤怒、讽刺、攻击是否影响了理性分析 |

例如，“现代商业活动中存在欺诈”是一个可以通过现实案例和数据研究的问题；“商业欺诈主要源于《三十六计》”是一项需要证明的因果判断；而“某种文化或某个群体是尔虞我诈的祖师爷”则包含了强烈的价值评价和概括性判断。
不要因为认同一个人的部分观点，就接受他的全部结论；也不要因为不喜欢一个人的表达方式，就认为他的所有观点都没有价值。

## 我的点评
这段视频最值得认同的地方，是指出了脱离历史语境评价传统思想、将复杂社会问题归咎于单一文化因素，以及用局部现象否定整个文明这三种常见的思维错误。《三十六计》作为军事谋略著作，确实不能直接被认定为现代社会信任危机的根源，但这也不意味着将权谋思想过度应用于日常社会关系不会产生负面影响。作者将视角转向商业竞争、资本逐利、信息不对称和消费主义，有助于寻找更加具体的现实原因，不过其对西方社会的整体性负面评价，也存在与其所批评的以偏概全相类似的问题。双方都没有提供足够的跨国社会信任度调查、历史研究或商业欺诈统计数据，因此这场争论更多属于观点交锋，而不是已经得到充分验证的因果分析。普通人真正值得关注的，是低信任如何形成自我强化的循环：欺诈导致防备，防备增加合作成本，合作成本上升又可能进一步恶化社会信任，而改善这种循环需要诚信教育、透明规则、有效监管和稳定的利益约束机制。最有价值的思考方式，是既不盲目否定传统文化，也不将传统文化神圣化，在文化自信、独立思考和理性批判之间保持平衡。
