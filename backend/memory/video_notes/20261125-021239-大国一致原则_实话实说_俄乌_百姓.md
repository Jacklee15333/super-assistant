## 背景与主题
视频主要针对网络上常见的一个争议展开讨论，即“既然美国可以打伊拉克、打阿富汗，为什么俄罗斯不能打乌克兰”。文字稿包含正反两方的论述：前半部分认为美国发动的相关战争具有联合国授权、反恐自卫或大国共识等依据，与俄罗斯对乌克兰发动的军事行动存在本质区别；后半部分则从事实、逻辑、国际规则三个层面逐一反驳，认为前者歪曲了“大国一致原则”，忽略了美国发动战争造成的人道主义灾难，也忽略了北约东扩、敦巴斯冲突等俄乌战争的历史背景。双方争论的实质，是如何在国际政治中区分战争的合法性、正当性、现实政治支持度与历史成因，以及能否用一套统一的标准评价美国和俄罗斯的军事行动。

## 核心观点

### 1. 评价战争不能简单地以“谁打谁”为标准，而应考察军事行动的法律依据与具体背景
正方认为，把美国打伊拉克、打阿富汗与俄罗斯打乌克兰直接画等号，是缺乏历史常识的表现，因为几场战争发生的背景、联合国的态度和国际社会的反应存在明显差异。其论证思路是：1991年海湾战争具有联合国授权，2001年阿富汗战争具有反恐自卫背景，而俄罗斯对乌克兰发动的军事行动遭到了联合国大会多数成员国的反对。反驳方则认为，正方选择性地强调了美国发动战争的理由，却忽略了美国军事行动的实际后果，以及俄罗斯所面临的地缘政治和国家安全问题。双方其实都反对简单地根据交战双方的身份判断是非，只是所采用的评价标准不同。这里需要进一步区分四个维度：战争的历史成因、发动战争的合法性、战争实施过程的合法性，以及战争造成的人道主义后果，这四者既相互关联，又不能相互替代。

### 2. 1991年海湾战争具有明确的联合国授权，但授权存在特定目的和范围
正方以1991年海湾战争作为第一个例子，指出萨达姆领导下的伊拉克于1990年出兵侵占科威特，随后美国联合英国、法国等国组成多国部队，对伊拉克发动军事行动。正方认为，这场战争经过联合国授权，因此不能与未经联合国授权的军事行动相提并论。反驳方则强调，联合国授权的目的在于将伊拉克军队逐出科威特，而不是赋予美国无限制打击伊拉克或推翻萨达姆政权的权力。事实上，联合国安理会于1990年11月29日通过第678号决议，允许与科威特政府合作的成员国在规定条件下采取一切必要手段，执行有关决议并恢复地区和平与安全。
digitallibrary.un.org
 因此，正方关于海湾战争具有明确授权的说法基本正确，反驳方关于授权存在边界的提醒也有价值，但将授权范围理解为只能在科威特境内驱逐伊拉克军队，又过于狭窄。
核心逻辑：有权采取军事行动，不等于拥有不受限制的军事行动权。

### 3. 2003年伊拉克战争没有获得新的明确授权，也不存在主要大国一致支持
正方承认，2003年美国发动第二次伊拉克战争时，确实绕过了联合国，但试图用“大国一致原则”解释这场战争的正当性。反驳方指出，中国、俄罗斯明确反对发动战争，德国、加拿大等国也没有参加此次入侵行动，因此所谓的大国一致并不符合历史事实。2002年11月8日，联合国安理会通过第1441号决议，要求伊拉克履行裁军义务、接受武器核查，但这并不等于明确授权美国发动新一轮战争。美国和英国后来主张，此前的联合国决议可以构成使用武力的依据，而中国、俄罗斯、法国等国反对这种解释。
digitallibrary.un.org
 这个案例说明，同样由美国主导、同样针对伊拉克的两场战争，其国际法依据却存在重大差别，不能将1991年的授权直接移植到2003年的战争中。

### 4. 阿富汗战争需要区分初期反恐自卫与后续长期军事行动
正方认为，2001年美国出兵阿富汗的直接背景是“9·11”恐怖袭击，本·拉登（Osama bin Laden）领导的“基地”组织（Al-Qaeda）制造了严重的人员伤亡，因此美国具有反恐和自卫的理由。正方还提到，事发后许多国家向美国表示慰问，各国领导人向时任美国总统小布什表达支持，试图说明美国当时具有广泛的国际政治支持。反驳方则将重点放在美国后续长期驻军、平民伤亡以及战争造成的人道主义灾难上，认为不能用最初的反恐理由为整个战争过程辩护。实际上，联合国安理会第1368号、第1373号决议确认了相关自卫权，但没有像海湾战争第678号决议那样，直接、明确地授权随后开始的阿富汗战争；美国和英国当时主要援引《联合国宪章》第51条的自卫权。
digitallibrary.un.org
 因此，将阿富汗战争从开始到结束全部认定为合法，或者仅凭后续长期驻军便将最初的军事行动一概认定为非法，都缺乏足够细致的法律分析。
核心逻辑：最初具备自卫理由，不意味着此后二十年的所有军事行动都自动具有合法性；同样，后续军事行动存在违法问题，也不能直接反推最初的自卫理由必然不成立。

### 5. “大国一致原则”是联合国安理会的表决规则，而不是独立于联合国之外的战争合法性依据
这是整个视频最核心的争议，也是标题“大国一致原则”的由来。正方认为，除了联合国授权以外，国际社会还存在一种被各国承认的基本秩序，即主要大国达成一致，就能够为军事行动提供正当性。反驳方指出，这实际上混淆了联合国安理会的表决机制与国际法上的武力使用规则，真正的“大国一致原则”是指安理会常任理事国对实质性决议的特殊表决机制。根据《联合国宪章》第27条，安理会共有15个成员，实质性决议需要至少9票赞成，并且中国、美国、俄罗斯、英国、法国这五个常任理事国均未投反对票；按照长期实践，常任理事国投弃权票并不构成否决。
Security Council
 因此，大国之间的政治默契、外交支持或暂时不反对，并不能自动构成发动战争的国际法依据。

### 6. 联合国大会的投票结果能够体现国际社会的态度，但不能简单等同于司法裁决
正方引用联合国大会针对俄乌战争的两次投票结果，分别是143票赞成、5票反对，以及141票赞成、7票反对，以此说明国际社会绝大多数国家反对俄罗斯的军事行动。经过核实，这两次投票分别发生于2022年10月12日和2023年2月23日，前者主要针对俄罗斯试图吞并乌克兰部分地区的问题，后者则强调按照《联合国宪章》实现全面、公正、持久的和平，并要求俄罗斯撤军。
digitallibrary.un.org
 反驳方认为，联合国大会的表决没有充分体现北约东扩、敦巴斯冲突等历史背景，不能单凭票数判断战争的全部是非。从法律层面看，联合国大会有关战争的决议一般具有建议性质，与安理会依据《联合国宪章》第七章作出的强制性决定存在区别，但这并不意味着大会决议没有法律和政治意义。因此，这些投票是国际社会反对俄罗斯军事行动的重要证据，却不能代替对战争历史、法律责任以及具体军事行为的完整分析。

### 7. 北约五轮东扩是俄乌冲突的重要历史背景，但解释战争成因不等于证明战争合法
反驳方认为，俄乌冲突的核心原因是北约（NATO，North Atlantic Treaty Organization，北大西洋公约组织）的五轮东扩，使西方军事联盟不断向俄罗斯周边推进，从而压缩俄罗斯的战略安全空间。冷战结束后、2022年俄乌全面战争爆发前，北约确实在1999年、2004年、2009年、2017年和2020年进行了五轮扩张，并在2008年布加勒斯特峰会上明确提出乌克兰和格鲁吉亚未来将成为北约成员。
NATO Topic
 反驳方从大国安全利益出发，认为任何一个大国都难以接受潜在敌对军事力量不断接近自身边境，这种思路体现了国际关系理论中的安全困境（Security Dilemma）。但从乌克兰及部分东欧国家的角度看，加入北约也是出于自身安全考虑，这些国家并非只有被大国安排的角色，也拥有独立的外交和安全政策选择权。由此可见，北约东扩确实是理解俄乌冲突的重要变量，但将其认定为唯一原因，或者直接将俄罗斯的安全焦虑转化为对乌克兰使用武力的合法理由，都属于需要进一步论证的判断。

这是理解国家间相互不信任如何不断升级的一种理论模型，并不意味着冲突各方的法律责任相同，也不代表战争不可避免。

### 8. 敦巴斯冲突及俄乌历史、民族和文化联系不能被忽略，但也不能凌驾于国家主权之上
反驳方批评正方对敦巴斯（Donbas）地区的人道主义危机，以及俄罗斯与乌克兰之间复杂的历史、民族、语言和文化联系避而不谈。俄乌两国具有长期交织的历史，均曾是苏联加盟共和国，1991年苏联解体之后，双方在国家认同、外交路线、安全政策等问题上逐渐出现分歧。2014年克里米亚事件以及乌克兰东部武装冲突的爆发，进一步加剧了俄乌矛盾，顿涅茨克、卢甘斯克等地的平民长期受到战争影响。反驳方希望以这些历史事实说明，2022年的全面战争并非突然发生，而是长期矛盾持续累积的结果。但是，历史联系、民族认同、语言文化以及保护相关群体的主张，并不能自动赋予一个国家对另一个主权国家进行军事干预、改变其边界或吞并其领土的权利。
需要同时承认两个事实：俄乌冲突有复杂的历史背景；乌克兰作为主权国家，也拥有受到国际法保护的独立地位和领土完整。

### 9. 战争造成的人道主义灾难必须受到同等关注，不能因为发动战争的国家不同而采用不同标准
反驳方对美国战争行为的主要批评，是认为正方只强调发动战争时的反恐、自卫或国际授权理由，却忽略了战争对普通民众造成的长期伤害。视频声称，美国在伊拉克和阿富汗发动的两场战争造成超过100万平民死亡、超过1000万难民，并以此指责正方存在明显的双重标准。这些具体数字没有在原视频中提供统计来源，而且可能混淆了直接死亡、间接死亡、平民死亡、全部死亡以及难民和境内流离失所者等不同概念。美国布朗大学（Brown University）的战争成本项目（Costs of War）估计，2001—2023年多个“9·11”后战争涉及地区的直接死亡人数超过94万，间接死亡人数约为360万至380万，但其统计范围包括伊拉克、阿富汗、巴基斯坦、叙利亚和也门等地，不能直接当作伊拉克和阿富汗两国的平民死亡人数。
Brown University
 反驳方要求重视战争中平民遭受的苦难，这一点具有合理性，但同样的标准也必须适用于俄罗斯在乌克兰的军事行动，以及其他交战方可能实施的违法行为。

### 10. 反对双重标准的正确方式是统一评价尺度，而不是用一个国家的错误为另一个国家辩护
反驳方将正方的主要逻辑问题归纳为双重标准、偷换概念和因果倒置，认为正方把联合国授权与大国不反对混为一谈，把反恐与后续长期驻军混为一谈，又把国际投票结果与战争正义性强行绑定。反驳方还使用了“霸权侵略”“西方中心主义”等措辞，批评正方只从美国及西方国家的叙事角度理解战争。其值得重视的观点，是国际规则应当对所有国家具有同等约束力，而不能因为国家实力、政治制度、意识形态或外交关系不同，就采用不同的评价尺度。不过，指出美国曾经发动缺乏充分国际法依据的战争，并不能由此推出俄罗斯对乌克兰使用武力就是合法的，否则也会陷入“诉诸伪善”（Tu Quoque）或“那又怎么样式辩护”（Whataboutism）的逻辑问题。真正一致的评价标准，应当允许人们同时批评美国2003年发动的伊拉克战争与俄罗斯2022年发动的对乌全面战争，而不必在两者之间进行非此即彼的政治站队。

### 七、《联合国宪章》中最值得了解的三个条款
第2条第4款：禁止威胁或使用武力。
各会员国原则上不得在国际关系中以武力威胁或侵害其他国家的领土完整、政治独立，也不得以不符合联合国宗旨的方式使用武力。
第27条：安理会表决规则。
规定安理会如何表决以及常任理事国在实质性事项上的特殊权力，是视频所讨论的“大国一致原则”的制度基础。
第51条：国家自卫权。
当联合国会员国遭受武力攻击时，在安理会采取必要措施之前，可以依法行使单独或集体自卫权，同时应向安理会报告有关措施。
这三个条款分别涉及三个不同的问题：国家原则上不能做什么、联合国如何作出集体决定、国家在遭受攻击时可以依法做什么。

## 值得记住的点 / 行动建议

### 1. 分析任何一场战争，都应当建立统一的评价框架
不要先确定自己支持哪个国家，再根据立场选择对己方有利的历史事实或法律条款。可以把任何一场战争放进同一套分析框架中，从战争背景、法律依据、实施过程、人道主义影响、国际社会态度等多个角度分别评价。

### 国际冲突分析清单

0/8

战争爆发之前发生了什么？是否存在长期的历史矛盾？
发动军事行动的一方是否获得联合国安理会授权？
是否存在符合国际法要求的自卫理由？
军事行动的规模、范围和持续时间是否符合必要性与相称性要求？
作战过程中是否遵守国际人道法、保护平民？
战争造成了哪些直接和间接的人道主义后果？
国际社会的支持、反对和弃权分别代表什么？
如果互换两个国家的身份，我是否还会采用同样的判断标准？
 复制分析清单
这套框架既可以用于分析俄乌冲突，也可以用于理解伊拉克战争、阿富汗战争及其他国际军事冲突，避免只根据舆论立场作出判断。

### 2. 区分战争的发动是否合法与战争中的行为是否合法
这是国际法中非常重要的两套概念：
- **Jus ad Bellum（诉诸战争法）：**研究一个国家在什么情况下可以合法使用武力，主要涉及自卫权、禁止侵略、联合国授权等问题。
- **Jus in Bello（战争行为法）：**研究战争已经发生之后，交战各方应如何规范自身行为，包括保护平民、对待战俘、限制攻击对象等。

例如，一场战争即便具有明确的安理会授权，参与战争的部队如果故意攻击平民，也可能违反国际人道法。反过来，一方即便发动了非法战争，其普通士兵、伤员和战俘也依然享有国际人道法规定的相关保护。
两套规则彼此独立，不能因为最初发动战争的理由成立，就默认此后所有行为都成立。

### 3. 遇到“联合国已经授权”的说法，要查具体决议及其授权内容
在国际政治类视频中，经常会有人以“联合国同意了”“安理会授权了”“国际社会支持”等表述为某项军事行动背书。但这些说法具体指什么，必须进一步查证。
例如，1990年第678号决议涉及采取军事行动的明确授权，而2002年第1441号决议主要涉及伊拉克的裁军、武器申报与核查义务，两者性质不同。

[《联合国宪章》中文版](https://www.un.org/zh/about-us/un-charter/full-text?utm_source=chatgpt.com)
查阅禁止使用武力、自卫权、安理会职权等基本规则。

[联合国数字图书馆](https://digitallibrary.un.org/?utm_source=chatgpt.com)
查阅历年联合国决议原文、投票记录与会议档案。

[联合国安理会表决规则](https://main.un.org/securitycouncil/en/content/voting-system?utm_source=chatgpt.com)

### 4. 学会识别国际政治讨论中常见的五种逻辑错误

| 逻辑错误 | 典型说法 | 问题所在 |
| --- | --- | --- |
| 双重标准 | 自己支持的国家打仗就是正义，其他国家打仗就是侵略 | 评价标准随立场变化 |
| 偷换概念 | 大国没有反对，就等于联合国授权 | 混淆政治态度与法律授权 |
| 诉诸伪善 | 美国都打过伊拉克，凭什么批评俄罗斯？ | 指出对方曾经犯错，并不能证明自己的行为正确 |
| 单一归因 | 俄乌冲突完全是北约东扩造成的 | 忽视其他历史因素及各方自主决策 |
| 诉诸多数 | 赞成某项决议的国家多，就说明该决议涉及的所有问题都已经不存在争议 | 混淆国际共识与对全部事实、法律问题的完整论证 |

这些逻辑错误并非某个国家或者某种政治立场所独有。在观看国际政治评论时，应当同时用它们审视自己认同的观点和自己反对的观点。

### 5. 看待伤亡、难民等战争数据时，必须关注统计口径
视频中“平民死亡超过百万”“难民人数超过千万”等数字具有很强的情绪冲击力，但数字越大、影响越强，就越需要确认来源。
特别需要区分以下概念：

| 数据类型 | 含义 |
| --- | --- |
| 直接死亡 | 因战争暴力直接造成的死亡 |
| 间接死亡 | 因战争破坏医疗、供水、粮食供应等条件而造成的死亡 |
| 平民死亡 | 非战斗人员的死亡 |
| 全部死亡 | 可能包括平民、军队及其他武装人员 |
| 跨境难民 | 因战争、迫害等原因逃往其他国家的人群 |
| 境内流离失所者 | 因冲突等原因被迫离开家园，但仍在本国境内的人群 |
| 累计流离失所人数 | 某一时间范围内累计被迫迁移的人数 |
| 当前流离失所人数 | 在特定时间点仍处于流离失所状态的人数 |

引用战争数据前，至少确认四个问题：谁统计的、统计了哪些地区、覆盖什么时间范围、具体统计的是什么人。
尤其不要把多个国家、多个战区、二十多年累积的死亡人数，直接描述为某一场战争的平民死亡人数。

### 6. 同时理解大国安全需求与中小国家的主权需求
国际政治中的现实主义（Realism）强调，国家特别是大国会关注自身安全、战略缓冲空间、军事力量平衡以及周边地缘政治环境。从这个视角出发，俄罗斯对北约持续扩张产生安全焦虑，并不难理解。
但是，如果只站在大国角度思考，就容易把中小国家理解成大国之间的棋子，忽略它们自身的安全诉求和政治选择。乌克兰、波兰以及波罗的海国家同样会根据自身历史经验、外部威胁认知和国家利益作出决策。
因此，理解国际关系需要同时拥有两种视角：
大国安全视角
战略纵深、军事力量平衡、周边联盟变化、国家安全利益、地缘政治竞争。

主权国家视角
国家独立、领土完整、外交自主、国家认同、自身安全政策选择。

两种视角都能够帮助解释国际冲突，但解释国家为什么采取某种行动，与证明这种行动在法律或道德上正当，仍然是两回事。

### 7. 不要把联合国大会投票理解为简单的国际政治站队
联合国大会的赞成票、反对票、弃权票以及未投票状态，可能受到多重因素影响，包括国家外交政策、地区安全利益、经济关系、历史联系以及对决议具体文字的态度。
例如，一个国家赞成要求俄罗斯撤军的决议，不一定意味着它赞成美国过去发动的所有战争；一个国家对相关决议投弃权票，也不一定意味着它认同俄罗斯的军事行动。
阅读投票新闻时，不仅要看票数，还要看决议原文、各国的投票解释、决议通过的历史背景，以及这项决议究竟要求采取什么行动。

### 8. 建立“可以同时反对多个错误”的独立判断能力
国际政治讨论容易形成一种二元对立：批评美国就被理解为支持俄罗斯，批评俄罗斯就被理解为支持美国。
实际上，普通人完全可以同时持有以下观点：认可1991年海湾战争存在明确的联合国授权，质疑2003年伊拉克战争的合法性，承认美国在“9·11”事件后存在反恐自卫诉求，批评阿富汗战争中造成平民伤害的行为，承认北约扩张给俄罗斯带来的战略压力，同时维护乌克兰的国家主权和领土完整。
这些观点并不必然相互矛盾，因为它们针对的是不同事实、不同法律问题和不同历史阶段。
独立思考不是必须在两个阵营中选择一个，而是能够让自己的判断标准不随阵营变化。
