## 一句话概括
视频从多篇疑似利用AI生成虚假实验图片、却成功发表于高影响因子学术期刊的论文切入，揭露学术出版行业依靠论文发表费和文献订阅费获利的商业模式，质疑其同行评审机制、利益冲突与责任承担问题，并进一步反思中国科研资源「两头在外、前后付费」的困境。

## 背景与主题
近期，学术圈出现多篇被质疑使用AI生成实验图片的论文，其中涉及湘雅相关科研团队和四川某医院，部分论文甚至出现一厘米有12个刻度、患者治疗前后胡茬完全不变等明显异常。令人质疑的是，这些论文不仅成功发表，部分期刊的影响因子还相当高，论文中也列出了多项科研经费资助信息。
作者认为，相比AI论文造假本身，更值得关注的是如此明显存在问题的论文为什么能够通过编辑审核和同行评审，最终进入正式的学术出版体系。视频由此延伸至开放获取出版（Open Access，OA）、论文处理费（Article Processing Charge，APC）、学术出版商的高利润率，以及中国科研人员既要付费发表论文、又要付费获取学术资源的问题。
整段视频采用讽刺、类比和反问的方式，试图从商业利益与制度激励的角度解释学术出版乱象，并呼吁学术出版商承担与其收入和行业地位相匹配的质量监管责任。
说明：以下笔记以视频文字稿为依据，对明显的语音识别错误进行了修正。涉及具体论文的造假指控、财务数据及科研经费问题，均属于视频作者的陈述或质疑，尚未在本笔记中进行独立核实。

## 核心观点

### 1. AI论文造假已经出现极其低级的错误，却依然能够发表在高影响因子期刊上
视频开头展示了一篇来自湘雅相关科研团队、发表于影响因子为9.7的期刊上的论文，其实验图片中竟然出现了「一厘米有12个刻度」的尺子。作者认为，问题并不仅仅出现在尺子上，而是该论文的多张乃至全部实验图片都存在明显的AI生成痕迹，与真实生物学实验图像不符。为了说明识别难度之低，作者将其类比为银行工作人员辨认假币：普通人可能无法识别，但长期接触某类事物的人，对异常特征往往十分敏感。
据作者所述，相关案例至少涉及三篇论文，其中最高的期刊影响因子达到12.1，这说明高影响因子并不能自动保证单篇论文的真实性。真正值得警惕的是，当一些专业人士通过肉眼就能发现的错误能够绕过正式的学术审核流程时，学术期刊作为科研质量把关者的公信力就会受到挑战。

### 2. AI生成论文背后可能存在科研经费使用与学术成果考核的问题
作者注意到，被质疑存在AI生成内容的论文中，明确列出了多项科研经费资助信息。按照正常的科研流程，研究经费可能用于购买实验材料、使用仪器设备、聘用研究人员、采集数据、开展临床研究以及支付论文发表费用等，最终形成具有真实科学价值的研究成果。
但如果论文中的实验图片乃至实验数据都来自AI生成，那么相关研究是否真实开展、科研资金是否按照申报用途使用，就值得进一步调查。作者讽刺道，生成一篇AI论文究竟需要消耗多少Token（词元），为什么还需要多项科研经费共同资助，并呼吁上级主管部门进行调查。
这一问题的本质不仅是学术诚信问题，也可能涉及科研资金监管、项目结题验收、科研绩效评价以及公共资源分配的合理性。不过，论文标注了多项基金资助，并不能直接证明科研经费被挪用，是否存在违规行为仍需要结合原始实验记录、项目账目和实际研究过程进行核查。

### 3. AI生成医疗图片可能危及临床证据的真实性，技术手段正在成为打假工具
视频列举了四川某医院相关论文中的另一个案例：作者声称两张患者照片分别展示了为期一个月的治疗开始前和治疗结束后的情况。然而，视频作者发现，患者嘴唇上的伤口发生了明显变化，胡茬的形态却几乎完全一致，这与一个月时间跨度下自然生长和日常变化的情况不符。
作者还称，相关图像被检测出了OpenAI生成图片所携带的隐蔽标记，人眼无法直接看到，但可以通过相应技术工具识别。如果图片确实由AI生成，却被当作真实患者的治疗效果证据，就可能严重误导读者对某种治疗方法有效性的判断。
随着生成式AI的发展，图像造假的成本不断降低，而数字水印、内容来源认证、图像取证和异常检测技术也在同步发展。作者将这种现象称为「造假与打假的军备竞赛」，认为双方技术能力正在相互推动。不过，图片中的异常特征和AI生成标记应当被视为调查线索，而不是在缺乏完整证据链的情况下直接认定整篇论文造假的唯一依据。

### 4. 相比论文造假本身，更严重的问题是学术期刊的审核机制为何失效
作者认为，整起事件最值得关注的，并不是AI生成图片有多假，而是「一眼假」的论文竟然能够顺利发表。正常情况下，一篇学术论文通常需要经历编辑初审、同行评审（Peer Review）、作者修改、编辑决策和正式出版等多个环节，医学和生物学论文还应特别关注图像、实验方法、数据和伦理方面的合规性。
如果图片中存在连具有基础实验室经验的人员都能发现的问题，那么就有必要追问：期刊是否进行了充分的专业审核，审稿人是否认真阅读了论文，编辑是否建立了基本的科研诚信检查机制？作者以非常尖锐的措辞批评经手这些论文的编辑和审稿人员，认为他们没有履行最基本的审核职责。
这种批评实际上指向学术出版体系的责任分配问题：作者对研究真实性负有首要责任，但编辑、审稿人和出版商也不能在严重质量问题出现后完全置身事外。期刊收取高额费用、拥有学术评价影响力并从科研成果中获得商业利益，也就理应建立与之相匹配的审核、纠错和问责机制。

### 5. 开放获取论文的高额发表费用，可能造成出版商的商业利益与审稿职责发生冲突
视频提到，湘雅相关案例中的三篇论文涉及的开放获取出版费用分别为4090美元、5250美元和2850美元，合计12190美元。开放获取（Open Access，OA）通常意味着论文发表后，读者可以免费阅读全文，而在许多商业化OA期刊中，出版成本和商业利润主要通过向作者收取论文处理费（Article Processing Charge，APC）来覆盖。
作者指出，这种模式与普通人对写文章、赚稿费的理解完全相反：不是杂志社向作者支付报酬，而是科研人员需要付费才能发表自己的研究成果。相关费用可能由科研项目经费、学校、医院或科研机构承担，也可能因为单位报销规定不同而需要作者自行承担。
作者进一步质疑，当期刊收入与论文发表数量存在一定关联时，出版商是否有足够动力严格拒绝质量不合格的论文。这构成一种潜在的利益冲突，即承担质量把关职责的机构，同时可能从增加论文录用数量中获得经济收益。但需要区分的是，OA本身并不等于低质量出版，关键在于期刊能否通过编辑独立性、透明审核制度和科研诚信监管来约束商业利益。

### 6. 学术出版的特殊商业模式，使出版商能够在内容供给端和阅读消费端获利
作者将学术出版商类比成一家特殊的超市：普通超市需要花钱进货，再通过卖货赚取差价，而学术出版商获得研究内容时，通常不需要像普通内容行业那样向作者支付稿费，部分情况下甚至还可以向提供内容的作者收费。科研人员承担实验、数据分析、论文写作等工作，而出版商则负责组织评审、编辑、出版、传播和商业运营。
在传统订阅模式中，学术出版商还可以通过向高校、科研机构、图书馆及个人读者出售数据库访问权限获得收入。作者认为，这种商业模式的特殊之处就在于，科研内容的生产成本主要由科研人员及资助机构承担，而出版商却掌握重要的传播渠道和收费权。
视频同时作出了一个重要限定：对于单篇论文而言，一般是作者付费或者读者付费，并不是所有论文都在两个环节重复收费。但是，从整个出版行业的收入结构来看，作者端的APC收费和读者端的订阅收入确实可以同时存在，这也是理解学术出版行业商业价值的重要切入点。

### 7. 中国科研面临「两头在外、前后付费」的学术资源困境
视频引用国家科技图书文献中心（National Science and Technology Library，NSTL）相关资料中的表述，称我国学术资源面临「两头在外、前后付费」的问题。所谓「两头在外」，可以理解为大量科研成果依赖国外学术期刊和出版平台进行传播，而国内研究人员获取国际学术资源时，也需要依赖这些出版商及其数据库。
所谓「前后付费」，则是指中国科研人员及机构已经承担了科研活动本身的经费、设备和人力成本，在发表部分研究成果时需要再支付论文处理费，而在获取其他订阅制学术资源时又需要支付文献订阅费用。视频称，我国每年为获取国外学术文献向国外学术出版商支付约20亿至30亿元，并援引中国通讯作者在SCI收录OA期刊上的APC总支出达到9.09亿美元的数据。
在作者看来，这种现象反映了科研成果生产能力与学术传播渠道控制能力之间的不对称：研究成果由国内科研人员生产，但重要的发表渠道、传播平台及定价权可能掌握在国外机构手中。这也是作者解释为什么中国长期倡导「把论文写在祖国大地上」、推动本土学术期刊建设的重要背景。

### 8. 学术出版并非单纯的学术公益事业，而是一个具有高利润特征的商业行业
视频以Elsevier（爱思唯尔）为例，试图打破人们将学术期刊单纯理解为学术交流平台的传统认知。Elsevier是全球主要学术出版商之一，旗下具有代表性的学术期刊包括Cell（《细胞》）和The Lancet（《柳叶刀》）等，其出版业务在医学、生命科学及多个科研领域具有重要影响力。
作者称，Elsevier在2025年的营收超过27亿英镑，利润率达到38.1%，并将这一数字与Microsoft（微软）的45.6%、Google（谷歌）的32.1%以及Apple（苹果）的32%进行对比。按照视频给出的比较口径，Elsevier的利润率甚至高于谷歌和苹果，说明学术出版具有相当可观的商业价值。
作者借此强调，不能因为出版物具有专业性、知识性和学术权威性，就忽略其背后的商业组织属性和盈利动机。学术期刊既是科研交流体系的一部分，也是出版商提供的商业化产品与服务，因此需要同时接受学术诚信和商业责任两个维度的监督。

### 9. 学术出版商应当像其他商业公司一样，对自身提供的产品和服务承担责任
视频最后提到，此前一位姚老师曾在回复作者的文章中，谈及Elsevier法律顾问委托第三方调查的相关争议，评论区有人认为出版商没有必要包庇编辑。作者则试图从出版商的盈利模式和商业利益出发，解释为什么不能默认出版机构一定会站在完全中立的立场处理有关争议。
他将学术论文类比为科技公司的产品：当消费者购买的手机出现质量问题时，科技公司通常需要回应、调查并提供解决方案；同理，当学术期刊发表的论文出现严重质量问题时，出版商也应当对审核和出版流程中的失误作出解释。尤其当出版商收取数千美元的论文处理费，并从学术传播中获取大量商业收益时，其责任更不应当仅限于完成排版和收款。
对于涉嫌造假的论文，合理的责任承担方式可以包括公开调查、发布关注声明、更正论文、撤稿、完善图像审核流程以及提高处理过程的透明度。作者的最终诉求并不是要求出版商完全替代科研人员承担真实性责任，而是强调商业收益与质量责任之间应当保持合理的对应关系。

| Subscription Model | 订阅制出版模式，通过个人或机构订阅获取收入 |
| Hybrid OA | 混合开放获取模式，订阅制期刊同时允许作者付费开放部分论文 |
| Retraction | 撤稿，正式撤回存在严重问题的已发表论文 |
| Conflict of Interest | 利益冲突，经济或其他利益可能影响独立专业判断的情形 |

## 值得记住的点 / 行动建议

### 1. 不要把SCI、高影响因子和论文真实性画等号
期刊影响因子主要衡量期刊论文在特定统计周期内的平均引用表现，并不是对每篇论文真实性、研究设计或实验质量的独立认证。
阅读论文时，不应因为它发表于高影响因子期刊，就默认其研究结论必然正确。尤其是在撰写毕业论文、开展科研项目、制定临床方案或者引用重要结论时，应当重点检查研究方法、样本规模、实验设计、统计分析、原始数据、研究局限性，以及是否存在后续更正或撤稿记录。
期刊的声誉可以作为筛选文献的参考，但不能代替对文献本身的判断。

### 2. 掌握识别AI生成科研图片的基础思路
AI生成的科研图片可能具有很强的表面真实感，但在物理规律、生物学特征、图像细节和实验逻辑方面存在不一致。

| 检查对象 | 值得关注的异常 |
| --- | --- |
| 尺子及比例尺 | 刻度数量、单位、间距是否正确 |
| 实验仪器 | 结构、操作方式、连接关系是否符合实际 |
| 生物组织图片 | 细胞结构、组织形态、纹理是否合理 |
| 治疗前后照片 | 毛发、胡茬、光影、皮肤纹理是否存在不合理的一致性 |
| Western Blot（蛋白质免疫印迹） | 条带是否存在异常重复、拼接或背景一致现象 |
| 显微镜图片 | 是否存在重复区域、异常纹理及不自然的结构 |
| 图片文字 | 是否出现乱码、拼写错误、错误单位或符号 |
| 实验数据 | 是否与实验设计、测量条件及理论规律相符 |

发现异常时，应优先检查原始图像和实验记录，也可以利用图像重复检测、元数据分析和内容来源认证工具辅助判断。但不应仅凭AI检测器给出的概率就认定他人造假。

### 3. 在科研和论文写作中，严格区分AI辅助与AI伪造
AI可以帮助科研人员提高效率，但效率工具与科学证据之间存在明确的边界。

| 使用场景 | 基本原则 |
| --- | --- |
| 语言润色 | 可以辅助，作者负责最终内容 |
| 文献整理 | 可以辅助，但必须核实原始出处 |
| 编程与数据分析 | 可以辅助，代码及结果必须验证 |
| 理论示意图 | 可以辅助制作，按期刊要求披露 |
| 真实实验图片 | 不得使用生成图像冒充真实实验结果 |
| 临床治疗照片 | 不得生成虚假患者照片作为临床证据 |
| 原始实验数据 | 不得为了符合预期结论而编造 |
| 参考文献 | 不得引用未经核实的AI虚构文献 |

最关键的原则是：AI可以帮助表达、整理和分析科学证据，但不能凭空创造本应通过真实研究获得的科学证据。
对于科研人员而言，保留原始数据、实验记录、代码、图像原文件以及处理过程，不仅能够增强研究的可重复性，也是应对学术质疑的重要保障。

### 4. 提交论文之前，提前了解目标期刊的收费模式
科研人员在选择投稿期刊时，除了关注影响因子、学科分区及审稿周期，还应充分了解期刊的收费模式和出版政策。

| 出版模式 | 作者是否付费 | 读者是否付费 |
| --- | --- | --- |
| 传统订阅制 | 通常无APC，但可能有其他费用 | 通常需要订阅权限 |
| 金色开放获取（Gold OA） | 部分期刊收取APC | 通常免费阅读 |
| 钻石开放获取（Diamond OA） | 不收取APC | 免费阅读 |
| 混合开放获取（Hybrid OA） | 选择开放获取时通常需要支付APC | 非开放论文通常需要订阅权限 |
| 绿色开放获取（Green OA） | 通常不因自行存档而产生APC | 可通过允许的存档版本免费阅读 |

投稿前应确认论文处理费、版面费、超页费、彩图费、税费等具体收费项目，同时查看所在学校、医院或科研机构是否允许使用科研经费报销相关费用。
还要注意，收费高并不代表期刊质量一定高，不收费也不代表期刊质量低。出版模式和学术质量需要分别评价。

### 5. 判断科研出版行业时，学会分析参与者的利益结构
视频提供了一个具有普遍适用性的分析视角：当一个机构拥有行业权威、专业身份或者公益性质的社会形象时，仍然需要研究其收入从哪里来、成本由谁承担、决策受到哪些激励影响。

| 参与者 | 主要投入 | 主要诉求 |
| --- | --- | --- |
| 科研人员 | 时间、实验、知识、论文写作 | 学术成果、毕业、晋升、科研资助 |
| 高校及科研机构 | 人员工资、设备、科研经费 | 科研影响力、人才培养、机构评价 |
| 基金及资助机构 | 科研资金 | 科学成果和社会价值 |
| 审稿人 | 专业知识、时间和精力 | 学术贡献、专业声誉 |
| 学术出版商 | 平台、编辑、出版与传播服务 | 收入、利润、品牌影响力 |
| 读者及图书馆 | 订阅及资源获取费用 | 获取可靠、充分的科研信息 |

学术出版乱象不能简单地解释为某个人缺乏道德，也需要考虑科研人员的发表压力、期刊的商业激励、审稿人的工作负担和科研评价制度之间是否形成了不合理的激励关系。
这种分析方法也可以应用于教育、医疗、互联网平台等同时具有公共价值和商业属性的行业。

### 6. 区分真正的科学研究与以发表论文为目的的形式化科研
当科研评价过度依赖论文数量、期刊影响因子、SCI分区等容易量化的指标时，科研人员可能更关注如何满足考核要求，而不是如何解决真实科学问题。
这可以用古德哈特定律（Goodhart's Law）来理解：当一个衡量指标成为直接追求的目标时，它可能逐渐失去原本的衡量价值。
过度依赖论文数量与影响因子考核

毕业、晋升、科研结题及发表压力增加

部分人员倾向于追求快速产出和形式化成果

AI降低虚假图片及内容的生成成本

如果期刊审查不足，问题论文可能进入正式文献体系

科研资源浪费、错误知识传播、学术公信力下降

基于视频观点延伸整理的潜在风险传导链，并不意味着所有科研机构或期刊都会出现上述问题。
因此，更合理的科研评价体系应重视研究原创性、实际贡献、数据可靠性、研究可重复性及长期价值，而不是单纯追求发表数量。

### 8. 理解建设本土高质量学术期刊的战略意义
「把论文写在祖国大地上」并不仅仅是关于论文发表地点的口号，还可以从科研传播能力、知识资源获取成本、学术评价自主性和国际学术话语权等方面理解。
如果一个国家具有较强的科研成果生产能力，却长期缺乏同等水平的学术传播平台，就可能在知识传播渠道、资源获取和商业定价方面受到外部平台影响。
建设高质量本土学术期刊、发展开放学术资源平台、推动机构知识库建设以及提高国际学术传播能力，有助于缓解这种不对称关系。但发展本土期刊并不意味着排斥国际学术交流，也不能通过行政保护代替学术质量竞争。
真正具有长期价值的本土学术出版体系，应当依靠高质量同行评审、严格的科研诚信标准、透明的收费制度和国际化传播能力建立信誉。

### 9. 对涉及造假的学术争议，坚持证据意识和责任边界
视频中作者的批评非常尖锐，但在实际判断和传播学术造假事件时，需要区分几个不同层次。

| 判断层次 | 所需要的依据 |
| --- | --- |
| 图片存在异常 | 肉眼观察、图像分析、专业知识 |
| 图片疑似由AI生成 | 来源标记、技术检测、生成记录等 |
| 实验是否真实开展 | 原始实验记录、设备记录、原始数据 |
| 论文是否构成学术不端 | 完整证据链及正式调查 |
| 科研经费是否违规使用 | 经费账目、项目记录、审计结果 |
| 编辑或出版商是否失职 | 审核记录、处理流程、具体职责 |
| 是否存在故意包庇 | 相关行为记录及充分证据 |

发现存在问题的论文时，可以保存论文原文、DOI、异常图像及对比证据，并通过期刊编辑部、科研机构诚信管理部门或相应的学术监督渠道反映情况。
既不能因为期刊具有较高声誉就拒绝质疑，也不能因为发现个别异常就直接认定所有作者、审稿人和出版人员存在故意违规行为。科学监督本身也应遵循科学的证据标准。

## 我的点评
这段视频最有价值的地方，是没有停留在「AI让论文造假更容易」这一表面现象，而是进一步分析了科研评价制度、学术出版商业模式和质量监管之间的潜在利益冲突，将个体学术诚信问题提升到制度层面讨论。作者用超市进货和卖货的类比解释学术出版的收费机制，虽然有所简化，但能够帮助普通人迅速理解科研内容生产者、传播渠道控制者与付费者之间的关系。需要保留的是，学术出版商也承担编辑、平台建设、长期存档、科研诚信调查等实际成本，不能因为其利润率较高，就直接推断所有审核问题都源于逐利动机。与此同时，OA模式具有降低读者获取知识门槛的积极价值，真正需要警惕的是缺乏制衡机制的商业化出版，而不是开放获取本身。视频中的具体造假指控、科研经费问题、企业利润率及国家层面的付费数据，也应当在核对原始材料和统一统计口径之后再进行正式引用。对于普通读者和科研人员而言，最值得吸收的思维方式是：既要审查科研成果本身的真实性，也要理解生产、评价、传播这些成果的制度究竟是如何运转的，以及其中的利益结构是否能够促进真正有价值的科学研究。
