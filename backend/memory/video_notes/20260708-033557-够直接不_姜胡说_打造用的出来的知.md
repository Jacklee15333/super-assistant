## 一句话概括
赚钱的本质，是在技术进步和市场变化中找到自己的获利位置：要么创造新需求，要么比别人更快抓住机会，要么向赚钱的人提供方法、低价产品或优质服务，要么投资优秀的经营者；如果整个行业已经陷入低价竞争、服务内卷却仍然不赚钱，就应该考虑及时退出。

## 背景与主题
这段视频来自内容创作者「姜胡说」的一次直播后分享，作者以非常直接、口语化的方式，讨论普通人在现代商业社会中究竟可以通过哪些途径赚钱。他认为，我们生活在一个由科技推动的时代，每次新技术出现，都会带来新的消费需求、赚钱机会和市场竞争，而不同的人可以根据自己的能力、资源、速度和资金状况，选择不同的获利方式。
作者用 iPhone 的出现、自己提前学习新事物的经历、抖音内容创作与个人 IP 培训、培训课程不断降价、赠送饮料提升服务，以及投资成功经营者等例子，归纳出六种赚钱方式。最后，他特别强调了一个容易被忽视的判断：当一个行业连低价策略和优质服务都无法带来利润时，继续坚持未必是正确选择，及时换行业可能更重要。
这段视频的核心并不是介绍六个具体职业，而是提供一套理解商业机会、市场竞争和个人赚钱位置的思考框架。

## 核心观点

### 1. 第一种赚钱方式：抓住技术创新带来的新需求，成为机会的创造者
作者首先提出一个判断：现代社会的发展很大程度上由科技推动，而新技术往往会创造过去不存在的需求。 他以 iPhone 的出现为例，说明一种新产品诞生后，人们可能开始产生此前没有的消费欲望，愿意为新体验、新功能和新的生活方式付费。对于能够研发新技术、推出新产品，或者率先组织资源满足这些需求的人来说，这些新增需求就可能转化为巨大的商业机会。这里最重要的因果逻辑是：技术突破改变人们的行为方式，新的行为产生新的需求，而能够满足需求的企业或个人就有机会获得收入。作者也承认，这一层机会通常不是普通人轻易能够拿到的，因为真正参与技术创新和产品创造，需要相应的技术能力、资金、团队或其他资源。
深层理解：
这一模式的优势，是能够在市场尚未充分竞争时率先建立位置，而不是等到市场成熟后才参与价格竞争。
例如，iPhone 不仅是一部手机，也可以被看作移动互联网商业生态发展的重要推动因素。围绕智能手机形成的应用软件、移动支付、手机配件和移动内容消费等市场，都体现了新技术如何催生新的商业需求。
不过，这些是对作者观点的延伸理解，并不是视频逐一列举的案例。
可以将第一种赚钱方式概括为：
技术创新 → 新产品或新体验 → 新消费需求 → 新市场形成 → 创新者获得收益。

### 2. 第二种赚钱方式：不必成为发明者，但要比多数人更早学习、更快跟进
作者认为，普通人即使没有能力创造一项新技术，也可以通过快速学习和提前进入市场来赚钱。他提到自己当年曾经提前学习某项新事物，文字稿将其识别为「downline」，但具体名称无法可靠确认；按照他的描述，他开始学习时，这项东西甚至还没有正式发布，直到大约一年后才面向市场推出。由于自己学习得足够早，当大多数人还不了解它的时候，就会有人主动向他请教，从而产生赚钱机会。作者随后用自己的抖音经历进一步解释：他在「去年」开始拍抖音，而到了「今年」，已经有很多人邀请他分享抖音的拍摄方法和经验。这说明市场机会不只属于最初的技术创造者，提前学习、提前实践、提前积累经验的人，也可能凭借时间优势获得商业回报。
深层理解：
第二种方式实际上利用的是市场参与者之间的时间差。
同一项技术或平台，对不同的人来说，接触时间可能相差几个月甚至几年。这段时间里，先行者已经经历了学习、尝试、犯错和总结，而后来者可能仍然停留在不了解、不知道如何开始的阶段。
于是，先行者手中的经验不仅具有实践价值，还可能具有商业价值。
可以归纳成以下过程：
提前发现趋势 → 提前学习 → 提前实践 → 积累经验 → 市场关注度提高 → 输出经验或提供服务 → 获得收入。
这里的关键并不只是「知道得早」，而是要在市场真正产生需求之前，把自己的认知优势转化为可以交付的能力。

### 3. 信息差可以赚钱，但真正有价值的是能够帮助别人少走弯路
作者在讲第二种方式时，明确说到自己可以「挣点信息差的钱」。他的抖音案例恰好说明了信息差形成的过程：有些人已经开始在抖音上获得关注甚至商业收益，另一些人却还不知道视频应该怎么拍、账号应该如何经营、个人 IP 应该如何打造。对于后者而言，向有实践经验的人请教，可以减少摸索的时间和试错成本，因此他们可能愿意付费购买指导。作者因为提前学习和实践，掌握了别人尚不熟悉的方法，就有可能从这种知识差距中获益。换句话说，信息差赚钱不是单纯依靠掌握秘密，而是利用别人尚未掌握的信息、技能和经验，帮助他们解决实际问题。
深层理解：
信息差可以进一步分为三个层次：
- 知道的信息不同： 有人已经了解新平台、新技术和新趋势，而大部分人尚未注意到。
- 理解的程度不同： 大家可能都知道抖音，但只有一部分人理解选题、定位、内容制作和商业变现之间的关系。
- 实践经验不同： 一些人可能看过很多理论，却没有真正做过；另一些人已经经历实际操作，知道哪些方法有效、哪些方法容易失败。

从商业价值来看，第三层往往更容易形成有说服力的付费服务。
这是因为一般信息随着互联网传播可能很快变得普及，但真实经验、具体判断和有效执行方法往往更难复制。
作者的经历说明：提前行动所积累的经验，可能在市场需求爆发时变成可以出售的知识资产。

### 4. 第三种赚钱方式：当别人开始赚钱，就向他们出售赚钱的方法
作者进一步提出，当一种新机会已经出现、很多人都知道有人通过抖音赚钱时，会产生另外一类需求：大家也想进入这个市场，却不知道具体应该怎么做。于是，就有人开始提供「教你怎么拍抖音」「教你怎么成为 IP」等培训、课程或指导服务，而作者指出，市场上已经有人通过这种方式赚到了不少钱。与亲自经营抖音账号获取收入相比，这种模式的特点在于，它把目标客户从最终消费者转向了希望进入这个行业的人。原文字稿将第三种方式的名称识别为「攻击」，但结合实际举例，更准确地理解，应是销售方法、攻略、培训或相关知识服务，而不是字面意义上的攻击。这种方式说明，一旦某个行业出现赚钱机会，不仅直接参与该行业可以赚钱，帮助别人进入该行业也可能成为一门生意。
深层理解：
这实际上是一种典型的「向淘金者提供工具」的商业思路。
当很多人希望通过某个领域赚钱时，他们往往需要培训、指导、软件工具、运营服务、资源渠道或其他专业支持。
例如，围绕短视频行业，可以形成不同的商业角色：

| 商业角色 | 为客户提供什么 | 主要收入来源 |
| --- | --- | --- |
| 短视频内容创作者 | 内容、关注度和影响力 | 广告、商品销售等 |
| 短视频培训者 | 拍摄与运营方法 | 培训费、课程费 |
| 个人 IP 顾问 | 账号定位和个人品牌建议 | 咨询费、顾问费 |
| 视频制作服务者 | 拍摄、剪辑与制作 | 服务费 |
| 内容工具开发者 | 提高创作效率的工具 | 软件订阅费或使用费 |

上述表格是基于视频案例进一步展开的商业分析，不代表作者在视频中逐项介绍过这些职业。
这一思路的重要启发是：
不一定非要直接参与热门行业的最终竞争，也可以成为热门行业的服务提供者。
但要注意，真正有价值的培训应当建立在真实的能力和经验上。教别人赚钱，并不等于能够保证别人赚钱。

### 5. 第四种赚钱方式：当行业竞争加剧，可以通过降低价格争夺市场
作者接着讨论了市场竞争变得激烈之后的情形：如果别人已经在某个领域赚到了钱，而自己再进入时很难凭借先发优势取胜，该怎么办？他的回答非常直接——便宜。视频中用了一组极具冲击力的价格来表达这一策略：原本可以卖到 6,888 元或 688 元的课程，现在用「68块8毛8」，也就是 68.88 元的价格出售。降价的核心思路是接受单个客户带来的毛利减少，尝试通过吸引更多客户来获取总体收益。作者用这组数字说明，当产品或服务逐渐同质化时，价格可以成为后进入者参与竞争的一种手段。
深层理解：
这一模式的逻辑是：
竞争者增加 → 同类产品变多 → 原有价格优势受到挑战 → 降低售价 → 吸引价格敏感客户 → 尝试通过规模增加总利润。
但是，价格低不等于一定更赚钱。
例如，下面是一个用于说明经营逻辑的假设：

| 项目 | 高价策略 | 低价策略 |
| --- | --- | --- |
| 单价 | 688 元 | 68.88 元 |
| 每单可变成本 | 188 元 | 28.88 元 |
| 单笔毛利 | 500 元 | 40 元 |
| 达到 5,000 元总毛利所需订单 | 10 单 | 125 单 |

这里的成本、利润和销量都只是解释低价策略的假设数据，并非视频中的真实经营数据。
可以看到，降价之后，单笔毛利可能明显缩小，因此必须依靠更大的订单规模才能获得相同的总毛利。
还要注意一个问题：客户数量增加，往往也会带来获客、客服、履约及售后成本增加。
所以低价策略能否成功，取决于销量增长是否足以覆盖毛利下降和新增运营成本。

### 6. 第五种赚钱方式：价格优势不够时，通过增加服务与附加价值争夺客户
当市场已经出现大量低价课程或低价产品时，作者认为，还可以继续从服务入手。他用了一个带有夸张和调侃意味的例子：有人不仅把课程价格降到「6块8毛8」，即 6.88 元，还额外赠送一瓶「蛇草水」之类的饮料。这个例子强调的并不是饮料本身，而是商家为了吸引客户，在原有产品之外不断增加服务、赠品和其他附加价值。当多个经营者提供的核心产品看起来差不多、价格也越来越接近时，客户可能会根据谁提供的体验更好、附加价值更多来选择。因此，第五种赚钱方式的本质，是通过服务体验和差异化价值，提高客户选择自己的可能性。
深层理解：
第四种和第五种方式存在明显区别：
- 第四种是降低消费者需要支付的价格。
- 第五种是增加消费者能够获得的价值。

如果只是把产品卖得更便宜，客户可能随时被另一个更低价的竞争者吸引。
但如果商家能够提供更好的教学效果、更快的响应、更清晰的交付过程和更完善的售后，客户的选择就可能不再仅仅取决于价格。
不过，视频里「6.88 元还送饮料」的极端例子，实际上也揭示了竞争过度的另一面：经营者可能为了争取客户，不断牺牲自己的利润。
服务必须真正解决客户问题，而不能只是无止境地增加赠品与成本。

### 7. 第六种赚钱方式：如果自己不直接经营，可以投资已经做得好的人
作者在介绍完前五种模式后，提出了一种完全不同的赚钱路径：投资。他用一种非常直白的说法表达这种选择——如果新机会已经被别人抓住，产品是别人做的、培训是别人做的、低价和服务竞争也由别人展开，那自己可以寻找其中做得比较好的经营者，投资他们。与前五种模式主要依赖个人经营、专业能力或市场执行不同，第六种方式的核心资源是资本和识别优质经营者的能力。投资者不一定需要亲自开发产品、拍摄视频或开设课程，而是通过参与企业或项目的所有权，争取分享其未来创造的经济价值。这一方式的本质，是把赚钱的重心从亲自完成经营活动，转向识别并配置资源给更有经营能力的人。
深层理解：
投资的逻辑可以拆解为：
发现有前景的行业 → 识别有竞争力的经营者 → 判断其商业模式和盈利能力 → 以合适价格参与投资 → 承担风险并争取长期回报。
这也是六种方式中需要特别强调风险的一种。
作者在视频里只用「选择这里面谁做得好，就投他」概括投资，但实际投资不能只看某个人当前能不能赚钱。
还需要判断：
- 现在的盈利是否真实、可持续；
- 业务是否依赖短期流量或平台政策；
- 企业是否拥有长期竞争优势；
- 投资价格是否合理；
- 投资者能否承担本金损失，以及是否存在退出渠道。

尤其需要区分：好生意不一定是好投资。
即使一家企业经营得不错，投资者如果支付了过高价格，仍然有可能亏损。

### 8. 最重要的退出原则：当低价和优质服务都无法盈利，就要重新评估行业
视频最后，作者提出了整套方法中最具决断性的一点：如果一个行业里，价格已经压得非常低的经营者赚不到钱，服务已经做得非常好的经营者同样赚不到钱，那就应该赶快考虑换行业。他的逻辑是，低价和优质服务已经是成熟竞争阶段常见的两类策略，如果两者都难以带来合理利润，那么行业本身可能存在较严重的盈利问题。此时继续投入，不一定能够通过更加努力来解决，反而可能造成更大的时间、资金和精力损失。作者用「赶快换行业，赶快跑吧」的强烈表达提醒大家，不应该把坚持本身当成商业上的正确选择。真正重要的是持续判断一门生意是否值得做，而不是只研究怎么把它做下去。
深层理解：
这里隐含了一套行业生命周期判断：
视频六种方式所对应的商业机会演变（概念性归纳）
技术创新
创造新需求，开辟新市场

快速跟进
提前学习，积累时间和信息优势

方法与培训
服务大量希望进入市场的人

低价竞争
靠价格吸引客户

服务竞争
靠体验增加价值

评估行业盈利空间
能否持续获得合理利润？

仍有利润
优化经营，继续发展

普遍无利可图
考虑转型或退出

第六种「投资」可以发生在多个阶段，并不必然排在上述竞争过程的最后。上述阶段也不代表每个行业都按此顺序演变。
需要强调，作者提出的是一种实用的判断原则，而不是严格的经济学定律。
某个行业的低价经营者不赚钱，可能是成本控制不佳；高服务经营者不赚钱，也可能是定价、定位或获客效率存在问题。
因此，更准确的判断应该是：
如果行业里的优秀经营者经过合理经营，仍然普遍难以获得可持续利润，那么这个行业就值得高度警惕。

理解： 商业经营不仅需要知道如何进入市场，也要有能力判断一个市场是否值得继续投入。

## 值得记住的点 / 行动建议

### 1. 先判断自己在赚钱链条中的位置，而不是只问什么行业最赚钱
视频最值得应用的地方，是将「赚钱」分成六种不同的参与方式。
面对一个新兴行业，可以先问自己：
- 我能否直接创造新技术、新产品或新需求？
- 我能否比大部分人更早掌握相关技术和实践经验？
- 我是否有能力把方法教给其他人？
- 我能否依靠成本结构和运营效率提供更低价格？
- 我能否提供竞争者没有做到的服务与体验？
- 我是否有资本和判断能力参与优秀经营者的成长？

这六种选择并不要求一个人全部具备。
例如，有技术能力但缺少资金的人，可能更适合提前学习和提供专业服务；拥有成熟客户渠道的人，可能更适合做产品销售和服务；具备资金、研究能力及风险承受能力的人，才适合进一步考虑投资。
最重要的是根据自己的实际资源选择模式，而不是看到别人在哪个行业赚钱，就盲目复制他的全部做法。

### 2. 建立持续发现新技术和新需求的机制
作者把科技变化放在六种赚钱方式的开头，实际上提示了一个很重要的行动方向：关注技术变化带来的真实需求。
可以定期观察三个问题：
第一，新技术让什么事情变得更容易？ 例如，某种工具是否显著减少了过去需要大量人工完成的工作。
第二，新技术让用户开始做哪些过去不常做的事情？ 新的使用行为可能带来新的产品、服务或消费习惯。
第三，这些变化是否已经产生了明确的付费需求？ 有人讨论某项技术，与有人持续愿意为相关产品和服务付费，是两个不同的市场信号。
实际操作中，可以建立一份「新机会观察清单」，每周记录一到三个值得关注的技术或行业变化，并跟踪真实用户问题、竞争产品和付费情况。
这样做的目标不是盲目追热点，而是培养发现新需求的能力。

### 3. 一旦发现机会，优先通过实际操作积累经验
视频中作者真正拿来说明自己如何获取信息差的，不是单纯阅读行业新闻，而是提前学习并开始行动。
因此，普通人想利用第二种赚钱方式，不能只停留在「我知道这个行业以后会很热门」。
更有价值的做法，是尽早完成一个实际项目。
例如，发现某个新内容平台正在发展，可以先尝试创建账号、发布内容、分析反馈、改进制作流程。
在这个过程中，把每次实践整理成记录：
- 做了什么；
- 使用了什么方法；
- 结果如何；
- 遇到了什么问题；
- 哪些经验可以复制；
- 哪些错误应该避免。

当更多人进入同一个领域时，这些记录就可能成为课程、咨询、案例研究或专业服务的基础。
发现机会只是起点，提前积累可验证的经验，才是将先发优势转化为长期价值的重要步骤。

### 4. 从自己会做，升级到能够帮助别人做成
视频中的抖音案例揭示了一条值得重视的成长路径：
个人技能 → 实践经验 → 方法体系 → 可交付服务 → 商业收入。
例如，一个人会拍短视频，只代表具备某种技能。
如果他还能说明如何根据受众确定内容方向、如何组织拍摄流程、如何分析视频表现，就开始具备帮助他人的能力。
如果进一步把这些经验整理成一套完整的方法，并能针对不同客户的问题进行调整，就可能形成培训、咨询或服务产品。
实际可以尝试三个步骤：
**1. 找出自己能够熟练完成、且他人普遍觉得困难的一件事。**
**2. 把完成这件事的流程拆解成清晰、可重复执行的步骤。**
**3. 用真实案例验证方法的有效性，再决定是否收费提供服务。**

这里需要特别注意，知识变现的基础应该是能够帮助他人解决问题，而不是单靠宣传赚钱前景来销售课程。

### 5. 不要轻易打价格战，先计算真实利润和获客成本
作者用 6,888 元、688 元、68.88 元这组价格强调低价竞争，但普通人真正执行时，需要先做好成本核算。
至少应当搞清楚四项指标：
- 售价： 每完成一笔交易，实际收到多少钱。
- 可变成本： 每多成交一单，需要多付出多少履约、材料、平台及其他直接成本。
- 获客成本： 平均获得一名付费客户需要投入多少广告费、销售费用或其他资源。
- 固定成本： 房租、固定薪酬、基础软件订阅等经营费用。

例如，一门课程卖 68.88 元，假设每单直接成本为 18.88 元，平均获客成本为 30 元，那么每单扣除这些费用后，仅剩 20 元可以用于覆盖固定成本和形成利润。
若固定成本较高，订单数量不足，就可能出现「卖得越辛苦、整体经营压力越大」的情况。
因此，降价之前必须先测算单位经济模型，而不是简单认为多卖一些就一定能赚回来。

### 6. 让服务成为差异化优势，而不是单纯赠送更多东西
视频里「6.88 元课程还送饮料」的例子非常有画面感，但从经营角度看，增加赠品不是提升服务的唯一方式，更不一定是最有效的方式。
真正值得投入的服务，应该是客户愿意认可、能够提高实际效果，并且经营者可以长期负担的部分。
例如，在知识付费和培训场景中，可能更有价值的服务包括：
- 清晰的入门指导，让学员知道从哪里开始。
- 能够直接使用的模板、工具和检查清单。
- 对学习过程中关键问题的及时反馈。
- 真实案例拆解，帮助学员理解方法适用的条件。
- 明确的交付范围与合理的售后支持。

如果一项赠品增加了大量成本，却对客户完成目标没有什么帮助，那么它可能只是一种短期促销手段，而不是可持续的竞争优势。
好的服务不是无条件付出更多，而是以合理成本，帮助客户获得更高价值。

### 7. 投资前先建立判断能力，不要把别人赚钱当成投资理由
作者最后提出投资优秀经营者，这个方向有合理性，但不能简单理解为「看到谁赚钱，就把钱投给谁」。
一个经营者当前赚钱，可能来自短期市场红利、特殊渠道、平台流量扶持或者不可持续的经营安排。
真正评估投资机会时，需要进一步分析其收入、利润、现金流、客户稳定性、竞争优势以及估值是否合理。
对于普通投资者，还应该特别重视资金安全与风险分散。
尤其是早期项目或私人股权投资，可能存在信息不透明、流动性不足、退出困难和本金全部损失的风险。
因此，如果缺少投资经验，优先学习基本的财务知识、风险管理和资产配置，比急于寻找所谓「赚钱高手」更重要。

### 8. 定期评估行业是否值得继续投入，避免沉没成本陷阱
视频最后的「赶快换行业」虽然表达得很强烈，但确实值得转化成一项具体行动：定期进行经营复盘。
可以每三个月或每六个月，对正在从事的业务进行一次系统检查。
重点关注以下几个方面：

| 判断维度 | 需要回答的问题 |
| --- | --- |
| 市场需求 | 客户数量和付费意愿是在增长还是下降？ |
| 利润空间 | 扣除真实成本后，是否还有合理利润？ |
| 竞争压力 | 是否只能通过不断降价获取客户？ |
| 差异化能力 | 客户选择自己的理由是否足够明确？ |
| 获客效率 | 获得一名新客户的成本是否越来越高？ |
| 长期趋势 | 新技术或市场变化是否正在削弱现有业务？ |
| 机会成本 | 同样的资金和时间，投入其他方向是否可能获得更好的风险调整后回报？ |

如果只是个人经营效率低，可以优先考虑改善产品、运营或客户定位。
但如果整个行业已经供给过剩、客户没有付费意愿、行业内优秀企业也持续无法获利，那么就应该认真考虑转型或退出。
特别要避免一种常见心理：
「我已经投入这么多了，现在退出不就全白费了吗？」
过去已经投入、无法收回的时间和资金属于沉没成本，不应该自动成为未来继续投入的理由。
是否继续一项生意，应主要看未来的收益、风险和替代机会，而不是过去投入了多少。

### 9. 把六种赚钱方式作为动态选择，而不是固定的职业标签
虽然作者把六种方式分别介绍，但一个人或一家企业未必只能选择其中一种。
例如，一个人在新技术出现时提前学习，可能先通过专业技能承接项目；随着经验增加，进一步提供培训；市场竞争加剧时，再通过专业化服务建立差异化优势。
如果未来积累了足够资金和判断能力，也可能从亲自经营逐渐扩展到投资其他项目。
这说明六种方式可以随着资源、能力和市场阶段发生变化。
不过，转换商业模式通常涉及新的能力要求，不能假设从内容创作者转型培训者、服务商或投资者就一定顺利。
因此，更好的策略是：
先在一种商业模式里建立真实优势，再根据市场需求和自身能力，逐步扩展新的收入来源。

## 我的点评
这段视频最值得肯定的地方，是用一个非常简洁的「六种赚钱方式」框架，帮助普通人从单纯追逐热门行业，转向理解技术创新、信息差、知识服务、价格竞争、服务差异化和资本投资之间的关系。尤其是作者强调「跑得比别人快」和「及时退出不赚钱的行业」，具有较强的现实意义，因为个人能够控制的往往不是技术创新的发生，而是自己的学习速度、行动效率、经营选择和风险暴露。
不过，这六种方式并不是严格、完整或互斥的经济学分类，例如知识培训本身就是一种服务，投资可以发生在市场发展的任何阶段，而品牌、渠道、网络效应、规模经济等其他盈利机制没有被系统展开。视频把「提前学习」与「通过信息差赚钱」联系起来是有道理的，但信息差通常会随着市场普及而缩小，因此更可持续的竞争力还是解决实际问题的能力、实践积累和客户信任。另外，低价和优质服务都不赚钱，并不必然证明整个行业没有机会，还需要分析企业的成本结构、经营效率、客户细分以及市场周期。
对普通人来说，这段视频最实用的价值，是建立一套持续思考的问题：新需求在哪里、自己有什么优势、客户为什么付费、利润能否持续，以及什么时候应该改变方向。
