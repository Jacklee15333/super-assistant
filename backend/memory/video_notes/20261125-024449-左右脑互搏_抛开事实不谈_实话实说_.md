## 核心观点

### 1. 宏观经济表现良好，不代表底层民众没有遭受生活冲击
被反驳者认为，美国政府停摆虽然持续了十几天，但美国的星舰照样升空，美股照样上涨，普通老百姓的生活没有受到任何影响，因此中国网民没有必要过度关注这件事。视频作者对此提出质疑，认为航天技术的发展、金融市场的表现与底层民众能否维持基本生活，属于不同层面的评价指标，不能用前者直接证明后者。
即使一个国家拥有先进的科学技术、强大的资本市场和发达的经济体系，也可能同时存在严重的贫困、食品保障不足以及家庭抗风险能力薄弱等问题。作者特别指出，对于依靠食品券生活的低收入群体，以及因政府停摆而无法正常获得工资的联邦雇员而言，宏观层面的繁荣并不能直接解决他们的生活困难。
这场争论反映出一个重要的社会评价问题：评价一个国家的发展水平，既要看经济总量、科技实力和金融市场，也要看发展成果是否惠及普通民众，以及弱势群体能否获得基本生活保障。 如果仅凭股市上涨、火箭升空就认定所有人的生活安然无恙，实际上是将局部的宏观表现错误地推广到了整个社会。

### 2. 美国政府停摆的两个具体案例，反映出部分家庭的经济脆弱性
为了反驳“老百姓丝毫没有受到影响”的说法，视频作者引用了两段涉及美国民众生活困境的视频。第一段视频中的女性表示，她和丈夫都有工作，也能够领取食品券，但即使如此，她仍然需要每天省掉晚饭，把有限的食物留到第二天中午，晚上只能通过睡觉来熬过饥饿。
这位女性表示，她完全无法想象失去食品券之后应该怎样生活，因为在已经获得食品援助的情况下，她甚至都无法保证每天正常吃晚饭。第二段视频中的女性则表示，她从未想过自己有一天会需要前往救济站，但政府停摆仅二十多天，就已经出现大量联邦雇员领取救济的情况，而她因为没能领到救济物资，只能哭着回家。
作者借这两个案例强调，一些看似拥有稳定工作和正常收入的人，也可能缺乏足够的储蓄和生活缓冲，一旦工资或社会福利出现中断，就会迅速陷入困境。这两个案例能够对“政府停摆完全没有影响任何普通人”的绝对化判断提出有效质疑，但若要进一步判断影响范围、受影响人数及其严重程度，仍需要更加全面的统计数据。

### 3. 关注国外社会问题与关注国内民生，并不是非此即彼的关系
被反驳者认为，与其天天关注美国政府停摆，不如关心自己身边真正影响生活的事情，例如食品安全隐患、职场压榨、老人跌倒后无人敢扶，以及长期受到忽视的民生难题。他强调，国内普通人的柴米油盐、衣食冷暖才是最值得关注的问题，不应总是隔着屏幕对其他国家的生活指手画脚。
视频作者并未否认这些国内民生问题的存在，而是反驳“国内问题没有人关注”的判断，并列举了网络上关于五天八小时工作制、农民权益、教育、养老和收入分配不均等问题的大量讨论。其中，有博主呼吁在三个月之内全面实行五天八小时工作制，并倡议抵制不执行的餐饮企业和其他企业，相关视频甚至获得了十几万点赞。
作者借此说明，国内网络舆论并非只关注国外负面新闻，也有相当多的人正在为国内民生问题发声。关注国外问题与推动国内问题解决可以同时进行，不能因为一个人讨论了美国的社会问题，就推断他不关心中国普通人的生活。 但同样需要区分的是，网络讨论、点赞和呼吁能够反映一定的社会关注度，并不直接等于现实问题已经得到解决。

### 4. 国际政治与经济事件并非与普通人的生活毫无关系
被反驳者提出，美国白宫停不停摆，与中国普通人的吃饭、睡觉没有什么关系，因此没有必要投入过多注意力。视频作者则认为，在全球经济高度相互联系的背景下，这种判断过于简单，因为美国政府的运转状况可能与国际贸易、金融市场、留学、商务往来等活动产生联系。
政府部门暂停或者降低服务效率，可能影响部分行政审批、经济数据发布、签证相关服务以及跨国商业活动的正常运行；国际金融市场出现波动，也可能通过投资、汇率和企业经营等渠道影响其他国家的居民。不过，不同政府部门和业务受到的影响并不一致，也不能将所有经济变化都归因于政府停摆。
作者真正想表达的是，普通人生活在一个相互联系的国际体系中，国外的政治经济事件并不天然属于与自己完全无关的“别人家的事”。关注国际新闻的价值不应只是看热闹或者满足情绪，而应当是理解外部变化如何通过经济、政策和市场传导到个人生活。 对国际事件是否值得关注的判断，应当取决于其实际影响，而不是简单依据事件发生在国内还是国外。

### 5. “落后就要挨打”与“强大后受到围堵”，在逻辑上不必然矛盾
被反驳者提出的第一种“双重标准”是：中国过去遭受外部侵略时，人们将原因归结为自身落后，形成了“落后就要挨打”的认识；而当中国逐渐强大、遭遇外部围堵时，人们又将原因归结为其他国家见不得中国发展得好。他认为，同样是面对外部压力，却根据自身处境的变化采用不同解释，是一种自我欺骗。
视频作者则认为，这两种说法并不必然矛盾，因为外部力量在不同历史阶段可能采取不同策略：面对弱小的国家，可以通过侵略、控制和不平等交换获取利益；面对逐渐强大的竞争者，则可能通过贸易限制、技术封锁或者其他方式维护自身优势。按照作者的解释，中国曾经长期承担世界工厂、商品倾销市场和资源供应者等角色，而中国的发展壮大可能改变原有利益格局，因而引发部分国家的抵制。
作者强调，前后两种解释针对的始终是外部力量如何根据自身利益对待中国，而不是简单地随着中国实力变化更换评价标准。从形式逻辑上看，一个主体在不同条件下采取不同策略确实是可能的，两种现象可以同时成立。不过，具体国家采取某项政策的真实原因，仍需要结合历史资料、政策文件、产业竞争和安全利益等证据判断，不能将所有外部压力都归结为单一动机。

### 6. 国际贸易本质上是利益交换，不应被简单包装成单方面的恩赐
被反驳者提出的第二种“双重标准”涉及进出口贸易：当中国进口外国商品时，有人认为中国依靠庞大的市场养活了外国企业；当中国出口商品时，又有人认为外国离不开中国供应的产品，如果中国停止出口，对方就无法正常生活。他批评这种思维将正常的商业买卖，无论进口还是出口，都解释成中国对其他国家的单方面施恩。
视频作者实际上并不否认国际贸易是一种商业合作，而是进一步追问：既然认可商业合作具有互利性质，那么为什么有些人在评价外国资本进入中国、外国企业投资中国时，又会要求中国消费者或者社会对其抱有感恩心态？作者还批评了一些将殖民者打开国门、资本家影响物价等历史经济现象包装成恩惠的叙事。
在作者看来，外国企业进入中国市场，首先是因为这里存在利润、市场规模、产业配套和投资机会，而不是专门为了开展慈善活动；中国企业参与国际贸易，也同样具有自身的商业目标。这场争论中，双方其实存在一个共同的认识：商业合作应当建立在利益交换基础上，而不应被轻易转化为道德上的恩赐或者亏欠。 真正的分歧主要在于，双方认为哪些舆论群体在选择性使用这种标准。

### 7. 外资进入中国、正常企业出海与资本外逃，必须进行概念区分
被反驳者提出的另一种逻辑矛盾是：当外国资本进入中国时，有人认为外资是来抢占市场、分走利益的；当中国资本走向海外时，又有人指责其将财富带走，属于资本外逃。他认为，对同一种跨境资本流动行为，不能因为资本来源和流动方向不同，就将其分别定义为掠夺与背叛。
视频作者首先质疑这种说法是否能够代表中国社会的主流观点，因为鼓励中国企业走出去、开拓国际市场，本身就是一种常见的发展思路。他特别强调，“走出去”和“逃出去”不是同一个概念，企业正常开展海外投资、建设工厂、拓展销售渠道，与为了规避监管、隐匿资产等目的而转移资金，在性质上可能存在明显差异。
同样，外国资本进入中国也不能被一概定义为掠夺或者无条件的贡献，而应该分析具体投资方式、经营行为及其经济社会影响。资本流动的方向并不是判断行为性质的唯一依据，真正需要考察的是投资目的、合规性、经营活动、资金用途及其产生的实际后果。 作者认为，把性质不同的行为强行归纳为同一种现象，再批评对方自相矛盾，本身就可能构成概念偷换。

### 8. 外资具有创造经济价值的能力，也具有逐利性，因此市场监管仍然重要
在讨论外资问题时，视频作者强调，外国资本进入中国的直接目的通常是获得商业回报，不能因为外资带来了投资、就业或者技术，就忽略资本逐利可能造成的负面影响。他提出，如果缺乏有效监管，拥有资金、品牌、技术和市场优势的外国企业，也可能通过市场集中、垄断或者其他经营方式损害消费者和其他市场主体的利益。
作者以反垄断调查为例，说明资本的经营行为并非天然符合公共利益，市场经济也需要相应的制度约束。这一观点所体现的逻辑是，欢迎外资与监管外资并不矛盾，就像支持企业发展与限制企业的不正当竞争行为也可以同时成立。
不过，逐利性并不是外国资本独有的特征，国内资本同样可能产生垄断、损害劳动者权益或者侵害消费者利益等问题。因此，如果将作者的观点进一步延伸，更合理的原则应当是：支持合法投资和公平竞争，同时依据一致的法律与监管标准约束所有市场主体，而不是单纯根据资本的国籍决定其好坏。 这样才能避免从批评双重标准走向另一种双重标准。

### 9. 不能以形式逻辑代替事实判断，也不能用立场代替证据
视频最后，双方都将批评重点放在了对方的思维方式上。被反驳者认为，有些人习惯使用非黑即白的滤镜看待世界，用立场代替理性、用偏见掩盖规律，即使已经摆脱了过去有形的辫子，思想上的“辫子”仍然存在。
视频作者则反过来指责对方脱离事实和历史背景，先设定中国舆论存在双重标准，再通过选择性的例子、概念归纳和逻辑包装来证明自己的结论。他用“用逻辑去推翻事实”“偷换概念”“抛开事实不谈”“左右脑互搏”等说法，批评对方试图用表面上的理性姿态掩盖预设立场。
这部分是整个视频最核心的方法论争论：一个论证即使形式上严密，如果起始前提不真实、概念定义不准确或者关键事实被省略，其结论仍然可能不可靠。反过来，拥有某些真实个案也不意味着所有基于个案作出的推论都成立。可靠的公共讨论必须同时满足事实真实、概念清晰、逻辑有效、证据充分和评价标准一致，而不能将事实与逻辑对立起来。

| 国内外民生关注 | 不应过度关注国外而忽略国内 | 国内外问题可以同时关注，国内也有大量民生倡议 |
| 国际事件的相关性 | 美国政府停摆与中国普通人的生活无关 | 可能通过贸易、金融、留学和商务活动产生影响 |
| 落后与强大 | 落后时强调自身原因，强大时指责外部力量，属于双重标准 | 外部力量可能根据不同阶段的利益关系采取不同策略 |
| 进口与出口 | 都被部分舆论包装成对其他国家的施恩 | 商业行为本质是利益交换，也不应要求中国单方面感恩外资 |
| 外资进入中国 | 不应将外国投资一概视为抢占利益 | 外资具有逐利性，需要客观评价和必要监管 |
| 中国企业出海 | 不应将资本流出一概视为背叛 | 正常企业出海与资本外逃不是同一概念 |
| 理性与立场 | 批评部分舆论以立场代替理性 | 反过来批评对方预设立场、选择性使用事实 |

### 四、重要概念及其含义

| 概念 | 含义及其在视频中的作用 |
| --- | --- |
| 双重标准 | 对性质相同的行为，因为主体、立场或者利益关系不同，而采用不同的评价标准 |
| 偷换概念 | 在论证过程中，将两个含义不同的概念混为一谈，使结论看起来成立 |
| 二极管思维 | 网络用语，指非黑即白、非此即彼，缺乏中间状态和复杂性分析的思维方式 |
| 世界工厂 | 对承担大量全球制造业生产活动的国家或地区的形象称呼 |
| 商品倾销 | 在贸易领域具有特定含义，视频中主要用来描述外国商品占据市场的现象 |
| 资本逐利性 | 资本投资和经营活动通常以获取经济回报为重要目的 |
| 企业出海 | 企业通过海外投资、设厂、出口、建立销售渠道等方式拓展国际业务 |
| 资本外逃（Capital Flight） | 资本因经济、政治、政策、风险等因素大量或迅速流出的现象，不等同于全部海外投资，也不必然意味着违法 |
| 反垄断（Antitrust） | 通过法律与监管制度防止和制止垄断行为，维护公平竞争 |
| 思想上的辫子 | 被反驳者使用的比喻，指虽然摆脱了过去外在的束缚，但仍保留狭隘、僵化的思想观念 |

## 金句摘录
以下摘录同时保留双方具有代表性的原话，对明显的语音识别错误和口语断句进行了轻微修正。
**1. 关于关注身边的现实生活——被反驳者**
“别总隔着屏幕对别人的生活指手画脚，先把目光拉回自己的一亩三分地。”

这句话强调将注意力放回个人能够直接感受、参与和改善的现实问题，避免把大量时间消耗在与自身利益关联不大的情绪化讨论中。
**2. 关于评价国家发展水平——视频作者**
“你们不是一直都说，看一个国家，我就看老百姓过得好不好吗？这叫过得好吗？”

作者借此反问，评价一个国家时，是否真正坚持了以普通民众生活质量为重要标准，而不是根据评价对象的不同临时更换指标。
**3. 关于国际贸易的本质——被反驳者**
“买卖本是你情我愿的平等交换，到了这里却成了单方面的施舍。”

这句话指出商业合作不应被过度道德化，交易双方原则上都有各自的利益诉求，而不是必然存在施恩者与受恩者的关系。
**4. 关于立场与经济规律——被反驳者**
“用立场代替理性，用偏见掩盖规律，最终只会堵死自己的路。”

其价值在于提醒人们，经济活动具有相应的规律，不能只凭个人情绪和政治立场判断贸易、投资和资本流动的性质。
**5. 关于逻辑与事实的关系——视频作者**
“我就服你这种用逻辑去推翻事实的人。”

这是视频中最能体现作者核心批评的一句话，针对的是先设定结论，再通过语言和逻辑包装来否定不利事实的论证方式。
**6. 关于企业出海与资本外逃——视频作者**
“那走出去和逃出去是一回事吗？能混为一谈吗？”

这句话强调概念辨析的重要性：行为表面相似，不代表其目的、性质、合规性和实际影响完全相同。

## 值得记住的点 / 行动建议
以下既包含视频作者直接表达的观点，也包含从双方争论中可以进一步提炼出的、适用于日常信息判断的方法。

### 1. 评价一个国家时，建立宏观与微观相结合的指标体系
不要仅凭股市表现、GDP、航天成就、城市建设、科技水平等宏观指标判断一个国家的全部发展状况，也不要仅凭几个底层民众的困难案例就否定其整体发展成果。
更完整的评价体系应当包括：

| 评价维度 | 具体观察指标 |
| --- | --- |
| 经济实力 | GDP、产业发展、劳动生产率 |
| 科技实力 | 科研水平、技术创新、制造业能力 |
| 居民收入 | 工资中位数、居民可支配收入、实际购买力 |
| 基本生活 | 食品、住房、医疗、教育等支出负担 |
| 社会保障 | 失业救济、养老保障、食品援助 |
| 劳动权益 | 工作时间、休假制度、劳动保障 |
| 抗风险能力 | 家庭储蓄、应急资金、债务压力 |
| 社会公平 | 收入分配、贫困程度、社会流动性 |

尤其要警惕使用某一个表现突出的指标，掩盖其他方面的不足。一个国家可以同时拥有世界领先的科技产业，以及需要进一步改善的社会保障体系，这两者并不矛盾。

### 2. 遇到绝对化观点时，优先检查它的适用范围
视频中“老百姓丝毫没有受到影响”是一种典型的绝对化表述，因为它否定了任何普通人受到影响的可能性。
面对类似观点，可以重点追问：说话者指的是所有人，还是大多数人？指的是短期影响，还是长期影响？有没有忽略特定职业、地区和收入群体？所依据的是完整统计数据，还是某几个被选择出来的案例？
需要特别记住的是：
一个真实的反例可以推翻全称判断，但不能自动证明与该判断完全相反的结论。
例如，只要有一名联邦雇员确实因停摆陷入生活困难，就足以反驳“没有任何人受到影响”；但这并不能直接证明所有联邦雇员都陷入困境，更不能仅凭这一案例判断整个美国社会的经济状况。

### 3. 不要将关注国内与关注国外人为制造成对立关系
普通人完全可以同时关注国内劳动权益、养老保障、食品安全和国际政治经济事件，没有必要把两类议题设置成只能选择其一的关系。
更重要的是区分关注的目的：是为了理解事实、获得有用信息、发现制度差异和经验教训，还是仅仅为了获得情绪满足、优越感或者寻找争论对象。
对于国内问题，可以进一步了解相关制度、投诉渠道、劳动权益保障方式和公共政策；对于国际问题，则可以关注其对就业、资产、贸易、留学和生活成本的潜在影响。
关注哪里并不是最重要的，关注之后是否形成了更准确的认识、是否能够推动现实改善，才是关键。

### 4. 分析国际事件时，找到真正影响个人生活的传导链条
国际新闻并不是天然重要，也不是天然与普通人无关。判断其价值，可以采用“事件—传导机制—个人影响”的分析方法。
国际事件影响个人生活的潜在传导路径示意，不代表每条路径必然受到政府停摆影响。
例如，投资者可以关注经济数据发布、市场预期和资产价格变化；从事外贸的人可以关注审批效率、订单、物流和客户需求；留学生可以关注相关政府服务是否受到影响。
通过寻找真实的传导路径，能够减少对国际新闻的无效关注，也能避免低估真正可能影响自身利益的外部变化。

### 5. 判断前后观点是否矛盾，必须先检查背景和条件是否相同
很多看似自相矛盾的观点，实际上可能是在描述不同条件下的不同现象。
例如，“弱小时受到欺负”和“强大后受到竞争对手限制”，并不必然构成逻辑矛盾，因为行为主体可能根据对方的实力和利益关系采取不同策略。同样，“欢迎合法投资”和“反对垄断行为”也可以同时成立。
在判断一个人是否使用双重标准时，应当检查：

| 检查项目 | 核心问题 |
| --- | --- |
| 行为主体 | 讨论的是不是同一类主体？ |
| 行为性质 | 两种行为是否真的具有相同性质？ |
| 历史背景 | 所处的时代和环境是否一致？ |
| 行为目的 | 双方的真实目标是否相同？ |
| 现实条件 | 权力、资源、实力、规则是否发生变化？ |
| 评价标准 | 判断好坏的原则是否发生了无理由的改变？ |

只有当两个案例在相关条件上具有可比性，却因为立场变化而被采用不同的评价标准时，才更有理由将其认定为双重标准。

### 6. 看待商业合作时，少用感恩和施舍叙事，多分析利益结构
无论是外国企业进入中国，还是中国企业进入海外市场，无论是进口商品还是出口商品，都应当首先从商业利益与经济规律出发分析。
企业为什么愿意投资？可能是因为当地拥有庞大的消费市场、成熟的供应链、相对有优势的生产成本、技术人才以及发展机会。
东道国为什么愿意引入投资？可能是为了增加就业、获得技术和管理经验、促进产业发展、创造税收以及增强市场竞争。
双方都可以从合作中获得利益，但利益是否对等、合作是否公平，则需要根据具体合同、市场地位、竞争环境和法律制度进行判断。
合作不必然意味着恩赐，互利也不必然意味着利益均等。
既不应该因为外国企业获得利润，就认定其一定在掠夺；也不应该因为企业创造了就业或者带来了技术，就将其所有商业行为都视为值得无条件感恩的贡献。

### 7. 区分正常企业出海、跨境资产配置和资本外逃
不能简单地将资金流向海外的行为全部认定为资本外逃，也不能认为所有对外投资都必然有利于本国经济。

| 类型 | 常见目的与特点 |
| --- | --- |
| 正常企业出海 | 建立海外工厂、拓展市场、完善全球供应链 |
| 海外直接投资（FDI） | 在外国建立或取得具有持久利益的经营性投资 |
| 跨境资产配置 | 分散投资风险、进行资产多元化配置 |
| 资本外逃 | 因风险、政策预期等因素大量或迅速转移资本 |
| 非法资金转移 | 可能涉及洗钱、逃税、规避监管等违法行为 |

判断具体行为时，应重点考察资金流动目的、合规性、投资是否具有真实经营活动、是否产生经济价值以及是否损害其他主体的合法权益。
这不仅适用于理解企业出海问题，也适用于理解各种公共舆论中的概念争论。

### 8. 对国内资本与国外资本采用一致的监管原则
资本具有逐利性，但逐利本身并不等于掠夺，也不意味着所有商业行为都是合理的。
真正重要的是企业是否遵守法律，是否存在滥用市场支配地位、侵害消费者权益、违法压榨劳动者或者破坏公平竞争的行为。
面对外国企业，应当既看到其可能带来的投资、技术、就业和竞争，也关注其可能造成的市场集中、利润分配和监管风险；面对国内企业，同样不能因为其国籍或品牌身份，就忽略其存在的垄断、产品质量和劳动权益问题。
坚持统一的评价标准，才是避免双重标准最有效的方法之一。

### 9. 建立“事实—概念—逻辑—结论”的信息判断流程
这是从整段视频中能够提炼出的最具普遍价值的思维方法，可以应用于热点新闻、短视频评论、商业分析、国际关系讨论和日常争论。

第一步：核查事实
事件是否真实发生？原始来源、时间和数据是什么？

第二步：明确概念
双方讨论的是不是同一件事？是否发生了概念偷换？

第三步：检验逻辑
前提能否支持结论？是否遗漏了条件或其他可能原因？

第四步：统一标准
如果将讨论对象换成自己支持的一方，还会不会得出同样的判断？

第五步：形成暂时结论
根据现有证据判断，并保留在出现新证据后修正观点的可能性。

尤其值得注意的是，事实和逻辑并非对立关系。事实是论证的基础，逻辑是从事实推导结论的工具，二者缺一不可。
有事实而没有逻辑，容易陷入个案堆砌和情绪化归纳；有逻辑而没有真实前提，则容易形成看似严密、实际上脱离现实的论证。

### 10. 警惕双方都可能存在的选择性取证与立场先行
视频作者主要是在批评对方的双重标准，但观看此类辩论视频时，也应当将同样的检验标准应用于视频作者本人。
例如，被反驳者使用股市上涨和星舰升空来证明普通人不受影响，可能存在以偏概全的问题；视频作者使用两个生活困难的个案来质疑这一结论具有一定合理性，但如果进一步推断整个社会都不关心底层民众，同样可能存在过度归纳的问题。
再例如，被反驳者声称某些群体将企业出海视为资本外逃，需要提供具体言论和具有代表性的证据；而视频作者以自己没有听过类似说法进行反驳，也不足以证明这种舆论完全不存在。
日常观看争论类视频时，可以使用下面这份检查清单：
公共议题理性判断清单

0/8

是否区分了双方的原话与转述？
是否找到了原始视频、数据或报道来源？
是否存在只展示有利于自身观点的案例？
是否将少数人的言论扩大为整个群体的观点？
是否混淆了相关性与因果关系？
是否对不同国家、企业和群体采用一致标准？
是否存在扣帽子、人身攻击代替事实论证的情况？
如果出现相反证据，自己是否愿意修正判断？

真正的独立思考，并不是找到一个与自己立场一致的博主，然后全盘接受他的论证，而是能够对所有信息来源保持相同的审视标准。

## 我的点评
这段视频最值得认同的地方，是指出宏观经济繁荣不等于所有普通人的生活都得到保障，同时强调关注国外问题与关注国内民生并不冲突，这两点具有较强的逻辑合理性。作者对“正常企业出海”和“资本外逃”的概念区分也具有实际价值，因为行为表面相似，并不意味着其目的和性质完全一致。
不过，视频作者在批评对方以偏概全的同时，也存在利用少数个案进行较大范围推论、将复杂国际竞争归结为单一利益动机，以及用“你们”概括不同舆论群体的问题。被反驳者提出的关注身边民生、尊重商业交换规律和避免双重标准等原则，本身也有合理之处，不应因为其部分论证存在问题就全部否定。
此外，双方均使用了较多讽刺、反问、标签化表达和立场指责，这种表达虽然能够增强短视频的传播效果，却不一定有助于深入理解问题。普通人真正应该从这段视频中学习的，不是如何在立场争论中击败对方，而是如何核实事实、区分概念、理解因果、统一评价标准，并且将同样严格的判断原则应用于自己认同的观点。
