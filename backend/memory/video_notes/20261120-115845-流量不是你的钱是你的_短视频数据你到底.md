# 流量不是你的，钱是你的 短视频数据你到底该怎么看？我发现很多人连方向都错，努力半天全是饲料。
先画个模型。拍视频第一层叫触达，就是你印了1000张传单、扔了800张，剩下200张被人看见——播放量就是触达，只是让人看见，不等于进你店。
第二层叫粉丝。这个词是骗人的。你以为500万粉丝多牛？点开他关注列表，每个人关注好几千人。你只是他1/1000里的一个，他可能一辈子不来。那不叫粉丝，那叫follow，放那备用。
第三层叫活跃。点赞、评论、收藏，看着热闹吧？可来的人可能是来骂你的。你挣到钱了吗？没有。
记住这条线：上面三层，触达、粉丝、活跃，全叫分发逻辑。它们帮你把平台搞活跃了，平台给你发工资，你自己一分钱没挣。流量过去就过去了，全是过眼云烟。
真正挣钱的是下面这条线，叫买单逻辑。第一，有人真掏钱。我写了本书印了18次、卖几十万册，那才是真金白银。第二，留存。我有个社群1.1万人，这才是真粉丝——已经买单还留下来。平台会凉、热度会蒸发，千万大V流量没了就成浮云，但鱼池是你的。第三，裂变。他用完觉得好，主动帮你背书、分享给别人，还带身份感。这时候不用你拍视频，新的人也会进来，还有复购。
你的收益＝利润×用户数×复购×传播。上面是过往云烟，下面才是你的资产。
今晚回去看一眼：你那几百万人里，有几个真买过你东西、留下来、还帮你转发的？数这个，别数播放量。
