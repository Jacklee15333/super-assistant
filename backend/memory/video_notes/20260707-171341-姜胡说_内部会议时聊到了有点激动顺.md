这段视频是内容创作者「姜胡说」刚结束一次内部会议后，针对许多人经常感到“迷茫、不知道自己到底为了什么而努力”的问题，临时录制的一段即兴讲话。作者没有从传统的职业规划、个人兴趣或励志心态入手，而是把问题放在更宏观的人类文明演进、经济运行机制与技术生产力变革的框架下进行解释。

## 核心观点

### 1. 人生方向不是凭空寻找的，而是由所处时代的核心规则决定的
作者首先从人类文明的演变切入，把人类社会概括为三个主要阶段：早期的狩猎文明、后来的农耕文明，以及今天的科技文明。按照他的理解，在早期文明中，决定一个人或群体生存能力的关键因素是力量，尤其是群体组织起来的力量，直白地说就是“谁能打”；到了农耕文明，土地成为重要生产资料，土地资源与科举等制度性晋升渠道影响着个人的发展机会。进入科技文明以后，决定机会分配和财富创造的底层因素发生了变化，个人不再只能依靠体力、土地或传统社会地位寻找出路。因此，要解决今天的人生迷茫，首先要理解今天这个时代究竟按照什么规则运行，而不是照搬过去时代的生存逻辑。
这套历史划分属于作者为了说明问题所采用的简化模型，并不意味着人类历史只能被严格划分为这三个阶段。

### 2. 科技文明有两个核心支柱：自由市场经济与科技生产力
作者明确指出，今天的科技文明有两个最值得普通人关注的因素：第一个是自由市场经济，第二个是科技生产力。自由市场经济决定了个人如何通过提供价值、满足需求参与社会交换，并获得相应的经济回报；科技生产力则决定了个人能够使用哪些工具，以什么样的效率生产、传播和交付价值。前者回答的是“为什么别人愿意为你付钱”，后者回答的是“怎样让更多人以更低成本接触到你的价值”。如果只有市场需求，却没有合适的技术工具，个人可能受到地理位置、资金和服务能力的限制；如果只有技术工具，却没有真实需求，流量和产品也可能无法形成收入。两者结合，才构成作者所说的现代普通人的主要发展机会。

### 3. 自由市场经济的基本逻辑：你能满足多少需求，就有机会获得多少回报
视频中最重要的一句话是：“只要你能给别人提供价值，只要你能给别人提供他想要的东西，你就能得到你想要的东西。”作者试图纠正一种常见的思考方式：很多人把赚钱看成自己想获得多少资源，却没有先思考别人为什么愿意把钱交给自己。在市场交易中，消费者通常不会仅仅因为一个人努力、辛苦或者渴望成功就支付报酬，而是因为某种商品或服务满足了自己的实际需求。这个需求既可能是解决现实问题，也可能是节约时间、减少麻烦、获得知识、改善体验，或者满足情绪与精神需要。因此，赚钱的出发点应该从“我想得到什么”，转向“我能为别人解决什么问题”，让个人回报成为创造价值之后可能产生的结果。
需要注意，这并不意味着付出必然获得回报；价值能否变现，还取决于支付意愿、竞争、信任和交易条件。

### 4. 不知道做什么时，就去观察别人需要什么，以及赚钱的人满足了什么需求
针对“我很迷茫，不知道方向在哪里”的问题，作者提出了一个非常具体的方法：每天观察市场中的需求，以及已经有人成功满足了哪些需求。他的原话是：“你每天就去给我观察他需要什么，他满足了谁的需要，所以他赚到钱了。”在这套思路中，赚钱的人和正在发生的交易，可以成为研究需求的线索；看到一个人或一家企业获得收入，不仅要关注其结果，更要分析背后究竟是谁在支付、为什么支付、得到了什么价值。长期进行这样的观察，可以帮助个人培养市场敏感度，从原本模糊的“我能干什么”，逐渐发现具体的客户群体、需求场景和商业机会。作者甚至用“每天观察，你不可能穷”来强化这套方法的重要性，强调观察不是偶尔进行的灵感活动，而应该成为一种持续的习惯。
这句话带有明显的鼓励和夸张色彩，更合理的理解是：持续观察有助于提高识别机会的能力，而不是对财富结果的保证。

### 5. 最值得长期坚持的方向，是不断思考怎样帮助别人变得更好
作者并没有要求每个人必须进入某个固定行业、掌握某项热门技能，或者立即找到独一无二的商业模式，而是提出一个更稳定的原则：“总想着怎么能帮助别人变得更好。”这一观点的意义在于，它把个人的发展方向建立在外部需求之上，而不是仅仅建立在自己的兴趣、焦虑或短期情绪之上。只要人们仍然希望生活更方便、效率更高、收入更好、能力更强，围绕这些需求提供帮助，就可能存在新的产品与服务机会。作者还明确表示，这些满足需求的方法是可以模仿、可以学习的，普通人不一定要从零发明一种全新的商业模式。真正需要学习的，是如何识别有价值的问题、理解别人解决问题的方式，再通过自己的能力提供可信、有效的解决方案。
这里的“模仿”更适合理解为学习商业逻辑、服务方式和经验，而非直接复制他人的作品或侵犯知识产权。

### 6. 技术革命不断改变普通人的机会，而互联网让个人获取用户的门槛大幅下降
谈到科技生产力时，作者依次提到蒸汽机、电力、工业化，以及距离我们更近的互联网和移动互联网。这些技术变化的重要性，不只是产生了新的工具，也在不断改变生产、交易和信息传播的方式。尤其在互联网和移动互联网出现后，个人可以借助数字平台突破过去的地理和渠道限制，不再必须先拥有实体门店、庞大的销售团队或者传统媒体资源，才有机会让大量用户看到自己。作者因此特别强调当下互联网所提供的机会，认为个人能够以相对低的成本接触到过去难以触达的客户群体。在他的逻辑里，互联网的关键价值不仅是方便获取信息，更是把过去昂贵的“用户触达能力”，变成普通人也有机会使用的工具。
视频所说的“几乎不需要任何成本”，主要是一种对进入门槛降低的强调，并不代表实际经营没有时间、内容制作、流量获取等成本。

### 7. 为什么一定要写东西、学习新媒体？因为它们是普通人建立用户连接的重要工具
作者专门提到，自己一直要求大家“写点什么”“学新媒体”，原因就在于文字内容与新媒体渠道能够帮助个人以较低的资金门槛持续接触用户。过去，一个普通人想让大量陌生人了解自己，往往需要购买广告、经营线下渠道或者借助传统媒体；而现在，借助互联网平台和内容传播，即使没有很大的初始资金，也有机会形成持续曝光。写作和新媒体的重要性不只在于获得关注，还在于能够通过内容表达观点、展示能力、积累信任，并逐渐吸引对某类问题感兴趣的目标人群。对于个人创业者和小团队来说，内容还可以作为一种持续存在的获客资产，让过去发布的内容在未来继续带来用户。因此，作者强调学习新媒体，并不是单纯要求每个人成为网红，而是在建议普通人掌握现代社会重要的用户连接与价值传播能力。
不过，具体使用哪个平台、采用何种内容形式，视频并未展开说明。

### 8. 商业模式可以非常简单：找到用户、了解需求，再用好产品完成匹配
作者对互联网商业的描述非常直接：“找到这些用户，了解他们，看看他们需要什么，然后找一个产品，好的产品和人对接就完事了。”这段话实际上概括了一条基础的商业链路：获取用户—理解需求—寻找产品—建立匹配—促成交易。他强调的不是先生产大量产品再想办法销售，而是先接触并理解用户，然后寻找真正适合这些用户的产品或服务。这种思路能够减少闭门造车的风险，因为商业活动不是从经营者的主观想象开始，而是从潜在客户已经存在的问题出发。与此同时，产品必须足够好、匹配度足够高，才能让前期通过内容和渠道积累的关注转化为有意义的交易，并为后续的复购创造条件。
“对接就完事了”是作者为了强调原理而使用的简化表达，实际执行仍需解决交付、定价、售后与信任等问题。

### 9. 收入增长可以从三个变量理解：客单价、用户数和复购
视频提出一个简洁的商业公式：“你的收益等于客单价乘以用户数乘以复购。”这里的客单价，可以理解为每次购买或每笔订单的平均金额；用户数在计算收入时应当指实际付费用户数量；复购则反映客户在一段时间内购买的次数或重复购买的行为。作者将这个公式放在互联网语境下，是想说明当互联网降低了用户触达门槛之后，个人就更有机会通过吸引用户、销售合适的产品并获得重复购买来扩大收入规模。由此可见，获取关注并不是商业活动的终点，客户需求、产品匹配、首次成交和后续复购共同决定了经营结果。真正值得关注的是一套能够持续运转的商业系统，而不是偶然获得某一次流量、卖出某一件商品。
更严谨地说，上述公式用于近似理解营业收入，而不能直接等同于净利润。

### 四、视频唯一明确提出的商业计算公式
作者的口语化收入公式
收益=客单价×用户数×复购\text{收益}=\text{客单价}\times\text{用户数}\times\text{复购}收益=客单价×用户数×复购

更适合实际经营核算的表达
营业收入≈平均客单价×付费用户数×人均购买次数\text{营业收入}\approx\text{平均客单价}\times\text{付费用户数}\times\text{人均购买次数}营业收入≈平均客单价×付费用户数×人均购买次数

需要区分各项变量的准确含义：
- 客单价：每笔成交订单的平均金额，实际分析时需要统一统计口径。
- 用户数：计算营业收入时应使用付费用户数，而非所有浏览、关注或注册用户。
- 复购：视频使用的是口语化概念，严格计算时宜使用某个统计周期内的平均购买次数，不能直接用“复购率”替代。
- 净利润：还必须进一步扣除商品成本、渠道费用、运营成本、售后支出等，不能把营业收入全部当作赚到的钱。

举例说明（以下为解释公式而设的假设数据，并非视频提供）：
如果某项业务拥有 1,000 名潜在用户，其中 5% 成为付费用户，平均客单价为 200 元，每个付费用户在统计期内平均购买 2 次，那么：
- 付费用户数：1,000 × 5% = 50 人
- 营业收入：200 × 50 × 2 = 20,000 元
- 如果想进一步扩大收入，理论上可以提高有效付费用户数、客单价或平均购买次数，但每一种方式都需要实际验证其可行性。

理解： 当你不知道该做什么时，不妨把“帮助别人解决问题”作为选择职业、创业项目或学习技能的基本原则。
“我为什么给大家说一定要写点什么，要学新媒体？为什么？因为这两个你几乎不需要任何成本就可以获得大量的用户。”

理解： 在作者看来，写作和新媒体不是可有可无的兴趣技能，而是普通人在互联网时代连接用户的重要能力。
“你的收益等于客单价乘以用户数乘以复购。”

理解： 商业收入可以拆解为可观察、可优化的具体变量。与其笼统地希望赚钱，不如分析自己到底缺少付费用户、合理的定价，还是持续购买的客户。

## 值得记住的点 / 行动建议
以下将作者提出的原则进一步转化为实际做法。其中具体的记录模板、验证步骤和时间安排属于延伸建议，并非视频逐字提出。

### 1. 停止空泛地寻找“人生使命”，先建立需求导向的思考习惯
当一个人不断纠结“我到底喜欢什么”“我这一生应该做什么”“现在还有没有机会”时，很容易陷入长期思考却没有实际行动的状态。作者提供的另一条路径是先不急着确定终身职业，而是主动观察周围的人正在经历哪些问题，以及自己有能力解决哪些问题。
可以尝试每天回答三个问题：今天我发现了谁的什么需求？这个人目前用什么方法解决？有没有可能提供一种更方便、更便宜或更有效的方案？
例如，有人抱怨工作效率低，背后可能有工具、培训或服务需求；有人反复搜索某类知识，背后可能存在信息整理和教学需求；有人愿意为节省时间支付费用，背后则可能有代办或专业服务机会。
行动原则：先找到值得解决的问题，再决定自己应该提供什么。

### 2. 每天拆解一个已经发生的商业交易，训练识别价值的能力
作者反复强调“每天观察”，这可以具体变成一种商业案例研究习惯。每天选择一种自己接触到的商品、服务或内容业务，不只是评价它好不好，而是尝试理解它的完整商业逻辑。
可以使用下面的观察表：

| 观察维度 | 需要回答的问题 |
| --- | --- |
| 目标客户 | 谁在购买？他们有什么共同特点？ |
| 具体需求 | 客户到底想解决什么问题？ |
| 产品价值 | 为什么客户愿意选择这个方案？ |
| 用户来源 | 客户通过哪里知道这个产品？ |
| 交易机制 | 产品通过什么方式收费？ |
| 持续购买 | 客户为什么会再次购买？ |
| 竞争优势 | 相比其他选择，它有什么不同？ |

连续进行一段时间，就可能逐渐发现：许多看似不同的生意，其实都是某些需求与解决方案的重复组合。
需要注意，看到某个商家收入不错并不能直接证明其盈利能力，观察时还应关注成本、竞争和是否具备长期需求。

### 3. 把写作和新媒体当成需要长期积累的基础技能
作者建议“写点什么”“学新媒体”，实际操作中最重要的不是一开始就追求大量粉丝，而是建立稳定表达价值的能力。
可以先选择一个自己比较了解、愿意持续学习的领域，每周发布几篇围绕真实问题展开的内容，例如回答常见疑问、解释复杂概念、分享实际经验、比较不同方案，或者整理能帮助别人节省时间的信息。
在内容方向上，要避免只有自我表达而缺少用户价值。比起单纯记录“我今天做了什么”，更值得思考的是“读者看完能获得什么、解决什么问题、少走什么弯路”。
之后再观察哪些内容吸引了真正有需求的用户，哪些问题被反复提出，哪些反馈表明读者愿意继续了解。最终要积累的不只是曝光量，而是内容能力、用户信任以及对需求的理解。

### 4. 在选择产品之前，先确定要服务的具体人群
视频提出“找到这些用户，了解他们，看看他们需要什么”，其中最值得执行的步骤就是先确定具体客户，而不是一开始就想着卖什么。
例如，“帮助职场人提高效率”是一个相对宽泛的方向；如果进一步缩小到“帮助经常制作汇报材料、又不熟悉自动化工具的职场新人节省时间”，就能够更清楚地判断目标用户的任务、痛点、预算和可能接受的解决方案。
确定人群以后，可以通过访谈、社区讨论、评论反馈、实际使用场景等方式验证需求，重点了解他们现在怎么解决问题，哪些地方最不满意，以及为解决这些问题已经投入了多少时间或金钱。
不要仅凭别人说“这个产品不错”“我可能会买”就认为需求已经得到验证。真正强烈的需求通常会体现为持续寻找解决办法、投入资源或实际支付的行为。

### 5. 用小规模真实交易验证产品，而不是一开始就追求大规模流量
作者强调寻找好产品，然后与用户匹配，但很多人容易忽略交易验证这一步。即使内容获得大量浏览，也不意味着用户愿意购买；即使有人愿意关注，也未必存在足够强烈的付费需求。
因此，更合理的做法是先找到一小批有明确问题的目标用户，提供一个范围清晰、可以交付的方案，验证是否有人愿意为此付款。在条件允许时，可以从一个简单的服务、小型数字产品或已有优质产品的合规推广开始，避免在需求尚未明确时投入过多库存和固定成本。
早期重点记录：客户购买的真正原因是什么、哪些问题阻碍成交、购买后是否满意、是否愿意再次购买或推荐。一次有真实支付和交付反馈的验证，往往比大量没有明确需求的浏览更能说明商业模式是否可行。

### 6. 建立自己的商业数据表，用数据找到收入增长的瓶颈
视频中的“客单价 × 用户数 × 复购”可以成为经营分析的起点，但要真正指导行动，还需要补充获客、转化和成本等指标。
建议每周至少记录以下信息：

| 指标 | 关注意义 |
| --- | --- |
| 有效触达人数 | 有多少真正可能需要产品的人接触到了内容或服务 |
| 付费转化率 | 潜在用户中有多少最终购买 |
| 平均客单价 | 每笔成交平均产生多少营业收入 |
| 平均购买次数 | 客户是否持续产生交易 |
| 获客成本 | 得到一位新客户需要花费多少资源 |
| 单笔贡献利润 | 每笔交易在扣除相关变动成本后贡献多少利润 |
| 客户反馈与退款情况 | 产品是否真正创造价值，是否存在交付问题 |

如果曝光量很多却很少成交，就要优先研究目标人群是否准确、需求是否足够强烈，以及产品介绍是否清楚。如果客户愿意首次购买却不再回来，就要研究产品体验、使用频率和客户满意度，而不是只顾获取更多新用户。
如果营业收入增长很快，但获客成本和交付成本也同步增加，就必须分析增长是否真正带来了利润改善。经营中的每个问题都应该尽可能转化成可以诊断、可以测试的具体变量。

### 7. 学习已有成功模式，但不要把模仿等同于复制表面形式
作者说“你都可以模仿，可以学”，这一点很适合资源有限、经验不足的普通人。与其幻想自己一开始就创造全新行业，不如研究现有市场中哪些模式已经有真实客户和持续交易。
但学习的重点应该是底层逻辑：别人为什么选择这群客户，为什么采用这种定价，为什么通过这个渠道吸引用户，以及为什么客户愿意复购。
真正有效的模仿，是在理解需求和商业原理的基础上，结合自己的技能、资源、地域、服务能力和客户特点重新设计方案。不能因为某个创作者通过新媒体获得收入，就认为照搬其选题、标题或销售方式也能得到同样结果。
要模仿经过验证的价值创造过程，而不是只模仿成功之后看得见的表面动作。
