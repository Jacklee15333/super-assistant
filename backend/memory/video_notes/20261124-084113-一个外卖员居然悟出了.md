## 背景与主题
视频中的外卖员曾经经营过10家店，后来因为负债而开始送外卖，生活经历和社会身份发生了较大的转变。在36天的送餐过程中，他进入了几百个小区，接触了高档小区居民、老旧小区居民以及居住在城中村的年轻人，并从订单金额、备注内容、沟通方式、服务需求等细节中观察不同人群的行为特征。
他逐渐意识到，外卖订单不仅是一笔简单的消费交易，也是一扇观察社会分工、消费需求、人际关系和认知差异的窗口。他试图从这些日常生活现象中寻找普通人可以利用的商业机会，以及实现个人成长和阶层跃迁的可能路径。
视频最后，评论者进一步将人的思维方式概括为“怨气型”和“建设型”两种，认为不同的思维方式会影响一个人获取、积累和支配资源的能力，并将这一观点延伸至家庭、组织乃至国家的发展。

## 核心观点

### 1. 普通的外卖订单，也是一扇观察社会运行规律的窗口
外卖员在36天内进入了几百个小区，接触到了不同经济条件、年龄阶段和生活环境的人群，这种高频、跨群体的接触使他拥有了一个特殊的社会观察视角。通过订单金额、备注内容、配送地址、顾客语气以及收餐时的行为，他甚至认为自己闭着眼睛也能够大致猜出订单背后的主人是什么样的人。
过去经营10家店时，他主要通过经营报表了解市场和消费者，而现在则通过一笔笔具体订单，直接观察真实的人和需求。经营报表能够反映营业额、成本和利润，却未必能够充分解释消费者为什么愿意付钱、为什么产生不满，以及他们真正重视什么。
这段经历说明，信息并不只存在于书籍、研究报告和商业课程中，大量有价值的信息也隐藏在日常交易和人与人的互动之中。 即便是看似重复、缺乏技术含量的工作，只要主动观察、比较和归纳，也可能成为理解社会与商业的一种途径。

### 2. 高档小区顾客购买的不只是商品，更是确定性、省心和服务体验
外卖员发现，部分高档小区的顾客往往会在订单备注中详细说明自己的需求，例如“不要香菜”“微辣”“汤和面分装”“麻烦小哥放门口，轻一点”。这些要求虽然比较细致，但表达清晰、语气温和，能够让配送人员提前知道如何完成服务，减少双方因理解偏差而产生的矛盾。
与此同时，这些小区通常门禁较严，但保安可能会耐心指路，有时还会帮忙按电梯，顾客收餐时也会说“辛苦了”“谢谢”。按照外卖员的观察，这类订单的金额往往达到七八十元，部分订单的配送收益也相对较高。
他由此认为，这些消费者不仅愿意为商品本身付费，还愿意为细节、便利、时间节约和优质服务付费。对普通创业者而言，这意味着商业机会不一定来自生产更便宜的商品，也可能来自帮助顾客解决麻烦、降低沟通成本、减少时间浪费，以及提供更加可靠的服务体验。
价格只是交易的一部分，消费者真正购买的可能是一个问题被妥善解决之后的确定性。

### 3. 良好的行为习惯可能促进财富积累，但不能简单地把财富等同于个人素质
外卖员最初认为，高档小区的部分居民之所以讲究、礼貌，是因为他们拥有较好的经济条件，但后来他改变了自己的看法，提出：“不是因为有钱才讲究，而是讲究的人，都慢慢变得有钱。”这里的“讲究”并不单指衣着、消费档次或者生活排场，而是指注重细节、尊重他人、明确表达需求，以及愿意为他人提供的价值支付合理报酬。
从长期合作的角度看，这类行为习惯确实可能减少交易摩擦，使一个人更容易获得信任、建立合作关系和积累社会资源。一个能够清晰表达要求、尊重合作伙伴并遵守约定的人，往往更容易维持长期、稳定的合作。
不过，视频中的观点来自个人生活观察，而不是经过严格验证的社会调查，不能据此断定礼貌一定会带来财富，或者经济条件较差就意味着认知水平较低。更有价值的理解是：良好的行为习惯是一种可以长期积累的个人资本，但并不是决定财富和社会地位的唯一因素。

### 4. 将交易理解为合作，还是理解为支配，会产生截然不同的长期结果
在部分老旧小区送餐时，外卖员需要面对没有电梯、步行爬六七层楼的情况，而有些顾客的订单备注只有一句“快点，饿死了”。当配送人员打电话沟通时，对方可能会用比较冲的语气催促：“你到哪了？都下单半小时了。”
送达以后，有些顾客只打开一条门缝，伸手接过外卖便直接关门，甚至可能因为汤洒了一点而责骂外卖员、给予差评。按照他的描述，这类订单有时只有十几元，顾客还会花较长时间凑满减优惠。
外卖员认为，两类顾客之间存在一种重要的思维差异：一类人将交易理解为合作共赢，另一类人则认为“我付了钱，我就是大爷”。前者通过清晰沟通和合理付费获得服务，后者更多依靠催促、施压和惩罚机制来表达自己的要求。
长期来看，如果一个人在各种合作关系中习惯于制造冲突、轻视他人，就可能增加自己的沟通成本，降低别人主动与其合作的意愿。当然，消费者对于配送延误、商品破损等实际问题拥有合理投诉的权利，真正需要反思的是不必要的敌意，而不是正常维权行为。

### 5. 城中村年轻人的故事说明，善良、潜力和当前经济状况并不完全相关
除了高档小区和老旧小区，外卖员还经常接到来自城中村出租屋的订单，这些地方可能存在定位不准确、电话打不通、道路难找等配送问题。当他费力找到地址以后，有些合租的年轻人会不好意思地向他道歉，并主动解释定位没有设置好。
虽然这些年轻人的订单金额并不高，居住环境也比较拥挤，但他们有时会递给外卖员一瓶水，说“天气热，辛苦了”，甚至会在订单备注中写下“不用急，注意安全”。这些细节让外卖员想起了自己刚毕业时的经历：同样住在城中村，经济条件有限，却依然对未来充满希望。
他认为，这些年轻人有可能通过未来的努力改善自己的生活条件，搬进更好的小区，并成长为拥有更强消费能力的人。这种预测未必一定实现，但它提醒人们不能仅仅根据一个人当前的收入、住址和职业判断其价值与潜力。
一个人的经济状况描述的是他的部分现实处境，却不能完整定义他的品格、能力和未来。

### 6. 人与人之间的差距，不仅体现在财富上，也体现在认知、习惯和待人接物上
经过36天的外卖配送经历，外卖员总结出了一个他认为比较扎心的真相：人与人之间的差距，不只是钱的差距，更是认知、习惯和待人接物方式的差距。他用三类顾客的行为进行了形象的对比：“高档小区的人，用备注教我怎么送；老旧小区的人，用差评教我怎么哄；城中村的年轻人，用一瓶水提醒我，善良跟钱没关系。”
这里所说的认知差距，具体体现在一个人如何理解交易、如何处理问题、如何对待陌生人，以及是否能够站在他人的角度思考问题。面对同一项服务，有些人选择提前明确要求、主动减少沟通障碍，有些人则习惯在问题发生后通过情绪和指责表达不满。
这些看似微小的差别，如果不断重复出现在工作、经营、人际交往和社会合作中，就可能逐渐产生不同的结果。人与人的差距未必在某一次重大选择中突然形成，也可能是在无数次日常决策和行为习惯中慢慢积累、不断放大的。

### 7. 高消费群体的商业机会，在于帮助他们节省时间、精力和解决麻烦
外卖员开始从消费者的行为中思考普通人的赚钱机会，他认为，高档小区部分居民的核心需求可以概括为两个字：省心。这些消费者有一定的支付能力，不一定追求最低价格，但希望自己付钱之后，事情能够被专业、可靠、高效地解决。
因此，普通人如果能够帮助他们处理不愿意做、没有时间做或者不擅长做的事情，就有可能获得相应的报酬。例如，品质家政、上门维修、宠物照顾、家庭收纳、代办跑腿、汽车养护等，都符合以服务换取客户时间和精力的商业逻辑。
这些业务的竞争力不一定来自低价，而可能来自准时履约、服务标准、专业程度、沟通效率和长期信任。一旦客户认可服务人员的可靠性，就有可能产生复购、转介绍以及其他衍生服务需求，这也是服务型生意积累长期客户资产的重要途径。

### 8. 普通居民的刚性需求，同样蕴藏着门槛较低、持续稳定的生意机会
外卖员没有认为所有商业机会都存在于高档小区，而是注意到老旧小区同样存在大量日常生活中离不开的服务需求。他提到了修车、换锁、管道疏通等基础维修服务（部分项目名称根据语音识别上下文整理），这些事情虽然看起来不起眼，但具有一定的刚需属性。
对于经济条件有限的消费者而言，他们可能对价格更加敏感，却仍然需要解决车辆故障、水管堵塞、门锁损坏等实际问题。这类需求通常不依赖消费潮流，也不需要通过复杂的营销教育消费者，因为问题出现以后，居民自然会寻找能够解决问题的人。
相较于追逐热门行业和高风险创业项目，部分基础生活服务具有投入可控、需求明确、服务半径较小等特点，值得普通人研究。不过，门槛较低并不代表没有竞争，真正能够建立稳定收入的经营者，仍然需要技术能力、合理定价、良好口碑和持续获客能力。

### 9. 不要只关注一个人现在拥有多少资源，也要关注他的成长潜力
外卖员认为，城中村里那些虽然经济条件一般，但有礼貌、有责任感、对未来充满希望的年轻人，可能是未来高档小区的住户。他提出，如果现在能够帮助这些人，将来他们发展起来以后，也有可能带着自己一起向上走。
这一想法体现的是一种长期视角：人际关系的价值并不完全由对方当前的收入、身份和资源决定，还可能来自对方未来的发展以及双方长期积累的信任。一个只愿意与已经成功的人交往的人，往往容易陷入短期利益交换，而忽视尚处于成长阶段的人。
当然，帮助别人并不意味着对方未来一定会成功，也不意味着对方必须给予回报。更健康的做法是，在力所能及的范围内与有责任感、愿意成长、相互尊重的人建立长期关系，而不是把善意变成一种等待兑现的投资。

### 10. “怨气型思维”与“建设型思维”，决定了人如何面对问题和使用资源
视频最后，评论者将人的思维方式概括为两种：一种是“怨气型”，另一种是“建设型”，认为二者不仅做事方式不同，能够获取和支配的资源也可能存在差别。怨气型思维倾向于抱怨、指责、宣泄情绪和寻找责任人，而建设型思维则更加关注如何解决问题、改善现状、创造价值以及推动合作。
例如，在配送过程中，顾客可以通过提前填写清晰备注来减少问题，也可以在问题发生之后单纯通过责骂表达不满，这两种做法所产生的实际效果可能完全不同。建设型思维并不意味着不能表达不满，而是强调表达不满之后，还需要找到切实可行的解决办法。
评论者进一步将这一观点延伸至家庭、国家和王朝，认为新中国由一批建设型的人创立，并提出一些王朝的衰败与怨气型的人占据重要位置有关。这种历史类比属于评论者的个人解释，不能替代对复杂历史因素的分析，但其值得借鉴的部分在于：无论个人还是组织，都需要将有限的时间、精力和资源投入能够改善现实的行动之中。

意义：普通工作并不意味着只能获得普通的信息，关键在于是否具备观察、思考和总结规律的能力。

意义：强调行为习惯、细节意识和合作能力对于长期财富积累的潜在价值，但不宜将其理解为绝对的财富规律。
“人和人之间的差距，不只是钱的差距，更是认知的差距、习惯的差距和待人接物的差距。”

意义：真正理解商业，不仅需要掌握经营数据，还需要深入真实交易场景，理解消费者的具体需求。创业经历和经营规模并不意味着一个人已经完全理解了市场。
“人只有两种，一种是怨气型的，还有一种是建设型的。这两种人，做事的思维方式完全不同。”

意义：与其将精力耗费在抱怨和情绪对抗上，不如更多地关注问题能否解决、价值能否创造以及现状能否改善。

## 值得记住的点 / 行动建议
以下是在视频观点基础上进一步提炼的可执行方法，其中具体操作方案属于延伸建议，并非全部来自作者原话。

### 1. 把自己的工作当作一个长期的社会观察实验
不必因为目前从事的工作收入不高、社会地位一般或者内容比较重复，就认为自己无法获得有价值的知识。
外卖员能够在36天内接触几百个小区，这是很多办公室工作人员、创业者甚至市场研究人员都不一定拥有的接触频率。任何一个能够频繁接触客户、商品、交易和真实生活场景的岗位，都可能提供独特的市场信息。
平时工作时，可以主动观察以下问题：客户最常抱怨什么？他们愿意为什么额外付费？哪些麻烦反复出现？现有服务有哪些不足？不同消费者的需求有什么区别？哪些问题是自己有能力解决的？
如果能够每天记录几个真实案例，每周进行一次归纳，就有机会逐渐形成属于自己的市场认知，而不是仅仅机械地完成工作任务。

### 2. 建立一份属于自己的商业需求观察表
不要只是模糊地感觉某个行业有机会，而应该将观察到的需求进行记录和分类。
可以使用如下表格：

| 观察项目 | 需要记录的内容 |
| --- | --- |
| 客户群体 | 谁存在这个问题 |
| 具体需求 | 客户究竟想解决什么 |
| 痛点程度 | 不解决会造成多大的麻烦 |
| 需求频率 | 每天、每周、每月还是偶尔出现 |
| 支付意愿 | 客户是否愿意付钱解决 |
| 现有方案 | 市场上目前如何解决 |
| 服务缺陷 | 现有方案有什么不足 |
| 自身能力 | 自己是否能够解决 |
| 获客成本 | 如何找到这类客户 |
| 复购可能 | 客户是否会持续购买 |

例如，发现某个小区经常有老年居民需要维修家电，某个年轻人聚集的社区经常存在搬家、清洁需求，或者高档小区部分居民经常需要宠物照顾，都可以进一步研究。
需要记录的是匿名化的需求规律，而不是擅自保存、利用客户的姓名、电话、具体地址等个人信息。
先发现需求，再验证需求，最后才考虑投入资金和开展生意。

### 3. 赚钱的第一步，是理解别人为什么愿意付钱
很多人考虑创业时，首先想到的是自己能够卖什么、做什么产品，以及如何赚到更多的钱。但从消费者角度出发，应该优先思考的是：客户为什么愿意把钱交给你？
一般来说，消费者愿意付费可能来自以下几种价值。

| 付费动机 | 客户购买的价值 |
| --- | --- |
| 节省时间 | 不必亲自处理繁琐事务 |
| 节省精力 | 不需要反复沟通和操心 |
| 解决问题 | 消除现实生活中的困难 |
| 降低风险 | 获得更加可靠的服务结果 |
| 改善体验 | 获得更舒适、方便的生活 |
| 获得专业能力 | 完成自己不擅长的事情 |
| 降低成本 | 用更合理的价格满足需求 |

如果自己提供的商品或服务，不能明确对应客户的某项需求，那么即使投入大量时间学习营销和推广，也未必能够形成稳定生意。
商业的起点不是自己想赚多少钱，而是自己能够为别人创造什么价值，以及别人是否认可并愿意为这种价值付费。

### 4. 根据不同消费者的需求，设计不同的服务策略
并非所有消费者都在追求低价，也并非所有消费者都愿意为品质支付高额溢价。不同收入水平、生活阶段、职业特点和家庭结构的人，对同一种服务的评价标准可能完全不同。
例如，同样是上门维修服务，一部分客户可能首先关心维修价格，另一部分客户可能更加重视能否准时到达、一次解决问题以及维修之后是否有售后保障。
针对不同需求，可以设计不同的服务层次：

| 服务定位 | 经营重点 | 主要竞争力 |
| --- | --- | --- |
| 基础服务 | 满足必要需求 | 价格透明、实用 |
| 标准服务 | 兼顾效率与质量 | 性价比、稳定性 |
| 品质服务 | 降低客户时间与精力成本 | 专业、省心、可靠 |
| 长期服务 | 持续满足重复性需求 | 信任、复购、口碑 |

这也是市场细分的基本思路：不必试图满足所有消费者，而是选择一个自己有能力服务的人群，并围绕其核心需求建立优势。

### 5. 普通人创业，可以优先关注不起眼但长期存在的刚需
一些人在寻找创业项目时，容易关注所谓的风口、高利润项目或者短期暴富机会，却忽视了自己周围那些长期存在的真实需求。
视频中提到的修车、换锁、管道疏通等业务，就是典型的基础生活服务。它们可能没有特别吸引人的商业故事，却能够直接解决居民的实际困难。
判断一个小生意是否值得尝试，可以重点考察五个条件：需求是否真实存在、客户是否愿意付费、启动成本是否可控、服务能否形成口碑、自己是否具备相应的技能和资质。
对资金有限或者已经负债的人来说，更应重视风险控制，可以先从掌握技能、小规模接单和验证真实需求开始，而不是再次依靠大规模投资和借贷扩大经营。

### 6. 训练自己从抱怨问题转向解决问题
建设型思维不是要求自己永远保持乐观，更不是遇到不公平待遇时只能忍耐，而是尽量避免让情绪成为处理问题的唯一方式。
怨气型表达

建设型表达

客户总是很难伺候。

客户最常提出哪些要求？能否提前沟通、明确服务标准？

现在赚钱越来越难了。

哪些需求仍然存在？我能提供什么有竞争力的服务？

为什么别人比我有钱？

别人有哪些值得学习的能力、习惯和资源积累方式？

这个工作没有任何前途。

它能否帮助我积累技能、客户认知或行业经验？

我创业失败了，什么都没有了。

失败的具体原因是什么？还有哪些经验和能力能够继续使用？

别人做错了，我必须让他难受。

怎样明确责任、维护权益，并推动问题得到解决？

每当自己产生强烈抱怨情绪时，可以进一步追问：到底发生了什么？哪些因素是我能够控制的？我现在可以做什么来改善结果？
这种思维训练的核心，是将注意力从单纯评价现实，逐渐转向改变现实。

### 7. 将尊重他人视为一种长期的合作能力
对外卖员、保洁人员、维修工、服务员等普通劳动者保持基本礼貌，并不仅仅是道德层面的要求，也是一个人处理社会合作关系的能力体现。
在现实社会中，几乎没有人可以完全独立地完成所有事情，每个人都需要依靠他人提供商品、服务、信息、知识和专业技能。
因此，清晰表达要求、尊重对方的劳动、遵守约定、合理支付报酬、及时给予反馈，都是降低社会合作成本的有效方式。
在工作和创业中，能够长期获得他人信任的人，往往更有机会形成稳定的客户关系、供应商关系和合作伙伴关系。不要因为自己在某一笔交易中处于付款方或者拥有更大的权力，就认为可以随意轻视另一方。

### 8. 不要用一个人当前的财富和职业判断他的未来
视频中居住在城中村的年轻人，是非常值得关注的一类案例。他们暂时没有很高的收入和优越的居住条件，却可能具备责任感、学习能力、成长意愿和良好的合作习惯。
判断一个人是否值得长期交往，可以更多关注他是否诚实守信、是否具有行动力、是否愿意承担责任、是否尊重他人，以及遇到困难时能否持续学习和调整。
这些特征不能保证一个人未来一定会取得经济上的成功，但有助于判断双方是否能够建立健康、稳定、相互支持的关系。
同时，对别人保持善意不需要附带对未来回报的期待。即使对方最终没有成为富裕人士，双方之间的尊重和互助也仍然具有价值。

### 9. 创业者不能只看报表，还要重新回到真实的消费场景
视频中最值得创业者反思的细节之一，是这位外卖员曾经开过10家店，却在亲自配送外卖之后产生了自己才刚刚入行的感受。
经营者在企业发展过程中，很容易逐渐将注意力集中在营业额、利润、人员管理、经营报表和扩张速度上，而忽略了一线消费者的真实体验。
经营数据能够告诉创业者发生了什么，但客户反馈、现场观察和直接交流往往能够帮助解释为什么会发生这些事情。
因此，无论公司规模多大，经营者都应该保持一定频率的一线接触，例如亲自体验自家产品、了解售后投诉、观察客户购买过程、研究消费者为什么放弃购买，以及询问一线员工最常遇到的问题。
真正有价值的商业认知，应当来自经营数据与真实市场观察的相互验证。

### 10. 用长期积累代替短期暴富思维
这位外卖员虽然已经观察到了不同消费群体的需求差异，但他也承认，目前还没有能力充分利用这些信息，也没有完全想清楚普通人可以从中获得哪些具体机会。
这种承认本身具有现实意义：发现规律不等于已经拥有赚钱能力，理解消费者不等于已经建立商业模式，看到市场机会更不等于一定能够成功创业。
从认知到商业结果，中间还需要经历技能学习、需求验证、服务设计、成本核算、客户获取和实际交付等过程。
可以将这一过程概括为：
1

接触真实市场
深入生活与工作场景，观察真实交易

2

识别重复需求
找到不断出现、尚未被充分满足的问题

3

验证支付意愿
确认客户是否真的愿意付费

4

建立解决能力
学习技能，设计可交付的服务

5

低成本尝试
小规模接单，检验收入与成本

6

积累信任与口碑
通过稳定交付获得复购与转介绍

7

形成持续收入
在需求和盈利得到验证后逐步扩大经营

与其急于将每一个发现变现，不如先不断提高自己识别需求和解决问题的能力，让认知优势逐渐转化为实际的价值创造能力。

## 我的点评
这段视频最有价值的地方，在于一位经历过创业和负债的普通劳动者，没有将送外卖仅仅视为维持生计的手段，而是将它变成了重新理解消费者、市场需求和社会合作的机会。其关于尊重他人、建设性思维、为客户解决问题以及关注刚性需求的观点，具有较强的现实参考价值，尤其适合正在寻找发展方向、准备创业或者处于人生低谷的人。
但视频也存在比较明显的样本偏差和因果关系简化问题，36天的配送经历不足以证明高收入人群普遍更加礼貌，也不能证明经济条件较差的人主要是因为行为习惯或者认知不足才陷入困境。财富积累和社会流动还受到家庭背景、教育资源、行业机会、健康状况、社会制度和运气等多种因素影响，不能将复杂的社会问题完全归结为个人素质，更不能把合理维权和表达不满一概视为怨气型思维。
普通人真正应该借鉴的，不是根据小区档次给人贴标签，而是培养观察真实需求、主动解决问题、尊重合作伙伴和持续创造价值的能力。无法立即改变自己的经济处境时，仍然可以积累知识、技能、信用和解决问题的能力，这些都是未来获得更多发展机会的重要基础。

## 📝 完整文字稿

一个外卖员居然悟出了，这个世界是如何运转的，还很有道理，36天我进了几百个小区。我发现了一件事，就是每个订单，其实都在告诉你，这个世界是怎么运转的，我现在我闭上眼睛。我都能够猜得出，订单背后的主人，大概是个什么样子的人，那有的订单，背中写得特别细。不要香菜，微辣，汤和面粉装，麻烦小哥放门口，轻一点，我送到的时候，小区门禁演，保安还会耐心地指路。有的还帮忙按电梯，开门的人，语气也温和，辛苦了，谢谢，我看到一眼，这个订单的金额，七八十块起步。

喷收位也比别的地方高，我刚开始以为，是有钱，所以数字高，后来我才想明白，不是因为有钱才讲究。而是讲究的人，都慢慢变得有钱，他们都愿意为细节买单，愿意为服务付费，那有的订单，来自老旧的小区。没有电梯，六楼七楼那都是常态，废柱上就一句话，快点，饿死了，我打电话过去了，对方的语气还特别冲。你到哪了，都下单半小时了，我送上楼了，门就开了一条缝，手伸出来接过餐，就啪的一声，门就关上了。有时候还会因为汤傻一点，就被骂一顿，然后还给个差评，那订单的金额，十几块钱，臭蛮奖还臭老半天。

我开始想，为什么差别这么大，后来我发现了规律，背书系态度好的人，他们越住越好，那些催命。说话难听的人，很多年还是住在，那种老旧的小区，这不是玄学，是思维习惯，前者懂合作共赢。后者就觉得我付了钱，我就是大爷，还有一种订单，来自城中村的出租屋，那定位也经常不是很准。电话也经常打不通，好容易找到开门的是，几个合租的年轻人，房间是唉唉唧唧的，他们会不好意思地说。抱歉哥，定位没弄，有时候还会塞给我一瓶水，说天气热辛苦了，订单的金额也不是很高，但是他们会在背书里写着。

不用急注意安全，这些人就让我想起了，毕业时候的自己，我也是住在城中村，但眼里有光。我觉得这种人，迟早就会搬走，搬到更贵的小区，点更贵的餐，写更细的背书，跑外卖的这段时间。我进了几百个小区，我发现了一个扎心的真相，那人和人之间的差距，不只是钱的差距，更是认知的差距。习惯的差距，和待人接物的差距，你看，这个高档小区的人，用背注教我怎么送，那老旧小区的人。用差评教我怎么哄，那城中村的年轻人，用一瓶水提醒我，善良跟钱没关系，以前开十家店的时候。

我看报表，我觉得自己很懂事情，签债出来送外卖，看订单，我才觉得自己刚入行，其实这些订单的背后。到底承担着什么，普通人能用的机会呢，我现在还没有完全想。但我看懂了一些规律，高档小区的人就是买省薪，你帮他们把麻烦事办了，他们就愿意为你分一杯羹。那老旧小区的人，就需要一些离不开的小事，修车换手书通，门槛虽然不高，但是天天有人找。那城中村的一些年轻人，就是未来高档小区的住户，你现在帮他们一把，以后啊，他们有可能带着你一起往上走。我现在呢，还没能力用这些细节，但我在看，一天天的看，新的订单来了，你们自己慢慢从，小伙子发现了这点很关键。

在我看来，人只有两种，一种是怨气型的，还有一种是建设型的，这两种人，做事的思维方式完全不同。他们所能拥有的，和支配的资源也是不同的，一个人是这样，那一个家庭，甚至是一个国家。一个王朝也是这样的，就比如咱们的新中国，就是一批建设型的人创立的，还有很多王朝。卧室王朝，好多都是因为怨气型的人，占了主要位置，最后把一个王朝给拖垮了，你仔细品品。是不是这味。
