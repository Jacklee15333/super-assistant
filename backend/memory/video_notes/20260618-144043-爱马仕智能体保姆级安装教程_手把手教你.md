## 一句话概括

这期视频是一份 **Hermes（爱马仕）智能体的保姆级安装教程**：作者手把手教普通用户如何在本地安装 Hermes，并通过“完全设置”对接国产大模型 **DeepSeek**，让它成为可学习、可扩展、能安装 Skill 的个人 AI 助手。

## 背景与主题

作者介绍的是一个名为 **Hermes / 爱马仕智能体** 的 AI 个人助手工具，但特别提醒它不是奢侈品品牌 Hermès 的官网，而是 AI 智能体项目官网。作者称，在过去几个月里，爱马仕智能体在国内外受到广泛讨论，讨论热度和安装量一度“甚至超过小龙虾”。这期视频的重点不是讲复杂原理，而是帮助普通用户完成从下载安装到对接 DeepSeek 大模型的完整流程。作者站在“降低普通人使用 Agent 门槛”的角度，强调即使没有外币信用卡，也可以通过完全设置和 DeepSeek API 把 Hermes 跑起来。

## 核心观点

### 1. Hermes 的定位是 AI 个人助手，不只是一个普通聊天机器人

作者首先把 Hermes 定位为 **AI 个人助手**，它的作用不只是像聊天机器人一样回答问题，而是帮助用户处理日常任务。视频里提到，Hermes 不仅能执行任务，还能在每次对话中学习、总结，从而在后续任务中做得更好。作者把这种能力称为“自我净化”，意思是它会通过一轮轮交互逐渐形成对用户习惯、偏好和任务模式的理解。相比一次性问答工具，Hermes 更像一个可以长期训练和沉淀的助手。这个定位决定了它的价值不只是“能不能回答”，而是“能不能越来越懂你、越来越适合你的工作方式”。

### 2. 安装 Hermes 的第一步，是去官网复制对应系统的安装命令

视频从最基础的安装入口讲起：打开 **Hermes 智能体官网**，根据自己的操作系统选择对应安装命令。作者特别强调，不是打开奢侈品爱马仕官网，而是打开爱马仕智能体官网。如果用户使用的是 **macOS 或 Linux**，就直接复制官网提供的命令；如果是 **Windows**，则需要点击 Windows 按钮，再复制对应的 Windows 命令。复制命令后，要在本机打开命令行工具：Mac 用户在“访达—应用程序—实用工具”里找到“终端”，Windows 用户在开始菜单搜索 **PowerShell**。把命令粘贴进去并回车后，程序会自动检查环境并安装 Hermes。

### 3. 安装后会进入设置环节，分为“快速设置”和“完全设置”

作者说，命令运行后大概 **一分钟左右**，Hermes 会进入设置流程，并给出两个选项：**快速设置**和**完全设置**。这两种方式本身都不需要用户付费，但使用门槛不同。快速设置会让浏览器自动跳转到 Hermes 官网，让用户选择订阅套餐；即使选择免费的基础套餐，也可以使用不少免费智能体能力。问题在于，快速设置无法避免绑定信用卡，因此对没有外币信用卡的国内用户不太友好。作者因此建议，如果没有条件绑定信用卡，或者不想走官方订阅流程，就选择第二种方式：**完全设置**。

### 4. “完全设置”的关键，是手动选择 AI 模型供应商 Provider

选择完全设置后，Hermes 会让用户选择 **Provider**，也就是 AI 模型供应商。作者解释说，可以把 Provider 理解为 Hermes 背后调用的大模型服务。Hermes 本身是智能体框架，但真正负责理解、推理和生成内容的是大模型，所以这一步非常关键。视频中作者选择的是 **DeepSeek**，也就是国产大模型服务。这个选择的核心原因是：对普通人来说，DeepSeek 的性价比很高，配置门槛也相对低，适合日常任务使用。也就是说，作者希望用户先用低成本、可落地的方式把智能体跑起来，而不是一开始就卡在海外订阅和支付环节。

### 5. 配置 DeepSeek 的核心步骤是创建并保存 API Key

进入 DeepSeek 配置阶段后，用户需要先访问 **DeepSeek 官网**并登录账号。登录成功后，点击左侧导航栏里的 **API Key**，再点击“创建 API Key”。创建时可以随便起一个名称，系统随后会生成一个专属密钥。作者特别提醒，这个 Key 生成后要立刻复制，并保存到一个安全的地方，因为一旦关闭窗口，就无法再次查看完整 Key。API Key 本质上就是模型调用凭证，Hermes 后续要通过它调用 DeepSeek 模型，所以既不能丢，也不能随便泄露。复制好 Key 后，将其粘贴回刚才 Hermes 的命令行配置窗口，并回车继续。

### 6. DeepSeek URL 可以默认，模型推荐 DeepSeek V4 Flash

填入 DeepSeek API Key 后，下一步会要求填写 URL。作者说，这里可以直接默认回车，不需要普通用户额外修改。之后系统会让用户从 DeepSeek 的不同模型中选择一个，作者个人推荐使用 **DeepSeek V4 Flash**。推荐理由很明确：它是作者认为性价比最高的模型，并且处理日常任务“绰绰有余”。这说明作者并不主张新手一开始就追求最强、最贵的模型，而是先选择够用、便宜、稳定的模型来跑通 Hermes。对于普通人的写作、总结、规划、简单资料处理等任务来说，V4 Flash 已经能够覆盖很多场景。

### 7. Hermes 默认运行在本地，也支持部署到远程服务器

配置完模型后，Hermes 会询问智能体运行在哪里。作者建议普通用户保持默认，也就是运行在 **本地电脑** 上。这样最简单，不需要服务器，也不需要额外部署环境，适合大多数个人用户。如果用户有远程服务器，也可以选择把 Hermes 部署到服务端。这个选项说明 Hermes 既可以作为个人本地助手使用，也可以被高级用户部署成更长期、更稳定的远程服务。不过视频面向新手，因此作者建议先不要折腾复杂部署，默认本地即可。

### 8. 聊天软件对接、浏览器操作等 Skill 可以先跳过

在后续配置中，Hermes 会询问用户是否要对接一些聊天软件，以及是否要适配某些 Skill，比如操作浏览器之类的能力。作者建议这些都可以先跳过，一直跳到最后完成安装。这个建议很重要，因为新手安装工具最容易在过多可选项里迷失，导致不知道哪里配置错了。先把最基础的 Hermes + DeepSeek 跑通，才是第一目标。等安装成功、聊天框能正常打开后，再根据真实需求慢慢安装 Skill，会更稳妥。作者的思路是先完成最小可用闭环，再逐步扩展能力。

### 9. 安装完成后，输入 `Hermes` 就可以启动智能体聊天框

安装结束后，程序会退出命令行安装流程。此时用户只需要在命令行里输入 **`Hermes`**，就能打开和爱马仕智能体的聊天框。作者说，这时你的个人专属爱马仕助手就已经“随时待命”了。用户可以直接让它完成任务，也可以让它自己去安装一些 Skill。更进一步，用户还可以给它描述一个需求，让它学习并总结成专属于你的技能。这样一来，Hermes 不只是安装完就固定不变，而是可以随着使用不断成长。

### 10. Hermes 的长期价值在于通过对话和 Skill 变得越来越懂你

视频最后，作者强调，Hermes 可以在一轮轮对话中越来越理解用户。比如你经常让它写文章，它会逐渐掌握你的写作风格；你经常让它处理某类任务，它可以总结出固定流程；你让它安装 Skill，它就能扩展新的能力。作者认为，随着互动次数增加，Hermes 写出的文章、做出的成果会越来越让用户满意。这个观点背后的逻辑是，智能体真正有价值的地方，不只是接入某个模型，而是能把模型能力、用户习惯、Skill 工具和任务经验结合起来。对于普通人来说，这意味着你不是在使用一个冷冰冰的工具，而是在逐步搭建自己的 AI 工作助手。

## 值得记住的点 / 行动建议

### 1. 先把 Hermes 理解为“可成长的个人助手”，而不是一次性聊天工具

安装 Hermes 前，最好先理解它的定位。它不是单纯的问答机器人，而是可以通过对话、Skill 和任务经验不断成长的智能体。普通聊天机器人回答完一次问题就结束，而 Hermes 的目标是通过多轮互动越来越理解你的偏好。你可以让它处理日常任务，也可以让它学习你的需求，并把这些需求总结成专属技能。这个理解很重要，因为只有把它当成长期助手来使用，才能发挥它“越用越懂你”的价值。

### 2. 安装时一定要选择与自己系统匹配的命令

安装 Hermes 的第一步，是在官网选择正确的操作系统命令。Mac 和 Linux 使用同一类命令，Windows 使用专门的 Windows 命令。不要混用命令，否则容易在终端或 PowerShell 里报错。Mac 用户打开终端，Windows 用户打开 PowerShell，然后粘贴对应命令回车即可。对新手来说，这一步看似简单，但它决定了安装能不能顺利开始。

### 3. 没有外币信用卡，就优先走“完全设置”

视频里作者明确建议，没有条件绑定信用卡的用户选择 **完全设置**。快速设置虽然也可以使用免费基础套餐，但会要求绑定信用卡，这对很多国内用户不方便。完全设置虽然多了模型供应商配置步骤，但可以直接接入 DeepSeek，更适合普通用户。这个建议的核心是降低门槛：先不用依赖海外订阅体系，把本地智能体和国产模型跑起来。只要能顺利启动，后续再慢慢研究更多官方 Skill 和高级功能。

### 4. DeepSeek API Key 要像密码一样保存

创建 DeepSeek API Key 后，一定要马上复制并保存到安全位置。作者特别强调，一旦关闭生成窗口，就无法再次查看完整 Key。API Key 是 Hermes 调用 DeepSeek 模型的凭证，如果丢了就需要重新创建，如果泄露则可能被别人盗用额度。普通用户可以把它保存在密码管理器、加密笔记或其他安全位置。不要把 Key 发到群里、评论区、公开文档或截图里。

### 5. 新手优先选择 DeepSeek V4 Flash，先跑通再升级

作者推荐 DeepSeek V4 Flash，因为它性价比高，处理日常任务已经足够。新手刚开始使用 Hermes，不必追求最强模型，而应该先追求稳定、便宜、可用。很多日常任务，比如写作、总结、简单规划、资料整理，并不一定需要最昂贵的大模型。先用 V4 Flash 跑通安装和基础对话，再根据后续任务复杂度决定是否换更强模型。这样既节省成本，也能降低配置压力。

### 6. 第一次安装时，额外 Skill 和聊天软件对接可以先跳过

安装过程中出现的高级选项，比如对接聊天软件、操作浏览器、适配某些 Skill，新手可以先跳过。第一次安装的目标不是一步到位，而是先让 Hermes 成功启动、模型成功接通、聊天框可以正常使用。如果一开始配置太多功能，出错时很难定位问题。等基础功能跑通后，再根据自己的真实需求逐步添加 Skill，会更稳妥。这个思路适合所有 Agent 工具：先建立最小可用版本，再逐步扩展能力。

### 7. 安装完成后，用 `Hermes` 命令启动并做基础测试

安装流程结束后，在命令行输入 **`Hermes`** 就可以打开聊天框。第一次启动后，不要马上让它做复杂任务，可以先做几个基础测试。比如让它简单自我介绍、总结一段文字、生成一个待办清单，确认模型是否正常响应。这样可以快速判断 DeepSeek API 是否配置成功、Hermes 是否能正常运行。如果基础测试没问题，再进入安装 Skill、处理文件、执行任务等更复杂阶段。

### 8. 让 Hermes 根据你的真实需求安装 Skill

作者提到，用户可以让 Hermes 自己去安装一些 Skill。Skill 可以理解为智能体的能力模块或操作手册，决定它会不会做某类任务。不要为了追求功能多而盲目安装，而应该从自己的真实需求出发：如果你经常写文章，就让它学习你的文章结构和语气；如果你经常整理资料，就让它学习你的资料归纳格式；如果你想自动处理某类工作，就让它总结成固定流程。这样 Hermes 才会从通用助手变成“你的专属助手”。

### 9. 用多轮对话训练它，而不是期待一次配置就完美

视频里反复强调，Hermes 会在一轮轮对话中学习总结。普通用户不要期待安装完成后它立刻完全懂你，而应该通过持续使用来训练它。每次它输出结果后，你可以告诉它哪里好、哪里不好、下次应该怎么改。它可以把这些反馈总结成偏好或技能，后续任务就会更贴合你的要求。长期来看，使用 Hermes 的关键不是“一次设置”，而是“持续反馈”。

### 10. 注意本地智能体的权限和安全边界

虽然视频主要讲安装和使用便利性，但普通用户还需要注意安全。Hermes 作为本地智能体，未来可能会读取文件、调用模型、安装 Skill，甚至执行某些本地操作。使用时要注意不要随便让它接触敏感文件，不要安装来源不明的 Skill，也不要泄露 API Key。尤其在让智能体执行命令、操作浏览器或对接聊天软件前，要确认自己理解它会做什么。AI 助手越强，越需要明确权限边界。
