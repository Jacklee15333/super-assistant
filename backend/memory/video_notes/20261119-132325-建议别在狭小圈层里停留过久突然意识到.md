# 建议别在狭小圈层里停留过久
突然意识到，当一个人长期禁锢在单一的小环境之中，认知很容易被周遭的氛围悄悄驯化。
这里说的小环境，不一定是物理空间。
它可以是固化的职场圈子、同质化的社交圈层，也可以是反复循环的信息茧房。身边所有人想法高度趋同，大家共享同一套评判标准，是非对错都被限定在狭小的框架内。久而久之，你会误以为眼前所见，就是世界的全部模样。
你慢慢接受这里的价值观，把局部的规则当成普世真理。别人的焦虑会变成你的焦虑，他人的局限会变成你的局限。你甚至察觉不到自己正在被同化，以为自己的思考，全部都源于自我。
西蒙娜·德·波伏瓦《第二性》里写道："人的想法，深受所处集体的浸染，若缺少向外眺望的机会，便会把集体的偏见当作世间的公理。"
长期待在同质圈层，最可怕的不是资源有限，而是潜移默化的思想禁锢。你的参照系只有身边几个人，眼界被压缩，想象力也会随之收窄。#学习提升自我认知能力 #个人学习成长分享 #干货分享 #信息差 #普通人逆袭
