# 给谁提供什么价值 你以为做自媒体是做内容，其实是占位置。 
先说最要命的：想清楚给谁、提供什么价值。你给别人的价值，必须大于他付的钱。大于才长久，不大于就是一锤子买卖。很多人一上来就想怎么变现，顺序反了——先问给谁提供什么价值，变现是结果。 
第二件，传递。价值有六种：你懂我（同理心）、拿过来就能用（干货）、让我看见更大的世界（认知增量）、让我笑（情绪）、关注你让我觉得我是这样的人（身份）、值得转给朋友（关系）。不用全占，两三种就够。我只占三种：干货、认知增量、身份。 
第三件，分发。别先选平台，先问你的用户在哪儿、有多少。找女朋友去图书馆比去足球场概率高。你在哪儿人多就去哪儿。 
第四步最多人做错：位置。 
你去菜市场，所有人都在卖韭菜，你也卖，合适吗？更高明的做法：这个菜市场里你独一家；做不到，就做到一想到买这个就想到你。 
我刚来的时候，知识博主几乎都在卖课——99、199、1990元。我不卖课，也不做陪跑；我收钱的地方只有两处：社群和专栏、书。我给普通人讲真正有用的知识，免费。当免费的知识比收费的还有用，人们对我的认知就定在那儿了——位置是我的。后面有人跟进也没用，我是第一个。 
我不告诉你们社群在哪。不是藏着，是筛选：连找都不愿意找的人，进来也做不成。我给你留了后路——一年之内，没交税之前，随时退。 
很多人研究算法，找流量密码。密码是暂时的，年年换一茬网红。我研究不变的东西：这个菜市场里，谁站在哪个位置。 
买单只有两个条件：你对我有价值，我信任你。价值有了、信任不够，我不会掏钱。信任不是靠说服，是靠一条一条视频往上加：人品加1，信任加1，加到100分，你有产品我自然就买了。我几乎不做宣传，专栏和书卖得还行，原因就在这。 
最后是变现。我不卖东西，只做自己的事：开过公司、做过产品、做过营销、做过投资——我讲的就是这些事怎么做。大家问得多了，我就做成一款产品：我本来就在做，成本几乎为零。 
今晚做一件：写下三句话——我帮谁、解决他哪个问题、他为什么信我。写不出来，先别拍。
