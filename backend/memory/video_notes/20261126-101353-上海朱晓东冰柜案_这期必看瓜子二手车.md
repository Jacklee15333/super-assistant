## 核心观点

### 1. 受害者拥有稳定的工作和良好的家庭环境，却在婚恋关系中逐渐失去了原有的生活秩序
杨俪萍1987年出生于上海，是家中的独生女，毕业于上海师范大学中文系，后来进入一所重点学校的附属小学，担任语文老师兼班主任。她性格安静、善良，大学宿舍里飞进虫子，她会将虫子捉住放到窗外；小区里有一条腿被人打断的流浪狗，她长期拿肉喂养，直到这条狗每天接送她上下班，甚至认得她的汽车。她工作认真负责，名为《尊严》的公开课还成为学校的教学范本，说明她原本拥有稳定的职业发展、社会关系和独立生活能力。
相比之下，朱晓东10岁时父母离婚，跟随母亲居住在虹口区一套30多平方米的老房子里，读过职校，后来在外资百货商场做陈列员，月收入约4000—5000元，大约只有杨俪萍的一半。两人的教育经历、生活习惯和经济条件存在明显差异，但杨俪萍并不在意这些差距，反而欣赏朱晓东身上与自己截然不同的特质。视频通过这种反差说明，拥有学历、稳定工作和良好家庭支持的人，同样可能遭遇亲密关系中的欺骗与控制，社会能力并不必然等同于识别情感操控的能力。

### 2. 朱晓东通过塑造特殊经历和个人形象，建立了杨俪萍对他的信任
2012年，杨俪萍在一次同学聚会上认识了朱晓东，后者有纹身、喜欢泡酒吧、饲养异宠，还曾于2007年参加选秀节目《我型我秀》，这些特点恰好与杨俪萍喜欢日本摇滚歌手的审美产生了联系。两人最初聊得不错，但朱晓东不久后突然失联，约一年后才重新联系杨俪萍，并开始追求她。对于失联原因，他声称自己患上了脑部肿瘤，独自去了西藏生活，最终病情奇迹般好转，这段未经证实的经历让杨俪萍觉得他特别、勇敢，与以前认识的人不同。
2014年1月，两人已经确立恋爱关系，并与朋友一起前往无锡旅游；2015年春节，朱晓东第一次登门见杨俪萍的父母。尽管外婆对朱晓东印象不好，父母对部分情况也有所疑虑，但杨俪萍在家人面前一直强调他爱干净、会做饭、很孝顺，父母最终选择尊重女儿的决定。作者将这段经历视为后来一系列欺骗的起点：当一个人对伴侣形成了特别强烈的正面想象，就可能更倾向于接受对方给出的解释，而忽略解释本身是否经得起验证。

### 3. 婚前已经出现社交控制、占有欲和经济关系失衡等危险信号
2015年2月，朱晓东删除了杨俪萍社交账号中的大部分男性好友，杨俪萍随后发微博表示，以后女性朋友可以随时联系自己，男性朋友则可能被删除，并写下“这不是演习，这是一场没有硝烟的战争”。除此之外，杨俪萍每次参加同学聚会或者回家见父母，朱晓东往往都要跟随，这使她单独与朋友、家人交流的机会受到限制。经济方面，杨俪萍曾多次替朱晓东偿还信用卡，还攒下几个月工资为他购买价值5000多元的手表。
婚前的一次家庭聚会上，杨俪萍的小舅提醒朱晓东要善待她，朱晓东却回答：“杨俪萍我老喜欢的，别人不可以打骂她，要骂只有我骂。”这句话虽然当时以类似玩笑的形式说出，却体现出一种值得警惕的占有观念，即把伴侣视为自己可以支配的人，而不是拥有独立人格的平等个体。这些行为单独出现并不能证明一个人未来会实施犯罪，但当社交限制、经济索取、隐私侵犯和支配性言论反复出现时，就应当重视这种持续性的关系失衡。

### 4. 婚姻中的出轨与威胁性保证书，并没有带来真正的行为改变
2015年12月31日，两人登记结婚，2016年5月28日举行婚礼，女方承担了约10万元的婚房装修费用，而男方负责的婚礼仅摆了6桌，未请司仪，新娘甚至没有穿婚纱。婚礼结束不久，杨俪萍便发现朱晓东与其他女性有染，为了取得原谅，朱晓东在一张钻戒广告纸上写下保证书，承诺不再与其他女性联系、允许妻子检查手机和通信记录。保证书末尾却出现了带有共同死亡意味的威胁性内容，这已经明显超出了正常道歉和承担责任的范畴。
杨俪萍最终选择原谅朱晓东，但后者不久便再次与其他女性交往，甚至向对方谎称自己已经离婚。2016年6月30日，杨俪萍又在朋友圈透露，朱晓东以观察蜥蜴为由在家中安装摄像头，实际上也可以监视她的活动。这个阶段最值得注意的是，朱晓东的口头承诺与实际行为始终相互矛盾，而一段关系能否修复，不能只看认错时的态度，更需要观察欺骗、侵犯边界等行为是否真正停止。

### 5. 虚假的香港升职计划使杨俪萍失去了工作，并进一步脱离了原有的社会支持网络
2016年8月，两人曾前往民政局准备办理离婚，但最终没有离成，至于离婚的真正原因，杨俪萍没有告诉家人，朱晓东关于妻子以自杀相威胁的说法也属于其单方面陈述。随后，朱晓东告诉杨俪萍，公司准备提拔自己并派他赴香港培训，月薪将达到2万元，希望妻子辞职后一起前往香港生活。9月14日，杨俪萍在丈夫陪同下向学校递交辞职申请，校长十分舍不得她，并承诺只要自己还在学校，她将来遇到困难就可以回来。
9月19日，杨俪萍在屏蔽家人的朋友圈中写道，丈夫最近对自己特别好，以至于自己感到有些恐慌，而此时朱晓东所说的升职计划实际上并不存在。杨俪萍没有将辞职、此前准备离婚等重大事项告诉父母，直到10月14日正式离职时，她仍在给学生家长的信中表示自己即将赴香港生活。这一系列事件不仅造成她职业上的损失，也客观上削弱了同事、家人和朋友及时发现异常的能力，是本案中社会支持网络逐渐失效的重要环节。

### 6. 法院最终认定这是一起有预谋的故意杀人案件，而非单纯因夫妻争吵导致的意外
朱晓东始终试图将案件解释为夫妻之间因生活琐事发生争执，声称自己并没有预先计划杀害妻子。视频则通过案发前的异常行为、虚假的香港工作安排、双方先后辞职，以及与案件有关的物证和购买记录等，指出其说法存在大量疑点。2016年10月17日，杨俪萍遇害，法医后来认定其死因为机械性窒息。

### 8. 数字身份并不等同于真实身份，持续收到微信消息也无法证明一个人平安
在长达三个多月的时间里，杨俪萍的父母仍然能够收到女儿的微信消息，也能看到她更新朋友圈，却始终无法与女儿进行正常的语音或视频交流。2016年11月7日，父母注意到女儿使用了平时几乎不用的称呼，例如把丈夫叫作“东”，把母亲叫作“妈咪”，但当时没有意识到这些异常意味着什么。11月8日，母亲因为想念女儿，专门发消息要求她上完课后打个电话，却不知道女儿早已辞职。
11月21日，杨俪萍养了18年的猫去世，收到的文字回复也与家人熟悉的女儿的反应存在差异；此后，原本应该见面的生日聚会、结婚纪念日及春节家庭团聚又接连未能实现。亲友一直能够收到消息，并且相信杨俪萍正在外地生活，使这些异常没有及时汇聚成一个明确的危险警报。本案揭示了一个重要的信息安全问题：账号在线、朋友圈更新、文字回复正常，只能证明有人在使用该账号，不能证明账号本人安全。

### 9. 自首并不必然免除死刑，法院更关注犯罪性质、情节及社会危害程度

### 10. 刑事案件虽然已经结案，但受害者家庭承受的伤害并不会随判决结束
杨俪萍是父母唯一的女儿，父母在她恋爱、结婚时虽然有过顾虑，但最终选择尊重她的意愿，没想到这段婚姻会成为家庭无法挽回的悲剧。2017年4月，父母在殡仪馆见到女儿时，已经无法正常瞻仰遗容；同年12月22日冬至，杨俪萍被安葬，随葬物品中还有一件婚纱，弥补了她结婚时没有穿婚纱的遗憾。据视频介绍，父亲说这件婚纱是女儿托梦向他要的，体现了他对女儿深切的思念。

## 值得记住的点 / 行动建议
以下是在视频内容基础上进一步提炼出的现实安全启示，并非全部为作者逐字提出的建议。

### 1. 判断一个人，要看长期行为，而不是听他如何描述自己
朱晓东曾讲述自己患病、独自前往西藏、最终战胜疾病的特殊经历，杨俪萍因此认为他勇敢、特别。
但是，一个人讲述的故事，只能说明他希望别人怎样认识自己，并不能自动证明他就是这样的人。
在恋爱、结婚等重大决定中，应当更多关注以下几个方面：
- 他是否能够长期保持诚实，重要经历是否真实。
- 他面对利益冲突时，是否尊重他人。
- 他遇到问题时，是承担责任还是不断寻找借口。
- 他如何对待服务人员、父母、朋友及过去的伴侣。
- 他是否尊重你的拒绝、隐私、工作和正常社交。
- 他作出的承诺能否转化为持续、可观察的行为改变。

故事可以塑造个人形象，长期行为才能提供更可靠的人品证据。

### 2. 不要把控制欲误认为爱得深
删除异性好友、检查手机、干预正常社交、限制与家人单独见面，以及未经同意进行监视等行为，都可能是亲密关系中的控制信号。
尤其当对方使用“因为我太爱你”“因为我怕失去你”“你这样做就是不在乎我”等理由要求你交出个人权利时，需要分辨这究竟是合理的情感需求，还是对自主权的侵犯。

| 健康的亲密关系 | 具有控制性的关系 |
| --- | --- |
| 尊重双方的朋友圈 | 要求删除或断绝朋友关系 |
| 可以表达自己的不安全感 | 要求对方服从以消除自己的不安全感 |
| 尊重彼此隐私 | 强行检查手机、账号和私人通信 |
| 支持对方拥有独立生活 | 要求对方的一切活动围绕自己展开 |
| 遇到分歧可以平等协商 | 通过威胁、惩罚迫使对方让步 |
| 允许伴侣说“不” | 将拒绝视为背叛或挑战权威 |
| 鼓励伴侣与家人保持联系 | 阻止伴侣获得外部帮助和支持 |

真正健康的关系不会要求一个人通过不断缩小自己的生活空间来证明爱情。

### 3. 保留自己的工作能力、收入来源和经济自主权
杨俪萍原本拥有稳定职业，学校领导对她也非常认可，但虚假的赴港计划让她放弃了工作。
职业的意义不仅在于收入，还包括社会身份、同事关系、信息渠道、独立决策能力，以及遇到婚姻危机时重新开始的可能性。
在涉及辞职、随伴侣迁居、全职照顾家庭等重大决定时，建议先核实工作及迁居安排是否真实，评估家庭收入的稳定性，并保留必要的应急资金、职业资格和重新就业渠道。
辞职或者全职照顾家庭本身并没有问题，真正的风险在于，一个人是否在信息不透明、受到胁迫或缺乏退路的情况下放弃了自己的选择权。

### 4. 婚姻关系中也应当建立清晰的财务边界
本案涉及信用卡代偿、较大的婚姻支出，以及案发后对个人账户和信用额度的侵占，体现出财务安全的重要性。
伴侣之间可以合理地共同承担支出，但不意味着个人账户、身份证件和信用信息必须完全失去独立性。
具体可以做到：
- 保留个人能够自主支配的银行账户。
- 不随意向他人提供支付密码及短信验证码。
- 妥善保管身份证、银行卡等重要证件。
- 开启银行账户、信用卡的大额消费提醒。
- 定期检查个人征信及借贷情况。
- 对替伴侣偿还债务、担保、大额转账等行为保持审慎。
- 明确家庭共同开支与个人债务的界限。
- 在存在经济控制风险时，保留能够安全使用的应急资金。

经济独立并不能保证一个人免受伤害，但能够增加其自主选择和获得外部帮助的能力。

### 5. 不要用反复原谅代替问题的真正解决
朱晓东首次出轨被发现后写下保证书，但此后再次出轨，说明保证书并没有促成实际行为的改变。
判断一个人的道歉是否具有意义，应关注三个方面：

承认责任
是否承认自己的具体错误，而不是将问题归咎于伴侣的性格、要求或者反应。

停止伤害
是否真正停止欺骗、威胁、监视等行为，尊重对方的安全和边界。

持续改变
是否在足够长的时间内保持行为一致，而不是在矛盾爆发后短暂表现良好。

尤其需要注意的是，如果道歉过程中出现伤害自己、伤害伴侣或者共同死亡的威胁，那么这已经不再是普通的感情修复问题，而是需要严肃对待的人身安全问题。

### 6. 对死亡威胁和极端言论保持高度警惕
朱晓东保证书中出现的共同死亡威胁，是整段婚姻中非常严重的危险信号之一。
无论对方是否声称自己只是开玩笑、说气话或者因为太爱你，涉及伤害、死亡、限制人身自由的言论，都不应该被简单忽略。
如果现实中出现类似情况，应尽可能向可信任的亲友说明情况，保存相关威胁证据，并在安全条件下寻求警方或专业反家暴机构的帮助。
如果对方已经表现出明显的暴力倾向，不宜独自进行激烈对质，也不宜为了验证对方是否真的敢实施威胁而使自己暴露在危险环境中。

### 7. 永远保留亲密关系之外的社会支持网络
杨俪萍原本拥有父母、朋友、同事和学校领导等多个支持渠道，但随着关系的发展，她的正常社交受到限制，婚姻中发生的重大问题也没有及时传达给家人。
一个健康的社会支持网络，通常应当包括：
伴侣是社会支持网络的重要组成部分，但不应成为唯一的信息、情感和经济来源。
即使已经结婚，也应当尽量保持与朋友和亲人的正常联系，拥有可以单独交流的机会。
外部社会关系不仅提供陪伴，也能够帮助一个人发现自己长期处在某种环境中而逐渐习惯的异常行为。

### 8. 涉及重大人生决定时，最好引入独立的信息核实机制
杨俪萍没有将辞职和准备赴港生活的决定告诉父母，客观上减少了家人为她提供建议、核实信息的机会。
面对结婚、辞职、迁居、共同借贷、购买房产等重大决定，可以主动问自己：
- 这项决定建立在已经核实的事实之上，还是仅仅建立在对方的承诺之上？
- 如果对方的承诺无法兑现，我是否有可行的退路？
- 这项决定是否使我更加依赖对方？
- 是否有与此事利益无关的可信任人士能够帮助我判断？
- 为什么对方希望我尽快决定，或者不要将这件事告诉家人？
- 如果我的朋友遇到完全相同的情况，我会建议她怎么做？

引入第三方意见，并不意味着不信任伴侣，而是对重大人生风险进行必要的独立判断。

### 9. 长期联系不上亲友本人时，不能只依靠文字消息判断安全
本案一个特别值得普通家庭记住的教训是：能收到微信回复，不代表真的联系到了本人。
如果一名原本经常见面、打电话的亲友，突然长期只进行文字交流，同时伴随语言习惯变化、连续失约或者生活信息不一致，就应该主动进行安全核实。
亲友联系异常时的安全核实流程
发现长期失联、异常回复或行为变化

尝试与本人进行实时语音或视频交流

联系其他亲友、同事，交叉核实安全状况

仍无法确认安全，或发现明确危险信号
及时向警方求助，不独自进入可能存在危险的环境。

中国境内遇到紧急人身安全威胁，可以拨打110报警；如涉及家庭暴力，也可以向当地妇联等机构寻求支持。
尤其在存在暴力威胁或疑似人身危险的情况下，不应因为仍能收到对方账号发出的文字消息，就放弃进一步核实。

### 10. 学会识别累积性风险，而不是孤立地看待每一个异常
回顾杨俪萍的遭遇，可以发现其中包含多个性质不同的异常：
01

信任问题
重要经历未经证实，反复出现欺骗

02

社交控制
删除好友、限制单独社交

03

经济失衡
反复代偿债务、经济付出不对等

04

情感胁迫
出轨后的威胁性承诺、侵犯隐私

05

独立性受损
职业中断、外部支持减少

06

严重人身安全风险
多种控制、威胁和欺骗行为持续累积

本案中出现的风险因素归纳，并非所有控制型关系都会按照这一顺序发展。这些异常中，单独一项并不足以预测恶性犯罪，但是，当欺骗、监视、社交隔离、经济控制、死亡威胁等多种行为同时存在，并且不断加重时，就不应继续把它们解释为彼此无关的小矛盾。
识别风险的重点不是预测一个人将来是否会犯罪，而是判断当前关系是否已经损害自己的安全、自由与基本权利。

### 11. 区分善良、信任与毫无边界的付出
视频作者在结尾总结，杨俪萍曾经三次相信朱晓东：
第一次，相信他患过脑瘤、独自前往西藏的经历。
第二次，相信他在出轨后写下的保证书。
第三次，相信他即将升职并带自己赴香港生活的承诺。
这三次信任分别涉及对个人经历的相信、对婚姻修复的期待，以及对未来共同生活的规划。
善良并不是缺点，信任也是健康亲密关系不可缺少的基础，但信任不应意味着放弃核实事实、容忍持续伤害或者交出全部自主权。
可以爱一个人，也可以保留自己的工作；可以相信伴侣，也可以核实重大事项；可以原谅错误，也可以要求对方承担责任；可以经营婚姻，也可以保留退出一段不安全关系的权利。

### 12. 理解自首、预谋、犯罪情节与死刑判决之间的关系
本案具有一定的刑事法律学习价值。

| 法律概念 | 基本含义 |
| --- | --- |
| 故意杀人 | 故意非法剥夺他人生命的犯罪行为 |
| 预谋杀人 | 在实施杀人行为之前已经形成犯罪意图，并可能存在相应准备行为，并非独立罪名 |
| 自首 | 犯罪后自动投案，并如实供述自己的罪行 |
| 从宽处罚 | 法院根据法定情节及案件实际情况依法作出的量刑处理，并非任何情况下都必须从轻 |
| 二审 | 上一级法院依法审理当事人不服一审判决而提出的上诉等案件 |
| 死刑复核 | 对依法报请核准的死刑案件进行审查的特殊司法程序 |
| 剥夺政治权利终身 | 法院依法判处犯罪人终身丧失相关政治权利的刑罚 |

本案中，朱晓东存在自首情节，但法院仍然依法作出死刑判决，说明量刑并不是只考虑某一个从宽因素，而是需要结合犯罪性质、主观恶性、具体情节、危害后果等进行综合判断。
日后遇到类似刑事案件报道，可以重点区分被告人的自述、律师的辩护意见、检察机关的指控以及法院最终认定的事实，避免将几种性质不同的信息混为一谈。

## 我的点评
这期视频的价值不仅在于复盘一起恶性刑事案件，更在于通过婚恋经历、职业变化、社交控制、经济侵占与数字身份冒用等多个维度，呈现亲密关系中的风险如何逐渐累积。作者将杨俪萍三次相信朱晓东作为叙事主线，具有较强的解释力，但对于朱晓东究竟为何杀人、每一个婚前行为是否具有犯罪目的等问题，仍应当区分事后推断与法院已经认定的事实。
此外，学历差距、收入差距、父母离异、纹身、饲养异宠、喜欢泡酒吧等个人背景，本身并不是判断一个人是否危险的可靠依据，真正值得关注的是反复欺骗、威胁、控制、暴力及侵犯他人权利的具体行为。也不能因为已经知道悲剧结局，就认为受害者及其家人当初理应识破所有异常，这属于典型的事后偏差（Hindsight Bias，即在知道结果之后，高估事件原本的可预测性）。
普通人最值得从本案中吸取的经验，是在亲密关系中保留独立人格、经济自主权、外部社会支持和事实核实能力，并在出现明显威胁时及时寻求帮助。日后回顾这篇笔记时，可以尤其关注“控制行为识别—社会支持网络—人身安全核实”这三个方面，将案件教训转化为具体的安全意识，而不是仅仅停留在对犯罪人的愤怒上。
