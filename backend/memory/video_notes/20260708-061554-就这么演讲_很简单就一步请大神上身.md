## 核心观点

### 1. 提升演讲能力，不一定需要花钱报培训班，找到优秀的学习对象就能开始训练
作者开篇就提出，这是一种「一分钱不用花，但是基本上可以秒杀市面上大部分培训机构」的方法。
他想表达的是，学习演讲并不一定非要依赖专业培训机构。市面上的演讲培训课程可能需要花费不少时间和金钱，但优秀演讲者已经公开了大量高质量的演讲视频，这些视频本身就是可以反复学习的素材。
与其花钱听别人讲解什么是好的演讲，不如直接去观察那些已经具备优秀演讲能力的人是如何表达的。通过观看、模仿、重复练习，可以把抽象的演讲技巧转化为具体的动作和表达习惯。
这种学习方式的优势在于成本极低、学习素材丰富，而且不受时间和地点限制。只要有网络、视频播放设备以及愿意练习的时间，就可以随时开始。
作者的核心思路是：不要只学习别人总结出来的演讲理论，直接向优秀的演讲实践者学习。

### 2. 首先要找到一个自己真正喜欢、真正有感觉的优秀演讲者
作者强调，训练的第一步不是马上练习，而是先找到一个值得模仿的对象。
他给出了几个具体选择：
- Steve Jobs（乔布斯）： Apple 苹果产品发布会。
- 罗永浩： 锤子科技（Smartisan）产品发布会。
- 雷军： 小米（Xiaomi）产品发布会。
- TED 演讲者： 可以从 TED 的各类公开演讲中寻找自己喜欢的表达风格。

这些演讲者虽然风格不同，但都可以成为模仿学习的对象。
乔布斯的产品发布会、罗永浩的锤子发布会和雷军的小米发布会，都是具有代表性的商业演讲场景。TED 演讲则提供了更加丰富的主题和表达风格。
这里有一个非常重要的细节：作者并没有要求所有人都去模仿同一个人，而是反复强调要找一个「自己特别有感觉的」。
这意味着，学习对象的选择不应该只看名气，还要看自己是否真正欣赏对方的表达方式。只有当你对某个演讲者的表达有强烈的认同感，才更容易产生模仿的动力，愿意反复观看和练习。
底层逻辑：先找到自己喜欢的表达风格，再通过模仿逐步建立自己的表达能力。

### 3. 不要把看演讲当成普通的视频娱乐，而要创造沉浸式的学习环境
找到喜欢的演讲视频之后，作者建议不要随便拿手机看几分钟就结束，而是要专门创造一个安静、沉浸的观看环境。
具体做法包括：
- 找一个安静的环境，避免外界干扰。
- 尽可能使用屏幕比较大的设备观看。
- 把音响打开，让声音更加清晰、有现场感。
- 像听音乐一样，专心欣赏整场演讲。

作者特别使用了「像听音乐一样沉浸进去」这个表达。
这实际上强调了一种学习状态：观看时不要只是获取演讲内容，而要把注意力放到演讲本身，感受整个表达过程。
例如，一个演讲者如何进入主题、如何组织语言、如何控制表达节奏，以及在什么地方让人产生情绪共鸣，都可以成为观察对象。
大屏幕能够帮助观察演讲者的整体状态，音响则让声音表现更加清楚。安静的环境能够减少注意力分散，让观看者真正进入演讲场景。
作者希望建立的不是碎片化的视频观看习惯，而是一种有意识、有投入感的模仿学习过程。

### 4. 不要试图一次性模仿整场演讲，先找到最让自己有感觉的片段
这是整套训练方法中非常关键的一步。
作者并没有要求初学者从头到尾完整背诵某位演讲者的整场发布会，而是建议在欣赏过程中，找到其中一段特别有感觉的内容。
原文提到：
「这一段特别有感觉，听下来你就可以来回踱步。」
也就是说，当你听到某一段表达特别精彩、特别有感染力，甚至让自己产生强烈模仿冲动时，就可以把这一段单独拿出来练习。
这种做法有几个优势：
第一，优秀演讲通常包含大量内容，整场模仿的难度较高，而短片段更容易集中注意力。
第二，自己真正有感觉的部分，往往更容易激发练习动力，不容易半途而废。
第三，片段化训练能够让练习更加精细，可以反复听、反复模仿，直到对表达方式形成熟悉感。
第四，通过不断练习一个个精彩片段，可以逐步积累表达经验，而不是一开始就追求完整演讲。
因此，这套方法实际上采用的是一种由小到大的训练思路：先模仿一个精彩片段，再逐渐积累，最后形成更完整的表达能力。

### 5. 通过「请神上身」的角色代入，暂时让自己成为优秀的演讲者
这是整个视频最有特色、也最容易让人记住的训练方法。
作者提出，在开始模仿的时候，可以站在镜子前，或者站在窗户旁边，然后在心理上告诉自己：
「我就是乔布斯，我就是雷军。」
如果觉得有必要，还可以专门举行一个有仪式感的过程，作者把它称为：
「请神上身」。
例如：
- 乔布斯上身。
- 雷军上身。

这并不是字面意义上的什么神秘仪式，而是一种角色扮演和心理代入。
在日常生活中，我们往往习惯于用自己原本的表达方式说话。即使观看了优秀演讲，也可能只是觉得对方讲得很好，却无法真正进入对方的表达状态。
而角色代入可以暂时打破这种心理限制。
当你告诉自己「现在我就是乔布斯」，你就不再只是一个站在屏幕前欣赏演讲的人，而是开始尝试以乔布斯的身份、状态和表达方式去完成这段演讲。
这种心理暗示可以帮助练习者减少拘谨，增强舞台感，并且更主动地模仿优秀演讲者的整体表现。

### 6. 模仿时要彻底代入角色，而不是只学表面的语言内容
作者在「请神上身」之后，进一步用两个非常有感染力的例子说明这种角色代入应该达到什么程度。
他说：
「这个时候你就是乔布斯，整个苹果都是你的。」
「你就是雷军，整个小米都是你的。」
这两句话是整段视频中最有代表性的表达。
它强调的不是简单地记住乔布斯讲过什么，或者雷军说过什么，而是要把自己放进对方的角色和场景之中。
例如，当你模仿乔布斯时，可以想象自己正在主持一场 Apple 产品发布会，面对台下的观众介绍一款重要产品。
当你模仿雷军时，可以想象自己正在小米发布会上，作为公司的核心人物向观众介绍产品和技术。
这种角色代入会让模仿更有真实感。
在实际练习中，可以进一步观察和复刻演讲者的：
- 站姿和身体状态。
- 说话时的语气和语调。
- 语言节奏与停顿。
- 手势和身体动作。
- 表情与情绪变化。
- 面对观众时的自信程度。
- 重点内容的强调方式。

需要注意，这些是根据作者提出的「一比一复刻」思路进一步拆解出的训练维度，视频本身没有逐项列举。
核心是不要只模仿文字内容，而是尽可能还原对方在那个演讲场景中的整体状态。

### 7. 对选定的精彩片段进行一比一复刻，而不是只看、只听、只理解
作者给出的最直接的训练要求是：
「一比一的复刻，就那一段特别有感觉的那一段，你就这么练。」
这句话说明，整个方法最重要的环节不是观看，而是实际模仿。
很多人看完优秀演讲之后，会觉得演讲者很厉害，也能总结出一些优点，但这些认识并不会自动转化成自己的能力。
只有自己真正站起来，模仿对方说话，才能把观看过程中的感受转化为身体和表达上的练习。
所谓一比一复刻，就是尽可能按照原演讲的方式进行还原，而不是只记住大概意思，然后用自己的方式重新讲一遍。
例如，可以反复播放选定的片段，观察演讲者的动作和表达，再暂停视频，自己站起来模仿。发现某个地方不自然，就重新观看、重新练习。
在这个过程中，重点不是一开始就追求原创，而是先通过模仿建立对优秀表达方式的具体感受。
这与学习音乐、舞蹈等技能有相似之处：先通过模仿优秀范例掌握基本动作和节奏，再逐步形成自己的风格。

### 8. 坚持练习两三个月，才能真正把模仿转化为自己的表达能力
作者最后给出了一个明确的时间参考：
「练上两三个月，你的水平就基本上可以超越市面上很多教你怎么演讲的这种培训老师。」
这里的两三个月，是作者对这套方法训练周期的经验性描述。
它想强调的是，演讲能力不是通过看几场视频、模仿一次动作就能获得的，而是需要持续练习。
如果只是偶尔看一看乔布斯、雷军的演讲，可能会产生短暂的兴奋感，但很难真正改变自己的表达习惯。
反过来，如果每天或者定期拿出时间，反复练习那些真正有感觉的片段，就能够不断熟悉优秀演讲者的表达方式。
随着练习次数增加，最初需要刻意模仿的动作和表达，可能会逐渐变得自然。
作者还特别说明，这套方法就是自己实际采用过的方式，并不是单纯提出一个理论。
最后，他用一句「我就是这么干的，试试看，请神上身」来鼓励观众亲自实践。
需要理性理解的是，两三个月并不是保证超过所有专业培训老师的科学标准，而是作者对长期模仿练习效果的经验判断。实际进步程度还会受到练习频率、反馈质量、个人基础等因素影响。

## 值得记住的点 / 行动建议
下面把视频中的方法进一步拆解成可以直接执行的练习方案。前五项是对作者原有方法的具体化，后续是为了让训练更加有效而补充的实践建议。

### 9. 不要贪多，先选定一个真正喜欢的演讲者
刚开始练习时，不建议同时模仿十几个人。
例如，可以先选择乔布斯，专门研究他的 Apple 产品发布会；也可以选择雷军，专门研究他的小米发布会。
选择标准不应该只是对方是不是名人，而应该看自己是否真正喜欢他的表达方式。
可以问自己几个问题：
- 我是不是喜欢他讲话的感觉？
- 我是不是愿意反复观看他的演讲？
- 我是不是希望自己也能拥有这种表达状态？
- 他的表达方式是不是适合我希望提升的能力？

如果这些问题的答案大部分都是肯定的，就可以把他作为第一个模仿对象。
建议：先集中模仿一个人，练习一段时间之后，再尝试学习其他人的风格。

### 10. 建立自己的优秀演讲素材库
不要每次练习时才临时寻找视频。
可以提前建立一个专门的演讲学习素材库，把自己喜欢的演讲视频和精彩片段分类保存。
例如：

| 分类 | 素材方向 | 重点观察内容 |
| --- | --- | --- |
| 产品发布会 | 乔布斯、雷军 | 产品介绍、重点强调、舞台表现 |
| 个人表达 | 罗永浩 | 语言组织、个人风格、表达感染力 |
| 主题演讲 | TED | 故事讲述、观点表达、情绪调动 |
| 开场表达 | 各类优秀演讲者 | 如何吸引观众注意力 |
| 结尾表达 | 各类优秀演讲者 | 如何总结观点、强化记忆 |

每次发现一段特别有感觉的内容，就把它保存下来。
长期积累之后，这个素材库就会成为自己的演讲训练资料库。

### 11. 重点练习精彩片段，而不是只看完整视频
作者强调的是找到「特别有感觉」的那一段，然后反复模仿。
因此，实际操作时，可以把一个精彩片段控制在自己能够反复练习的长度内。
例如，选择一段一两分钟的演讲内容：
**1. 第一遍：完整观看，理解演讲内容。**
**2. 第二遍：重点听对方的表达方式。**
**3. 第三遍：注意对方的动作、停顿和语气。**
**4. 第四遍：自己站起来，尝试模仿。**
**5. 第五遍：再次播放原视频，对比自己的表现。**
**6. 第六遍：继续练习不够自然的部分。**

这里最重要的是建立「观看—模仿—对照—修正」的循环。
不要只因为自己已经记住了台词，就认为练习完成了。
真正值得训练的是如何把内容讲出来，以及如何呈现出与优秀演讲者相似的感染力。

### 12. 认真执行「请神上身」，用角色代入打破表达拘谨
这一点尤其值得实践。
很多人在自己一个人时讲话很自然，但一旦面对镜头、面对观众或者站到台上，就会突然紧张。
可能出现声音变小、语速不自然、动作僵硬、表情不协调等问题。
作者提出的「请神上身」，可以作为一种心理训练方法。
具体操作：
- 选定今天要模仿的对象。
- 找到合适的练习位置。
- 站起来，不要坐着练。
- 在心里告诉自己：「现在我就是乔布斯。」
- 想象自己正在主持一场 Apple 产品发布会。
- 进入演讲情境，开始完整复刻选定片段。

关键是不要一边模仿，一边不断提醒自己「我是在模仿别人」。
而是暂时把注意力放到演讲角色上，想象自己真的处于那个舞台、那个场景。
这种方法有助于减少心理包袱，让自己更大胆地尝试不同的表达方式。

### 13. 不只模仿说了什么，更要模仿是怎么说的
如果只背诵乔布斯或者雷军的演讲稿，其实还没有真正掌握作者所说的一比一复刻。
演讲是一种综合表达能力，内容只是其中一部分。
在练习过程中，可以重点观察以下维度：

| 训练维度 | 具体练习方法 |
| --- | --- |
| 语音语调 | 模仿原演讲者的音高变化和语气 |
| 语言节奏 | 观察对方什么时候说快、什么时候说慢 |
| 停顿 | 注意重要观点之前和之后的停顿 |
| 肢体动作 | 模仿自然的手势和身体移动 |
| 面部表情 | 观察演讲者如何通过表情表达情绪 |
| 目光交流 | 观察对方如何面对观众和镜头 |
| 情绪感染力 | 体会对方如何让观众对内容产生兴趣 |
| 舞台状态 | 观察站姿、移动方式和整体自信程度 |

尤其值得注意的是停顿和节奏。
优秀演讲并不是从头到尾一直说，而是懂得通过快慢变化、语气变化和停顿来突出重点。
练习时，可以尝试先完整模仿，再逐渐把注意力集中到某个具体维度。

### 14. 通过录制视频检查自己的表现，让模仿从主观感觉变成客观训练
这是在作者方法基础上值得补充的一步。
如果练习镜头表现力，建议直接打开手机摄像头，把自己的模仿过程录下来。
录完之后，将自己的视频与原演讲片段对照。
重点检查：
- 自己的表达是否流畅？
- 有没有明显的紧张和不自然？
- 说话节奏是否过快？
- 手势是否过多或者过少？
- 重点内容有没有突出？
- 表情是否与讲话内容匹配？
- 镜头前是否能够保持自然的状态？

不要仅凭「我觉得自己讲得不错」来判断练习效果。
因为自己说话时的主观感受，和观众看到的实际表现可能存在差异。
通过录制、回看和对照，可以更加准确地发现问题。
这也让原本的「一比一复刻」形成一个完整的训练闭环。

### 15. 坚持两三个月，但最终目标是形成自己的表达风格
作者建议持续练习两三个月。
这个时间段可以作为一个阶段性的训练目标，而不是练习几天就期待立刻产生明显变化。
可以按照以下节奏执行：
建议的两三个月训练安排
第一阶段：第 1—2 周
建立模仿基础

- 确定一位主要模仿对象。
- 选择 2—3 个自己喜欢的演讲片段。
- 熟悉对方的表达方式。
- 开始进行角色代入和基础复刻。

第二阶段：第 3—4 周
强化表达细节

- 重点练习语气、节奏、停顿和动作。
- 反复模仿同一个精彩片段。
- 开始录制自己的练习视频。
- 找出自己与原演讲者之间的差距。

第三阶段：第 2 个月
提升完整表达

- 从短片段逐渐过渡到更长的内容。
- 尝试独立完成一段完整表达。
- 练习在镜头前保持自然和自信。
- 开始将学到的表达技巧用于自己的主题。

第四阶段：第 3 个月
形成个人风格

- 尝试脱离原演讲稿进行表达。
- 将模仿学到的技巧用于自己的内容。
- 找到适合自己的语气、节奏和肢体语言。
- 独立完成短视频录制或主题演讲。

说明：这是根据视频训练思路整理的建议计划，并非视频作者明确给出的分阶段安排。
特别重要的一点是：模仿只是学习的起点，不应该成为最终目的。
最初可以高度还原乔布斯、雷军的表达方式，但经过一段时间的训练之后，应该逐渐把学到的能力转化为自己的东西。
最终希望达到的状态是：不需要刻意模仿某个人，也能够自然、自信、有感染力地表达自己的观点。

## 我的点评
这段视频分享的方法有很强的实践价值，尤其是「找到优秀范例—沉浸式观看—角色代入—一比一模仿—反复练习」这条路径，简单直接，而且几乎没有经济成本。它最大的价值在于把原本比较抽象的演讲能力训练，变成了一项普通人可以立即开始的具体行动。
我尤其认同「不要只看，要真正站起来模仿」这一点，因为观看和实际输出之间存在很大的差距，只有通过反复练习，才能逐渐改变自己的表达习惯。不过，视频中「两三个月就能超越大部分培训老师」的说法有一定夸张成分，模仿优秀演讲者并不意味着一定能够掌握完整的演讲能力，也不代表能够自动学会内容组织、逻辑论证和临场应变。
另外，过度模仿也可能导致表达僵化，甚至让人形成不适合自己的舞台风格。因此，更合理的方式是先模仿，再理解，最后内化和创新。对于普通人而言，这套方法特别适合用来提升短视频出镜表现力、工作汇报、公开表达、产品介绍和日常沟通能力。
我认为整段视频最值得记住的核心思想是：不要只羡慕优秀的人是怎么表达的，要亲自站起来，按照他们的方式练习。看一百遍不如认真模仿一遍，而真正的进步来自持续重复。
