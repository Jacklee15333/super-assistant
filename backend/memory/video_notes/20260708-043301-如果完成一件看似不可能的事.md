## 核心观点

### 1. 做一件困难的事之前，首先判断底层逻辑是否成立
作者回答“如何完成一件看似不可能完成的事情”时，首先强调的不是勇气、毅力或执行力，而是判断事情本身是否在逻辑上可行。他的思考顺序非常明确：先判断底层逻辑是否能够成立，如果不成立，就根本不会去做；如果成立，即便执行起来非常困难，也值得投入。 这里实际上区分了两种完全不同的“不可能”：一种是事情本身在客观条件或基本原理上无法实现，另一种是事情在原理上能够实现，但现实中存在大量困难。对于前一种，他选择放弃；对于后一种，他会认真寻找实现路径。这个区分决定了创业者是在进行有依据的长期探索，还是在缺乏可行性基础的情况下盲目坚持。
背后逻辑： 决心只能帮助人克服执行中的阻力，不能自动让一个根本不成立的商业模式或技术方案变得可行。因此，判断方向在逻辑上是否成立，比讨论自己能不能吃苦更重要。

### 2. “看似不可能”与“真正不可能”，是两回事
作者认为，自己不会因为外界认为某件事不可能，就刻意去挑战它。如果他本人判断这件事根本不可能成功，那么他从一开始就不会做；既然选择开始，就说明他已经在自己的认知体系里判断出这件事具有可行性。因此，别人眼中的“不可能”，在他的理解中可能只是“困难极大，但存在实现路径”。他并不是先认定一个目标不可能，再靠顽强意志强行实现，而是在确认目标具有可行性后，开始解决阻碍目标实现的具体问题。真正重要的不是证明自己有多敢挑战困难，而是判断自己是否掌握了别人没有看到的可行性依据。
这也解释了为什么同一个项目，在旁观者和创业者眼中会呈现截然不同的风险：双方对事情能否做成的判断依据，本来就可能不同。

### 3. 底层逻辑成立之后，最大的难点往往是协调人、资源与共识
作者提到，一件事情即使在逻辑上成立，实际操作起来仍然可能非常困难，例如必须面对一大群人，不断解释、说服、协调，并逐层达成共识。这反映出一个重要的现实：从“理论上可行”到“组织能够执行”，中间存在巨大的鸿沟。 特别是需要长期资金投入、技术研发、跨团队合作或外部支持的复杂创业项目，成功往往依赖大量利益相关方的共同参与。创业者不仅需要自己相信项目能够成功，还必须让投资人、员工、合作伙伴以及其他相关方理解其中的逻辑，并愿意承担相应责任。换句话说，创业不是独自拥有正确答案就能成功，还需要把个人判断转化为可以动员资源、推动组织行动的共同认知。
延伸理解： 随着项目规模扩大，技术问题、资金问题、组织问题和信任问题可能相互影响；判断方向正确只是起点，把多个环节连接起来才是实际难度所在。

### 4. 优秀创业者必须区分“谋事”与“成事”，接受结果的不确定性
作者明确表示，当自己判断一件事能够做成时，就会真正开始行动，并为此努力，但最终仍然可能失败。他用中国传统说法“谋事在人，成事在天”来表达对结果的态度：人可以决定是否认真判断、是否采取行动、是否持续努力，却无法完全决定最终结果。 这并不意味着创业者不需要承担责任，而是意味着即便判断合理、执行认真，结果仍可能受到外部环境、时机、资源以及其他不可控因素影响。因而，他能够同时保持对方向的强烈信心，以及对最终结果的开放态度。这是一种很值得注意的心理结构：既不因为存在失败概率就不敢开始，也不因为自己坚信方向正确就认为成功必然发生。
这里有一个需要特别区分的概念：相信“这件事具备可行性”，不等于相信“我一定能成功”。

### 5. 旁观者觉得创业者“疯了”，往往源于双方掌握的信息不对称
作者专门解释了为什么很多人会觉得一些创业者是“疯子”。他认为，原因之一是旁观者没有掌握创业者掌握的信息，只能根据外界看得见的行为和结果作判断，而无法完整了解创业者的思考过程。例如，旁观者可能看到一个人投入很多年、不断犯错、长期没有明显成果，于是认为这个人缺乏理性，甚至认为其坚持违背常识。但创业者可能掌握了更多行业信息、关键技术进展、趋势变化或可行性证据，这些信息并没有完整呈现在外界面前。因此，旁观者看到的是一系列异常行为，创业者看到的却可能是一条有内在逻辑、正在逐步实现的长期路径。
作者所说“你只是个观众”，实际上是在提醒：观察别人的行为，不代表已经理解了支撑其行为的全部依据。
不过，这个观点并不意味着所有被外界质疑的人都具有信息优势；信息差只能解释判断差异，不能自动证明创业者是正确的。

### 6. 长期创业可能看起来是在不断犯错，实际上是在逐步解决问题
作者以自己的长期经历为例，提到大约从2010年开始投入某个领域，后来在2015年前后进入公司化发展阶段，经历约9年的持续经营或创业过程，并且在此期间“屡屡犯错”。对于没有掌握更多背景信息的旁观者而言，这种长期投入却不断出现错误的过程，很容易显得不合逻辑：既然这么多年都没有顺利完成，为什么还要继续？但从作者的视角来看，困难和错误并不一定意味着方向有问题，也可能只是复杂项目在推进过程中必须经历的试错与修正。尤其是一个涉及大量新技术、新商业模式或产业链协同的领域，现实进展往往不是一条平滑上升的直线，而是经过反复探索、调整和突破，逐步接近目标。长期过程中出现错误，并不能单独证明最初的方向判断错误；真正需要关注的是，每次错误之后是否产生了新的认知、解决了新的问题。
这段经历也揭示了长期主义的重要前提：不是坚持同一个错误，而是在基本方向仍然成立的情况下不断改进实现方法。

### 7. 创业者的高度确定性，来自对多个趋势的综合判断
作者谈到，自己之所以能够如此坚定，并不是单纯依靠乐观，而是因为团队看到了几个重要趋势，并认为这些趋势叠加起来，恰好能够帮助所选择的方向取得进展。他甚至用非常强烈的表达形容自己的确定性：“不是百分之百，是百分之一千。”这里的“百分之一千”显然是修辞性夸张，并不是经过统计计算的成功概率，而是表达他在认知层面对方向具有极强信心。值得注意的是，这种信心并不完全来自某一个单独条件，而是来自多个趋势同时朝着有利方向发展，并且相互产生支持作用。当技术、市场需求、产业条件、资源供给等因素开始相互配合时，一个过去极难推进的项目可能逐渐出现现实中的突破机会。
原视频没有具体列出这些趋势，因此不能确定作者所指的是哪些技术或市场因素；但可以明确的是，他强调的是趋势叠加形成的判断依据，而不是缺乏证据的自我鼓励。

### 8. 当方向足够确定时，面对困难的正确方法是逐个解决，而不是反复怀疑目标
作者在谈到后续推进时，使用了很朴素的表述：只需要慢慢解决问题，后面逐步做起来就行。这句话的背后，是一种将宏大目标分解成具体执行问题的思维方式。对于外界而言，整个目标可能庞大到难以想象，但创业者不需要在第一天就解决所有问题，而是不断识别当前最大的障碍，调动资源，寻找办法，再进入下一阶段。把一个极其困难的目标拆分成一系列可以处理的具体问题，是将“理论可行”转化为“现实可行”的关键方法。 这种方法还能够减少长期面对巨大不确定性时产生的心理压力，因为关注点不再只是遥远的最终成功，而是眼下能否取得具体进展。
但这里的前提仍然是要持续验证底层逻辑，不能把“逐步解决问题”理解为无条件拒绝重新审视方向。

### 9. 优秀创业者的特殊心理特质：越困难，反而越兴奋
作者在视频开头和结尾都强调“越困难我越兴奋”，并将这种状态视为许多优秀创业者共同具备的特点之一。普通人在面对高度复杂、短期看不到成果且需要不断承受压力的任务时，往往更容易产生焦虑和退缩，而作者描述的创业者则可能从挑战本身获得动力。这种兴奋并不意味着他们完全感觉不到压力，也不意味着他们喜欢毫无意义的折磨，而是在确信方向值得追求的情况下，能够把困难视为需要攻克的问题，而不是立即撤退的理由。从竞争角度延伸理解，真正困难的领域通常意味着参与者需要跨越更高的技术、资金、组织或时间门槛；如果一个团队确实拥有解决这些难题的能力，困难反而可能成为其建立优势的机会。因此，最有价值的创业韧性不是单纯忍受痛苦，而是在解决重要难题的过程中，持续获得动力、积累能力与强化信心。
这也是整个视频最具感染力的一点：创业者对困难的情绪反应，可能与普通旁观者完全相反。

## 值得记住的点 / 行动建议
以下结合视频原意，将其中的方法论转化为可实际应用的行动建议。需要说明的是，具体的检查清单和操作步骤属于对作者观点的延伸，而非视频中逐字提供的方案。

### 1. 面对一个看似不可能的目标，先做“底层可行性检查”
不要把“我特别想做”当成“这件事能够做成”的证据。最值得借鉴作者的地方，是在行动之前先评估基本可行性，而不是只凭兴趣和热情投入大量资源。
可以从四个方面检查：
- 原理是否成立： 实现目标所依赖的技术、商业或因果机制是否合理？是否存在根本性的客观障碍？
- 需求是否真实： 如果涉及创业，是否确实有人需要这个产品或服务？这种需求是否足以支撑商业模式？
- 资源是否可能获得： 人才、资金、技术、渠道及其他必要条件，是否存在现实中的获取途径？
- 路径是否可验证： 能否先通过成本较低的实验，验证最关键的假设，而不是一次性投入全部资源？

例如，想做一个具有重大技术难度的新产品，首先应确认核心技术在原理上具有可行性，再判断是否存在经济上可承受的研发路径，而不能单纯依靠“坚持就有希望”。
行动原则：先证明值得做，再决定如何做。

### 2. 将“逻辑不成立”与“执行暂时受阻”分开管理
面对困难时，人很容易出现两种错误反应：一种是因为眼前遇到障碍就认为整个方向错误；另一种是明明核心假设已经被证伪，却仍用长期主义为继续投入寻找借口。
实际应用中，可以把问题分成两个清单：
方向性问题： 是否有真实需求？关键技术是否可行？行业趋势是否支持？长期经济模型能否成立？
执行性问题： 人才暂时不足、团队协调困难、资金尚未落实、进度落后、合作尚未达成等。
如果核心方向仍有充分证据支持，而当前主要是执行性障碍，就应重点寻找解决办法；如果核心前提已经失效，则需要认真考虑调整方向或停止投入。
这正是视频中“底层逻辑通不通”的实用价值：不是遇到困难就放弃，也不是只要开始就必须坚持到底。

### 3. 建立属于自己的“趋势判断体系”，而不是依靠单一预测
作者提到，自己之所以对某个方向非常确定，是因为看到了几个趋势，并认为它们能够共同产生有利影响。
把这一思路应用到创业、投资或职业选择中，可以建立一张趋势分析表。

| 分析维度 | 需要回答的问题 |
| --- | --- |
| 技术趋势 | 有没有新技术正在改变行业原有的成本或能力边界？ |
| 需求趋势 | 客户需求是否正在增强，是否出现过去没有得到满足的问题？ |
| 产业趋势 | 供应链、基础设施或产业分工是否正在发生有利变化？ |
| 竞争趋势 | 现有竞争者是否忽略了新的市场机会？ |
| 时间趋势 | 为什么是现在开始，而不是三年前或五年后？ |

例如，设想一个新产品过去因成本高昂而难以商业化，如果核心技术成本下降、用户需求增长、相关基础设施逐步完善，那么这些趋势叠加后，可能使项目的可行性明显提高。
需要注意，趋势并不是彼此独立的成功保证，多个趋势也可能同时被错误解读。因此，真正有价值的是寻找相互印证的证据，并不断检验自己的假设。

### 4. 不要只问“最后怎么成功”，而要问“下一步解决什么问题”
一个宏大的创业目标之所以令人望而生畏，往往是因为人们将所有困难同时摆在眼前。
但实际执行时，不必一次解决全部问题。可以采用以下方式：
**1. 明确最终目标及判断成功的标准。**
**2. 找出目前阻碍项目继续推进的关键瓶颈。**
**3. 判断哪些障碍具有先后依赖关系。**
**4. 选择当前最重要、可以验证或突破的一个问题。**
**5. 集中资源完成这一阶段，然后根据结果重新评估下一步。**

例如，一个项目最终需要解决技术研发、生产制造、客户获取和规模化交付等问题，但早期可能只需要先证明核心技术具有可行性。
这种分阶段推进方法，能够减少同时处理大量不确定因素带来的混乱，并使团队不断获得能够验证的进展。
行动原则：把“看起来不可能完成的大目标”，转化为“当前能够采取行动的小问题”。

### 5. 做长期项目时，必须建立持续记录与复盘机制
作者的经历说明，一个真正复杂的项目可能需要很多年才能逐步取得进展，而且过程中难免出现多次错误。
但如果只是重复犯错，而不从错误中学习，时间本身并不会自动产生价值。
建议为长期项目建立一个简单的复盘记录，至少包含以下内容：

| 记录项目 | 需要填写的内容 |
| --- | --- |
| 当前关键假设 | 我们相信什么？依据是什么？ |
| 本阶段行动 | 为验证假设做了什么？ |
| 实际结果 | 取得了哪些客观结果？ |
| 错误或偏差 | 哪些判断与现实不一致？ |
| 新增信息 | 这次实践让我们知道了什么？ |
| 下一步决策 | 继续、调整还是停止？ |

这样做的目的，是把长期坚持从单纯的时间投入，转化为不断积累证据、修正模型和提升能力的过程。
真正值得坚持的是不断接近事实，而不是永远维护自己的最初判断。

### 6. 对外界的质疑保持开放，但不要让缺乏信息的判断主导决策
作者认为，旁观者往往没有创业者掌握的全部信息，因此可能无法理解其决策。
这一观点可以应用到很多长期选择中，包括转型、创业、学习新技能或进入新行业。当外界对你的目标提出质疑时，不能简单地因为反对声音多就立即放弃，也不能因为自己相信方向正确就完全排斥他人的意见。
比较有效的方法是区分两类质疑：
- 证据型质疑： 对方指出了具体的错误数据、技术障碍、市场问题或逻辑漏洞。这类质疑值得认真验证。
- 印象型质疑： 对方只是说“从来没人做成过”“我觉得不可能”“这个太难了”，但没有提供具体依据。这类意见可以作为提醒，却不足以单独否定计划。

更好的判断标准是：对方是否提供了能够改变你原有判断的新信息？
尊重事实，比争取所有人的认同更重要。

### 7. 学会把个人信念转化为其他人可以理解的共同目标
视频指出，复杂项目即使底层逻辑成立，实际推进时也需要面对很多人，并不断达成共识。
这说明创业者不能停留在“我看懂了，所以大家应该相信我”的思维阶段。
在团队协作中，可以尝试建立一套清晰的沟通结构：
- 我们要解决什么问题？ 明确最终目标以及它为什么重要。
- 为什么现在有机会解决？ 解释关键趋势、技术条件和市场变化。
- 为什么相信能够成功？ 展示已经获得的证据、实验结果和阶段性成果。
- 困难在哪里？ 坦诚说明风险、资源缺口及未解决的问题。
- 需要对方参与什么？ 提出明确、可执行的合作需求。

创业者必须把自己掌握的信息转化为别人能够验证和理解的内容，才能逐渐建立信任、形成共识，并获得持续支持。

### 8. 建立“对行动负责、对结果保持谦逊”的心理机制
“谋事在人，成事在天”体现了一种处理长期不确定性的态度。
对于个人而言，最有效的实践方式，是把精力集中在能够影响的因素上：是否进行了充分研究，是否验证了关键假设，是否投入必要资源，是否及时纠正错误，以及是否持续完成阶段性任务。
至于宏观环境、行业变化、其他竞争者的行为以及最终结果，很多时候并不完全受自己控制。
在实际复盘时，不仅要看“最后有没有成功”，还应评估：
- 当时的判断是否有充分证据？
- 决策过程是否合理？
- 行动是否认真执行？
- 新信息出现后有没有及时修正？
- 是否在合理控制风险的前提下推进？

这种方法能够帮助人避免两种极端：成功后将一切归功于自己，失败后又因为结果不理想而彻底否定过去所有努力。

### 9. 把困难视为可以研究的对象，而不是需要回避的情绪
视频中最鲜明的特质，就是作者对困难的积极情绪反应。
但普通人不必强迫自己一遇到困难就兴奋，也不需要刻意追求痛苦。更有价值的做法，是训练自己在遇到复杂问题时，首先从情绪化评价转向问题分析。
可以尝试三个问题：
第一，这件事真正难在哪里？ 是知识不足、资源缺乏、协调成本过高，还是核心假设本身有问题？
第二，困难是否能够被分解？ 能否找出其中最关键、最先需要解决的部分？
第三，如果解决这个困难，能形成什么能力或优势？ 是新的经验、技术积累、组织能力，还是更可靠的判断方法？
这样一来，困难就不只是令人焦虑的阻碍，而可能成为帮助自己成长的具体课题。
不过，如果困难来自不合理的资源投入、长期身心透支或已经失效的目标，就不应该用“越困难越兴奋”为继续冒险寻找理由。

## 我的点评
这段视频最有价值的地方，是把“完成不可能的事”从常见的励志叙事，提升到了底层逻辑判断、信息优势、趋势识别、组织协调与长期执行的层面，强调真正的勇气应当建立在理性判断之上。作者将“事情具有可行性”和“最后一定成功”区分开来，也非常值得认同，因为这能够帮助创业者在保持行动信念的同时，接受复杂现实中的不确定性。需要保留的是，他对自己判断的“百分之一千”的确定感属于个人心理体验，不能取代可验证的证据；过度自信也可能导致确认偏误、忽视反面信息以及不断追加错误投入。另一个需要注意的地方是，信息不对称确实可能让旁观者误判，但创业者掌握更多信息并不代表其判断必然正确，长期坚持也必须以持续学习和有效进展为前提。对于普通人而言，最值得借鉴的不是模仿创业者的高风险行为，而是学习一套更稳健的方法：先验证方向，再分解难题；用证据建立信心，用行动取得进展，用复盘修正错误，并对最终结果保持理性。
最终值得记住的一句话：真正能做成困难之事的人，不是看不到困难，而是看到了困难背后的可行性，并且愿意一步一步把它变成现实。
