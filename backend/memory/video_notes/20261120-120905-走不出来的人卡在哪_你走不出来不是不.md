# 走不出来的人，卡在哪 你走不出来，不是不够努力，是三件事同时缺了：方向、专注、积累。 
第一件，方向。 
我们大多数人走同一条路：上十几年学，考个好学校，选个好专业，找份稳定工作。然后就在一个城市、一个专业里待着，再也不动了。不是你不选，是你接触不到别的选项。 
选择只有两类。一类是几十年上百年不变的东西，吃穿住行、投资，稳，但挤。另一类是科技：软件、互联网、短视频、AI。我从一开始就选最新的技术，因为技术推动生产力，改变生产关系，机会就长在变化的地方。 
以前拍电视剧，影视公司拿七到八成，演员分两三成，因为拍摄和分发都攥在他们手里。短视频把这两个成本都降下来，影视公司拿不到那么多，有才华的人反而能多分。 
一个选BP机的人和一个选短视频的人，聪明程度可能一样，但一条船在下沉，一条船在上行。 
第二件，专注。 
我中专生，软件自学，干了十多年，开软件公司，后来营销、咨询、投资、自媒体全自学。每个领域都算不上顶尖，但都比一般人好。原因就一个：专注。 
刚开始做自媒体，你上班，我在做自媒体；你和同事闲聊，我在研究；你打游戏、逛街、刷视频，我还在做自媒体。 
你每天真正花在上面的有效时间，可能就一个小时，还老走神，因为你不喜欢。我每天14个小时。14比1。 
同样五年，这个比例会长成什么样，你自己算。 
第三件，积累。 
罗马不是一天建成的。燕子搭窝，今天衔一块泥，明天衔一块，慢慢成了窝。 
我做自媒体不太在乎这条是不是爆款，爆了更好，不爆也正常。因为我建的不是一件衣服，是一个小工厂。手工缝一件衣服，很漂亮，掌声很多，但下一件还得从零开始。小工厂刚开始慢，转起来以后，很多事就自动了。我现在每天花5到10分钟，就能让飞轮转一圈。 
大多数人没有积累。今天上班8小时，明天还是8小时，每天重复昨天，第二天清零。追爆款也一样，偶尔爆一条，但全是手工的。 
所以卡点就三个：没方向，在小圈子里选；不专注，时间被切碎；没积累，天天重复。 
今晚做一件：写下你现在花时间最多的三件事，划掉一件对健康、钱、家庭、成长都没帮助的。该删的软件删掉，该取关的取关。
