## 一句话概括

## 背景与主题
视频围绕“商机究竟从哪里来”这一问题，从商业认知、技术变革、历史规律和价值创造等角度展开分析。作者以2003年非典与中国电子商务的发展为例，说明危机如何改变原有商业环境，并催生新的市场需求。随后通过报纸、电视、互联网、移动互联网以及图文、视频等信息传播方式的演变，分析技术进步带来的商业机会。最后，作者借助“强势文化与弱势文化”的概念，以及商业、公司、用户和价值之间的关系，强调理解事物本质的重要性。
整段视频实际上建立了一套关于发现商机、判断商机、把握商机的底层认知框架，其核心是：变化产生机会，需求决定方向，价值决定商业的可持续性，认知决定一个人能否识别和把握机会。

## 核心观点

### 1. 商业机会主要来自三个方面：环境变革、技术变革和规律洞察
作者认为，商机并不是凭空产生的，而是存在于社会发展、技术进步以及客观规律之中。第一类机会来自外部环境的变化，例如疫情、经济周期和社会消费习惯的改变；第二类机会来自新技术的诞生，新技术往往会重新定义原有行业的生产方式、传播方式和商业模式；第三类机会则来自对这个世界本来发展规律的深刻理解，这类机会不一定需要等待风口。前两类机会更多依赖外部条件的变化，第三类机会则更考验个人的商业认知和独立判断能力。真正具有商业洞察力的人，不仅能够看见变化，还能够理解变化背后的因果关系，并判断哪些需求会因此产生、哪些价值会因此被重新发现。

### 三大商机来源模型
根据视频观点归纳：变化是商机的触发条件，价值创造才是商机转化为商业成果的核心。

### 2. 外部环境的剧烈变化，往往会导致旧商业秩序瓦解、新商业秩序形成
作者以**2003年非典（SARS）**为例，指出当时很多企业因为外部经营环境恶化而倒闭，但这一年也被部分商业叙事称为中国互联网电子商务的元年。疫情限制了传统线下商业活动，却客观上推动了消费者和企业尝试线上交易、远程沟通等新方式。过去已经形成的消费习惯、渠道优势和竞争壁垒，在外部环境发生变化时可能被削弱，从而为新的商业模式提供发展空间。这意味着同一种外部冲击，对不同企业、不同经营模式所产生的影响可能完全不同。商业机会往往并非来自危机本身，而是来自危机造成的供需失衡、行为习惯改变和资源重新配置。

### 3. 历史不断重复相似的商业逻辑，危机与机会往往同时出现
作者强调：“历史不只可以明智，历史总是惊人的相似，并且在不断地重演。”他认为，虽然每一次社会变革所处的时代背景不同，但旧模式受到冲击、新需求产生、新模式逐步建立的过程，具有一定的重复性。研究2003年非典期间电子商务的发展，不只是记住一个历史事件，更重要的是理解为什么原本处于发展初期的商业模式能够获得加速成长的机会。当未来出现类似外部冲击时，人们就可以借助历史经验，观察哪些需求正在迁移、哪些服务出现供给不足、哪些行业正在发生结构性改变。不过，历史经验真正值得借鉴的是因果机制，而不是简单地认为过去成功过的生意在未来一定还能成功。

### 4. 发现商机的正确出发点，不是想着如何赚钱，而是思考谁需要帮助
作者引用阿里巴巴创始人马云（Jack Ma，视频中称“杭州马”）关于灾难与机会的一段话：当灾难来临时，不应首先将其视为赚钱的机会，而应该思考谁需要帮助，以及怎样才能更好地帮助他们。公开报道中也记录过马云在回顾非典时表达的类似观点。
![图片](https://www.google.com/s2/favicons?domain=https://finance.sina.cn&sz=32)

 作者认为，这句话体现的不仅仅是企业家的格局，也包含了深层次的商业逻辑。如果一个人只关注自己能够获得多少收益，容易忽略消费者真正的困难；如果从用户遇到的问题出发，则更容易发现尚未被满足的市场需求。帮助他人解决问题、降低成本、提高效率、改善体验，才是能够产生合理商业回报的基础。
这里隐含着两种截然不同的商业思维：

| 维度 | 利益驱动思维 | 价值驱动思维 |
| --- | --- | --- |
| 思考起点 | 我能赚多少钱 | 谁遇到了什么问题 |
| 关注对象 | 风口、利润、流量 | 用户、需求、痛点 |
| 行动方式 | 寻找快速变现的方法 | 提供有效的解决方案 |
| 竞争优势 | 信息差、短期红利 | 产品能力、用户信任 |
| 经营目标 | 尽快获得收益 | 建立持续交易关系 |
| 潜在风险 | 红利消失后难以维持 | 前期可能需要较多投入 |

赚钱与帮助用户并不矛盾，但可持续的商业回报通常需要建立在真实的价值交换之上。

### 5. 每一次新技术的出现，都会冲击原有领域并重新分配商业机会
作者列举了五组技术或媒介变革：电视对报纸的变革、互联网对电视的变革、移动互联网对传统互联网的变革、图片对文字的变革，以及视频对图片的变革。这些变化不仅改变了信息呈现形式，还改变了人们获取信息、分配注意力、建立信任以及进行消费决策的方式。当新技术能够以更低的成本、更高的效率或者更好的用户体验满足原有需求时，旧商业模式便可能面临竞争压力。与此同时，率先掌握新技术、新渠道和新表达方式的经营者，也可能获得更低的获客成本和更大的发展空间。因此，新技术真正带来的商机，并不局限于技术研发本身，还包括技术与传统行业结合之后形成的新产品、新服务和新模式。

### 视频提到的媒介与技术变革
这些变革并不意味着旧媒介必然消失，而是意味着用户注意力、使用场景及商业价值可能发生转移。

### 6. 新技术来临时，过去被验证过的商业模式值得重新做一遍
这是整段视频中非常具有实践价值的一个观点，即每一次技术革命发生时，都值得重新审视过去已经成功的经验和商业方法。因为人类的很多底层需求并没有发生根本变化，发生变化的主要是满足需求的工具、成本、效率和场景。以信息传播为例，人们始终需要获取知识、了解商品和寻找娱乐内容，但报纸、电视、网站、移动应用和短视频满足这些需求的方式各不相同。因此，创业者不一定非要创造一种前所未有的需求，也可以借助新技术，把一种已被市场验证的生意做得更便宜、更方便或者更高效。真正需要重新做一遍的是价值创造方式，而不是机械地复制上一代商业模式。
下面是根据作者思路延伸出的商业案例，并非视频中逐一提到的内容：

| 原有商业模式 | 新技术下的实现方式 | 核心需求 |
| --- | --- | --- |
| 线下实体零售 | 电子商务、直播电商 | 购买商品 |
| 报纸广告 | 搜索广告、信息流广告 | 商业曝光 |
| 线下课堂 | 在线教育、AI辅助教学 | 学习知识 |
| 传统客服 | 智能客服、AI客服 | 获取帮助 |
| 纸质地图 | 手机导航、智能路线规划 | 寻找路径 |
| 人工设计服务 | AI辅助设计、自动化设计 | 获得设计成果 |
| 传统咨询服务 | AI知识库、智能咨询助手 | 解决专业问题 |

这种商业创新的基本逻辑是：
已经存在的真实需求 + 已被验证的商业模式 + 新技术带来的效率优势 = 值得重新探索的商业机会。

### 7. 真正深层次的商机，来自对世界客观发展规律的理解
作者认为，除了等待外部环境发生变化和新技术出现，人们还可以通过提升自身认知来发现商业机会。为此，他引用了电视剧中关于“强势文化”和“弱势文化”的经典观点，这段内容可对应到电视剧《天道》及其原著《遥远的救世主》中的相关论述。
![图片](https://www.google.com/s2/favicons?domain=https://k.sina.cn&sz=32)

新浪看点
 所谓强势文化，在这套思想体系中，并不是指性格强硬或者拥有更大的权力，而是指尊重客观规律、根据事物真实的运行机制采取行动。弱势文化则更容易依赖简单易懂的流行方法、现成答案和外部力量，而忽略成功所需要的真实条件。应用到商业领域，就是不能仅凭热点、情绪或者他人的成功结果来判断机会，而应深入研究需求、成本、竞争、供给和价值交换等基本规律。

| 对比维度 | 强势文化 | 弱势文化 |
| --- | --- | --- |
| 判断依据 | 客观事实与规律 | 流行观点与主观期待 |
| 商业认知 | 理解生意为何成立 | 模仿别人如何赚钱 |
| 学习方式 | 研究原理与因果关系 | 寻找现成方法和捷径 |
| 行动方式 | 主动创造必要条件 | 等待外部机会与帮助 |
| 面对失败 | 检查假设与行动 | 容易将原因完全归于外部 |
| 长期目标 | 建立独立判断能力 | 获得短期确定性 |

需要注意，这是一种文学作品中的哲学分类，并不是经过严格验证的社会科学定律。

### 8. 阅读人物传记与教科书，是理解商业底层规律的两种重要方式
作者提到，某位企业创始人曾在南开大学的毕业典礼上分享自己的阅读习惯，主要阅读两类书：一类是人物类书籍，另一类是教科书。人物传记能够帮助读者理解现实中的成功者如何面对环境变化、进行重大决策、配置资源以及承担失败的后果。教科书则能够提供更加系统的基础知识，例如经济学中的供需关系、管理学中的组织效率、市场营销中的用户需求等。两类书籍分别提供真实案例和理论框架，一类帮助理解现实世界是怎样运行的，另一类帮助理解现实世界为什么会这样运行。相比只学习流行的商业技巧，持续积累基础知识和研究真实案例，更有助于建立能够跨越不同商业周期的判断能力。

### 9. 商业的本质是交换，公司的本质是创造用户，而创造用户的本质是创造价值
作者提出了一条十分重要的商业逻辑链：商业的本质在于交换，公司的本质在于创造用户，而创造用户的本质在于创造价值。所谓交换，是指交易双方各自提供对方所需要的东西，企业提供产品和服务，用户支付相应的金钱、时间或者其他资源。企业无法仅凭成立公司、生产商品或者投入广告就自动获得用户，只有当消费者认可产品的实际价值时，交易才可能持续发生。因此，企业经营的根本任务不是单纯扩大销售规模，而是不断识别用户需求、提供解决方案并维持有吸引力的价值交换。这个观点也与管理学家彼得·德鲁克（Peter Drucker）强调的创造顾客的企业经营思想高度相近，但视频并未明确提及德鲁克本人。

### 商业价值创造的因果链
价值是基础，用户是结果，交易是价值被市场认可的表现，利润则是持续经营的重要条件。

### 10. 长期价值没有改变，但外部环境导致短期波动时，可能出现较好的入局机会
视频最后提出，对于那些能够持续为世界创造价值的公司，如果仅仅因为外部环境发生变化而出现一些短期、微弱的波动，那么这种波动可能恰恰是进入市场的较好时机。这个观点体现了作者对长期价值与短期表现的区分：企业当前遇到困难，并不一定意味着其产品价值、市场需求或长期竞争力已经消失。如果用户需求依然存在，企业仍然拥有有效的价值创造能力，而市场却因为短期情绪或者外部因素降低了对它的评价，那么可能形成认知差或者价格与价值之间的偏差。这套逻辑不仅可以应用于投资判断，也可以用于创业、行业选择、职业发展和经营决策。不过，真正困难的地方在于判断眼前的变化究竟是暂时性波动，还是行业基本面已经发生永久改变，不能把所有下跌和经营困难都视为机会。

| 判断维度 | 短期波动型机会 | 长期衰退型风险 |
| --- | --- | --- |
| 用户需求 | 依然存在 | 持续萎缩或消失 |
| 产品价值 | 仍能解决实际问题 | 被更好的方案替代 |
| 经营困难 | 主要来自暂时性因素 | 来自商业模式失效 |
| 竞争能力 | 基本保持稳定 | 持续恶化 |
| 未来恢复 | 具有合理依据 | 缺乏恢复的基础 |
| 决策方向 | 可以深入研究 | 应保持谨慎 |

核心不是任何低谷都值得进入，而是寻找价值仍然存在、却因为暂时性因素而未被充分认可的机会。

## 金句摘录
以下内容摘自视频文字稿，仅对标点及明显的口语识别错误进行了轻微调整。
“历史不只可以明智，历史总是惊人的相似，并且在不断地重演。”

**理解：**学习历史的价值不仅是了解过去，更是发现不同历史事件背后反复出现的因果机制。
“危险的旁边，往往伴随着机会。”

**理解：**危机可能破坏旧有的商业秩序，同时产生新的需求和供给缺口，但并不意味着危机必然带来收益。
“当灾难来临的时候，每个人都不应该想它是一个机会，而是看谁需要什么样的帮助，我们应该如何更好地去帮助他们。”

**理解：**从用户问题出发，比从自身获利愿望出发，更有可能发现真正具有价值的商业需求。
“那么那些在每次变革中获得成功的经验和方法，值得在新技术来临的时候重新再做一遍。”

**理解：**新技术未必需要创造新需求，也可以通过提高效率、降低成本、优化体验，重新满足已经存在的需求。
“强势文化创造强者，弱势文化创造弱者。”

**理解：**遵循客观规律、建立独立判断能力，与单纯依赖流行方法和外部机会，是两种不同的认知路径。此处为视频转述，《天道》中常见的原台词版本使用的是“造就”。
“商业的本质在于交换，公司的本质在于创造用户，创造用户的本质在于创造价值。”

**理解：**这是视频最核心的商业价值观之一：价值创造是商业经营的起点，而不是经营成功之后才需要考虑的事情。

## 值得记住的点 / 行动建议
以下结合视频中的观点进行实践层面的延伸，将抽象商业认知转化为可以执行的分析方法。

### 1. 建立观察外部环境变化的习惯，主动寻找新增需求
不要只关注某个行业现在是否赚钱，而应关注社会、经济和技术环境正在发生哪些变化。环境变化的价值，在于它可能改变原本稳定的供需关系。
可以定期观察以下几个方面：

| 观察方向 | 重点关注的问题 |
| --- | --- |
| 人口结构 | 哪些年龄群体正在扩大，产生哪些新需求 |
| 消费习惯 | 用户更重视价格、便利、品质还是情绪价值 |
| 工作方式 | 哪些工作正在被自动化或重新组织 |
| 技术工具 | 哪些原本昂贵的服务正在变得便宜 |
| 政策制度 | 哪些行业的经营条件正在变化 |
| 行业竞争 | 哪些企业退出，哪些需求仍然存在 |
| 信息渠道 | 用户的时间和注意力正在向哪里转移 |

观察这些变化时，不要停留在新闻事件本身，而应继续追问：这件事改变了谁的生活？产生了什么新的问题？原有的解决方案为什么不再有效？

### 2. 把“寻找赚钱机会”转换成“寻找值得解决的问题”
商业研究可以从用户的实际困难开始，而不是从某个看起来利润很高的项目开始。
在判断一个需求是否值得做时，可以重点调查：用户遇到的问题是否真实存在、是否频繁发生、现有解决方案是否令人满意、用户是否愿意为更好的方案付费，以及自己是否有能力稳定地提供解决方案。
例如，一款商品拥有很大的网络讨论热度，并不一定意味着它拥有真正的市场需求；相反，一种看起来并不起眼的专业服务，如果能够持续帮助企业节约成本，反而可能形成稳定的商业模式。
发现问题是发现商机的第一步，用户愿意为解决问题付费，才是商业需求获得验证的重要标志。

### 3. 每当新技术出现，就重新审视已经成熟的行业
新技术带来的最大机会之一，是让原本无法经济地实现的事情变得可以实现。
以人工智能（Artificial Intelligence，AI）为例，不一定非要研发底层模型才能获得商业机会，也可以研究它怎样与设计、电商、教育、翻译、客服、软件开发、制造业以及专业咨询等成熟行业结合。

| 成熟行业 | AI技术可能带来的价值 |
| --- | --- |
| 电商 | 商品内容制作、评论分析、客服辅助 |
| 平面设计 | 创意探索、图像生成、批量素材制作 |
| 教育 | 个性化辅导、学习内容整理 |
| 软件开发 | 代码辅助、测试与文档生成 |
| 制造业 | 质量检测、生产信息分析 |
| 市场营销 | 广告素材测试、用户需求分析 |
| 企业管理 | 文档处理、知识管理、流程自动化 |

重点不是为了使用新技术而使用新技术，而是判断这种技术是否真的能够减少成本、提高交付速度、改善产品质量或提升用户体验。

### 4. 研究过去的成功案例，但重点学习成功的原因，而不是表面的做法
很多人学习商业案例时，往往只关注成功者做了什么，例如开了什么店、使用了什么平台、发布了什么内容，却没有深入研究这些行为为什么能够带来结果。
更有价值的案例分析，应该包含当时的市场环境、尚未被满足的需求、竞争格局、经营者拥有的资源、商业模式的成本结构以及成功是否依赖特定的时代红利。
例如，研究2003年电子商务发展的历史，真正值得学习的是新交易渠道怎样承接原有商业需求，而不是简单地得出“发生疫情就应该做电商”的结论。
可迁移的是商业原理，不一定是商业形式；可以重复的是因果机制，不一定是历史结果。

### 5. 减少对流行商业技巧的依赖，建立理解底层规律的能力
视频借用《天道》中的强势文化与弱势文化，提醒人们不要过度迷信简单、快速、容易复制的成功方法。
具体而言，学习商业时，应逐步掌握以下基础概念：

| 基础规律 | 应用价值 |
| --- | --- |
| 供需关系 | 判断价格、需求规模与竞争程度 |
| 边际成本（Marginal Cost） | 判断业务扩大后的成本变化 |
| 机会成本（Opportunity Cost） | 比较不同选择的真实代价 |
| 规模经济（Economies of Scale） | 理解扩大生产能否降低单位成本 |
| 网络效应（Network Effect） | 理解用户增长如何影响产品价值 |
| 信息不对称（Information Asymmetry） | 发现信息差及其可能的商业价值 |
| 用户生命周期价值（LTV） | 判断用户长期能够贡献的经济价值 |
| 获客成本（CAC） | 判断获取新用户所需的投入 |
| 现金流（Cash Flow） | 判断企业能否维持正常经营 |

短期技巧可能帮助一个人抓住一次机会，但基础规律能够帮助一个人在不同的行业、技术环境和商业周期中进行相对独立的判断。

### 6. 建立长期阅读体系：人物传记与基础教科书相结合
根据视频中提到的阅读方法，可以将商业学习分为两个方向：一类研究真实人物和企业案例，另一类学习经过系统整理的基础理论。
以下为基于视频观点延伸的推荐书目，并非视频原文提及的书籍。

| 书籍 | 作者 | 学习重点 |
| --- | --- | --- |
| 《经济学原理》 | N. Gregory Mankiw（曼昆） | 供需关系、市场规律、经济决策 |
| 《管理的实践》 | Peter Drucker（彼得·德鲁克） | 企业目的、顾客创造、管理 |
| 《创新者的窘境》 | Clayton Christensen（克莱顿·克里斯坦森） | 技术变革与颠覆式创新 |
| 《竞争战略》 | Michael Porter（迈克尔·波特） | 行业结构与竞争优势 |
| 《穷查理宝典》 | Charlie Munger（查理·芒格）相关著述与演讲 | 多元思维模型与理性判断 |
| 《史蒂夫·乔布斯传》 | Walter Isaacson（沃尔特·艾萨克森） | 产品创新与用户体验 |
| 《鞋狗》 | Phil Knight（菲尔·奈特） | 耐克创业史与商业实践 |
| 《遥远的救世主》 | 豆豆 | 文化属性、认知与客观规律的文学思考 |

阅读时，可以把人物故事中的具体决策与教科书中的理论进行相互对照，分析其中哪些结果来自个人能力，哪些来自市场环境、资源条件或者偶然因素。

### 7. 判断一个项目时，优先分析它创造了什么价值
无论看到一个创业项目、一种商业模式、一家公司，还是一项新的投资机会，都可以按照用户价值的逻辑进行拆解。
需要重点回答五个问题：
- 用户是谁？ 服务的是具有明确需求的人群，还是一个模糊的市场概念？
- 痛点是什么？ 产品解决了用户的什么实际问题？
- 价值是什么？ 相比原有方案，用户获得了哪些具体改善？
- 交易为什么成立？ 用户为什么愿意付费，是否愿意持续付费？
- 商业能否持续？ 收入是否能够覆盖成本，是否存在长期竞争优势？

如果一个项目无法清晰回答这些问题，即使它拥有很大的流量、很高的行业热度或者极具吸引力的宣传概念，也不意味着它具有长期商业价值。

### 8. 区分短期价格波动和长期价值损坏，不要盲目抄底
当一个行业、一家公司或者一个商业项目进入低谷时，首先要判断它遇到的问题究竟是周期性的，还是结构性的。
周期性问题可能来自短期需求下降、暂时性的供应链困难、市场情绪变化或者外部经济环境；结构性问题则可能来自长期需求消失、技术替代、竞争优势丧失、商业模式失效等。
前者在满足一定条件时可能形成机会，后者则可能意味着原有的价值正在消失。

### 低谷入局判断流程

不能仅仅因为一个项目比过去便宜，就认为它值得进入。只有当价值仍然存在、经营风险可承受、未来具有合理的恢复依据时，低谷才可能具有吸引力。

### 9. 用小成本试错验证商业机会，而不是仅凭认知进行重投入
理解商业规律，并不等于已经掌握了具体市场的真实情况。任何商业机会在投入大量资金、时间和人员之前，都需要通过市场实践进行验证。
可以按照以下顺序逐步推进：
**1. 提出商业假设**
明确哪一类用户存在什么问题，以及准备提供怎样的解决方案。
**2. 调查真实需求**
访谈潜在客户，查看竞争产品及用户评价，确认问题是否普遍存在。
**3. 制作最小可行产品**
MVP（Minimum Viable Product，最小可行产品），即以较低成本制作能够验证核心需求的产品或服务。
**4. 验证真实付费**
不只观察用户是否点赞或者表示感兴趣，更要观察用户是否愿意实际购买。
**5. 计算经济效益**
分析获客成本、交付成本、毛利、售后成本和现金流。
**6. 优化产品并逐步扩大规模**
在需求和商业模式得到初步验证之后，再考虑追加投入、扩大经营。

只有当理论判断与市场反馈相互印证时，一个概念上的商机才开始具备成为真实生意的条件。

## 我的点评
这段视频最值得认同的地方，是它将商机从简单的风口、信息差和快速赚钱技巧，提升到了环境变化、技术进步、用户需求与价值创造的层面，为理解商业提供了一套具有迁移价值的认知框架。尤其是“新技术来临时，过去成功的商业模式值得重新做一遍”这一观点，既具有较强的解释力，也能够为创业者提供具体的创新方向。不过，视频对危机与机会之间的关系略有理想化，因为外部变革虽然能够创造机会，也会带来大量无法克服的经营风险，过去的成功案例还可能受到幸存者偏差（Survivorship Bias）的影响。关于强势文化与弱势文化的论述，可以作为提醒人们尊重客观规律的思维工具，但不应忽略资源禀赋、社会结构、制度环境和运气对个人及企业发展的影响。价值创造是商业成立的重要基础，却不是充分条件，企业还需要合理定价、有效获客、成本控制、现金流管理和持续交付能力。对于普通人而言，最实用的方式是从自己熟悉的行业出发，观察正在发生的变化，寻找真实需求，再通过小成本实践验证自己的商业判断。
