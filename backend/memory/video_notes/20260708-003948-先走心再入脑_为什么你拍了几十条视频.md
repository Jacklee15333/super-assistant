## 一句话概括
短视频创作的关键不仅在于提供有价值的内容，更在于通过情绪、真诚、镜头表现力和利他心态，让用户先在情感上接纳创作者，再在认知上接受内容，最终产生关注、信任和行动，即先走心，再入脑；先传递情绪，再传递价值。

## 背景与主题
视频作者（被粉丝称为“胡子哥”）从自己在卧铺车厢里拍摄短视频的经历出发，反思为什么一些原本具备爆款潜力的内容，却可能因为情绪表达不到位而失去传播力。作者早年曾为大型企业和品牌提供设计服务，也有担任老师的经历，因此对品牌设计、环境营造、用户心理和知识传播有一定的实践经验。他将过去在线下教学、广告营销和品牌设计中使用的方法迁移到短视频创作领域，提出了情绪先于内容的传播理念。与此同时，他指出很多短视频新手过于关注播放量、运营技巧和爆款套路，却忽略了自身的基本功和创作动机。整条视频的核心是从人的心理接纳机制出发，重新理解内容创作、个人IP打造以及创作者与用户之间的关系。

## 核心观点

### 1. 情绪是内容的入口，好的内容不一定等于好的传播
作者前两天曾在火车卧铺车厢里拍摄一条短视频，他认为那条视频的选题和内容本身具备成为爆款的潜力。可是，由于卧铺车厢是四人空间，当他拿出大疆（DJI）拍摄设备时，旁边两个人一直盯着他看，导致他难以自然地调动自己的情绪。最终，他只能用非常平淡的方式讲完了整条视频，拍摄结束后觉得十分可惜。这个经历让他再次意识到，同样的内容，由不同的情绪状态、语气和表现方式传递出来，可能产生完全不同的传播效果。内容价值决定了你能给用户什么，而情绪表达在很大程度上影响用户是否愿意接收这些东西。

### 2. 先营造情绪环境，再传递知识：优秀的教学不只是讲课
作者早年为一些大型企业做过设计，后来有一段时间担任老师，他表示自己的课程经常爆满，而且好评度很高。对于一些重要课程，他会提前一个小时到达现场，布置场景、播放专门挑选的舒缓背景音乐，并使用一种从大型品牌借鉴来的、具有特殊树木香气的精油，而不是普通香水。即使学员当天和妻子吵架、被老板批评，或者带着其他负面情绪进入教室，也可以通过视觉、听觉、嗅觉等方面的体验逐渐放松下来。此外，作者从不穿正式的西装、打领带讲课，而是穿着随意的衣服，以轻松而真诚的方式和学员打招呼。他真正做的不是立即输出知识，而是先调整学员的情绪状态，降低人与人之间的距离感，为后续的知识传递创造有利条件。优秀的教学不仅在于知识本身，更在于设计一个让人愿意接受知识的环境。

### 3. 人首先在情感上接纳一个人，才更容易在认知上接受他的观点
很多创作者认为，只要自己的内容足够专业、知识足够有价值，用户自然就会喜欢，但作者认为这种思路忽略了人类的心理防御机制。当一个陌生人试图向我们灌输某种观点、推销某个产品或者改变我们的认知时，我们往往会本能地产生怀疑和防备。作者将这种防御心理比喻为一面盾牌，而突破这面盾牌的柔软方式，就是通过情感和内心建立连接。他强调，创作者必须首先让别人愿意听自己讲话、愿意接纳自己，然后才有机会真正传递知识和观点。这也解释了为什么有些创作者虽然表达得并不完美，甚至有些啰嗦，却仍然拥有一批愿意长期追随他们的用户。

### 4. 广告、品牌营销与短视频创作，都遵循相似的心理接纳逻辑
作者认为，最糟糕的广告就是试图直接将企业自己的认知强行塞进消费者的大脑，却没有考虑消费者是否愿意接受。作为案例，他提到了麦当劳（McDonald's）从儿童阶段就开始建立品牌认知的营销思路，借此说明品牌往往倾向于在消费者防备较低时建立好感和情感连接。作者还将知识传播、广告营销和短视频创作归纳为一套相似的逻辑，即先调动情绪，再促成接纳，然后传递内容，最后才是召唤行动（Call to Action，CTA）。如果前面的情感连接没有建立起来，后面的知识讲解、产品介绍、点赞关注和购买转化就容易受到阻碍。因此，创作者不应仅仅研究如何说服用户，更应该研究用户为什么愿意听自己说话。

### 作者的内容传播逻辑
先让用户愿意接收信息，再考虑信息的传递与转化。

### 5. 用户不仅在消费产品和内容，也在消费整个体验过程
作者举了一个非常生活化的例子：假设你在北京或者上海的街头想买一瓶水或者一些零食，而面前刚好有两家便利店。其中一家类似于7-Eleven（7-11）或者罗森（LAWSON），另一家则是普通夫妻便利店，灯光昏暗、商品陈列不够整洁，甚至可能存在异味。在没有其他因素干扰的情况下，很多人可能会优先选择环境更舒适、视觉体验更好的那一家，即使两家店销售的是完全相同的商品。这说明消费者作出选择时，不仅考虑商品的功能价值，也受到环境、感官刺激和情绪体验的影响。短视频也是如此，用户不仅在判断你讲的知识有没有价值，也在判断看你的视频是不是一种舒服、愉悦或者值得投入时间的体验。

### 6. 短视频的本质不只是信息传递，更是有限感官条件下的情绪传递
在线下实体空间里，品牌和商家可以通过视觉、听觉、嗅觉、味觉、触觉等多种感官共同塑造用户体验。作者在视频中提到了类似“六入”的认知概念，用于解释人是如何通过感官认识外部世界的。相比之下，短视频无法直接向用户传递气味、味道或者触感，主要能够利用的是视觉、听觉，以及由两者共同激发的心理感受。也就是说，创作者的表情、眼神、肢体语言、镜头构图、声音、语速、停顿和情绪状态，都成为影响用户体验的重要因素。短视频虽然限制了感官的传递渠道，但并没有限制情感的传递深度，反而更考验创作者调动情绪的能力。

### 7. 很多短视频新手的问题不是缺少运营技巧，而是基本功全面不足
作者在与很多老粉丝交流短视频创作经验时发现，不少人的镜头表现力、视觉表达能力、语言表达、说话顿挫、声音掌控以及内容质量，严格来说都没有达到及格水平。然而，这些创作者却特别热衷于研究各种运营技法，并且不断询问为什么自己的播放量上不去。视频中提到了一位创作者的例子，对方抱怨自己已经拍了不少视频，播放量却仍然卡在2000左右。作者认为，当一个人的基本能力尚未达标时，单纯依靠所谓的爆款公式、运营套路和技术技巧，很难从根本上解决问题。与其研究如何让平台给自己更多流量，不如先反思自己的内容和表达，是否真的值得用户花时间观看。

### 8. 当你没有足够的创作技巧时，最有效的方法就是“送礼物”
作者很早就向粉丝推荐过一种短视频创作方法，叫作“送礼物”，这里的礼物并不是实物，而是创作者能够为他人提供的有价值的经验、知识、方法、见解或者产品推荐。例如，你可以分享自己实践过的有效方法、亲身踩过的坑、用过并且真正认可的产品，以及能够帮助别人解决问题的经验。关键是认真准备这份礼物，并且真诚地分享给那些真正需要它的人，而不是把分享当作获取播放量的手段。作者借用了“有理不打笑脸人”这句俗语，说明即使一个人的表达技巧并不成熟，真诚和善意也能在一定程度上降低别人对他的防备。他认为，对于基本功还不够成熟的新手来说，真诚地为别人提供价值，是最原始、最简单，同时也是最值得长期坚持的创作方法。

### 9. 创作者在拍摄前的心理状态，会直接影响视频的感染力
作者回忆，自己刚进入短视频平台时，有一段时间会在拍摄前喝一点啤酒，让自己进入微醺的状态，从而变得更加放松。更重要的是，他会主动调整自己的心理状态，想象自己并不是在面对一个冰冷的摄像头，而是在和自己的好朋友、兄弟们聊天。他不是为了展示自己有多厉害，也不是为了刻意追求粉丝和播放量，而是真心希望自己的见解能够帮助这些朋友。按照作者的说法，这也是为什么他的视频即使没有背景音乐、没有剪辑、没有提前准备完整稿件，讲话甚至有些啰嗦，却依然有人愿意观看。这里真正值得借鉴的不是喝酒，而是拍摄之前主动调整情绪、消除紧张感，并且建立一种自然、真诚、利他的表达状态。

### 10. 先让用户坐下，再给用户上菜：重新理解短视频创作的顺序
作者在视频结尾用一个非常形象的比喻总结了自己的观点：“一定要让用户先坐下，然后再上菜。”这里的“坐下”指的是用户愿意停留、愿意倾听、愿意在心理上接受创作者，而“上菜”才是正式传递知识、经验、观点或者其他有价值的内容。很多创作者的问题在于，一开始就急于讲干货、讲专业知识、展示自己的能力，或者要求用户点赞关注，却没有考虑用户是否已经进入接收信息的状态。作者建议大家回归创作的本质，每天认真花一点时间，为自己的朋友们准备一件自己真正认可的礼物，并且在分享之前放下对流量的执念和其他杂念。长期来看，这种以用户价值和情感连接为出发点的创作方式，更有利于积累稳定的信任关系，而不仅仅是追逐一次性的播放量。

## 金句摘录
01｜关于情绪与知识的关系
“在知识前面还有一个东西很重要，叫什么？叫情绪。就是我要先接纳这个人，然后才愿意听你在说什么。”

知识是传播的内容，情绪是传播得以发生的重要条件。
02｜关于广告与心理防御
“最糟糕的广告是什么？糟糕的广告就是想去把自己的认知放到用户的大脑里。”

单方面的信息输出，并不等于有效的认知传递。
03｜关于内容传播的正确顺序
“一定要让别人愿意听你的，然后能够接纳你，然后你这个内容才能被接受，然后才是召唤行动。”

用户的行动，是前面一系列心理过程的结果。
04｜关于创作者的基本功与真诚
“当你所有东西都不及格的时候，记住，回到最原的点，就用一招的方法，用真诚认真的把自己好的礼物分享给别人。”

技巧不足的时候，至少可以先做到真诚和利他。
05｜关于短视频创作的本质

## 值得记住的点 / 行动建议
以下结合作者的原始观点，对具体的执行方法进行进一步展开，以便应用到短视频、自媒体、个人IP、知识分享和商业营销中。

### 1. 建立一个新的创作习惯：每天准备一份礼物
不要每天起床就想着今天应该拍什么视频、什么选题容易爆、怎样才能涨粉，而是应该先思考，今天自己能够为别人提供什么有价值的东西。
这份礼物可以是刚刚学会的一项技能、一个提高工作效率的方法、一件自己使用了很久的产品、一段失败的经历、一个行业内幕，或者一个能够帮助别人节省时间和金钱的认知。

| 礼物类型 | 可以创作的内容 |
| --- | --- |
| 知识型礼物 | 讲清楚一个很多人容易误解的概念 |
| 经验型礼物 | 分享自己做某件事多年来积累的经验 |
| 避坑型礼物 | 告诉别人自己曾经犯过什么错误 |
| 工具型礼物 | 推荐一个真正好用的软件或工具 |
| 产品型礼物 | 分享经过自己长期使用的产品 |
| 方法型礼物 | 教别人如何更高效地解决一个问题 |
| 认知型礼物 | 提供一种看待问题的新角度 |
| 情绪型礼物 | 帮助某一类人缓解困惑、焦虑或孤独感 |
| 资源型礼物 | 整理一批有价值的资料、网站和学习渠道 |

在准备内容之前，先问自己三个问题：
- 这份礼物是送给谁的？
- 它能够帮助对方解决什么问题？
- 即使这条视频没有带来任何收益，我是否依然认为它值得分享？

将用户能得到什么，作为内容创作的第一出发点。

### 2. 拍摄前，主动调整自己的情绪状态
不要在情绪低落、精神疲惫、心烦意乱或者过度焦虑的时候，直接打开摄像头开始拍摄。
因为你当前的情绪状态，很可能通过眼神、表情、语气、声音和肢体动作传递给屏幕另一端的用户。即使你的文案写得非常好，也可能因为表达状态不佳而削弱实际传播效果。
可以建立一套固定的拍摄前准备流程。

### 拍摄前10分钟准备清单
根据作者理念延伸的可执行流程，可逐项勾选。

0/5
第1—2分钟：清理杂念
暂时放下播放量、涨粉、变现等问题。
第3—4分钟：放松身体
深呼吸、喝水、活动肩颈，放松面部肌肉。
第5—6分钟：想象具体的受众
想象自己正在和一个真正需要帮助的朋友聊天。
第7—8分钟：明确礼物的价值
想清楚视频最重要的信息，以及它为什么有用。
第9—10分钟：试讲并调整情绪
检查语气、眼神、声音、节奏是否自然。
重置清单
作者曾使用啤酒让自己进入微醺状态，但不建议将饮酒作为拍摄前的固定习惯。真正需要学习的是主动管理情绪和降低镜头紧张感的能力，而不是依赖酒精来改善表达。

### 3. 不要对着镜头讲话，要对着一个具体的人讲话
很多新手一打开摄像头，就会下意识地进入表演状态，说话开始机械化，表情变得不自然，甚至使用很多平时根本不会使用的词汇。
其中一个原因是，他们在面对镜头时，并没有一个具体的沟通对象，脑海里想的都是抽象的观众、粉丝和流量。
拍摄的时候，可以想象摄像头后面坐着的是自己的好朋友、刚刚进入行业的新人、以前的自己，或者一个正在被某个问题困扰的人。
例如，同样是讲人工智能工具的使用方法，两种表达方式会给人完全不同的心理感受。
信息输出式表达
今天给大家分享三个非常实用的AI工具，建议大家点赞收藏，避免以后找不到。

朋友分享式表达
我前段时间做一个项目，每天都要花两三个小时整理资料，后来发现有三个AI工具特别好用，现在能省下不少时间。如果你也经常被这些事情困扰，我把自己用过的方法分享给你。

第二种表达方式不只是介绍工具，还具备真实经历、具体场景、潜在需求和帮助别人的动机。
它使用户更容易产生一种感受：这个人不是单纯地在向我输出信息，而是在和我交流，并且可能真的理解我的问题。

### 4. 重新设计短视频的内容结构：先建立连接，再提供价值
可以将作者提出的传播逻辑，转化为一套具体的短视频脚本结构。

### 60秒短视频脚本结构示例
时间分配为实践建议，并非作者在原视频中给出的固定公式。
01 情绪入口

0—5秒
提出用户正在面临的问题，制造共鸣、好奇或获得感。

02 建立连接

5—15秒
分享相关经历，让用户感受到你理解他的处境。

03 送出礼物

15—50秒
提供具体知识、经验、案例、方法和解决方案。

04 引导行动

50—60秒
总结价值，引导用户实践、收藏、关注或交流。

这里特别需要注意，情绪入口并不意味着必须制造焦虑、夸大痛点或者使用极端的标题。
好奇、惊喜、希望、理解、温暖、幽默、轻松、认同、获得感，都可以成为用户愿意继续观看的理由。
情绪不等于情绪激烈，而是内容能够引起人的心理反应。

### 5. 系统训练自己的短视频基本功，而不是只研究流量套路
作者明确指出，很多人的问题是多项基本能力同时不及格。因此，在学习高阶运营技巧之前，更应该逐项检查并加强自身的基础能力。
