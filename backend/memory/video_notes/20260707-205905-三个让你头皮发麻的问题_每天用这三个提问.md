## 一句话概括
视频介绍了三种利用AI提升个人认知水平的提问方式，通过逆向视角发现认知盲区、跨学科思考探寻事物本质、复盘对话反思自身思维缺陷，将AI从一个信息获取工具转变为个人认知训练工具。

## 背景与主题
大多数人使用AI仍然停留在搜索信息、解决问题、生成内容和提高工作效率的层面，没有充分挖掘AI在认知提升方面的价值。视频作者提出了一套可以每天重复使用的AI深度对话方法，建议在条件允许的情况下开启AI的深度思考模式。整个方法分为三个阶段：打破固有认知、建立多维度思考框架、反思并修正自己的思维模式。其核心目的不是让AI代替人类思考，而是借助AI不断扩大自身的认知边界，提升独立思考能力。

## 核心观点

### 1. AI更深层次的价值在于升级人的思维方式
普通人使用AI，往往关注的是如何更快地获得答案，而作者更加关注如何通过AI提高提出问题和分析问题的能力。如果只是让AI完成自己原本就会做的事情，那么提升的主要是生产效率，而不一定是认知水平。作者提出的三个问题，分别针对认知盲区、事物本质和思维缺陷展开。通过持续对话，人不仅可以获得新的知识，还可以发现自己为什么没有想到这些知识。真正有价值的AI使用方式，不只是提高做事的效率，更是提高思考的质量。

### 2. 启动逆向视角，发现人类习以为常的认知盲区
作者建议每天打开AI后，首先提出这样一个问题：
站在你们的角度看我们人类，给我一个你认为很重要、显而易见，却被大多数人忽略掉的认知。

这种提问方式将观察视角从人类自身转移到一个相对外部的观察者位置。人类长期生活在既定的社会环境、文化观念和价值体系之中，容易将某些习惯、规则和常识视为理所当然。借助AI模拟外部观察者的视角，可以重新审视那些被忽略的现象与默认前提。这种方法的本质是打破思维惯性，主动发现自己不知道自己不知道的事情。

### 3. 开启深度思考模式，减少停留在表面的回答
作者特别强调，如果AI支持深度思考模式，最好在开始对话前将其开启，如果没有这一功能，也可以继续进行练习。普通的问答往往以快速获取结论为目标，而深度思考更适合涉及复杂因果关系、抽象概念和多学科知识的问题。视频中的三个提问都不是简单的事实查询，而是要求AI进行综合分析、视角转换和归纳反思。不过，深度思考模式并不能保证答案一定正确，仍然需要使用者进行判断。重点在于为复杂问题创造更加充分的分析条件，而不是单纯追求更长的回答。

### 4. 使用跨学科视角，突破单一学科的认知局限
在获得第一个问题的回答之后，作者建议继续要求AI分别站在八类专业人士的角度分析问题，包括哲学家、生物学家、历史学家、科学家、数学家、艺术家、物理学家和工程师。不同学科拥有不同的知识体系、观察方式和分析工具，对同一现象往往能够给出不同层次的解释。例如，哲学关注底层假设与价值判断，生物学关注生存与进化机制，历史学关注社会演变，工程学则关注现实解决方案。将这些视角结合起来，可以避免用单一知识框架解释所有问题。这种方法体现了跨学科思维（Interdisciplinary Thinking）的价值，即利用不同领域的思维模型相互补充。

### 5. 不仅要理解事物的本质，还要明确自己应该怎么做
作者的第二个问题包含两个重要部分：“这件事情背后的本质是什么”以及“我到底该怎么做”。前者解决认知问题，后者解决实践问题，两者缺一不可。如果只是获得深刻的理论解释，却没有将其转化为现实行动，那么认知提升就容易停留在知识积累层面。通过追问底层原因、形成机制和具体解决方案，可以将抽象知识转化为个人决策依据。高质量的思考应该形成从现象到本质、再从本质到行动的完整闭环。

### 6. 真正有价值的答案往往产生于持续追问
作者连续三次强调“不断对话”，说明他并不认为一个提示词就可以解决所有复杂问题。AI第一次给出的答案可以被视为思考的起点，而不是最终结论。当遇到不理解、不认同或者值得进一步研究的地方时，应该继续追问原因、证据、适用条件以及潜在反例。在多轮对话中，人可以逐渐发现最初没有意识到的问题，并不断修正自己的理解。这种具有苏格拉底式提问（Socratic Questioning）特征的交流方式，比单纯接收现成答案更有利于培养思辨能力。

### 7. 利用AI复盘整个对话过程，识别自己的思维缺陷
视频中第三个问题，是在完成一系列深度对话之后，让AI回顾整个交流过程，并分析使用者的思考模式、存在的问题以及补救措施。与前两个问题不同，这一步的研究对象不再是外部世界，而是使用者自身。AI可以根据用户提出的问题、关注的重点、推理过程和对不同观点的反应，尝试识别其中反复出现的思维倾向。例如，是否过早下结论、是否忽略反面证据、是否习惯从单一角度理解复杂问题。这实际上是一种元认知（Metacognition）训练，也就是对自己的思考过程进行观察、反思和调整。

### 8. 将三个问题变成日常训练，建立持续迭代的认知系统
作者建议每天进行这样的操作，而不是偶尔使用一次。三个问题并非彼此孤立，而是构成了一个具有递进关系的认知训练体系：首先发现未知，其次理解未知，最后反思自己认识未知的方式。长期坚持，可以帮助使用者积累不同学科的思维模型，并逐步识别自己的认知局限。随着知识水平和提问能力的提高，人也能够更加深入地使用AI。其最终目标是形成一种能够持续自我反思、自我修正和自我更新的思维习惯。

## 值得记住的点 / 行动建议
以下提示词在视频原有方法的基础上进行了进一步扩展，方便直接复制使用，并非全部来自视频原话。

### 1. 建立一套完整的AI认知训练流程
第一阶段：发现认知盲区
逆向视角 · 打破固有假设

第二阶段：理解事物本质
跨学科思考 · 分析底层逻辑

持续追问与验证
寻找证据 · 检验假设 · 制定行动方案

第三阶段：反思自身思维
元认知 · 识别偏差 · 修正思维模式

形成新的认知与实践经验
进入下一轮认知训练

这一流程最重要的地方在于，既研究外部世界，也研究自己认识世界的方式。每一轮对话不仅要解决具体问题，还应当尽可能积累可以迁移到其他领域的思维方法。

### 2. 收藏第一个提示词：发现认知盲区
请你跳出人类习以为常的思维框架，以一个相对独立的外部观察者视角，告诉我一个极其重要、看似显而易见，却被绝大多数人忽略的认知。请深入解释：1. 这个认知究竟是什么？
**2. 为什么大多数人无法意识到它？**
**3. 它背后的形成机制是什么？**
**4. 有哪些现实案例可以证明它？**
**5. 有哪些反例或适用条件？**
**6. 如果我真正理解了它，我应该改变哪些行为？**

不要刻意追求反常识和猎奇，而要提供具有逻辑依据、现实价值和长期启发性的观点。

 复制提示词

这个提示词特别适合在没有明确研究主题时使用，帮助自己主动发现值得深入思考的问题，而不是永远局限在已有的知识范围之内。

### 3. 收藏第二个提示词：跨学科拆解事物本质
针对我们刚才讨论的问题，请你分别站在哲学家、生物学家、历史学家、科学家、数学家、艺术家、物理学家和工程师的角度，对其进行深度分析。请说明不同学科能够提供哪些独特的解释，它们之间存在哪些共识、分歧和局限。进一步回答：1. 这个问题的底层逻辑是什么？
**2. 哪些因素是真正的核心变量？**
**3. 哪些现象只是表面结果？**
**4. 普通人最容易产生哪些认知误区？**
**5. 我应该怎样将这些认知应用到现实生活和工作中？**

最后综合各个学科的观点，给出一套具体、可执行、可验证的行动方案。

 复制提示词

不同学科可以提供不同的思维工具：

| 学科视角 | 主要思考方向 |
| --- | --- |
| 哲学 | 底层假设、价值判断、逻辑与本质 |
| 生物学 | 生存机制、进化规律、人类本能 |
| 历史学 | 历史演变、社会规律、周期变化 |
| 科学 | 证据、假设、实验与验证 |
| 数学 | 概率、变量关系、结构与最优化 |
| 艺术 | 感知、情绪、创造力与意义 |
| 物理学 | 基本规律、系统约束、因果机制 |
| 工程学 | 问题拆解、系统设计、实践与迭代 |

不必强行使用所有学科，而应该根据问题的性质，选择真正能够提供有效解释的思维模型。

### 4. 收藏第三个提示词：让AI成为自己的思维审查者
请你完整回顾我们当前对话中的全部交流过程，不要迎合我，而是以客观、严谨的思维教练身份，对我的思考方式进行分析。请重点回答：1. 我的思考模式具有哪些明显特征？
**2. 我的思维优势是什么？**
**3. 我有哪些固有假设和认知盲区？**
**4. 我是否存在逻辑漏洞、确认偏误或其他认知偏差？**
**5. 我忽略了哪些重要问题？**
**6. 哪些思维习惯可能限制我的长期发展？**
**7. 如果一个更成熟的思考者面对同样的问题，他会如何分析？**
**8. 我应该通过哪些具体练习修正自己的思维模式？**

请引用我们对话中的具体内容作为分析依据，区分事实与推测，不要进行缺乏依据的人格判断。
