## 一句话概括
本节课通过 this、that、these、it、here、there 等基础英语词汇，结合人物、身体部位、日常物品和真实生活场景，训练学习者准确指认不同距离、不同数量的对象，并通过可理解性输入、自然拼写和情境化输出，逐步建立英语表达能力，而不是依赖机械抄写和死记硬背。

## 背景与主题
这是 Teacher Eric 主讲的英语30天训练营的第二节课，建立在上一节课学习人称代词和基本位置表达的基础之上。上一节课主要解决“我是谁、你是谁、他是谁、他在哪里”等问题，本节课进一步解决“这个是什么、那个是什么、这些是什么、某个具体对象正在做什么”等问题。
课程从人物指认入手，逐渐扩展到帽子、桌子、手、手指、手机等日常事物，并将名词、指示代词、人称代词、位置副词和动作表达组合起来。老师强调，英语学习应该以“可理解的输入，有目的的运用”为核心，通过反复接触、主动拼写、情境模拟和实际表达，自然形成语言能力，而不是将英语学成一门单纯依赖记忆和考试技巧的学科。

## 核心观点

### 1. 英语学习的重点不是抄写和背诵，而是理解、运用与反复接触
课程开头，Eric 再次提醒学员，要避免过度依赖笔记本和机械抄写的学习方式，不要死记硬背，而应该保持轻松、自然的学习状态，甚至可以泡一杯花茶来享受学习过程。他认为，只要认真听完30分钟的课程，跟随老师完成习题、操练情境，就能够获得实际的语言训练效果。整个训练营的核心理念是“可理解的输入，有目的的运用”，即先理解语言在具体场景中的含义，再主动使用语言完成表达任务。
对于新单词，老师不要求学习者第一次接触就必须记住，而是提出“听一次算一次，听三次记住，听五次运用”的学习思路。其背后的逻辑是，通过多次、有意义的接触，把词汇与具体对象、动作和情境建立联系，使英语从需要刻意回忆的知识，逐渐转变为能够自然调用的语言能力。不过，这里的三次、五次属于教学经验式的说法，并不是适用于所有人的固定记忆规律。

### 2. This 和 that 的本质区别，是说话者与指认对象之间的距离
本节课最基础的知识点，是使用 this（这个）和 that（那个）指认单数对象。老师借助画圈的方式建立空间概念：如果某个人或物品处于说话者附近、属于当前范围，就使用 this；如果对象处于较远的位置或当前范围之外，就使用 that。例如：
- This is a man.（这是一个男人。）
- This is a woman.（这是一个女人。）
- That is a man.（那是一个男人。）
- That is a woman.（那是一个女人。）

老师不断交替呈现不同性别和位置的人物，让学习者真正理解，决定使用 this 还是 that 的关键不是对象的性别、身份或者类别，而是说话者与对象之间的相对距离。这种规则同样适用于 boy（男孩）、girl（女孩）、hat（帽子）、table（桌子）、phone（手机）等其他名词。掌握这一核心规则以后，即使遇到新的名词，也可以直接套入相同的表达结构。

### 3. 将 this、that 与 here、there 组合，可以形成更完整的位置描述
上一节课已经涉及 here（这里）和 there（那里），本节课则将它们与具体名词及指示词组合起来，使学习者从简单指认对象，进阶到描述对象所在的位置。例如：
- This man is here.（这个男人在这里。）
- That man is there.（那个男人在那里。）
- This woman is here.（这个女人在这里。）
- That woman is there.（那个女人在那里。）

这里实际上包含了两个不同的语言功能：this 和 that 用于确定正在谈论的是哪个对象，here 和 there 用于说明该对象所在的位置。老师通过人物在圈内、圈外的变化，让学员同时理解对象的指认和位置描述，并逐渐熟悉“指示限定词＋名词＋be动词＋位置副词”的句型结构。
老师还强调，学习者不要小看这些简单句子，因为它们已经包含了限定、指认、主语、谓语和位置等多个表达要素。这些基础结构虽然不属于严格语法意义上的复杂句，却是未来构建更丰富英语句子的基本组成部分。

### 4. 具体名词与人称代词可以相互衔接，但应根据语境选择
指认一个男性时，可以使用 this man（这个男人）、that man（那个男人），也可以使用 he（他）；指认一个女性时，则可以使用 this woman（这个女人）、that woman（那个女人）或者 she（她）。老师通过反复切换两种表达方式，让学习者意识到，具体名词短语和人称代词在特定语境中可以指向同一个人。

| 明确指认对象 | 使用代词表达 |
| --- | --- |
| This man is here.（这个男人在这里。） | He is here.（他在这里。） |
| That man is there.（那个男人在那里。） | He is there.（他在那里。） |
| This woman is here.（这个女人在这里。） | She is here.（她在这里。） |
| That woman is there.（那个女人在那里。） | She is there.（她在那里。） |

老师指出，究竟应该明确说出 this man，还是直接使用 he，取决于具体情境的表达要求。当谈话双方尚未明确正在讨论哪个人时，使用具体名词短语更加清楚；当对象已经被确认，双方都知道所指的人是谁时，使用代词则更加简洁、自然。课程中的填空练习也体现了这种区别，如果句子只允许填写一个词，就需要考虑使用 he 或 she，而不是由两个词构成的 that woman。
这一知识点不仅涉及代词的使用，更涉及英语表达中的上下文意识：先建立明确的指代对象，再通过代词延续话题，避免不必要的重复。

### 5. 指认非人物对象时，应掌握 it，并区分首次指认与后续描述
当讨论的对象不是男性或女性，而是帽子、手机、桌子等普通物品时，老师引入了 it（它）这一人称代词。与 this、that 相比，it 本身不强调对象距离说话者的远近，主要用于指代已经明确的单数对象。例如：
- It is here.（它在这里。）
- It is there.（它在那里。）
- This is a hat.（这是一顶帽子。）
- It is a hat.（它是一顶帽子。）
- This is a phone.（这是一部手机。）
- It's a phone.（它是一部手机。）
- It's a tool.（它是一种工具。）

老师借助手中的帽子、手以及手机等事物，帮助学习者建立 it 与日常物品之间的联系。在实际交流中，可以先用 This is a phone 明确指出对象，再用 It's a tool 进一步介绍其性质或用途，这样就形成了一段完整、连贯的表达。
需要补充的是，it 并不只用于物品，在英语中还可以指代某些动物、事件、抽象事物，以及用于天气、时间等特殊句型；但本节课为了降低初学者的理解难度，主要讲解它指代单数物品的基本用法。

### 6. 指认对象时不仅要考虑距离，还要考虑单数与复数
课程从手掌过渡到手指时，引入了一个新的指示词 these（这些）。当老师指向一根拇指时，可以说 This is a thumb（这是一根拇指）；当指向其余四根手指时，就需要使用 These are fingers（这些是手指），不能继续使用 this is。
这个例子同时涉及三个语法变化：指示词由 this 变成 these，be动词由 is 变成 are，名词由 finger 变成 fingers。老师特别提醒，很多初学者容易将单数句型直接套用到复数对象上，忽视英语中主语、谓语和名词数量之间的一致性。

### 英语指示词的四种基本组合

| 距离 | 单数 | 复数 |
| --- | --- | --- |
| 近处 | This is... | These are... |
| 远处 | That is... | Those are... |

Those 在本节课结尾被提前提及，正式教学将在后续课程展开。
课程最后，老师还通过全家福照片举例，说明 these 不仅可以指认多个物品，也可以用于介绍多个人，例如 These are my children（这些是我的孩子）和 These are my parents（这两位是我的父母）。由此建立起一个完整的判断框架：先判断远近，再判断单复数，最后选择正确的指示词和句型。

### 7. 学习单词拼写时，应建立字母、发音与词汇之间的联系
老师在讲解 hat、table、hand、thumb、finger 等词汇时，并没有要求学员单独抄写单词表，而是尝试让大家根据听到的声音推导出单词的拼写。例如，听到 hand（手）的发音后，尝试拼出 h-a-n-d；学习 finger（手指）以后，再理解复数形式 fingers 为什么需要增加 s。
Eric 认为，掌握26个英文字母及其常见发音规律，比单纯记忆音标更重要，并建议成年人、儿童以及经常拼错单词的学习者，在遇到拼写困难时回归单词的实际读音。他还以自己的童年学习经历为例，表示自己没有专门学习音标或者某种发音体系，而是在不断尝试拼写的过程中逐渐掌握了英语单词的拼写。
老师提出，英语拼写和发音在大部分情况下能够对应，并给出了“90%的情况是对得上”的经验性判断；对于无法直接对应的词，他认为可以通过后续的自我修正进行学习。他也提到了英语漫长的语言演变历史：部分单词的读音随着时代发生变化，而拼写保留了较早时期的语言痕迹。
这种方法与 Phonics（自然拼读）的部分理念相近，但不能简单地理解为只要会读就一定会拼。英语还存在不发音字母、多种字母组合对应同一音素等情况，例如 thumb 中的 b 不发音，正是自然拼写需要额外注意的例子。

### 8. 从指认对象进阶到描述动作，才能真正形成实战表达能力
当学习者掌握了 this、that 与具体名词的组合后，老师进一步加入动作表达，使句子不再停留在“这是什么”和“他在哪里”的层面，而是能够回答“这个对象正在做什么”。课程中最重要的两个动作场景是手拿着一支笔，以及一个男人正在读书。
第一个场景中，一只靠近说话者的手正在握着笔，因此可以说 This hand is holding a pen（这只手正握着一支笔）。第二个场景中，一个距离说话者较远的男人正在读书，因此可以说 That man is reading a book（那个男人正在读一本书）。
这两个句子实际上已经涉及 Present Continuous Tense（现在进行时），即使用 be 动词加动词的 -ing 形式，描述正在发生的动作。老师没有先展开复杂的语法定义，而是让学习者直接观察情境、识别对象、判断距离，然后自然地表达正在发生的事情。
老师还认为，考试在很大程度上是将实际情境转化为文字形式；如果学习者拥有较强的真实场景表达能力，就不必将应付考试作为唯一训练目标。其教学逻辑是先获得语言能力，再将这种能力迁移到阅读、填空、写作和考试任务之中。

### 9. 最有效的练习场景就在日常生活中，不需要额外准备复杂教材
课程最后安排了一个桌面物品指认练习，要求学员利用自己附近的餐桌、办公桌或者工作台进行场景模拟。老师建议重点使用 This is...、It is... 和 These are... 三类句型，观察身边实际存在的物品，并尝试用英语介绍它们。
例如，拿起自己的手机时，可以说 This is a phone，接着说 It's a phone 或 It's a tool；如果桌上摆放着一张全家福，可以指着照片中的孩子或父母，说 These are my children 或 These are my parents。如果桌子较大，或者某个手机放在另一张桌子上，就可以尝试使用 That is a phone（那是一部手机）。
这一练习将英语学习从教材和课堂转移到了学习者自己的生活环境中，让每件看得见、摸得着的物品都成为可以训练的语言素材。老师最后使用 Practice makes perfect（熟能生巧）来强调，真正的语言能力来自反复实践，而不是仅仅知道句型规则或者记住单词的中文含义。

### 四、核心句型与完整例句
句型一：This is a/an + 单数名词——指认近处的一个对象。

| 英文例句 | 中文翻译 |
| --- | --- |
| This is a man. | 这是一个男人。 |
| This is a woman. | 这是一个女人。 |
| This is a hat. | 这是一顶帽子。 |
| This is a table. | 这是一张桌子。 |
| This is a hand. | 这是一只手。 |
| This is a thumb. | 这是一根拇指。 |
| This is a phone. | 这是一部手机。 |
| This is my hand. | 这是我的手。 |
| This is the thumb. | 这是拇指。 |

句型二：That is a/an + 单数名词——指认远处的一个对象。

| 英文例句 | 中文翻译 |
| --- | --- |
| That is a man. | 那是一个男人。 |
| That is a woman. | 那是一个女人。 |
| That is a hat. | 那是一顶帽子。 |
| That is a thumb. | 那是一根拇指。 |
| That is a phone. | 那是一部手机。 |
| That's a pen. | 那是一支笔。 |

句型三：These are + 复数名词——指认近处的多个对象。

| 英文例句 | 中文翻译 |
| --- | --- |
| These are fingers. | 这些是手指。 |
| These are the fingers. | 这些就是手指。 |
| These are my children. | 这些是我的孩子。 |
| These are my parents. | 这两位是我的父母。 |

句型四：It is / It's + 名词或位置——描述已经明确的单数对象。

| 英文例句 | 中文翻译 |
| --- | --- |
| It is here. | 它在这里。 |
| It is there. | 它在那里。 |
| It is a hat. | 它是一顶帽子。 |
| It is my hand. | 它是我的手。 |
| It's a phone. | 它是一部手机。 |
| It's a tool. | 它是一种工具。 |

句型五：This/That + 名词 + is + here/there——描述具体对象的位置。

| 英文例句 | 中文翻译 |
| --- | --- |
| This man is here. | 这个男人在这里。 |
| That man is there. | 那个男人在那里。 |
| This woman is here. | 这个女人在这里。 |
| That woman is there. | 那个女人在那里。 |
| He is here. | 他在这里。 |
| He is there. | 他在那里。 |
| She is here. | 她在这里。 |
| She is there. | 她在那里。 |

句型六：具体对象 + is + 动词-ing——描述正在发生的动作。

| 英文例句 | 中文翻译 |
| --- | --- |
| This hand is holding a pen. | 这只手正握着一支笔。 |
| The hand is holding a pen. | 这只手正握着一支笔。 |
| That man is reading a book. | 那个男人正在读一本书。 |
| He is reading a book. | 他正在读一本书。 |

| 教学案例 | 场景设置 | 训练目标 |
| --- | --- | --- |
| 圈内与圈外的人物 | 男性或女性出现在不同距离的位置 | 区分 this 和 that |
| 男人与女人的位置 | 人物在说话者附近或远处 | 组合 this、that、here、there |
| 男孩与女孩 | 替换原有的人物名词 | 验证句型的通用性 |
| 老师展示帽子 | 手中拿着一顶帽子 | 练习 this、that、it |
| 桌子拼写 | 根据单词读音尝试拼写 table | 建立发音与字母的联系 |
| 手掌与拇指 | 指向自己的手和拇指 | 学习 hand、thumb |
| 其余四根手指 | 同时指认多个手指 | 学习 these、are、fingers |
| 人物代词填空 | 用一个单词代替具体人物 | 区分 he 和 she |
| 手握着笔 | 描述一只手正在握笔 | 学习 holding a pen |
| 男人正在读书 | 描述远处人物的行为 | 学习 reading a book |

| 客厅餐桌、办公桌 | 利用现实环境自主表达 | 实现课堂知识向生活场景迁移 |

### 六、本节课最容易出现的错误

| 错误表达 | 正确表达 | 错误原因 |
| --- | --- | --- |
| This is four fingers. | These are four fingers. | 多个对象不能使用单数指示词 this |
| These is fingers. | These are fingers. | these 应搭配 are |
| These are finger. | These are fingers. | 名词需要使用复数形式 |
| This is phone. | This is a phone. | 单数可数名词通常需要限定词 |
| That man are there. | That man is there. | 单数主语应搭配 is |
| She is a man. | He is a man. | 人称代词与指代对象不匹配 |
| That man is read a book. | That man is reading a book. | 现在进行时需要使用动词-ing形式 |
| Thamb | Thumb | 不能完全按照听感推断拼写 |
| It is my parents. | These are my parents. | 父母属于多个指认对象 |

其中，单复数搭配错误是本节课最值得关注的问题。学习者不能只记住 this 和 these 的中文意思，还需要同时调整 be 动词和名词形式。

## 金句摘录
**1. 关于英语学习的核心原则**
“可理解的输入，有目的的运用。”

这是整节课最重要的教学理念。语言输入必须能够被学习者理解，而输出则需要服务于真实的表达目的，不能只是无意义地重复句子。
**2. 关于放松学习心态**
“不要去死记硬背，放松心情，泡一杯花茶，好好享受这个过程。”

老师试图降低学习者面对英语时的心理压力，强调持续学习的体验比一次性记忆大量知识更加重要。
**3. 关于词汇的自然积累**
“听一次算一次，听三次记住，听五次运用。这辈子就不会忘了。”

这句话体现了老师对反复接触、自然吸收和实际运用的重视。不过，具体重复次数及长期记忆效果因人而异，不宜将其理解为严格的记忆定律。
**4. 关于单词拼写的学习方法**
“我建议大家在学拼写的时候，不论是孩子还是自己，还是后续你经常拼错词，回归到读音去修正自己。”

通过发音寻找字母及字母组合的规律，再根据正确拼写修正错误，可以减少完全依赖机械记忆的情况。
**5. 关于英语能力与考试的关系**
“考试无非也就是把情境转成文字。所以当你的实战能力强的时候，你就不会专门把考试当做一个训练目的。”

老师认为，考试应该是检验语言能力的一种方式，而不应成为英语学习的唯一目的。真实场景中的理解和表达能力，才是更值得长期培养的基础。
**6. 关于持续实践的重要性**
“Practice makes perfect.”
中文翻译：熟能生巧。

只有不断在不同场景中使用相同的基础词汇与句型，才能逐渐减少思考和翻译的时间，形成更加自然的英语表达习惯。

## 值得记住的点 / 行动建议

### 1. 建立“距离＋数量”的对象指认思维模型
学习 this、that、these、those 时，不要把四个单词孤立地背下来，而应该建立两个判断维度：
第一，目标对象离自己近还是远；第二，目标对象是一个还是多个。

### 对象指认练习器
切换对象的距离、数量和类型，观察英文句型如何变化。对象距离
近处远处

对象数量
一个多个

指认对象手机 phone

# This is a phone.
这是一部手机。
This（指示词）＋ is（be 动词）＋ phone（单数名词） 复制例句
经过反复训练以后，看到近处的一个物品，就应该能够自然地想到 This is...；看到远处的多个物品，则想到 Those are...。这种直接建立情境与英语之间联系的方法，比先在脑海中组织完整中文句子再逐词翻译更接近实际交流过程。

### 2. 每天利用桌面物品进行5分钟英语口语训练
不需要专门购买教材或者寻找复杂的英语练习材料，可以直接利用自己家中的餐桌、书桌、办公桌进行训练。
第一轮，指认距离自己较近的单数物品：
- This is a phone.（这是一部手机。）
- This is a pen.（这是一支笔。）
- This is a book.（这是一本书。）
- This is a cup.（这是一个杯子。）

第二轮，指认距离自己较远的单数物品，例如 That is a chair（那是一把椅子）或 That is a table（那是一张桌子）。
第三轮，寻找多个同类物品，使用 These are books（这些是书）、These are pens（这些是笔）等复数表达。
第四轮，在指认对象的基础上增加位置描述、属性描述或者用途描述，例如先说 This is a phone（这是一部手机），再说 It is here（它在这里）或 It's a tool（它是一种工具）。
建议同一个对象至少尝试两种表达方式，并通过移动物品的位置改变 this 和 that 的使用条件，让练习具有真实的情境变化，而不是单纯背诵固定答案。

### 3. 养成“先明确对象，再使用代词”的表达习惯
在练习英语时，可以有意识地使用两句话完成一段表达：第一句话明确对象，第二句话使用代词补充信息。
例如：

| 第一句：明确对象 | 第二句：延续话题 |
| --- | --- |
| This is a man.（这是一个男人。） | He is here.（他在这里。） |
| That is a woman.（那是一个女人。） | She is there.（她在那里。） |
| This is a phone.（这是一部手机。） | It is a tool.（它是一种工具。） |
| That is a man.（那是一个男人。） | He is reading a book.（他正在读书。） |
| These are my parents.（这是我的父母。） | They are here.（他们在这里。） |

这种练习可以同时解决两个问题：一是帮助学习者理解 he、she、it、they 的实际指代对象；二是避免每句话都重复相同的名词，使英语表达更加连贯自然。
尤其需要注意的是，代词并不是单纯根据中文的“他、她、它”来选择，而应该结合上下文、指代对象和单复数情况来判断。

### 4. 将单数和复数的变化作为一个整体学习
很多英语初学者的问题不是完全不知道单词，而是知道每个单词，却无法将它们按照正确的语法关系组合起来。
例如，学习者可能知道 this、these、finger 的含义，但面对四根手指时，却说出 This is four fingers 这样的错误句子。
正确的训练方式是将三个变化绑定在一起记忆：

训练时不要只替换一个单词，而应该进行完整的句型转换，例如从 This is a book 转换为 These are books，从 That is a man 转换为 Those are men。
通过这种方式，可以逐渐培养英语中的语法一致性意识，同时自然积累规则复数与不规则复数的知识。

### 5. 使用“听音—尝试拼写—核对—修正”的词汇学习流程
Eric 提出的自然拼写思路，可以整理为一个可实际操作的词汇学习流程。
第一步：听清单词发音
例如 hand，不急于查看拼写。
第二步：分析声音与字母的对应关系
尝试识别 /h/、/æ/、/n/、/d/。
第三步：主动尝试拼写
h - a - n - d

第四步：核对标准拼写
发现错误，分析是发音问题还是拼写规则问题。
第五步：放回句子中运用
This is my hand.

这种方法与直接抄写20遍、50遍单词不同，它要求学习者主动分析单词的声音结构，并利用反馈修正自己的错误。
实际学习时，可以先从 hand、hat、pen 等拼写相对简单的词开始，再过渡到 table、phone、thumb 等含有特殊字母组合或不发音字母的单词。遇到不规则拼写时，应结合词典、标准发音和针对性记忆，而不是强行用简单的字母发音规律解释所有单词。

### 6. 不要孤立背单词，而要把单词放入完整的句子中
例如，学习 hand 这个单词时，如果只是背诵 hand 等于“手”，那么获得的主要是单词识别能力；如果能够围绕 hand 进行多种表达，才更容易形成主动调用词汇的能力。
可以按照以下层次逐步增加表达内容：

| 训练层次 | 例句 | 获得的能力 |
| --- | --- | --- |
| 第一层 | Hand. | 识别单词 |
| 第二层 | This is a hand. | 指认对象 |
| 第三层 | This is my hand. | 表达所属关系 |
| 第四层 | My hand is here. | 描述位置 |
| 第五层 | My hand is holding a pen. | 描述动作 |
| 第六层 | I am holding a pen. | 从人物角度表达动作 |

同样，学习 book 时，也不应只停留在“书”的中文含义上，而可以依次练习 This is a book、That is a book、These are books、He is reading a book 等句子。
真正有用的词汇量，不仅是能够认出多少单词，更是能够在实际表达中主动使用多少单词。

### 7. 从简单指认逐步过渡到描述动作，不必一开始就学习大量复杂语法
可以将语言表达能力的提升分成四个阶段。

## 1

知道对象是什么
This is a man.
这是一个男人。

## 2

知道对象在哪里
That man is there.
那个男人在那里。

## 3

使用代词指代对象
He is there.
他在那里。

## 4

描述对象正在做什么
He is reading a book.
他正在读一本书。

这个过程体现了语言能力的逐层构建：从名词到指认，从指认到位置，从位置到动作，再从单句到连续表达。
对于基础薄弱的学习者，与其一开始就研究大量时态、从句和复杂语法，不如先把这些能够覆盖大量日常场景的基本句型练熟。等到能够自然使用以后，再系统理解背后的语法规则，会更容易将理论知识与实际语言经验结合起来。

### 8. 将全家福、照片和现实人物变成英语学习材料
老师在课程末尾举出的全家福案例非常实用，因为照片中的人物都是学习者已经熟悉的人，不需要额外理解背景信息，可以将注意力集中在英语表达上。

## 我的点评
这节课最大的价值在于，它没有把英语入门变成孤立的词汇背诵和语法规则记忆，而是通过距离、数量、位置、动作等直观概念，将语言与真实世界建立联系，这与情境化学习、可理解性输入以及主动输出等语言学习理念具有较高的一致性。尤其值得认同的是，老师使用手指、帽子、手机和全家福等日常事物，将 this、that、these、it、he、she 等基础词汇组合成能够直接使用的句子，这对于英语基础薄弱、认识单词却不会开口的人非常有帮助。
不过，老师关于“音标不重要”“90%的拼写与发音能够对应”“听五次运用就一辈子不会忘记”等说法存在一定程度的简化，英文字母名称、字母实际发音、音素、自然拼读规则和国际音标并不是完全相同的概念，学习者仍然需要根据自身情况补充系统知识。另外，真实情境表达能力虽然能够帮助考试，但考试还涉及阅读速度、书面语法、题型要求等专项能力，因此不能认为日常口语训练可以完全替代考试训练。
普通学习者最值得借鉴的做法，是以真实情境为主线，将单词、语法、发音和表达能力放在同一个学习过程中，同时保留必要的规则学习、标准发音核对、间隔复习和主动回忆。本节课真正值得长期坚持的原则，不是完全不做笔记、不背单词、不学语法，而是不让笔记、背诵和语法知识取代实际的语言运用。
