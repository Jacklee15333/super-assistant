## 一句话概括
Remotion 并不是一个直接生成视频的 AI 工具，而是一套能够将代码转化为可视化视频动画的技术框架，通过结合 GPT、Claude 等大模型以及各种视觉开发库，普通创作者可以大幅降低高质量动画的制作成本，并逐步建立属于自己的、可复用、可积累、可精准控制的 AI 视频生产工作流。

## 背景与主题
随着 AI 视频制作的兴起，Remotion 受到越来越多内容创作者和科技博主的关注，但很多人并不清楚它的实际定位、能力边界以及具体使用方法，甚至误以为它本身就是一个 AI 视频生成工具。
视频作者 RK 是一位专注于动画、科普和 AI 的创作者，近期六期视频中的动画全部使用 GPT 与 Remotion 结合制作，并在实践过程中探索出了自己的动画制作工作流。
作者从实际制作案例出发，介绍了 Remotion 的底层工作原理、与传统视频制作软件的区别、高阶动画的实现方式，以及如何利用 AI 建立个人动画素材库。
视频真正想传达的，不只是如何使用一个新工具，而是如何借助大模型和已有的软件开发生态，重新构建视频创作的生产方式，将更多时间与精力投入创意本身。

## 核心观点

### 1. Remotion 是一个可以本地部署、高度定制的视频制作框架
Remotion 在 GitHub 上拥有自己的官方代码仓库，源码公开，按照官方许可规定，符合条件的个人创作者可以免费使用。官方还提供了一套用于视频制作的 Skill（技能指令集），方便 AI Agent（智能体）理解和使用 Remotion 的相关功能。
作者强烈建议创作者将 Remotion 部署到自己的电脑上，而不是仅仅使用其他人已经封装好的工具，因为本地部署意味着可以根据自己的实际需求，让 AI Agent 直接修改工程代码、扩展功能。
例如，前段时间许多科技博主分享的 AI 视频编辑台，其实就可以通过这种方式快速搭建出来，并没有想象中那么高的技术门槛。
作者由此提出一个关于 AI 时代工具发展的判断：当某种产品或功能在短时间内被大量创作者制作出来时，背后的实现门槛往往已经大幅降低。
很多看起来复杂的新产品，本质上只是已有技术的重新组合，真正的壁垒可能仅仅是信息差。

### 2. Remotion 不是 AI 视频生成工具，而是大模型手里的剪映
理解 Remotion 的关键，在于区分内容生成与内容渲染这两件事。
Remotion 本身并不具备自动理解创作需求、设计画面或生成视频内容的能力，真正负责这些工作的是大模型，大模型根据用户的要求编写相应的程序代码。
Remotion 则负责运行这些代码，将其转化为一帧一帧的画面，并提供视频预览、时间轴定位、逐帧检查和最终导出等功能。
作者给出了一个非常形象的类比：大模型相当于坐在电脑前制作视频的人，而 Remotion 相当于这个人手里的剪映。
因此，同样的提示词、同样的 Remotion 环境，使用不同的大模型仍然可能得到质量差距很大的视频作品，因为动画设计、代码编写和审美判断等核心能力，仍然主要取决于模型本身。

### 3. Remotion 不是 AI 时代才出现的产品，而是恰好与 AI 高度适配
Remotion 这个项目早在 2021 年就已经出现，最初开发出来是为了服务人类开发者，而不是专门为大语言模型设计的。
这也解释了为什么 Remotion 会提供可视化预览、时间轴以及逐帧检查等功能，即使大模型能够直接理解代码，人类创作者依然需要通过视觉界面判断最终效果。
随着大模型的代码生成能力快速提升，原来需要程序员手工编写的视频动画代码，现在可以大量交给 AI 完成。
Remotion 原本以代码为核心的视频制作方式，因此天然适合与大模型结合。
这也是 AI 时代一个值得关注的技术发展方向：许多成熟的传统工具并不需要被重新发明，只需要通过 AI 降低使用门槛，就能够释放出巨大的新价值。

### 4. AI + Remotion 大幅降低了高质量动画的制作成本
作者最近六期视频中的动画，全部使用 GPT 与 Remotion 结合完成。
按照作者过去的制作经验，如果使用 Adobe After Effects（简称 AE）制作同等类型的动画，仅一期视频的动画制作就至少需要七八个小时，而且 AE 对电脑硬件配置、个人专业技能和软件熟练程度都有一定要求。
而现在，创作者可以使用相对简单的自然语言提示词，在电脑配置要求相对较低、学习成本较低的情况下，制作出品质相当不错的动画。
这种变化不仅意味着生产效率的提升，也意味着创作者可以将原本用于处理关键帧、调整参数和重复操作的时间，转移到更高阶的动画与视觉创意探索上。
作者甚至表示，这种制作方式让自己重新找到了久违的创作乐趣，因为过去那些费时费力、容易劝退自己的技术实现工作，现在可以大量交给 AI。

### 5. Remotion 并不局限于简单动画，也能够实现高阶视觉效果
很多人可能认为，AI 通过代码制作的视频，只能完成文字移动、图形缩放、简单转场等基础动画，但作者通过自己的实践证明，这种理解低估了它的能力。
作者平时有收集设计灵感的习惯，有一次看到了一张具有视觉美感的旗帜图片，于是突发奇想，将图片交给 GPT，要求它利用 Remotion 模拟布料的运动效果。
起初作者并没有抱太大期待，但没过多久，GPT 就展示出了令他非常惊讶的旗帜动画。
在验证技术可行性后，作者进一步想到，自己可以按照特定的视觉风格设计旗帜，再让 AI 将静态设计转化为具有动态质感的画面，从而实现艺术风格与内容表达的结合。
这个案例说明，代码驱动的视频制作不仅能够完成基础动态图形，还能够借助合适的算法和开发库实现布料运动、三维场景、粒子效果等复杂视觉表现。

### 6. 建立个人动画库，让每一次创作都成为可以积累的数字资产
作者认为，如果每次创作都依靠人工收集灵感，然后等待某一次突发奇想，再去测试 AI 能否实现，那么整个创作流程依然不够高效。
因此，他让 GPT 帮自己搭建了一个专门用于管理动画的网页，将自己的动画资产、历史作品和外部优秀案例集中起来。
这个动画库主要分为三个板块：常用动画效果、自己制作过的视频，以及收集来的优秀动画。
其中，常用动画可以直接复用，历史作品可以帮助大模型了解创作者的制作习惯和视觉偏好，外部优秀动画则能够在创意阶段提供参考。
这种做法实际上是将个人的审美、经验与技术成果逐步沉淀为一套可持续增长的知识资产，使后续创作不必每次都从零开始。

### 7. 将优秀动画的收集、复刻、修改与归档变成一套自动化工作流
为了进一步提高动画素材的收集和复用效率，作者专门开发了一个能够根据短视频链接下载视频的工具。
当他在短视频平台上看到一个优秀的动画作品时，只需要将对应的视频链接提供给工具，工具就会下载原始视频，再交给 GPT 分析和复刻其中的动画效果。
完成初步复刻后，GPT 会将制作效果展示给作者，作者可以继续提出修改意见，让 AI 不断调整，直到达到自己的要求。
最后，作者将满意的动画效果保存到个人动画库中，使其成为可以在未来项目中反复调用的动画资产。
而这个视频下载工具本身也不是什么高门槛的原创技术，因为 GitHub 上早已有大量相关开源项目，作者所做的主要是将几个口碑较好的工具整合起来，再通过 AI Agent 完成定制化开发。

### 8. 不同大模型的审美和创作能力存在差异，但复刻与原创是两种不同的任务
作者特别强调，即使使用完全相同的提示词和 Remotion 框架，不同大模型也会表现出明显不同的视频制作能力。
在作者的个人使用体验中，Claude Opus 系列模型在视觉审美和原创动画制作方面表现突出，甚至可以说是独一档的存在。
相比之下，作者认为 GPT 的原创审美能力可能不如 Opus，但在已经拥有明确参考案例的情况下，GPT 完全能够胜任动画复刻工作。
这是因为原创任务需要模型同时解决审美判断、创意设计、视觉构图、运动节奏与代码实现等多个问题，而复刻任务已经有了较为明确的目标，大模型主要负责分析和技术实现。
因此，创作者不必要求一个模型解决所有问题，而是可以针对不同的生产环节，选择更适合该任务的大模型，或者通过提供优质参考，弥补模型自身审美能力的不足。

### 9. 真正拓展 Remotion 能力边界的，是成熟的 JavaScript 开发库生态
Remotion 之所以能够实现三维动画、粒子效果、复杂图形和数据可视化，并不意味着它本身内置了所有这些功能，而是因为大模型在编写代码时，可以调用大量已经成熟的第三方开发库（Library）。
所谓开发库，就是其他开发者已经编写好的一整套代码和功能，使用者不需要从零开始实现底层技术，而是可以直接调用这些现成的能力。
例如，Three.js 已经准备好了大量三维绘制工具，大模型只需要通过代码创建三维物体和场景，为其设置材质、灯光、摄像机以及运动方式，就能够实现复杂的三维视觉效果。
作者将大模型与 Three.js 的关系，类比为人类创作者与 Blender 三维制作软件之间的关系：一个负责设计和操作，另一个提供实现这些设计的工具。
除此之外，还有 GSAP、Rough.js、D3.js 等成熟的视觉开发库，只要能够合理组合这些工具，创作者就可以制作出更加丰富、精准且可控的视频动画。

**1. 关于 AI 时代的信息差**
我总说，短期内成批量冒出来的东西，门槛肯定很低，往往就是一个信息差的事。

**2. 关于 Remotion 的本质**
Remotion 并不是一个视频生成工具，这意味着它不具备自动生成视频的能力，生成或者绘制视频，本质上靠的还是大模型。

**3. 关于大模型与 Remotion 的关系**
咱们可以把大模型想象成坐在电脑前做视频的人，把 Remotion 想象成他手里的剪映。

**4. 关于传统技术与 AI 的结合**
它本身开发出来就是给人用的，只不过现在 AI 突然崛起，而它也非常适配 AI，所以很容易让人以为它是纯 AI 时代的产物。

**5. 关于 AI 对创作体验的改善**
现在完全可以用相对简单的提示词，在电脑配置一般、较低学习成本的情况下，做出品质非常不错的动画。

**6. 关于复用成熟技术的价值**
库就是别人已经写好的一套代码，里面的功能咱们可以直接拿来用。

## 值得记住的点 / 行动建议

### 1. 优先学习如何驾驭 AI 视频制作工具，而不是从零学习所有专业技能
过去，想要制作专业的动画，往往需要花费大量时间学习 AE、Blender 等复杂的软件，掌握关键帧、运动曲线、材质、渲染等技术知识。
现在可以先从自己想要实现的视觉效果出发，让 AI 负责选择合适的技术方案，再通过不断预览、修改和反馈完成作品。
创作者需要优先培养的能力包括：
- 准确描述自己想要的画面。
- 判断动画的审美质量。
- 理解画面的运动节奏。
- 收集和筛选优质参考案例。
- 将复杂的创意拆解为具体制作任务。
- 对 AI 生成的结果提出明确的修改意见。

当技术执行的成本下降之后，发现问题、定义需求和判断结果的能力就变得更加重要。

### 2. 在本地搭建自己的 AI 视频制作环境
与其不断寻找别人开发好的 AI 视频工具，不如尝试建立一套自己可以随时修改和扩展的制作环境。
可以从以下官方项目和技术资源入手：

| 工具 | 官方地址 |
| --- | --- |
| Remotion | remotion.dev |
| Remotion 源码 | GitHub - Remotion |
| Three.js | threejs.org |
| GSAP | gsap.com |
| Rough.js | roughjs.com |
| D3.js | d3js.org |
| Blender | blender.org |

安装和配置工作可以交给具备代码执行能力的 AI Agent，再让它根据自己的制作需求逐步增加视频预览、动画组件管理、参数调整、素材导入和视频导出等功能。
不必一开始就开发一个完整的剪映替代品，可以先解决一个小问题，再慢慢扩大工具的功能范围。

### 3. 根据想要实现的视觉效果，主动让大模型调用合适的开发库
在使用 AI 制作动画的时候，可以有意识地指定成熟的技术工具，而不是只告诉 AI“帮我做一个高级的动画”。

| 想实现的效果 | 可以尝试的技术 |
| --- | --- |
| 三维旋转产品展示 | Three.js |
| 地球与行星运动 | Three.js |
| 三维粒子流动 | Three.js |
| 旗帜飘动、布料模拟 | Three.js + 顶点变形等算法 |
| 文字逐个出现 | Remotion / GSAP |
| 多元素有序入场 | GSAP |
| 手绘科普动画 | Rough.js |
| 思维导图、草图风格示意图 | Rough.js |
| 动态柱状图 | D3.js |
| 人口、经济、金融数据展示 | D3.js |
| 抽象概念的视觉化表达 | 多种开发库组合 |

这些开发库相当于给大模型增加了大量现成的专业工具，让 AI 不必重新发明底层技术。
当然，制作复杂动画时，还需要让 AI 注意动画与 Remotion 帧数之间的同步关系，确保预览和导出的结果一致。

### 4. 学会通过自然语言描述高质量动画的制作要求
不要只给大模型下达“做得高级一点”“做一个震撼的动画”之类模糊的指令，而是尽可能明确画面内容、视觉风格、动画时长、运动规律、色彩搭配和具体用途。
例如，下面是一份根据作者旗帜案例延伸设计的提示词，可以作为实际测试的起点。

写作

请使用 Remotion 和 Three.js 帮我制作一段具有高级视觉质感的旗帜飘动动画。
具体要求：
- 视频尺寸：1920 × 1080。
- 帧率：30 FPS。
- 动画时长：8 秒。
- 使用我提供的旗帜图片作为纹理参考。
- 模拟自然风吹动布料的视觉效果。
- 旗帜表面需要有自然的褶皱、光影与起伏变化。
- 设置柔和但具有立体感的灯光。
- 摄像机缓慢推进，增强空间感。
- 整体风格简洁、克制，具有电影质感。
- 将动画设计为可复用的组件。
- 将风速、颜色、光照、摄像机位置和动画时长设置为可修改参数。
- 所有动画进度应与 Remotion 的当前帧同步，确保预览与最终渲染一致。

先完成一个可以预览的版本，展示效果后，再根据我的反馈进行调整。

这样的提示词比简单要求 AI 制作旗帜动画更有效，因为它不仅明确了目标，还考虑到了后期修改与长期复用。

### 5. 搭建属于自己的动画素材库，让创作产生复利效应
作者的个人动画库是整期视频中非常具有长期价值的实践。
传统的视频制作往往是项目制的，一个项目完成之后，其中的动画、设计经验和技术方案可能就被遗忘了。而通过建立动画库，每制作一个视频，都可以为未来的视频积累新的生产工具。
个人动画库可以逐步增加以下内容：
- 文字动画组件。
- 视频开场与结尾组件。
- 标题与字幕设计。
- 动态统计图表。
- 三维物体展示动画。
- 粒子特效与动态背景。
- 转场效果。
- 手绘科普动画。
- 常用配色与字体方案。
- 优秀参考视频及其实现代码。
- 自己过去视频的完整工程文件。

保存动画时，不仅可以保存成品，还应该保存源代码、预览图、提示词、可调整参数和使用说明。
