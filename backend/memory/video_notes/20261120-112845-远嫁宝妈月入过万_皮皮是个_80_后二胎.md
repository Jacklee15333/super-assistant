# 远嫁宝妈月入过万 皮皮是个 80 后二胎宝妈，从贵州远嫁到了山东。 
从小当留守儿童，7 岁就一个人提着煤油灯做饭睡觉。家里老二不受待见，身上有极严重的“不配得感”：借给人家的钱不敢要还，结婚连彩礼都不敢提，在娘家和婆家全都是透明人。 
不想一辈子当牛马，她听了句“做个小闭环”，辞职跑去摆摊。40 度大热天，买菜洗切卤出摊全自己扛，从早忙到半夜，累死累活却根本不赚钱。 
后来她转去干直播卖黄豆。 
起步难得要命：刚开播就违规封禁，第一个月天天播几个小时，总共才卖出 14 单。换别人早不干了，她咬着牙从山东跑回贵州老家。大雪天里，别人生火烤火，她一个人站在冰天雪地里开播，邻居站在屋檐下像看戏一样看她笑话。 
熬过去，就是另一片天地。 
第二个月单日卖出 78 单，三四个月直接冲进月入五位数，成了素人带货榜第一，后来还带着一群老伙计破万。现场讲起豆子，没有套路，全是对产品实打实的体验与真诚。 
很多普通人一辈子卡在“不配得感”里，总觉得自己不行，连伸手去要都不敢。 
你不敢要，就只能一辈子躲在阴暗角落。 
走出来，认准一件小事听话照做。你先学会爱自己，生活才会给你好脸色。
