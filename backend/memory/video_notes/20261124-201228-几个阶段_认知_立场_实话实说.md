## 背景与主题

作者站在中国国家利益、历史经历和国家实力变化的角度，认为理解国际关系不能只看外交表态、合作规模或者阶段性的舆论变化，更应该关注各方的战略动机、实际行为及其历史背景。

## 核心观点

### 1. 三里的核心观点：中美关系存在明显的历史阶段，民众态度随国家关系变化而变化
三里认为，从清末民初到今天，中国社会对美国的认知并非一成不变，而是随着两国外交关系、国际形势以及国家战略的变化而不断调整。他将民国初年视为对美国相对陌生、向往的时期，将1927年以后视为友好时期，将第二次世界大战期间视为同盟时期，而1949年新中国成立及1950年朝鲜战争爆发后，则进入敌对时期。1971年基辛格访华、中美关系正常化及改革开放，又使两国关系逐渐缓和，2001年至2008年前后则被他视为关系较好的阶段。2016年前后经济摩擦加剧、2018年中美贸易战爆发后，美国在不少中国人心目中重新成为敌对对象。三里由此得出结论：绝大多数普通人在看待美国时，往往受到国家立场、社会环境和整体舆论的影响，连麦者母亲反感美国，并不是一种孤立的个人现象。
三里的阶段划分大致如下：

| 历史阶段 | 三里对美国形象的概括 |
| --- | --- |
| 清末民初 | 遥远、富裕、发达的国家 |
| 1927年以后 | 友好国家 |
| 第二次世界大战期间 | 坚定的盟友 |
| 1949—1970年代初 | 敌对国家 |
| 1971年以后 | 关系缓和，但仍存在竞争 |
| 改革开放以后 | 合作增加，关系进一步改善 |
| 2001—2008年前后 | 关系相对较好的时期 |
| 2016年以后 | 经济摩擦逐步加剧 |
| 2018年以后 | 贸易冲突扩大，敌对认知上升 |

这张表反映的是三里在视频中的划分方式，并不代表各历史时期的中美关系只有单一性质。

### 2. 作者反对中美关系阶段论，认为国家利益博弈才是贯穿历史的主线
作者不认同以“友好国家”“坚定盟友”“敌对国家”等标签概括不同时期的中美关系，认为这些标签容易掩盖外交关系背后的利益交换与战略动机。他认为，国家之间的合作并不意味着双方不存在利益冲突，国家之间的竞争也不意味着所有合作都会停止。即使在外界普遍认为中美关系较好的时期，美国也曾采取被中方视为损害中国利益的行动；同样，即使在贸易战和科技竞争加剧的时期，中美之间依然存在大量经贸往来。作者因此提出，中美关系的底层逻辑一直没有发生根本改变，变化的主要是双方的国家实力、利益分配方式以及实现战略目标的手段。用他自己的话来说，所谓的阶段，更多是“老美霸权的策略调整”，而非国家关系在真正的友好与敌对之间反复切换。
双方最根本的分歧是：三里强调国际关系在不同时期呈现出的主要特征，作者则强调贯穿不同时期的利益逻辑与权力结构。

### 3. 清末民初的中美关系不能只从教育、医疗和外交合作的角度理解
针对三里提出的“1927年以后美国成为友好国家”，作者首先回顾了清末民初美国参与的一系列对华行动，包括1900年八国联军侵华、1901年《辛丑条约》以及1927年的南京事件。他认为，美国是中国近代屈辱历史的直接参与者之一，因此不能仅凭美国在中国创办医院、学校以及支持某些政治力量，就简单认定其对中国友好。对于美国在医疗、教育和文化领域的活动，作者更倾向于从扩大影响力、培养亲美力量以及维护自身利益的角度进行解释。作者还质疑，如果美国扶持当时中国的某些政治人物或政治力量就能被认定为友好，那么这种评价究竟是站在中国整体利益的角度，还是站在特定政治集团的角度？这部分论证强调的是，应当区分对某个政府或政治集团的支持，与对一个国家及其整体民众利益的支持。
不过，作者将医疗、教育和文化活动一概归入“破坏和渗透”，属于其个人的政治判断，仍需要针对不同机构、项目及历史背景分别分析，不能仅凭活动的发起者来自美国就确定其性质。

### 4. 二战时期的同盟关系有现实利益基础，不能直接等同于始终坚定的友谊
作者对三里将美国称为二战时期的“坚定盟友”提出质疑，重点讨论美国在正式参战之前的政策以及战争带来的利益。他声称，日本发动战争所需要的战略资源有“80%以上”来自美国，并据此认为美国在珍珠港事件之前并不是坚定支持中国，而是在不同国家之间谋取利益。作者将美国在这一时期的行为概括为“多头通吃的投机者”，并认为美国在珍珠港事件后正式参战，主要是由其自身国家利益和安全需求所推动。他进一步指出，美国在第二次世界大战结束后获得了显著的国际政治、经济和金融优势，现代美国的世界强国地位以及美元的国际货币地位，都在这一历史阶段奠定了重要基础。由此，作者试图说明，即使两个国家拥有共同敌人、建立军事同盟，也不能据此认定双方具有完全一致的长期利益。
这里需要区分三个问题：美国战前对日贸易、美国战时对华援助，以及美国参战后形成的正式同盟关系，它们可以同时成立，但不能相互替代；原稿中的“80%以上”也缺少明确的资源类别、统计年份和数据来源。

### 5. 判断国家之间为何走向敌对，需要分析具体政策及责任，而不能只描述结果
对于1949年新中国成立以后中美进入敌对状态的说法，作者认为，仅用“意识形态不同导致双方敌对”来解释历史过于简单。他提出了一个贯穿全文的反问：“是我们跟他敌对，还是他跟我们敌对？”在作者看来，“双方敌对”只是对关系状态的描述，并没有进一步解释冲突是如何产生的、哪些政策加剧了矛盾、各方分别承担什么责任。他强调中国奉行和平共处、互惠互利的原则，因此认为在分析中美冲突时，应当特别关注美国的对华政策及战略选择。其论证重点是，将国际冲突的结果与产生冲突的原因区分开来，避免用看似中性的概括遮蔽具体的历史责任。
不过，国家关系中的敌对往往涉及安全困境、意识形态、军事部署、外交承认、地区局势等多重因素，仅凭一方公开宣示的外交原则，并不足以完整证明每一次冲突的责任归属。

### 6. 即使在中美关系改善时期，也发生过严重的外交、安全与军事冲突
为了反驳“改革开放以后中美关系越来越好”的判断，作者集中列举了多个具有代表性的历史事件。这些事件包括1993年银河号事件、1996年台海军事演习期间有关GPS信号中断的说法、1999年中国驻南联盟大使馆被炸事件、2001年中美南海撞机事件，以及后来限制中美航天合作的《沃尔夫条款》。特别是2001年南海撞机事件中牺牲的中国飞行员王伟，以及编号“81192”的战机，被作者用来说明中美关系改善并没有消除国家安全领域的严重矛盾。这些案例横跨贸易运输、军事安全、外交主权和科技合作等多个领域，作者试图通过它们说明，经济关系改善并不必然带来政治和安全关系的全面改善。因此，他认为不能仅根据贸易增长、外交访问和人员交流，就得出两国之间不存在根本冲突的结论。
作者所采用的分析方法，本质上是用历史上的具体冲突事件检验宏观外交叙事，而不是仅接受“关系改善”这一抽象描述。但反过来说，发生严重冲突也不能自动证明两国总体关系从未改善，两者需要分别衡量。

### 7. 中国国家实力的变化，是作者解释美国对华政策变化的主要变量
作者认为，美国对中国采取什么样的政策，与中国自身的经济实力、科技水平、军事实力及国际影响力密切相关。在中国相对弱小时，美国可以通过不对称的经济关系和国际影响力获取利益，同时与中国开展贸易、文化等领域的合作，作者用中国过去为外国市场生产“衬衫、袜子”的例子说明这一阶段的产业分工。当中国逐渐进入更高附加值的产业领域、国家综合实力上升后，中美之间的竞争关系也随之变得更加突出，美国则采取贸易限制、技术限制等措施。作者将这种变化概括为：“我们弱的时候，他控制你；我们变强了，他就围堵打压你。”在这一解释框架下，美国政策的变化并非单纯来自情感上的好恶，而是来自对自身国际优势、产业利益和战略地位的维护。
这套逻辑与国际关系理论中的现实主义（Realism）存在相似之处，即强调国家利益、相对实力和权力竞争，而不是单纯依靠道德评价来解释国家行为。

### 8. 贸易战、科技战与经贸合作可以同时存在，中美并未因为竞争而完全切断联系
作者指出，尽管中美之间存在贸易战、科技竞争、关税壁垒以及所谓的“脱钩断链”，但两国之间的经济联系并没有因此完全消失。他认为，美国试图通过贸易及科技限制维护自身优势，却仍然需要与中国开展一定程度的经贸往来，因为中国已经深度参与全球产业链和供应链。作者用“我们离不开世界，世界也同样离不开我们”概括中国与全球经济之间的相互依存关系。这意味着，国际关系不是非黑即白的零和游戏，国家之间可能一边限制关键技术合作，一边继续进行普通商品贸易，也可能一边发生安全冲突，一边维持外交沟通。作者借此进一步反驳简单的友好与敌对二分法，认为“竞争与合作长期并存”才是理解中美关系的关键。
这一观点也说明，分析国际关系时，应当将经贸、军事、外交、科技、文化等不同维度分开，而不能用其中一个领域的变化概括整个国家关系。

### 9. 判断国内舆论为何反感美国，应当追溯历史经历，而非直接归因于立场先行
三里认为，多数国人对美国的态度受到国家立场和整体社会舆论的影响，而作者认为，这种解释忽略了舆论形成背后的历史经历与现实事件。作者特别对比了1993年银河号事件与中国国家实力增强后的情况，试图说明普通人的态度并不一定只是被动跟随舆论，也可能来自对国家利益、安全问题和历史冲突的判断。他建议三里在面对粉丝关于国内反美舆论的疑问时，应该进一步了解国际战争、地缘政治以及美国对外政策，而不是停留在对民众立场的概括上。作者认为，如果不了解上一代人经历过哪些国际冲突，也不了解这些事件对他们产生的影响，就很难准确解释他们为什么对美国持负面态度。其核心诉求是，先分析一种社会态度形成的原因，再评价这种态度是否合理。
需要注意的是，作者关于美国与世界战争根源、美国如今“不敢进我们的南海”等说法较为绝对，不能仅依据视频中的论述认定为客观事实。

### 10. 独立思考不是找一个认同自己的博主，而是主动检验自己的认知
视频最后从国际关系问题延伸到了个人认知问题，这也是标题中“认知”“立场”两个关键词的重要落点。作者质问连麦者，是否真正了解过自己母亲反感美国的原因，是否认真听过母亲的解释，以及是否调查过相关历史背景。在作者看来，这位连麦者可能并没有真正寻找问题的答案，而是找到了一个观点与自己相近的网红，借助对方的话为自己的原有认知提供支持。这种做法容易形成心理学中的确认偏误（Confirmation Bias），即人们更倾向于寻找、接受和记住支持自己原有观点的信息，同时忽略可能推翻原有观点的证据。作者最后提醒，网红的观点可能是正确的，也可能只是进一步加固了听众原本错误的认知，因此真正的独立思考需要追问原因、核查事实并保留修正自身观点的能力。
这一原则不仅适用于连麦者和三里，同样也适用于本视频作者及所有认同作者观点的人。

## 值得记住的点 / 行动建议

### 1. 分析国际关系时，少问谁喜欢谁，多问各方的利益是什么
不要将国家之间的关系完全类比为个人之间的友情或仇恨。个人可能因为情感而长期维持友谊，但国家的外交政策往往受到经济发展、国家安全、资源供应、产业竞争、国内政治和国际环境等因素的共同影响。
遇到国际政治事件，可以优先思考以下问题：
- 双方分别希望获得什么利益？
- 双方在哪些领域存在共同需求？
- 双方在哪些领域存在利益冲突？
- 现有政策能够给哪些群体带来收益，又会给哪些群体造成损失？
- 这种政策究竟是长期战略，还是短期应对措施？
- 如果国家实力和国际环境发生变化，现有政策是否也会改变？

这种分析方法，比单纯用“友好国家”“敌对国家”理解复杂的国际关系更具解释力。

### 2. 将国家关系拆解为多个维度，不要用单一指标概括整体关系
一个国家可能是另一个国家的重要贸易伙伴，同时也是其科技竞争者和军事安全领域的主要对手。因此，国家关系不应该只有“好”和“坏”两个选项。
可以建立一个多维度分析框架：

| 分析维度 | 重点观察内容 |
| --- | --- |
| 经贸关系 | 贸易规模、关税、投资、市场准入 |
| 科技关系 | 芯片、航天、通信、技术出口限制 |
| 军事关系 | 军事部署、安全冲突、战略威慑 |
| 外交关系 | 高层访问、外交沟通、国际组织合作 |
| 文化关系 | 教育交流、留学、旅游、文化传播 |
| 产业关系 | 供应链依赖、产业竞争、制造业分工 |
| 社会舆论 | 民意调查、媒体叙事、公众认知 |

例如，1999年中国驻南联盟大使馆被炸，说明中美在外交和安全领域发生了严重冲突；2001年中国加入WTO，则说明中国与美国在内的全球经济体系进一步融合。
这两件事相隔时间并不长，却反映了不同领域的关系变化。合作和冲突可以同时存在，并不必然互相否定。

### 3. 既要了解历史阶段，也要寻找贯穿不同阶段的底层逻辑
视频作者反对阶段论，但实际上，历史分期和利益博弈并不是只能选择其中一种分析方法。
历史阶段可以帮助人们理解中美关系什么时候发生了明显变化，例如1971年基辛格访华、1979年正式建交、2001年中国加入WTO、2018年贸易战升级；底层逻辑则帮助人们理解这些变化为什么发生。

### 国际关系的分析框架
基础条件
国家实力、地理环境、历史背景、国际秩序

国家利益与战略目标
安全、经济发展、技术优势、国际影响力

合作行为
贸易、外交、投资、文化交流

竞争行为
关税、制裁、技术限制、安全博弈

阶段性关系变化
缓和、紧张、合作扩大、竞争加剧

社会认知与舆论变化
历史记忆、媒体传播、个人经历、价值判断

更完整的认识方式应该是：用历史分期理解变化，用利益逻辑解释变化，再用具体事实检验自己的解释是否成立。

### 4. 对历史事件建立完整的证据链，不要只记住结论
视频中列举了大量历史事件，但部分事件只用了几个字进行概括。如果希望真正理解这些事情，而不是仅仅把它们当作争论时的素材，就需要进一步补充历史细节。
建议以后整理历史事件时，至少记录以下信息：事件发生时间、涉及国家及人物、事件起因、各方采取的行动、最终结果、各方对责任的解释，以及能够验证事件的原始资料。
以1993年银河号事件为例，不仅要知道美国要求检查中国货轮，还应该知道美国具体指控了什么、货轮在哪里接受检查、检查由谁参与、最后是否发现被指控的物品。
只有掌握这些具体信息，才能将历史记忆转化为可以讨论、查证和引用的知识，而不是停留在模糊的情绪印象上。

### 5. 国家实力和关键技术自主能力值得关注，但不能将实力视为唯一变量
作者非常强调国家实力，认为国家强大后才拥有更多维护自身权益、参与国际规则制定和抵抗外部压力的能力。
银河号事件、GPS技术依赖问题、《沃尔夫条款》以及中美科技竞争，都可以引申出一个重要议题：当关键基础设施和核心技术过度依赖外部供应时，国家和企业都可能面临供应中断、政策变化以及议价能力不足的风险。
这一逻辑同样适用于企业经营和个人发展。例如，一家企业过度依赖单一供应商、单一客户或单一平台，就可能在合作方改变政策时失去主动权；一个人如果只有单一收入来源或单一职业技能，也可能更容易受到外部环境变化的影响。
但拥有实力并不意味着可以忽视国际规则、外交沟通、合作机制和风险管理。真正的自主能力，不只是摆脱依赖，更是拥有选择合作对象和应对外部变化的能力。

### 6. 理解上一代人的立场，首先了解他们经历过什么
视频的起点是一位年轻人不理解自己的母亲为什么反感美国。作者认为，连麦者应该首先向母亲了解原因，而不是直接寻找一个博主来解释母亲的认知是否正确。
不同年代成长起来的人，接触的社会事件、国际新闻、教育内容和生活经历都不相同。例如，亲历1999年中国驻南联盟大使馆被炸、2001年南海撞机事件的人，可能对这些事件有很深的情感记忆；而年轻一代可能更多通过美国科技产品、影视作品、互联网文化以及国际教育来认识美国。
因此，在与父母讨论国际政治、社会问题或其他价值观差异时，应该先尝试理解其认知形成的历史背景。
可以直接询问对方：你是什么时候开始形成这种看法的？哪一件事对你的影响最大？你反对的是某个国家的政府政策，还是对这个国家的所有人都持有相同看法？
理解一个人为什么形成某种观点，不意味着必须同意他的观点，但可以让讨论从情绪冲突转向具体事实。

### 7. 警惕确认偏误，不要把寻找答案变成寻找认同
这是整段视频最值得迁移到日常生活中的认知方法。
很多人表面上在寻找答案，实际上是在寻找能够证明自己正确的人。当一个博主的观点符合自己的认知时，就容易觉得对方理性、客观、有深度；当另一个博主提出相反观点时，则容易认为对方存在立场问题。
这种心理机制就是确认偏误（Confirmation Bias）。

### 确认偏误如何不断强化原有认知
已经形成某种观点

主动寻找支持自己的信息

关注持相同观点的博主

忽略或排斥相反证据

原有观点进一步固化
不断重复，形成认知闭环

打破确认偏误的关键，是主动寻找最有可能推翻自己观点的证据，而不是只寻找能够证明自己观点的证据。
当你听完一个观点并觉得非常有道理时，可以问自己：如果这个观点是错误的，最可能错在哪里？如果由反对者来解释，他会提出什么证据？如果出现新的可靠事实，我是否愿意改变原来的判断？

### 8. 区分事实、解释、立场和情绪，避免将四者混为一谈
本视频既有真实的历史案例，也有作者对历史案例的解释，还有明确的政治立场和较强的情绪表达。观看类似视频时，应该学会分层处理信息。

| 信息类型 | 视频中的例子 |
| --- | --- |
| 事实 | 1993年银河号事件发生，检查未发现被指控的化学品 |
| 解释 | 作者认为该事件体现了国家实力不对等 |
| 立场 | 作者强调中国国家利益、主权与和平共处原则 |
| 情绪 | 作者使用“非蠢即坏”等措辞批评三里 |
| 待验证判断 | 美国在中国变强后采取的所有限制政策都是为了维护霸权 |

同一个历史事实可以存在多种解释，某一种解释是否成立，需要看它有没有足够的证据、能否解释反面案例，以及是否排除了其他可能原因。
事实是论证的基础，立场是观察问题的角度，情绪是个人的反应，三者不能互相替代。

### 9. 面对观点鲜明的网红，不要把判断权交给对方
无论是三里，还是反驳三里的作者，都在使用自己的历史解释框架讲述中美关系。两个人都选择了一部分事实、事件和时间节点，也都通过这些材料来支持各自的结论。
三里更关注不同时期国家关系与社会舆论的变化，作者更关注战略竞争、国家实力和历史冲突。两种视角都提供了一部分有效信息，但都不能天然代表全部真相。
判断一个博主是否值得长期关注，不应仅仅取决于他的观点是否符合自己的立场，而应该看他是否提供可查证的证据、是否能够公平呈现反方观点、是否愿意承认不确定性，以及当事实发生变化时是否愿意修正自己的判断。
独立思考并不意味着永远反对主流，也不意味着永远支持主流，而是保留自己理解事实、形成观点和修正观点的能力。

### 10. 避免从一种简单叙事跳进另一种简单叙事
作者指出，不能简单地把中美关系划分成友好和敌对的几个阶段，这一点具有启发性。但如果因此进一步得出美国所有行为都只是为了维护霸权、所有合作都是为了控制中国、所有国际战争都可以归因于美国，也可能形成另一种过度简化的解释。
真实世界往往存在多个原因同时发挥作用。一个国家的政策可能同时受到国家安全、经济利益、国内选举、企业游说、意识形态、国际联盟和领导人决策的影响。
因此，不能因为某种理论能够解释一部分事实，就认为它能够解释所有事实。更成熟的认知方式，是允许多种因素共同存在，并根据具体问题判断哪一种因素更重要。
真正的认知升级，不是用一个新的绝对结论替换旧结论，而是提高自己处理复杂性和不确定性的能力。

## 我的点评
这段视频最值得认同的地方，是指出国际关系并不是非友即敌，国家之间的经贸合作、技术竞争、外交冲突和军事博弈完全可以同时存在，这比单纯依靠情感标签理解国家关系更有深度。

普通人从这段视频中最应该吸收的，不是某个固定的政治结论，而是了解历史、查证事实、区分立场与证据、警惕确认偏误，以及在面对复杂问题时不轻易放弃独立判断的思考方法。
