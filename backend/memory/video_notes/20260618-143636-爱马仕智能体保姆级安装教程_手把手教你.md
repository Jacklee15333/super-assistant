## 一句话概括

这个视频是一份面向普通用户的 **Hermes（爱马仕）智能体安装与 DeepSeek 大模型对接教程**，核心是教你如何在本地安装 AI 个人助手，并通过配置 DeepSeek API，让它具备处理日常任务、学习总结、安装 Skill、逐步变得更懂你的能力。

## 背景与主题

视频讲的是一个名为 **Hermes / 爱马仕智能体** 的 AI 个人助手安装方法，但作者特别提醒，它不是奢侈品牌 Hermès 的官网，而是 AI 智能体工具。作者称，过去几个月里，爱马仕智能体在国内外受到热烈讨论，讨论热度和安装量一度甚至超过“小龙虾”。这个工具的定位是 AI 个人助手，不仅可以帮助用户处理日常任务，还能在每次对话中学习、总结、沉淀经验，从而在后续任务中表现得更好。视频重点是保姆级安装流程，尤其是如何跳过需要外币信用卡的官方快速设置，改用 **DeepSeek** 作为模型供应商，降低普通人的使用门槛。

## 核心观点

### 1. Hermes 智能体的核心价值不只是做任务，而是能“自我进化”

作者一开始就强调，爱马仕智能体作为 AI 个人助手，不仅能帮你处理日常任务，更重要的是它能够实现所谓的“自我净化”。这里的“自我净化”可以理解为：它会在每次对话和执行任务后学习、总结，把经验沉淀下来，之后做类似任务时表现得更好。相比普通聊天机器人只回答当下问题，Hermes 更像一个可以长期陪伴、逐步适配用户习惯的个人助手。作者认为，这种能力让它不只是一次性工具，而是一个会随着使用次数增加而越来越懂你的系统。也正因为这个特点，视频把重点放在安装和模型配置上，让普通人先把这个工具跑起来。

### 2. 安装 Hermes 首先要根据操作系统选择对应命令

视频的第一步是打开 **Hermes 智能体官网**，并根据自己的电脑系统选择安装命令。作者特别开玩笑说：“不是那个奢侈品爱马仕的官网”，避免用户误解。对于 **macOS 或 Linux** 用户，官网会提供一行命令，直接复制即可；对于 **Windows** 用户，则需要点击 Windows 按钮，复制对应的 Windows 安装命令。接下来用户需要打开电脑终端：Mac 用户可以在“访达”里进入“应用程序”，再找到“实用工具”，打开“终端”；Windows 用户则可以在开始菜单搜索 **PowerShell**，打开命令行工具。把官网复制的命令粘贴进去并回车后，程序会自动检查环境并安装 Hermes。

### 3. 安装过程大约一分钟后会进入设置环节，有“快速设置”和“完全设置”两种方式

作者说，命令执行后大概 **一分钟左右**，程序会进入配置阶段，并提供两个选项：**快速设置**和**完全设置**。这两种方式本身都不需要付费，但适合的人群不同。快速设置适合有外币信用卡、并且希望使用 Hermes 官方成熟 Skill 的用户；选择后浏览器会自动跳转到官网，让你选择订阅套餐。即使选择不需要任何费用的基础套餐，也可以使用许多免费的智能体能力，但绑定信用卡这一步无法避免。对于没有外币信用卡、或者不想绑定信用卡的普通用户，作者更推荐选择第二种方式，也就是 **完全设置**。

### 4. 完全设置的关键是选择模型供应商，作者推荐 DeepSeek

选择完全设置后，系统会要求用户选择 **Provider**，也就是 AI 模型供应商。作者在这里推荐选择 **DeepSeek**，并解释原因：对普通人来说，DeepSeek 是当前性价比最高的大模型之一。换句话说，Hermes 只是智能体框架，真正驱动它思考和执行任务的，是背后的大模型。用户如果不配置模型，即使智能体安装好了，也无法真正工作。选择 DeepSeek 的好处在于成本更低、配置相对简单，同时处理日常任务已经足够。作者因此把“配置 DeepSeek API Key”作为整个安装教程中非常关键的第二步。

### 5. DeepSeek API Key 必须在官网创建，并且生成后要立刻保存

作者演示的第二步，是访问 **DeepSeek 官网**并登录账号。登录成功后，点击左侧导航栏中的 **API Key**，再点击“创建 API Key”。创建时可以随便给一个名称，系统随后会生成一个专属于你的密钥。作者特别提醒：生成之后要点击复制，并保存到一个安全的地方，因为一旦关闭这个窗口，就无法再次查看完整 Key。这个细节非常重要，因为 API Key 相当于调用模型服务的凭证，如果丢失就要重新创建，如果泄露则可能被别人消耗额度。保存好 Key 后，把它粘贴回刚才 Hermes 的命令行配置窗口中，然后回车继续。

### 6. DeepSeek 的 URL 可以默认，模型作者推荐 DeepSeek V4 Flash

在填完 DeepSeek API Key 后，下一步会要求配置 URL。作者说这里可以直接默认回车，不需要新手手动修改。随后系统会让你在 DeepSeek 的不同模型中选择一个具体模型，作者个人推荐使用 **DeepSeek V4 Flash**。推荐理由是它“性价比最高”，而且用于处理日常任务已经“绰绰有余”。这意味着作者并不主张普通用户一开始就追求最贵、最强、最复杂的模型，而是应该先选择便宜、够用、稳定的模型，把智能体工作流跑通。对于 Hermes 这类个人助手来说，很多任务如整理信息、写作、总结、规划、安装 Skill，不一定需要最昂贵的大模型。

### 7. Hermes 默认运行在本地，也可以部署到远程服务器

配置完模型后，Hermes 会继续询问智能体运行在哪里。作者建议普通用户直接选择默认的 **本地运行**，这样最简单，也最适合个人电脑使用。如果用户有远程服务器，也可以选择部署在服务端。这个选项说明 Hermes 不只是一个网页聊天工具，而是可以作为本地或服务器端智能体运行。对于普通用户，本地模式更容易理解：它就运行在你的电脑上，可以作为一个个人助手随时调用。对于高级用户，部署到服务器则可能用于长期运行、远程访问、自动化任务或多设备使用。

### 8. 聊天软件对接和浏览器操作等 Skill 可以先跳过

在后续配置过程中，Hermes 会询问用户是否需要对接一些聊天软件，以及是否需要适配某些 Skill，比如操作浏览器等。作者建议新手这里都可以先跳过，不必一开始全部配置。这个建议很实用，因为新手最重要的是先完成安装、打通模型、成功启动智能体，而不是一次性把所有高级功能都打开。等基础功能跑通后，再让 Hermes 自己去安装 Skill，或者根据具体需求一步步扩展能力。这样可以降低安装失败概率，也避免用户被太多选项吓住。作者的整体思路是：先让助手可用，再逐步让它变强。

### 9. 安装完成后，只需要在命令行输入 `Hermes` 就可以启动聊天框

全部配置完成后，安装程序会退出。作者说，这时候只需要在命令行里输入 **`Hermes`**，就可以打开和爱马仕智能体的聊天框。此时，一个个人专属的 Hermes 助手就已经处于“随时待命”的状态。用户可以直接让它执行任务，也可以让它自己去安装一些 Skill。更进一步，用户还可以描述某个需求，让它学习并总结成专属于你的技能。随着一轮轮对话和任务积累，它会越来越理解用户偏好，写出的文章、做出的成果也会越来越让用户满意。

### 10. Hermes 的长期价值在于通过 Skill 和对话沉淀个人能力体系

视频最后，作者强调了 Hermes 与普通 AI 工具不同的一点：你可以让它安装 Skill，也可以让它根据你的需求总结成专属技能。也就是说，它不是一个固定功能列表，而是一个可以被用户逐步训练和扩展的个人助手。比如你经常写文章，它可以逐渐理解你的风格；你经常做资料整理，它可以总结出适合你的整理格式；你经常处理某类任务，它可以把流程固化成 Skill。作者认为，经过一轮轮对话后，Hermes 会变得越来越懂你，输出结果也会越来越符合你的期待。这个观点背后的逻辑是：AI 智能体的竞争力不只是模型本身，而是“模型 + 工具 + 记忆 + 用户习惯沉淀”的组合。

## 值得记住的点 / 行动建议

### 1. 先明确 Hermes 不是普通聊天机器人，而是可扩展的个人智能体

使用 Hermes 前，最好先理解它和普通聊天机器人的区别。普通聊天机器人主要是在对话框里回答问题，而 Hermes 更像一个可以配置模型、安装 Skill、沉淀用户习惯的个人助手。它的价值不是一次问答，而是长期使用后越来越懂你。你可以让它处理日常任务，也可以让它学习你的需求，总结成专属技能。普通用户如果想真正体验 Agent，而不是只停留在“问 AI 一个问题”的阶段，Hermes 这类工具就是一个入门方向。

### 2. 根据自己的系统复制正确安装命令，不要混用

安装 Hermes 的第一步，是确认自己的操作系统。macOS 和 Linux 使用一类命令，Windows 使用另一类命令。不要在 Windows PowerShell 里粘贴 macOS/Linux 的命令，也不要在 Mac 终端里复制 Windows 命令。作者的流程很清楚：Mac 用户打开“终端”，Windows 用户打开 “PowerShell”，然后粘贴官网对应命令并回车。对新手来说，这一步最容易出错，建议安装前先确认官网按钮是否选对系统。

### 3. 没有外币信用卡时，优先选择“完全设置”

Hermes 安装过程中有“快速设置”和“完全设置”两种方式。快速设置看起来更省事，也可以选择免费基础套餐，但作者提醒它无法避免绑定信用卡。如果你没有外币信用卡，或者不想把信用卡绑定到海外服务，直接选择“完全设置”更稳妥。完全设置虽然多几步配置，但可以手动选择 DeepSeek 这类模型供应商。对于国内普通用户来说，这条路线更容易落地，也更符合低成本使用需求。

### 4. 把 DeepSeek API Key 当成密码一样保存和保护

配置 DeepSeek 时，API Key 是最重要的凭证。作者特别提醒，Key 生成后必须立刻复制并保存到安全地方，因为关闭窗口后无法再次查看。这个 Key 不要发到公开群聊、截图、视频评论区，也不要随便放在不安全的文档里。API Key 一旦泄露，别人可能用你的额度调用模型，造成费用或额度损失。更稳妥的做法是，把它保存到密码管理器或加密笔记里；如果怀疑泄露，立即到 DeepSeek 后台删除旧 Key 并重新创建。

### 5. 新手模型优先选 DeepSeek V4 Flash，不必一开始追求最强模型

作者推荐使用 **DeepSeek V4 Flash**，理由是性价比高，处理日常任务足够。这个建议对新手很实用：刚开始安装智能体，重点是把流程跑通，而不是马上选择最高成本的模型。日常任务如整理文字、写文章、总结信息、简单规划、生成建议，通常不需要最贵模型。先用便宜稳定的模型熟悉 Hermes 的使用方式，等你真的遇到复杂任务，再考虑升级模型。这样既降低成本，也减少配置压力。

### 6. 额外 Skill 和聊天软件对接可以先跳过

安装过程中，Hermes 会问你是否要对接聊天软件、是否要适配一些 Skill，比如浏览器操作等。作者建议新手可以先跳过，这个建议非常重要。很多人第一次安装工具时，总想把所有功能一次性打开，结果配置越来越复杂，最后不知道哪里出错。更好的方式是先完成核心闭环：安装 Hermes、配置 DeepSeek、启动聊天框、发出第一条指令。等你确认它能正常工作后，再根据具体需求安装 Skill。

### 7. 安装完成后，用 `Hermes` 命令启动并先做小任务测试

安装完成后，命令行输入 **`Hermes`** 就能启动聊天框。启动后不要马上让它做复杂任务，建议先做几个小测试，比如让它自我介绍、总结一段文字、生成一个简单计划、说明当前配置是否正常。这样可以快速确认模型是否接通、交互是否正常、响应是否稳定。等这些基础测试通过后，再让它处理更复杂的日常任务。新手最重要的是建立信心，而不是一开始就做高难度自动化。

### 8. 让 Hermes 主动安装 Skill，逐步扩展能力

作者提到，启动后可以让 Hermes 自己去安装一些 Skill。Skill 可以理解为给智能体增加具体能力的说明书或工具包。比如你想让它更擅长写作，就让它总结你的写作偏好；你想让它处理资料，就让它学习你的整理格式；你想让它执行特定流程，就让它把流程沉淀成专属技能。不要把 Hermes 当成一次性工具，而要把它当成一个可以持续培养的助手。每次任务结束后，都可以让它总结经验：“下次遇到类似任务，应该按什么步骤做？”

### 9. 用需求驱动智能体成长，而不是盲目装功能

视频最后提到，用户可以在评论区留言想用 Hermes 实现什么工具。这背后的思路是：不要为了装 Skill 而装 Skill，而是从自己的真实需求出发。比如你经常写小红书笔记，就训练它总结选题、标题、结构和语气；你经常整理会议纪要，就让它学习会议纪要模板；你经常做资料汇总，就让它形成固定的检索和总结流程。AI 智能体最有价值的地方，不是功能列表有多长，而是它能否稳定解决你的高频问题。先围绕一个真实场景用起来，比追求“全能助手”更有效。

### 10. 记录安装流程，方便以后迁移或排错
