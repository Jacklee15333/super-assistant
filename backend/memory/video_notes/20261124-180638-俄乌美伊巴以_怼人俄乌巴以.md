## 核心观点

### 1. 判断战争正义与否，不能根据支持对象随意更换标准
视频开头提出了一个有关强弱关系的问题：俄罗斯进攻乌克兰时，很多人因为乌克兰是弱势一方而支持乌克兰，但在以色列与哈马斯的冲突中，为什么部分人又支持相对强势的以色列？被批评的两位评论者试图通过区分主权国家之间的战争与反恐行动，证明自己的态度并不矛盾。作者则认为，他们在俄乌问题上强调国家主权，在巴以问题上强调反恐，在美伊问题上又强调国家安全和人权，实际上是在为既定立场寻找理由。作者最反感的不是一个人拥有政治立场，而是先确定支持谁、反对谁，再选择能够证明自己正确的论据。当然，支持弱势一方本身也不是判断正义与否的充分条件，真正重要的是能否用一套相对统一的标准评价各方的具体行为。

### 2. 俄乌冲突具有长期地缘政治背景，但战争成因与战争合法性是两个问题
作者认为，俄乌冲突并非突然发生，而是持续约八年的地缘政治矛盾不断积累的结果，并将北约东扩、乌克兰国内民族主义及排俄政策视为冲突爆发的重要原因。他认为，如果完全忽略这些历史背景，仅仅从俄罗斯进攻乌克兰这一行为出发判断战争性质，就无法完整解释战争为什么发生。因此，作者不认可直接将俄乌战争定性为俄罗斯侵略，并认为这种定性主要来自美西方阵营的叙事。不过，这里需要区分战争的历史成因与法律责任：一个国家存在安全焦虑、地缘政治压力或者历史恩怨，并不自动获得向另一个主权国家发动战争的合法权利。事实上，2022年3月2日，联合国大会通过题为《对乌克兰的侵略》的ES-11/1号决议，投票结果为141票赞成、5票反对、35票弃权，因此视频将相关定性简单归结为美西方阵营的说辞，并不全面。

### 3. 巴以冲突不能仅从2023年10月7日开始讲述
作者认为，部分支持以色列的评论者只强调2023年10月7日哈马斯袭击以色列的事件，却忽略巴勒斯坦地区此前长达数十年的占领、压迫、领土争议及民族矛盾。这种人为选择历史起点的做法，会影响受众对整个冲突的因果关系及责任归属的认识。作者强调，被占领、被压迫群体的抵抗行为不能被一概定义为恐怖主义，巴勒斯坦问题也不能被简单缩减为以色列与哈马斯之间的反恐问题。2024年7月19日，国际法院（ICJ，International Court of Justice）发表咨询意见，认定以色列在巴勒斯坦被占领土上的持续存在属于非法，这说明长期占领确实是不能忽略的重要法律和历史背景。

 但历史背景能够解释暴力发生的原因，并不能使蓄意袭击平民、劫持人质等行为合法化，这一原则同样适用于冲突中的所有参与方。

### 4. 反恐、自卫不意味着拥有无限制使用武力的权利
作者反驳了将以色列军事行动简单定义为反恐的观点，认为即使一方遭到了袭击，后续采取的军事行动也必须受到法律约束。他列举了轰炸医院、学校、居民区，以及对数百万平民实施断水、断粮等情况，质疑这些行为是否已经超出了反恐和自卫的合理范围。作者特别强调了比例原则（Principle of Proportionality）与集体惩罚（Collective Punishment）的问题，认为不能因为对方实施了违法行为，就对与袭击无关的普通民众进行无差别报复。国际人道法确实要求交战各方遵守区分原则、比例原则及相关预防义务，并禁止针对平民的直接攻击、无差别攻击和集体惩罚。
ICRC
 需要注意的是，具体军事行动是否违法，应根据目标性质、预期军事利益、平民风险及采取的预防措施等证据判断，而不能仅凭任何一方声称自己是在反恐或抵抗，就认定其行为合法。

### 5. 集体自卫权不能被无限扩大为攻击其他主权国家的理由
针对美国和以色列对伊朗采取军事行动的正当性问题，作者首先反驳了「集体自卫论」。他的核心逻辑是，即使某些武装组织获得伊朗的支持，也不能直接将这些组织的所有军事行为等同于伊朗政府亲自发动的军事攻击。作者认为，如果美国或以色列仅仅因为第三方武装组织的行为就攻击伊朗本土，可能已经超出了自卫的合理范围，变成主动扩大冲突。这里涉及代理人战争（Proxy War）、国家责任归属以及《联合国宪章》第51条规定的自卫权。需要补充的是，作者所说的自卫权只针对其他国家正规军直接攻击本土，并不是国际法中普遍适用的绝对规则，非国家武装组织发动的攻击能否触发跨境自卫权，以及如何认定必要性与比例性，仍涉及复杂的法律争议。

### 6. 核威胁不能自动成为发动预防性战争的合法依据
作者反驳的第二个关于美伊冲突的理由是伊朗核问题，他认为不能仅仅因为伊朗未来可能拥有核武器，就认定现在对伊朗实施军事打击具有合法性。作者称伊朗没有制造核弹、没有宣布拥核，并指出美国率先退出伊核协议，是导致核问题进一步恶化的重要因素。其基本逻辑是，如果一个国家可以仅凭对另一个国家未来危险性的主观判断发动战争，那么任何强国都可能以潜在威胁为理由攻击其他国家。作者主张通过国际原子能机构（IAEA，International Atomic Energy Agency）的核查、联合国安理会制裁及外交谈判来处理核扩散问题，而不是由个别国家自行决定采取军事行动。美国于2018年5月8日宣布退出伊核协议属于可确认的历史事实，但伊朗核计划的实际进展、国际核查情况与具体威胁程度需要依据对应时期的证据独立判断，不能仅凭视频中的几句话得出确定结论。

### 7. 资助代理人武装与亲自发动战争不能直接画等号
作者反驳的第三个理由是「打击代理人网络论」，即通过攻击伊朗来削弱其在中东地区支持的其他武装力量。他认为，一个国家提供资金、装备或者政治支持，与这个国家直接发动军事行动，在国际法上并不是完全相同的行为。如果不能证明相关武装行为能够归责于伊朗，或者军事行动满足合法自卫的其他条件，那么直接攻击伊朗本土就可能构成对其国家主权的侵犯。作者借此批评一种不断扩大责任范围的逻辑：从某个武装组织的行为追溯到背后的支持者，再以打击支持者为理由扩大军事冲突。不过，资助武装组织本身也可能违反国际法中的不干涉原则或者禁止使用武力原则，跨境打击非国家武装组织同样不是天然合法的，因此这一问题需要具体分析，不能简单得出任何一方必然合法的结论。

### 8. 人权问题与民众要求外部介入，不能自动赋予外国军事干涉的权利
作者反驳的第四个理由，是以保护人权、帮助民众以及响应反对派呼吁为由，对其他国家实施军事干预。他讽刺这种叙事是又要给其他国家「带去文明」，认为其背后可能存在通过外部军事力量推动政权更迭的目的。作者同时质疑部分海外流亡团体提供的数据，认为这些单方面的信息不能未经核实就成为发动军事行动的正当性依据。这一观点涉及国家主权（State Sovereignty）、不干涉内政原则（Principle of Non-intervention）以及人道主义干预（Humanitarian Intervention）之间的关系。一个国家存在人权问题，并不自动意味着其他国家有权单方面发动战争，但这也不意味着人权问题不值得国际社会关注，或者海外反对派提供的信息必然不可信，关键仍然在于证据、法律依据与采取措施的合法性。

### 9. 选择性追溯历史，是政治叙事中常见的双重标准
作者认为，两位评论者最大的问题在于对历史背景与国际法的使用方式不一致：讨论俄乌时强调乌克兰的主权国家地位，讨论巴以时弱化长期占领背景，而讨论美伊时又试图用过去的矛盾、潜在威胁等因素解释军事行动。他将这种做法概括为「不是是非决定立场，而是立场决定是非，屁股决定大脑」。作者还反驳了「有前因就不算侵略」的逻辑，指出有历史恩怨、有安全矛盾或者曾经受到威胁，并不代表主动进攻另一个国家就天然具有合法性。这一批评具有普遍意义，因为通过改变事件的历史起点、筛选有利证据和调整评价标准，可以将性质相似的行为包装成截然不同的政治叙事。不过，同样的逻辑也应适用于作者本人：既然历史恩怨不能自动消除美伊冲突中的违法责任，也不能仅仅依靠北约东扩和地缘矛盾来否定俄罗斯进攻乌克兰可能承担的法律责任。

### 10. 安理会否决权暴露了国际规则执行与大国现实政治之间的矛盾
视频最后将讨论从具体战争转向国际治理体系，认为联合国安理会（UNSC，United Nations Security Council）的否决权机制存在重大制度缺陷。作者举例说，如果安理会试图认定俄罗斯对乌克兰实施侵略，俄罗斯可以使用否决权；如果相关决议涉及美国或其盟友以色列的军事行为，美国也可能使用否决权予以阻止。在作者看来，当冲突涉及拥有否决权的大国及其核心利益时，安理会容易陷入决策僵局，使国际规则难以得到有效执行。作者由此得出一个具有现实主义色彩的悲观结论，即自己虽然不愿承认「谁赢谁说了算」，但国际政治在很多时候确实受到实力和权力结构的影响。不过，安理会无法通过某项决议并不意味着相关行为没有法律性质，也不意味着国际法院、联合国大会等机构不能作出法律判断或政治评价，法律规则是否存在与法律规则能否得到有效执行，是两个不同的问题。

一个国家存在内部治理或人权问题，不自动赋予外国单方面发动战争的权利。

5

有前因就不算侵略论
历史恩怨、安全矛盾与政治冲突，可以解释战争发生的原因，但不必然消除战争的违法性质。

### 五、值得进一步了解的国际法概念

| 概念 | 具体含义 |
| --- | --- |
| 国家主权（State Sovereignty） | 国家依法独立处理内外事务的权利，不应遭受其他国家非法侵犯 |
| 禁止使用武力原则 | 《联合国宪章》第2条第4款规定的国际关系基本原则 |
| 自卫权（Right of Self-defence） | 在满足国际法规定的条件下，国家为应对武装攻击而使用武力的权利 |
| 集体自卫（Collective Self-defence） | 在符合法律条件的情况下，其他国家协助受到武装攻击的国家进行自卫 |
| 比例原则（Principle of Proportionality） | 自卫行动应与合法防卫目的相称；在国际人道法中，则涉及预期附带平民损害与军事利益之间的衡量 |
| 区分原则（Principle of Distinction） | 交战各方必须区分平民、战斗人员、民用物体和军事目标 |
| 集体惩罚（Collective Punishment） | 因部分人员的行为而惩罚不应对此承担个人责任的群体，属于国际人道法禁止的行为 |
| 代理人战争（Proxy War） | 国家或其他政治力量通过支持第三方武装参与地区冲突的战争形式 |
| 预防性战争（Preventive War） | 为阻止未来可能形成的威胁而发动的战争，不存在普遍认可的单方面发动此类战争的权利 |
| 不干涉内政原则（Non-intervention） | 国家不得以违反国际法的强制手段干涉其他国家有权自主决定的事务 |
| 否决权（Veto Power） | 安理会常任理事国阻止实质性决议通过的制度性权力 |
| 选择性叙事（Selective Narrative） | 通过筛选事实、历史背景和论据，使受众倾向于接受特定结论的叙事方式 |

## 值得记住的点 / 行动建议
以下结合视频的主要论证，进一步提炼出普通人分析国际新闻、政治评论和网络争议时可以使用的方法。

### 1. 建立一套统一的判断标准，而不是根据国家阵营决定是非
评价一场战争时，可以先暂时不考虑自己喜欢或者讨厌哪个国家，而是从以下几个问题入手：
- 是否存在侵犯其他国家主权及领土完整的行为？
- 使用武力的行为是否具有充分的国际法依据？
- 自卫行动是否满足必要性与比例性要求？
- 是否存在直接攻击平民或集体惩罚的行为？
- 历史矛盾是否被错误地当成违法行为的免责理由？
- 支持的一方与反对的一方实施相似行为时，自己是否使用了相同的评价标准？

这套标准应当同时适用于俄罗斯、乌克兰、美国、伊朗、以色列及其他武装冲突参与方，而不是只用于批评自己不喜欢的一方。

### 2. 学会区分战争的四个分析层面
很多国际政治争论之所以无法达成共识，是因为不同的人实际上在讨论不同层面的问题。
第一层：历史成因
战争为什么发生？此前存在什么历史恩怨、民族矛盾、地缘政治及安全问题？

第二层：使用武力的合法性
发动军事行动是否具有合法依据？是否符合《联合国宪章》关于禁止使用武力及自卫权的规定？

第三层：战争行为的合法性
军事行动实施过程中，是否遵守保护平民、区分目标、比例原则等国际人道法要求？

第四层：现实政治与执行结果
国际社会能否进行制裁、追责或阻止战争？大国实力、联盟及否决权怎样影响结果？

这四个层面不能混为一谈。有历史原因不等于发动战争合法，发动战争具有合法依据也不等于战争中的所有行为都合法，而无法追责同样不代表不存在法律责任。

### 3. 警惕通过选择历史起点操纵因果关系
讨论俄乌冲突，可以将时间线追溯至2022年、2014年，甚至苏联解体及冷战结束后的欧洲安全格局变化；讨论巴以冲突，则不能只从2023年10月7日开始，还涉及1967年、1948年及更早的历史背景；讨论伊朗核问题，也需要了解2015年伊核协议的达成、2018年美国退出协议以及此后的局势发展。
不同历史起点可能呈现出不同的责任叙事。因此，看到一篇国际政治评论时，应主动思考：作者为什么选择这个时间点开始讲述？此前发生了什么？有没有被刻意忽略的重要事实？
同时也要防止另一种极端，即无限追溯历史，用过去发生的所有事情为今天的违法行为辩护。

### 4. 不要把反恐、自卫、抵抗等政治标签当成合法性证明
反恐、自卫、解放、抵抗、维护国家安全、保护人权等词语，都具有很强的道德正当性色彩，因此也很容易被用于包装军事行为。
判断一项行动时，不能只听行动发起者如何描述自己的目的，而要看实际行为、证据和法律依据。
例如，一个国家声称自己在反恐，并不能证明其所有军事行动合法；一个武装组织声称自己在反抗占领，也不能证明其针对平民的行为具有正当性。
评价具体行为，比评价行为的政治标签更重要。

### 5. 使用“交换角色测试”识别自己的双重标准
视频最值得提炼的一种思考方法，是将事件中的国家或者政治阵营进行交换，再观察自己是否仍然坚持原有标准。

| 原有判断 | 可以反问自己的问题 |
| --- | --- |
| 某国因为受到长期安全威胁，所以有理由进攻其他国家 | 换成自己反对的国家，是否仍然认可这个理由？ |
| 某国为了反恐，可以采取大规模军事行动 | 换成另一阵营实施相同行动，是否仍称之为反恐？ |
| 某国可能研发核武器，因此应提前实施打击 | 是否接受其他国家以同样理由攻击自己支持的国家？ |
| 某国存在人权问题，所以外国可以进行军事干预 | 是否愿意将这项权利普遍赋予其他大国？ |
| 某一方长期受到压迫，所以应当理解其暴力行为 | 是否仍然坚持保护所有无辜平民的原则？ |

如果交换角色之后，评价标准突然发生了变化，就值得检查自己是否存在确认偏误（Confirmation Bias）或动机性推理（Motivated Reasoning）。
不过，交换角色测试也需要确保事实条件具有可比性，而不是把法律地位、攻击性质和历史背景不同的事件强行等同。

### 6. 不要把联合国安理会的决议机制等同于全部国际法体系
作者最后提到的安理会否决权，是理解国际政治的重要切入点，但还需要认识其他国际机构的作用。

| 机构 | 主要作用 |
| --- | --- |
| 联合国安理会（UNSC） | 维护国际和平与安全，可以在相关法律框架下决定强制措施 |
| 联合国大会（UNGA） | 讨论国际问题、形成国际社会的集体政治立场，通常作出建议性决议 |
| 国际法院（ICJ） | 在具有管辖权的情况下处理国家间法律争端，并提供咨询意见 |
| 国际刑事法院（ICC） | 在具有管辖权的情况下追究个人涉嫌实施的特定国际犯罪责任 |
| 国际原子能机构（IAEA） | 开展核查、安全保障及核技术和平利用等工作 |

安理会因为否决权无法通过某项决议，不代表有关战争没有法律责任，也不代表其他机构无法进行调查、评价或司法判断。
需要建立的认知是：规则、裁判、执行和现实结果，并不是一回事。

### 7. 通过原始资料核实政治评论，而不是仅凭短视频形成判断
国际政治短视频通常需要在较短时间内表达观点，因此容易省略背景、反方证据和法律细节。
针对本视频，可以优先查阅以下资料：

| 查阅资料 | 重点了解的问题 |
| --- | --- |
| 《联合国宪章》全文 | 禁止使用武力、自卫权、安理会权限及否决机制 |
| 联合国大会ES-11/1号决议 | 国际社会对俄乌战争性质的正式表态及投票情况 |
| 国际法院2024年7月19日咨询意见 | 巴勒斯坦被占领土及以色列长期占领的法律问题 |
| 红十字国际委员会（ICRC） | 平民保护、战争规则、比例原则及集体惩罚 |
| 国际原子能机构（IAEA） | 伊朗核问题的核查报告及技术事实 |

对于视频中提到的核武器、平民伤害、海外流亡团体统计及各国军事行动等具体事实，应尽量查找对应时期的原始报告，并区分已证实事实、各方指控和评论者的推测。

### 8. 不要把擅长辩论、讽刺和反驳等同于拥有正确的结论
视频作者使用了大量反问、讽刺、情绪化表达和针对评论者个人的攻击性语言，这能够增强视频的传播效果，也容易让认同其立场的观众产生共鸣。
但一个人能把对方说得哑口无言，不意味着他的观点在事实上或者法律上一定正确。尤其是在国际政治话题中，双方都可能拥有部分正确的事实，同时又省略对自身立场不利的内容。
分析一段评论时，应重点观察证据是否充分、因果关系是否成立、概念是否准确，以及作者是否主动回应了对自身观点不利的事实。
真正的独立思考，不是从一个阵营的叙事切换到另一个阵营的叙事，而是能够对双方的论证使用同样严格的审查标准。

## 我的点评
这段视频最有价值的地方，是指出了国际政治评论中选择性叙事、立场先行、双重标准以及用道德标签包装军事行为的问题，这些确实是普通人在接收政治信息时需要警惕的现象。作者强调反恐和自卫不能成为无限制使用武力的借口，也强调安理会否决权可能阻碍国际规则的执行，这些观点具有一定的国际法和现实政治基础。不过，作者自身也存在明显的论证不一致：一方面试图通过北约东扩和长期地缘矛盾弱化俄罗斯的侵略责任，另一方面又强调历史恩怨不能抵消美国、以色列主动使用武力可能具有的侵略性质。此外，作者关于自卫权只适用于他国正规军攻击、只有安理会能够判断侵略性质，以及对哈马斯袭击平民的历史解释等论述，都存在需要修正或进一步限定的地方。由于文字稿没有提供视频发布日期、被批评者的完整原始论述及美伊军事行动的具体时间，本笔记只能核实部分历史事实与一般法律原则，不能对相关军事事件作出完整的法律定性。总体而言，最值得吸收的不是作者具体支持哪个国家，而是他提出的反双标意识，并且应当把这种批判精神同样用于检验作者自己的观点，做到既不因为立场认同而放弃质疑，也不因为立场不同而否定全部事实。
