## 一句话概括
胡律师围绕张雪机车在重庆大学校园招聘时因薪资水平遭到媒体批评的事件，从劳资双方的双向选择、薪资待遇的综合评价、跨行业薪资比较的合理性、品牌认知偏差以及新闻媒体的舆论引导方式等角度展开分析，认为企业开出的工资可以被质疑，但不能仅凭选择性的数据对比，就将薪资问题上升为企业不尊重年轻人才的道德问题。

## 背景与主题
10月26日，张雪机车创始人张雪在重庆大学举办校园宣讲会，为985、211高校应届毕业生提供研发岗位年薪12万—15万元、非研发岗位年薪10万—12万元的招聘待遇，并提供加班费另算、六险一金、带薪假期、购车优惠及实习期免费双人间宿舍等福利。
随后，媒体《都市现场》发布评论视频，将张雪机车的薪资与同城其他车企普遍20万元、部分算法岗位超过40万元的年薪进行对比，认为张雪机车的薪酬缺乏竞争力，并批评其试图以未来的期权吸引当下的年轻人才。
11月3日，张雪通过个人抖音账号回应，强调招聘是双向选择，企业没有义务按照外界要求提高工资，求职者也没有义务接受企业提供的岗位，并对媒体将薪资偏低与不尊重人才联系起来表示不满。
据视频中援引的时代财经报道，《都市现场》随后删除了相关评论视频。
胡律师对张雪的回应表示支持，并认为这起事件真正值得讨论的，不仅是应届毕业生应该拿多少工资，更是媒体能否通过不对等的数据比较和带有倾向性的叙事，将正常的市场招聘行为塑造成一个道德争议事件。

## 核心观点

### 1. 招聘本质上是双向选择，企业和求职者都拥有自主决定权
胡律师最认同的是张雪关于招聘双向选择的回应，即企业有权根据自身经营情况、岗位需求和人才预算决定工资水平，求职者也有权根据自己的能力、预期和其他就业机会决定是否接受。张雪在回应中明确表示：“你不能逼我把应届生工资提到20万，就像我不能逼你来上班一样。”如果企业开出的待遇低于人才的市场预期，那么正常的市场结果就是招聘困难、人才流失或者不得不提高薪酬，而不是企业必须无条件满足某个群体的工资要求。只要企业遵守相关法律规定，招聘信息真实透明，没有通过欺骗等方式损害求职者权益，双方就可以自由作出选择。胡律师认为，薪资是否具有竞争力，首先是一个市场问题，而不应该自动转化为道德问题。

### 2. 工资低与不尊重人才是两个不同层面的问题
张雪在《都市现场》评论视频下留言：“你可以说我工资低，你说我不尊重，你是不是有病？”这句话也是胡律师明确表示赞同的观点之一，因为工资水平属于可以通过数据、市场行情和岗位价值进行讨论的经济问题，而是否尊重人才则涉及企业的态度、用工方式和价值判断。企业即使开出的薪资低于某些竞争对手，也不必然意味着企业轻视大学生或者不尊重知识与技术。反过来，一家企业即便提供很高的工资，如果存在虚假招聘、强制无偿加班、职场羞辱等问题，也不能仅凭高薪就认定其尊重员工。因此，可以批评企业的薪酬竞争力不足，但不能在缺乏其他证据的情况下，把薪酬偏低直接等同于不尊重人才。

### 3. 评价一份工作，不能只看年薪数字，还要看完整的薪酬福利结构
胡律师反复强调，张雪机车提供的并不是只有一项12万元年薪的简单招聘方案，而是一整套包含工资、加班费、社会保障及生活福利的待遇组合。根据活动现场照片，研发岗位年薪为12万—15万元，非研发岗位为10万—12万元，同时明确提出加班费另算、六险一金、带薪假期、员工优惠购车以及实习期免费双人间宿舍。免费宿舍可能降低应届毕业生初入职场时的租房支出，加班费另算则意味着至少从招聘信息上看，并非直接将所有额外劳动时间都包含在固定年薪之中。如果另一家公司虽然开出更高年薪，却伴随更长的工作时间、更高的生活成本或较少的福利，那么单纯比较年薪可能无法体现两份工作的真实差距。胡律师借此说明，判断一份工作的价值，应该比较综合待遇，而不是只挑选一个最容易制造传播效果的工资数字。

### 4. 将张雪机车换成特斯拉，可能会产生完全不同的舆论评价
为了说明公众可能存在的品牌认知偏差，胡律师进行了一个假设性的思想实验：保持张雪机车的招聘条件完全不变，只将企业名称替换为 Tesla（特斯拉）。假设特斯拉来到重庆大学招聘，为研发人员开出12万—15万元年薪、非研发人员10万—12万元年薪，同时提供加班费另算、六险一金、带薪假期、购车优惠和免费双人间宿舍，胡律师认为评论区的评价很可能截然不同。他推测，在知名外资品牌的背景下，同样的工资和福利可能会被更多人解读为待遇规范、员工保障较好，而不是被批评为不尊重年轻人。这一假设意在揭示，公众有时候并不是完全依据客观待遇作出评价，而是受到品牌声誉、企业形象以及既有认知框架的影响。不过，这只是视频作者提出的假设，并没有实际对照实验或舆情统计作为支撑，因而不能将其直接视为已经被证实的事实。

### 5. 摩托车企业与汽车企业的薪资不能简单横向比较
胡律师对《都市现场》报道中使用的“同城车企普遍开出20万”这一比较方式提出了重点质疑。张雪机车从事的是摩托车行业，而报道中所谓的同城车企并没有明确限定为摩托车制造企业，可能将汽车企业也纳入了比较范围。尽管摩托车和汽车在道路交通法律分类中都属于机动车，但两者的产品价格、消费群体、市场规模、研发投入、企业经营模式以及盈利能力并不必然相同。胡律师以《道路交通安全法》相关分类作为一种讽刺性的比喻：不能因为摩托车和汽车都属于机动车，就认为两类企业应该采用完全相同的薪资标准。如果要判断张雪机车的招聘薪资是否偏低，更严谨的方法应该是优先比较同地区、同行业、相近规模企业的同类岗位，而不是仅仅因为企业都在制造交通工具，就将其薪酬放在同一标准下评价。

### 6. 用40万元年薪的算法岗位对比普通研发岗位，存在明显的可比性问题
《都市现场》在报道中不仅提到同城车企普遍开出20万元年薪，还特别强调部分算法岗位年薪甚至超过40万元。胡律师认为，当前汽车企业的部分高薪算法岗位可能与智能驾驶、自动驾驶等技术方向有关，这类岗位在技术门槛、人才供需关系、研发投入和业务价值等方面，与一般摩托车研发岗位存在差异。即使某家汽车企业确实愿意为算法人才提供40万元以上的年薪，也不能据此推导出摩托车企业的机械设计、产品研发或其他普通岗位同样应该提供这一待遇。这样的比较容易让受众忽略岗位类型和人才市场的差异，仅仅记住“12万对比40万”这一具有强烈反差的数字。胡律师认为，这种比较更像是一种吸引眼球、强化情绪冲突的传播方式，而不是严谨的行业薪酬分析。

### 7. 评价应届毕业生的薪资，应区分入职起薪与长期职业收入
胡律师多次强调，张雪机车此次面向的是刚刚毕业、尚未积累多年工作经验的大学生，因此招聘信息中提供的是“起薪”，并非员工整个职业生涯的收入上限。他认为，即使重庆大学是985、211重点高校，也不能简单认为每一名毕业生都应该获得与顶尖技术人才相同的工资待遇，并以北京大学、清华大学、南京大学等高校作为主观参照。对于初入职场的年轻人而言，起薪固然重要，但还需要考虑后续调薪空间、技术积累、岗位发展以及工作经验所带来的市场价值提升。不过，胡律师关于“一进去月薪至少1万元”的说法并不完全准确，因为非研发岗位10万—12万元的年薪，按12个月平均折算约为8333—10000元。与此同时，起薪不等于最终薪资，也不代表企业未来一定会涨薪，因此求职者仍然有必要了解实际的薪酬增长机制。

### 8. 关于就业困难与月薪过低的舆论叙事，应该采用一致的评价标准
胡律师指出，社会舆论中经常出现关于经济下行、就业环境不佳、大学生毕业即失业、灵活就业增加等讨论，但在张雪机车提供年薪10万—15万元的岗位时，又出现了对薪资过低的强烈批评。他认为，如果一方面承认当前就业市场存在较大压力，另一方面却把提供相对稳定收入和完整福利的招聘行为描述为不尊重人才，这两种评价标准之间就可能存在脱节。他通过连续反问的方式，质疑公众及媒体是否能够对就业形势和企业招聘待遇保持相对一致的评价逻辑。其背后的观点是，薪酬预期应该结合现实的就业环境、人才供需关系和实际可获得的工作机会，而不能仅仅依据理想收入水平进行判断。当然，整体就业困难与某个特定专业、特定高校毕业生具有较强议价能力并不矛盾，因此是否存在逻辑冲突，还需要进一步区分不同人才群体和细分就业市场。

### 9. 新闻媒体可以批评企业，但不应该通过选择性比较制造道德冲突
胡律师最终将整起事件归纳为对新闻媒体职业操作方式的批评，认为《都市现场》的报道存在吸引眼球、刻意制造矛盾和引导舆论的倾向。在他的理解中，报道通过将12万元、20万元、40万元等数字放在一起，制造薪酬差距显著的第一印象，再通过“别拿十年后的期权宽慰现在的年轻人”“真金白银才能抢到人才”等评论，将经济层面的待遇讨论进一步引向企业对年轻人才的态度问题。对于普通受众而言，这种报道结构容易使人先产生情绪反应，而忽略比较对象是否一致、招聘福利是否完整以及相关数字是否具有代表性。时代财经随后注意到《都市现场》删除了相关评论视频，胡律师认为该媒体遭到舆论反击并不意外。但删除视频的具体原因在文字稿中没有得到证实，而媒体是否存在主观上的刻意引导，也需要区分报道客观效果与报道者真实意图。

## 金句摘录

### 1. 关于招聘中的双向选择
“难道选择不是双向的吗？你不能逼我把应届生工资提到20万，就像我不能逼你来上班一样。”

——张雪
**值得记住的含义：**企业拥有定价权，劳动者拥有选择权。在合法、真实、自愿的前提下，双方都没有义务无条件满足对方的要求。

### 2. 关于薪资与尊重的区别
“你可以说我工资低，你说我不尊重，你是不是有病？”

——张雪
**值得记住的含义：**经济层面的价值判断与道德层面的价值判断不能随意混淆。批评薪资可以有数据依据，但对企业价值观的指责需要额外证据。

### 3. 关于企业创始人的自我定位
“很多大学邀请我去做演讲，但是全都拒绝了，因为我觉得自己不够格。这次到重庆大学是来打招聘广告的。”

——张雪
**值得记住的含义：**明确表达真实目的，不必将正常的商业招聘活动包装成宏大的教育、创业或人生指导活动。

### 4. 关于跨行业的薪资比较
“你卖摩托车的跟卖汽车的，那真的能是一个概念吗？那能是一个市场环境吗？能是一个消费受众群体吗？卖出去的利润什么东西的能是一样吗？”

——胡律师
**值得记住的含义：**进行横向比较时，应先确认比较对象是否处于相近的市场环境、商业模式和经营条件下，否则数字差距可能不具有直接解释力。

### 5. 关于起薪与职业发展
“他不是说你在这个岗位你最终能拿多少钱。”

——胡律师

## 值得记住的点 / 行动建议

### 1. 找工作时建立综合薪酬评价体系，而不是只看年薪
在比较不同企业的招聘待遇时，不能仅仅记录年薪，还应将现金收入、社会保障、工作时间、生活成本和企业福利全部纳入考量。
尤其对于刚毕业的大学生而言，一份年薪12万元、提供免费住宿并且加班费另算的工作，在某些情况下可能比一份年薪15万元、需要自行承担高额房租并且工作时间更长的工作更适合自己。
可以重点评估以下指标：

| 评价维度 | 应当了解的问题 |
| --- | --- |
| 固定工资 | 每个月实际固定发放多少钱？ |
| 绩效奖金 | 是否存在不确定的绩效考核？ |
| 年终奖金 | 是否包含在招聘宣传的年薪中？ |
| 加班待遇 | 加班是否计费，具体如何计算？ |
| 工作时间 | 实际每周工作多少小时？ |
| 社会保险 | 缴纳基数是多少？是否足额缴纳？ |
| 住房公积金 | 企业和员工各自缴纳多少？ |
| 住宿福利 | 免费住宿持续多久？条件如何？ |
| 通勤与租房 | 每月需要承担多少生活成本？ |
| 职业成长 | 能否积累具有市场价值的技术和经验？ |
| 调薪机制 | 多久调薪一次？标准是否明确？ |
| 劳动保障 | 劳动合同、休假及试用期待遇是否规范？ |

真正值得比较的，不只是企业承诺支付多少钱，而是劳动者最终能够获得怎样的收入、生活质量和职业发展机会。

### 4. 比较行业薪资时，尽量保证比较对象处于同一维度
无论是观察企业招聘，还是阅读媒体发布的收入排行榜，都应该先判断比较对象是否具有足够的可比性。
例如，要评价张雪机车的研发薪资，可以优先寻找以下参照：
- 同地区的摩托车制造企业。
- 企业规模及发展阶段相近的同行。
- 相同或者相近专业背景的应届毕业生。
- 岗位职责、技术门槛及工作年限相近的研发岗位。
- 工资、奖金、加班费和福利统计口径一致的招聘信息。
- 相似的工作时间及劳动强度。

而不应该直接用普通摩托车研发岗位与汽车自动驾驶算法工程师相比，也不应该用应届毕业生的起薪与资深技术人员的薪资相比。
比较对象的选择本身，就是结论形成过程中非常重要的一部分。即使引用的数据全部真实，选择不恰当的参照对象，也可能产生具有误导性的结论。

### 7. 对未来期权保持理性，不要将尚未兑现的收益当成现有工资
《都市现场》关于“真金白银才能抢到人才”的观点，虽然受到胡律师在本事件中的批评，但对求职者而言仍然具有一定参考价值。
如果企业提供股票期权、未来股权激励或其他长期收益承诺，不能仅仅依据企业创始人描绘的未来发展前景，就将这些潜在收益计入确定性收入。
期权待遇需要重点关注兑现条件、归属周期、行权价格、企业估值、退出机制、离职后的处理方式以及企业未来经营状况等因素。

| 收益类型 | 确定性 | 评价方式 |
| --- | --- | --- |
| 合同约定的固定工资 | 相对较高 | 作为当前基本收入评价 |
| 绩效奖金 | 存在波动 | 根据考核标准及历史兑现情况估算 |
| 年终奖 | 存在波动 | 确认发放条件与实际执行情况 |
| 免费住宿等福利 | 取决于适用条件 | 按实际节约的成本评价 |
| 股票期权 | 不确定性较高 | 单独进行风险评估 |
| 口头承诺未来涨薪 | 较低 | 尽量要求明确、书面化的机制 |

需要强调的是，视频并没有交代张雪机车所涉期权的具体内容，因此不能据此认定其期权一定有价值、没有价值，或者企业已经向所有应届毕业生提供了明确的期权方案。
职业选择最好建立在确定性收入可以满足现实生活需求的基础上，再考虑长期激励所带来的潜在额外收益。

### 8. 应届毕业生应当同时评估起薪、成长性与未来跳槽价值
胡律师强调此次校招给出的是起薪，而不是最终收入，这对年轻人制定职业发展策略具有一定启发。
对于刚进入职场的人而言，第一份工作除了提供现金收入之外，还可能决定其早期技能结构、行业方向、项目经验和未来职业选择空间。
例如，一份起薪相对较低但能够参与核心研发、接触完整产品开发流程的工作，可能比一份起薪更高却长期从事重复性工作的岗位更有利于部分人的职业发展。
但是，不能仅凭企业宣称具有成长性，就主动放弃合理的薪资诉求。
可以着重了解企业是否拥有成熟的技术团队、是否有明确的培养机制、是否允许新人参与有价值的项目、过往员工的晋升路径是否清晰，以及这些技能能否在其他企业得到认可。
低起薪不必然意味着低价值，高成长性也不能成为企业长期低薪的万能理由。

### 9. 企业招聘困难时，应当通过调整市场条件解决问题
对于企业而言，张雪关于双向选择的观点并不意味着企业只要开出合法工资，就一定能够顺利招到优秀人才。
假如企业确实出现招聘冷场、人才不愿意接受录用邀请、入职率偏低或者员工短期内大量离职，这些情况本身就是非常有价值的市场信号。
企业可以据此调整薪资预算、优化岗位职责、改善工作时间、提供更加明确的晋升路径、强化技术培训，或者改变招聘对象及人才选拔标准。
企业公布招聘待遇

观察实际招聘效果
投递人数、录用接受率、入职率、离职率
招聘效果良好
维持并持续优化现有待遇

招聘效果不佳
分析薪资、岗位、福利及人才需求

根据真实反馈调整，而不是单纯依赖舆论判断

企业不必因为网络批评就无条件提高工资，但也不应该将自主定薪权理解为市场必须接受其招聘方案。
市场选择具有双向约束作用：劳动者可以拒绝低于预期的工作，企业也需要承担薪资缺乏竞争力可能造成的招聘后果。

### 10. 对企业行为的批评应区分经济评价、法律评价和道德评价
本期视频最值得推广到其他场景的思维方式，是将不同层面的判断分开。

| 评价层面 | 核心问题 | 需要的判断依据 |
| --- | --- | --- |
| 经济评价 | 工资是否具有竞争力？ | 同行业薪资、供需关系、岗位价值 |
| 法律评价 | 招聘和用工是否合法？ | 劳动合同、工时、工资及社会保障等规定 |
| 道德评价 | 企业是否尊重劳动者？ | 企业实际行为、管理态度、诚信及劳动者体验 |
| 个人评价 | 这份工作是否值得接受？ | 个人需求、能力、机会成本及职业规划 |

一家企业可能在经济层面缺乏竞争力，但在法律层面完全合规，也可能在人员管理方面很尊重员工。
同样，一家高薪企业也可能存在违法用工、管理粗暴或者严重损害员工个人生活的问题。
因此，面对任何具有争议的企业行为，都应该先确定自己正在讨论哪个层面，并采用与该层面相匹配的证据和评价标准，避免把个人的不满、市场竞争问题和道德指责全部混为一谈。

## 我的点评
这期视频最有说服力的地方，是指出了跨行业、跨岗位薪酬比较的局限性，以及薪资竞争力与尊重人才之间不能简单画等号，这些观点对于理解就业市场和识别媒体叙事偏差都具有较高的参考价值。
胡律师强调综合待遇、双向选择以及起薪不等于收入上限也具有合理性，但他反复使用“至少月薪1万元”的说法并不严谨，忽略了非研发岗位年薪10万元这一明确的下限。
此外，摩托车企业与汽车企业虽然不能无条件进行比较，但两者也可能争夺相同专业背景的工程师，因此跨行业薪酬并非完全没有参考价值，其有效性取决于具体岗位和人才市场是否存在重叠。
将张雪机车替换为特斯拉的思想实验能够帮助人们反思品牌偏见，但不能证明公众一定存在双重标准，同样，整体就业困难与优秀毕业生追求更高薪资也并不必然矛盾。
《都市现场》强调现实现金收入的重要性具有一定合理性，而其报道是否真的存在刻意误导、招聘是否确实冷场、相关期权是否具有价值，仍然需要更完整的数据和证据才能下结论。
对于普通求职者来说，最有价值的做法不是在企业和媒体之间盲目站队，而是建立独立的薪酬评价体系，既尊重企业自主定薪的权利，也维护自己争取合理待遇、拒绝不合适工作以及选择更优就业机会的权利。
