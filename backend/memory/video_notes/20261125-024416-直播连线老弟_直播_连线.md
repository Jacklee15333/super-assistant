## 核心观点

### 1. 双方争论的起点：通过博主橱窗买到有问题的商品，博主算不算卖家？
质疑方在直播开始时直接展示自己购买的商品，其中明确提到了鱼子酱，并强调这些商品是通过老谢的橱窗购买的，希望对方正面解释商品存在的问题。老谢则将对方的指控拆解为三个关键词：第一，指控对象是自己；第二，商品是自己卖的；第三，商品是假货或者假药。老谢认为，要让“老谢卖假货”这个指控成立，首先就需要证明自己属于商品销售者，其次还要证明涉事商品确实是假货。质疑方关注的却不是商品究竟由谁生产或者发货，而是消费者是否通过老谢的推荐渠道完成了购买，以及老谢是否从交易中获利。双方从一开始就存在认知分歧：一方强调法律意义上的销售主体身份，另一方强调实际交易中的参与程度和获利关系。

### 2. 老谢提出三个关键问题，试图证明自己不是商品销售者
面对售假质疑，老谢连续提出三个问题：“这个货是我发的吗？”“这个货是我生产的吗？”“你的钱是给我的吗？”质疑方承认，涉事商品并非由老谢直接生产或发货，消费者购买商品的钱也不是直接支付给老谢，但随即反问：“那你赚佣金吗？”老谢承认自己获得佣金，不过认为佣金是由商家支付给平台，再由平台结算给自己，因此自己与商家并不存在直接的佣金支付关系。他试图通过生产、发货、货款归属三个维度，将自己与商品实际销售者区分开来，并进一步把自己的角色定义为链接展示者。质疑方则认为，这三个问题只能说明老谢不是生产商和直接发货方，并不能自动证明他与商品交易及其后果毫无关系。

### 3. 双方对佣金性质的理解完全不同：推广辛苦费还是交易利益？
老谢反复强调，自己获得的佣金属于商品链接的展示费、曝光费或者推广辛苦费，而不是直接销售商品所获得的货款或利润。按照他的解释，平台已经对商家进行资质审核并生成商品链接，自己所做的事情只是将链接放在个人橱窗里供消费者浏览。质疑方则从佣金的实际产生过程出发，指出如果消费者不点击老谢的橱窗购买商品，老谢就无法从这笔交易中获得相应佣金。即使佣金并非由商家直接转账给博主，也不意味着商家、消费者和博主之间不存在经济利益联系。这里最重要的逻辑分歧是：佣金通过谁结算，与佣金因何产生，是两个不同的问题；支付路径上的间接性，并不能单独证明经济利益关系不存在。

### 双方讨论的带货交易链条
根据直播中描述的交易关系整理，仅用于解释双方争论的逻辑，不代表具体法律责任的认定。

### 4. 老谢援引最高法规定和电商服务协议，主张推广者不等于销售者
老谢表示，自己可以从法律层面和平台规则层面分别解释为什么橱窗带货不等于直接销售商品。在法律层面，他声称最高人民法院已经明确规定，只要平台明确标明实际卖家是商家，那么橱窗展示者就不属于商品销售者。在平台规则层面，他声称电商服务协议已经明确将橱窗带货人员定义为推广者，而不是销售者，因此自己只是展示经过平台审核后生成的商品链接。质疑方对这种解释不予认同，认为即使博主不是法律意义上的直接卖家，也不能因此推导出博主不承担任何责任。需要注意的是，直播中老谢并未完整展示具体司法解释条文或平台协议原文，因此其说法是否准确、适用条件是什么，以及推广者在特定情况下是否还需要承担其他责任，均需要进一步查证。

### 5. 商品资质审核究竟是谁的义务：平台、商家还是带货博主？
老谢认为，平台收取了商家的保证金，并且参与交易抽成，因此平台才是审核商家经营许可、营业执照等资质的主要责任主体。他反问质疑方，普通带货博主是否具备专业审核资质和审核能力，认为不能将本应由平台完成的专业审核工作转嫁给博主。质疑方则认为，当博主主动把某个商品放进自己的橱窗时，实际上已经向粉丝传递了自己认可该商品和商家的信号，因此博主至少应该对所推广的商品进行一定程度的筛选和了解。质疑方并不否认商家和平台需要承担责任，而是反对将平台有审核义务理解成博主就可以完全免责。这里需要区分两个概念：平台的法定或合同审核义务，与博主基于商品推荐、宣传行为及粉丝信任所产生的注意义务和商业责任，并不是天然互相排斥的。

### 6. 商品到底是不是假货，不能只靠个人指控，需要证据和鉴定
老谢多次强调，不能因为消费者一句“这个商品是假的”，就直接将涉事商品认定为假货或者假药，并要求质疑方拿出能够证明商品存在问题的实锤证据，必要时进行专业鉴定。他提出“你质疑，你举证”的观点，认为如果对方要公开指控自己售假，就必须证明商品的性质以及相关责任关系。质疑方则提到，自己购买的所谓德国商品与实际收到的商品存在不一致的情况，并追问这种情况为什么与推广博主没有关系。实际上，宣传与实际发货不一致、商品质量不合格、虚假宣传、假冒商品以及假药认定，是几个性质不同的问题，不能简单混为一谈。老谢要求以证据认定商品问题具有合理性，但是否必须由消费者承担全部举证责任、是否一定需要专业鉴定，也不能仅凭直播中的一句话作出判断。

### 7. 超市导购类比引发争议：互联网博主与传统导购是否属于同一种角色？
老谢为了说明自己的角色，举了一个超市购物的例子：消费者进入超市购买商品，超市导购同样可能获得销售提成，但消费者买到假货后，应该找超市或者厂家，而不是直接找导购追究商品销售责任。他认为自己就相当于超市里的导购员，负责展示商品和提供购买渠道，并不直接负责商品生产、销售履约与售后。质疑方承认消费者应该追究超市和厂家的责任，但认为如果导购主动向消费者推销某款商品，消费者因为信任其推荐而购买，商品最终导致损害，那么导购的推荐行为也不能完全忽略。双方由此围绕“超市导购有没有责任”展开争论，并互相指责对方偷换概念。这个类比的局限在于，传统导购可能属于超市员工，而互联网带货博主可能具有独立经营、自主选品、个人信用背书、佣金分成等特征，双方的法律关系与商业模式未必完全相同。

### 8. 质疑方强调信任与获利的对等关系，并以食品安全事故进行反问
质疑方认为，许多消费者并不是先认识某个商家或者厂家，再主动找到商品，而是因为长期关注某位博主、信任其个人形象，才点击博主橱窗购买茶叶、食品或者其他产品。在这一过程中，博主虽然不直接生产商品，却充当了连接消费者与商家的中间环节，并从消费者的购买行为中获得经济收益。质疑方进一步提出一个极端的假设：如果粉丝购买博主推荐的食品后出现身体不适，甚至发生死亡等严重后果，博主是否还能坚持自己与商品完全无关？他认为消费者家属在描述购买来源时，很可能首先提到“在抖音上通过老谢的橱窗购买”，而不是实际发货商家的名字，这体现了博主个人信用在交易中的作用。老谢对此回应，具体责任应由法律认定，而不能依靠对方的常识和主观判断；同时需要明确，直播中所说的食品致死属于假设性案例，并不是已经发生的事故。

### 9. 橱窗托管与自主选品的争论，暴露出带货博主对商品控制程度的差异
在直播接近结束时，质疑方将话题转向双方橱窗运营方式的区别，认为老谢使用了平台托管机制，由平台自动向橱窗补充商品，而不是自己逐一选择。按照质疑方的描述，平台托管可以根据账号及粉丝相关情况自动上架商品，从而减少博主手动选品的工作量。他表示自己的橱窗只有十多种商品，因为自己已经取消平台托管，不允许平台自动上货，橱窗中的商品是自己购买过的，以此强调自主选品与商品了解程度的重要性。老谢随即否认自己使用过橱窗托管，并要求对方仔细查看自己的橱窗，因此关于老谢是否使用托管功能，双方并没有达成一致。这个争论反映出一个重要问题：博主是被动展示平台分配的商品，还是主动选择、体验并推荐商品，可能影响外界对其商品控制能力、推荐可信度和责任程度的判断。

“你别管你赚的推广费还是你这个佣金，你通过这个东西赚到钱了，你就产生一定责任，你一定要负责。”

这是质疑方最核心的商业责任观：不能只享受交易带来的收益，却完全忽视商品推荐可能产生的风险。
**4. 关于商品真伪与证据——老谢**
“你说这个东西是假的，你得证明它是假的才行……你质疑，你举证。”

强调公开指控他人售假需要事实和证据支持，但实际法律上的举证责任仍需结合具体争议判断。
**5. 关于法律与常识的区别——老谢**
“那个责任不是你来定的，不是你想当然来定的，那得法律说了算……有很多常识的东西都是不对的。”

提醒人们不能仅凭主观道德判断、生活常识或者网络舆论，直接认定某个人的具体法律责任。
**6. 关于自主选品——质疑方**
“你看我的橱窗为什么只有十多种货？因为我取消平台托管，我不让平台自动给我上货。”

反映了质疑方对于商品数量和选品质量之间关系的理解，即宁愿少推广一些商品，也希望对商品有更多实际了解和控制。

## 值得记住的点 / 行动建议
以下是结合双方辩论提炼出的实用方法，其中既包括直播当事人明确提出的观点，也包括从争议中延伸出来的消费者维权和带货经营建议。

### 1. 消费者买东西时，要区分推荐人、实际卖家、生产商和平台
很多消费者通过短视频博主或者主播购买商品时，会下意识地认为自己是在向这位博主买东西，但实际订单对应的销售主体可能是另一个商家。
因此，购买前应该弄清楚几个问题：是谁推荐了商品、订单显示的商家是谁、商品由哪家公司生产、售后由谁负责、平台提供哪些交易保障。
特别是购买食品、保健相关商品、化妆品以及价格较高的产品时，不应该只关注博主的知名度，还应该查看店铺名称、营业资质、商品详情、产品标签、生产厂家和消费者评价。
你信任的推荐人，不一定就是与你建立买卖合同关系的人。 弄清楚这一点，可以避免出现问题后连应该联系谁都不知道。

### 2. 商品出现问题时，第一时间保存完整证据链
本次直播的一个重要争议就是，质疑方认为商品存在问题，而老谢要求其提供足以证明商品真伪和质量问题的证据。
普通消费者在遇到疑似售假、货不对板、商品损坏或者虚假宣传时，应该尽早保存以下材料：

| 证据材料 | 主要用途 |
| --- | --- |
| 商品链接及橱窗截图 | 证明购买渠道和推广关系 |
| 博主宣传视频或直播录屏 | 证明商品是如何被介绍和推荐的 |
| 商品详情页截图 | 证明购买时展示的规格、产地及其他承诺 |
| 订单及支付记录 | 证明购买行为、金额和实际销售主体 |
| 快递单及外包装 | 证明商品来源、发货信息 |
| 商品实物、标签及批次 | 用于核实商品信息、生产者和真伪 |
| 开箱录像 | 辅助证明实际收到的商品情况 |
| 客服聊天及售后记录 | 证明商家或平台对问题的处理过程 |
| 专业检测或鉴定材料 | 必要时证明商品真伪、成分或质量问题 |
| 就医记录及相关凭证 | 如发生身体损害，用于记录症状和相关损失 |

尤其需要注意，博主可能删除相关视频、下架商品或者修改橱窗内容，商家也可能调整商品详情页，因此及时保存证据通常比在评论区争论更有价值。
如果商品疑似存在食品安全风险，应停止食用并妥善保留实物；如果已经出现身体不适，应及时就医。

### 3. 不要将货不对板、假货、质量问题和虚假宣传混为一谈
视频中，双方反复使用“假货”“假药”“产品有问题”等表述，但这些问题并不完全相同。

| 问题类型 | 通俗理解 |
| --- | --- |
| 货不对板 | 收到的商品与下单时约定的商品不一致 |
| 假冒商品 | 涉及冒用品牌、商标、来源等真实性问题 |
| 商品质量问题 | 商品不符合相关质量要求或约定标准 |
| 虚假宣传 | 对商品产地、成分、功能等作出虚假或者误导性介绍 |
| 假药问题 | 涉及药品的法定认定标准，不能仅凭个人感受判断 |

不同问题所需要的证据、可以提出的维权诉求以及适用的责任规则可能不同。
例如，购买的是宣传为德国进口的商品，但实际收到的商品名称、包装或者产地信息存在差异，首先应该核对商品详情、订单约定及实际产品信息，而不是立即跳过证据核实环节，直接认定对方销售假药。
准确描述问题，比使用最严重、最具有冲击力的指控更加有利于解决纠纷。

### 4. 带货博主不应只考虑佣金收益，也应考虑商品质量和长期信用
从商业经营角度看，博主最大的资产之一是粉丝信任，而不是某一次带货产生的佣金。
粉丝购买橱窗商品，很多时候并不认识背后的生产商或者销售商，只是因为相信博主的测评、推荐或者个人形象。
如果博主大量推广自己不了解的产品，短期内可能获得更多佣金，但一旦商品频繁出现质量问题、发货不符或者售后纠纷，就可能消耗此前积累的信任，影响账号未来的商业价值。
比较稳妥的经营方式，是在上架商品前了解商家资质、产品信息、商品来源和历史售后情况，对能够实际体验的商品进行体验，并且不对自己无法证实的功效作出保证。
即使某次纠纷最终不需要博主承担销售者责任，消费者信任受到的损害也可能真实存在。

### 5. 自主选品比盲目扩大橱窗商品数量更有利于风险控制
质疑方在视频中强调，自己的橱窗只有十多种商品，并且已经取消平台托管，理由是希望自己控制商品上架，而不是让平台自动补充商品。
这一思路具有一定的经营参考价值：商品越多，博主需要了解的商家、供应链、产品特点和售后情况通常也越多。
对于规模较小、没有专业选品团队的个人博主而言，橱窗内放置大量自己完全不了解的商品，可能带来超过自身管理能力的风险。
可以考虑建立基本选品流程，包括核实商家身份、检查商品相关资质、购买样品、了解商品真实体验、核对宣传文案以及定期查看售后反馈。
需要注意的是，自用体验不能代替专业检测，自主选品也不意味着商品一定安全可靠；它只是提高商品了解程度和控制风险的一种方式。

### 6. 平台审核通过，不等于商品质量得到永久保证
老谢认为，橱窗商品链接是在平台审核商家资质之后生成的，因此审核责任主要应由平台承担。
但从经营常识看，商家具有营业执照、经营许可等资质，与其每一件商品都不存在质量问题，是两个不同的判断。
即使某个商家符合入驻平台的基本条件，也可能在后续经营中出现产品批次异常、供应链变化、宣传失实或者售后问题。
因此，消费者不能将“已经上架正规平台”直接等同于“商品绝对可靠”，博主也不应该仅凭商品已经进入平台选品库，就认定自己不需要关注商品后续表现。
平台准入是风险控制的一道环节，不是商品安全与真实性的无限担保。

### 7. 遇到带货纠纷，应当针对不同主体的具体行为追究责任
这场直播中，双方最激烈的争论之一，就是到底应该找商家、平台还是带货博主。
实际上，更有效的分析方法不是预先认定某一方必须承担全部责任，而是分别考察不同主体做了什么。

| 主体 | 应重点核查的问题 |
| --- | --- |
| 生产厂家 | 是否存在生产质量、成分、标签或者真实性问题 |
| 实际销售商家 | 是否按约定交付商品，是否存在欺诈或者售后违约 |
| 电商平台 | 是否履行适用的审核、管理及消费者保护义务 |
| 带货博主 | 是否主动宣传、作出承诺、存在误导或者其他应承担责任的行为 |

不能因为博主赚取佣金，就直接认定其必须承担商品的一切后果；同样，也不能因为博主不生产、不发货、不直接收款，就认为其在任何情况下都不会承担责任。
具体法律责任需要结合主体身份、行为、合同关系、相关法律规定和实际证据综合判断。

### 8. 不要仅凭直播中引用的法律概念和平台协议判断谁对谁错
老谢多次援引最高人民法院相关规定及电商服务协议，但在文字稿中，没有看到具体条文、完整上下文及适用条件。
因此，普通观众在遇到类似辩论时，需要特别警惕将某一条法律规则无限扩大解释的情况。
例如，“推广者不等于销售者”，讨论的是主体身份问题；“推广者在任何情况下都没有责任”，讨论的则是责任范围问题，两者并不是同一个结论。
平台服务协议也不应被简单理解为可以排除所有其他法律义务的依据。
遇到重大商品质量纠纷时，应当核实实际订单、宣传内容及适用法律，通过平台投诉、消费者维权渠道或者专业法律咨询解决，而不是将某场直播中的口头解释直接当成最终法律结论。

### 9. 公开讨论商品问题时，要把事实、推测、法律结论和道德评价分开
这场直播中，双方经常打断彼此，并围绕“卖假货”“有没有责任”“是不是销售者”等问题不断重复争论，却没有先将关键事实逐项确认。
更有效的沟通顺序应该是：
先确认购买行为和订单主体，再确认实际收到的商品与宣传内容是否一致，然后核实商品存在什么性质的问题，最后讨论各参与者分别可能承担什么责任。
例如，“我通过某博主橱窗购买了一款商品，收到的商品与详情页介绍不一致”是可以通过订单和实物进一步核实的事实陈述；而“该博主销售假货”则包含了对商品性质及博主行为的进一步认定。
对于消费者和公开发表评论的人来说，越是严重的指控，越应该有充分的事实依据；对于被质疑的博主而言，正面解释商品来源、推广过程和处理方案，通常也比单纯强调自己不是卖家更有助于解决信任危机。

## 我的点评
这场直播最有价值的地方，在于它揭示了互联网带货行业一个长期存在的权责矛盾：博主利用个人信用促成交易并获取经济利益，但商品生产、发货、收款和售后往往由其他主体完成。老谢强调商品真伪必须依靠证据认定、法律责任不能仅凭常识判断，以及推广者不必然等同于销售者，这些观点具有合理性，但他将佣金结算路径作为自己与商家没有经济利益联系的论据，并不充分。质疑方强调消费者信任、博主获利和商品筛选责任之间的关系，在商业伦理和长期信用经营层面具有说服力，但“只要赚了佣金就一定要对所有商品问题承担法律责任”的推论同样过于绝对。双方都存在将某一层面的合理观点扩大为全部责任结论的问题，没有充分区分销售责任、推广责任、平台责任、商业责任和道德责任。由于视频没有提供完整订单、商品鉴定报告、法律条文及平台协议原文，因此不能据此认定任何一方已经售假或者必然免责。对于普通消费者和带货从业者而言，最值得吸收的原则是：法律责任要依据证据和规则判断，商业责任要重视获利方式与信任关系，长期经营则应尽可能让收益、商品控制能力和风险承担相匹配。
