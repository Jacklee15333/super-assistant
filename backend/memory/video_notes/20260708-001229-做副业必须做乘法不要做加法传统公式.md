## 核心观点

### 1. 做副业一定要做乘法，而不是做加法
传统的收入模式可以用一个简单的公式来表示：
收入=工作时间×时薪收入=工作时间\times时薪收入=工作时间×时薪
这种收入模式存在两个天然的增长瓶颈：第一，每个人每天只有24小时，能够用于工作的时间更加有限；第二，个人时薪受到学历、能力、工作经验、行业资历等因素的限制，通常很难在短时间内成倍增长。如果一个人通过下班后兼职、周末接单等方式增加收入，虽然短期能够赚到更多钱，但本质上只是不断累加工作时间。一旦身体、精力或者时间达到极限，收入增长就会停滞，甚至因为过度劳累而下降。因此，作者认为，副业的核心不是让自己变得更加忙碌，而是改变原有的收入生成机制。

### 2. 打破“推石头上山”的赚钱方式，学会使用杠杆
作者将传统的劳动收入模式比喻为“推石头上山”，每一次获得收入都需要重新投入自己的时间和精力，一旦停止推动，新的收入也可能随之停止。真正的杠杆思维，是让一次劳动产生多次收益，让同一份劳动成果能够服务不同的人。例如，一篇文章、一套课程、一本书、一个软件程序，都可以在完成之后继续被传播、销售和使用。相比于一对一提供服务，这类产品不需要随着用户数量的增加而同比例增加工作时间。使用杠杆的本质，就是逐渐解除个人收入与个人劳动时间之间的强绑定关系。

### 3. 免费提供咨询，不一定是吃亏，也可能是在积累商业资产
作者曾经担任企业咨询顾问，后来经常接到来自深圳、上海、香港、贵阳等地的老朋友的电话，有些朋友甚至准备专门坐飞机到北京向他请教问题。面对这种情况，作者通常会劝对方不要特意飞来，而是花一两个小时整理一份详细的报告，免费发送给对方。以贵阳的朋友为例，临时购买往返机票、住宿以及请客吃饭，至少需要花费大几千元，但这些支出没有一分钱真正进入作者的口袋，作者反而还要搭上至少半天时间。更重要的是，对方可能会在心理上将这笔费用归入向作者请教问题的成本，认为自己已经为此付出了很大的代价。因此，作者选择用更低成本、更高效率的方式解决问题，既减少了双方的时间消耗，也为自己积累了能够进一步加工和复用的内容。

### 4. 识别并减少“清零行动”，避免劳动成果无法积累
作者提出了一个重要概念——清零行动，指的是一项工作完成之后，其成果无法继续复用，下一次遇到类似的任务时仍然需要从头开始。比如，为某个客户提供完全定制化的个人服务，服务结束、费用结清之后，这份劳动就不再产生新的价值。如果一个人的工作和副业充满了这种清零行动，那么即使工作十年，也可能只是在重复执行相同的劳动，而没有真正建立自己的资产。当然，并不是所有一对一服务都属于清零行动，如果能够从中提取共性问题、标准解决方案和通用方法，那么原本的一次性劳动同样可以转化为长期资产。作者真正反对的，是那些既不能产生持续收入，也不能沉淀经验、产品或其他可复用成果的低积累性劳动。

### 5. 重复出现的问题，往往意味着潜在的产品市场
作者发现，虽然向自己咨询问题的人来自不同地区、拥有不同背景，但他们提出的问题往往大同小异，而且过去有人询问，未来还会继续有人询问。这意味着，自己面对的可能并不是某个人的孤立需求，而是一群人共同存在的需求。如果针对每个人分别回答，那么相同的知识就需要被反复讲解，每一次都需要重新投入时间；但如果将这些问题统一整理为报告、文章、书籍或者课程，那么同一份解决方案就能够服务大量用户。作者根据自己过去的咨询经验判断，某些问题背后至少存在几万名潜在用户。因此，判断一个问题是否值得投入时间，除了考虑当前能够赚多少钱，更应该考虑它背后有多少人存在相同的需求，以及解决方案能否被标准化和复制。

### 6. 从提供服务转向生产产品，建立可以反复出售的资产
作者认为，一份咨询报告并不一定只是发给某个朋友的临时文件，它还可以进一步演变成文章、书籍、付费专栏等不同形式的知识产品。他以自己之前创作的《价值心法》为例，称这项成果至少已经为自己带来了100万元的收入，并提到自己的付费专栏已经积累了4万多名用户，未来预计有可能达到10万名用户。产品化的优势在于，前期虽然需要投入时间进行内容整理、结构设计和质量打磨，但后续增加用户时，不必按照相同的比例增加劳动时间。即使作者当天没有继续写作或者提供咨询，之前已经完成的产品仍然有可能继续销售。过去只能出售一次的时间，在产品化之后，可以通过劳动成果被反复出售。

### 7. 用户数量与客单价，是产品化收入增长的两个重要变量
作者进一步提出了一套新的收入公式，更准确地表达为：
收入=付费用户数量×平均客单价收入=付费用户数量\times平均客单价收入=付费用户数量×平均客单价
与传统的时间收入模式相比，用户数量可以随着产品传播、口碑积累和市场扩大而增长，客单价则可以随着产品质量、品牌影响力和用户信任的提升而提高。作者提到，自己之前运营的一个专栏已经调整过四次价格，每增加约1000名用户便进行一次涨价，其中明确提及的价格阶段包括49元、98元和128元。通过这种方式，即使个人工作时间没有增加，也有可能依靠更多用户和更高客单价实现收入增长。不过，视频中所谓的用户数量和客单价“无限增长”，应理解为它们的增长空间不再直接受个人每日工作时间限制，而不是现实中的市场需求和价格真的没有上限。

### 8. 判断副业值不值得做，要看停止投入时间后能否继续赚钱
作者给出了一个非常直接的副业筛选标准：如果停止继续投入时间，这项副业还能不能产生收入？如果答案是否定的，那么这份副业本质上仍然是“手停口停”的工作，例如必须亲自完成每一个订单、每一次咨询或者每一项临时任务才能获得报酬。相比之下，已经完成的书籍、课程、数字模板、软件工具等产品，即使创作者暂时停止工作，也可能继续获得销售收入。当然，现实中这些产品通常仍然需要更新、推广和维护，但它们不再要求创作者为每一个新增用户重新完成全部工作。因此，一个具有长期价值的副业，应该逐渐降低单位收入所需要投入的个人劳动时间，而不是永远依赖创作者亲自参与。

### 9. 早期没有收入不代表没有价值，复利型副业需要耐心
作者多次强调“一定要有耐心”，并以自己拍摄短视频的经历为例，很多视频刚发布的时候并没有获得多少流量，但在之后相当长的一段时间里仍然可能逐渐得到传播。他认为，有些看起来暂时没有收益的工作，只要能够沉淀为可复用的内容或者产品，就值得投入时间。这种模式与即时劳动报酬不同，往往存在明显的时间滞后性：前期投入较大、回报较少，后期随着内容积累、用户增长和信任建立，过去的劳动成果才可能持续释放价值。作者提到，自己大约在七八年前开始改变赚钱思维，而十多年前还没有充分认识到这种模式的价值。因此，不应该仅凭短期收入来判断一项工作的价值，还要看它是否在增加未来获得收益的能力。

### 案例二：《价值心法》与付费专栏的商业逻辑

## 值得记住的点 / 行动建议

### 1. 第一步：全面盘点自己的“清零行动”
首先，检查目前工作和生活中的各类任务，判断哪些工作结束之后就完全归零，哪些工作能够产生长期价值。
例如，每次都重新制作相似的报告、反复回答相同的问题、重复进行数据整理、为不同客户从零设计类似方案，都存在较大的优化空间。
可以按照以下标准进行判断：

| 判断维度 | 需要思考的问题 |
| --- | --- |
| 重复性 | 这项工作未来是否还会出现？ |
| 通用性 | 其他人是否存在类似的需求？ |
| 复用性 | 已经完成的成果能否再次使用？ |
| 标准化 | 能否形成固定流程或模板？ |
| 商业价值 | 是否有人愿意为解决方案付费？ |
| 持续收益 | 完成之后是否还能带来收入？ |

不一定要立即放弃所有一次性工作，而应该优先改造其中重复性最高、耗费时间最多的部分。

### 2. 第二步：把重复性工作转化为标准化产品
视频作者建议，把自己经常重复做的事情、别人经常重复做的事情，以及大量人群共同面临的问题，提炼成SOP、模板、流程或者程序。
SOP（Standard Operating Procedure，标准作业程序）是指将一项工作拆解成明确、可重复执行的步骤，使其不再完全依赖个人的临场判断。
例如：

| 原有的重复劳动 | 可沉淀的产品 |
| --- | --- |
| 反复回答专业问题 | 知识手册、电子书 |
| 为客户提供咨询 | 标准化诊断报告 |
| 经常制作PPT | PPT模板库 |
| 重复处理Excel数据 | 自动化数据处理模板 |
| 经常制作电商图片 | 设计素材库、标准化设计流程 |
| 重复进行短视频剪辑 | 剪辑模板、制作教程 |
| 反复进行编程操作 | 自动化脚本、软件工具 |
| 经常进行行业研究 | 行业数据库、分析框架 |
| 重复教授某项技能 | 录播课程、付费专栏 |
| 经常进行AI内容创作 | 提示词库、AI工作流 |

核心是把原本依赖个人执行的工作，转变为一套别人也能使用、未来自己也能够反复调用的成果。

### 3. 第三步：邀请真实用户试用，不断迭代产品
作者不建议完全脱离市场需求、独自花费大量时间打造一个自认为完美的产品，而是建议先邀请身边的朋友使用自己的初步成果。
这一过程实际上接近MVP（Minimum Viable Product，最小可行产品）的商业理念，即先制作能够解决核心问题的基础版本，再通过真实用户反馈验证需求。

### 4. 优先选择具有“低边际成本”的副业
边际成本（Marginal Cost）是指每增加一个产品单位或者服务一名新增用户所产生的额外成本。
例如，一对一咨询每增加一名客户，通常就需要增加一次咨询时间；而一套已经制作完成的电子课程，每增加一名客户，额外的内容生产成本可能很低。

| 副业类型 | 收入对工时的依赖 | 产品复用潜力 |
| --- | --- | --- |
| 兼职代驾 | 高 | 低 |
| 临时劳务 | 高 | 低 |
| 定制设计接单 | 较高 | 中等 |
| 一对一咨询 | 较高 | 中等 |
| 数字模板销售 | 较低 | 高 |
| 电子书销售 | 较低 | 高 |
| 录播知识课程 | 较低 | 高 |
| 软件工具 | 较低 | 高 |
| 自动化程序 | 较低 | 高 |
| 自媒体内容资产 | 较低 | 较高 |

这并不是说兼职、接单和咨询没有价值，而是它们更适合解决短期现金流需求，或者作为积累行业经验、发现市场需求的入口。
理想的路径是从出售时间开始，逐渐将自己在服务过程中积累的经验转化为可以出售的产品。

### 6. 建立合理的涨价机制，而不是永远低价出售
作者采用过随着用户数量增长而逐步提高专栏售价的策略。这一策略的合理之处在于，早期可以用较低的价格降低用户使用门槛，积累反馈，验证市场需求；随着产品完善、用户评价增加和品牌信任提升，再适度提高价格。
一个合理的定价增长路径可以是：
早期低价验证需求 → 收集用户反馈 → 完善产品功能与内容 → 提高产品价值 → 调整价格 → 持续积累口碑。
需要注意的是，涨价应该建立在真实价值提升和市场接受度的基础上，而不能单纯因为用户数量增加，就认为价格必然能够持续上涨。

### 7. 建立自己的内容资产库和知识资产库
如果想实现劳动成果的复用，就应该养成主动保存、分类和整理工作成果的习惯。
例如，可以建立个人知识库，将过去制作的报告、客户常见问题、专业知识、工作模板、操作流程、数据分析方法、优秀案例和自动化工具统一归档。
当未来遇到同样的问题时，优先检索和调用已有成果，而不是重新开始；当某类资料逐渐积累到一定规模时，再考虑将其整合成完整产品。
不要让自己过去做过的工作，只存在于已经完成的订单和结束的聊天记录里。

### 8. 同时积累产品复用性和个人信任度
视频最后特别强调了两个资产：可复用性和信任度。
可复用性决定了同一份劳动成果能够服务多少人，而信任度决定了有多少人愿意相信产品有效，并为此付费。
一个产品即使制作得很好，如果没有传播渠道和用户信任，也可能无法获得销量；反过来，一个人即使拥有大量粉丝，如果所有服务都需要亲自执行，收入规模同样会受到时间限制。
因此，长期副业需要同时建立以下几种资产：

| 资产类型 | 实际价值 |
| --- | --- |
| 知识资产 | 专业能力、行业经验、方法论 |
| 产品资产 | 课程、软件、书籍、模板 |
| 内容资产 | 视频、文章、案例、教程 |
| 渠道资产 | 自媒体账号、社群、销售渠道 |
| 信任资产 | 用户评价、品牌口碑、专业影响力 |
| 系统资产 | SOP、自动化程序、标准化流程 |

这些资产之间能够相互促进。例如，免费内容可以积累用户信任，用户信任可以促进产品销售，产品销售又能带来反馈，推动产品继续完善。

## 我的点评
这段视频最有价值的地方，是指出了个人收入增长的结构性矛盾：如果始终依靠出售时间赚钱，那么再努力也很难突破个人精力和时间的限制。作者提出的“清零行动”“成果复用”“使用杠杆”等概念，对于知识工作者、设计师、程序员、咨询顾问和自媒体创作者具有很强的参考价值。不过，产品化收入并不等于完全被动收入，产品研发、市场推广、客户服务、维护更新等环节依然需要付出成本，用户数量与客单价也不可能真正无限增长。此外，一次性服务并非没有价值，它既可以提供稳定的现金流，也可以帮助个人积累经验、了解客户需求，为未来的产品化奠定基础。对于普通人而言，更稳妥的方式是在维持主业和现金流的同时，逐渐将自己的重复性劳动转化为长期资产，而不是贸然放弃现有收入来源。
最终值得记住的是：努力的方向，比单纯增加努力的时间更加重要；不要只想着今天的工作能赚多少钱，还要思考今天完成的工作，能否在未来反复为自己创造价值。
