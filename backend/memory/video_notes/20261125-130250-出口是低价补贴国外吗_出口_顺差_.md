## 核心观点

### 1. “压低工人工资补贴外国消费者”的说法，将出口竞争力与收入分配问题捆绑在了一起
作者认为，关于中国出口的舆论争议已经从质疑贸易数据，转向质疑贸易收益的分配方式：即便中国出口规模大、贸易顺差高，如果这些成果建立在工人低工资的基础上，又有什么意义？这种叙事具有较强的情绪感染力，因为它能够把每一个认为自己工资应该上涨的人，都拉到质疑出口模式的一方。作者提出，判断这一逻辑是否成立，首先需要验证其基本前提，即中国主要出口商品的成本是否高度依赖人工，以及压低工资是否能够显著改变这些商品的国际竞争力。如果人工成本在产品总成本中的占比很低，那么即使大幅降低工资，也未必能够形成明显的价格优势。因此，讨论中国出口不能只关注工人的绝对工资水平，还需要考察出口商品结构、生产效率、成本构成、技术含量以及企业的国际定价能力。

### 2. 中国出口结构已经发生根本性变化，不能继续用二十年前的劳动密集型制造逻辑解释今天的出口
传统纺织、鞋帽、服装、玩具、家具及部分塑料制品等劳动密集型产品，人工成本占营业收入的比例据作者所述普遍可以达到20%—30%，因此压低工资确实可能产生比较明显的价格竞争优势。但作者援引海关总署数据称，服装、鞋靴、箱包、玩具、家具等劳动密集型产品在中国总出口中的占比已经下降到15%左右，而机电产品已成为出口主力。视频称，2026年上半年机电产品出口额达到9.36万亿元，占总出口的63.5%，同比提高3.5个百分点；高技术产品出口额达到3.26万亿元，同比增长39%；新能源汽车、锂电池、光伏产品组成的出口“新三样”同比增长45.8%。作者据此认为，中国接近85%的出口商品已经不属于上述传统劳动密集型产品，汽车、电池、光伏、船舶、工业母机等产品不能再按照传统服装厂的成本逻辑理解。中国出口竞争力的分析框架，需要从廉价劳动力转向资本投入、技术能力、设备水平、产业配套和生产效率，但非劳动密集型产品也不能直接全部等同于高技术、高附加值产品。

### 3. 现代制造业的成本优势，更多来自技术、良率、规模效应和生产效率，而不是单纯压缩工资
作者以比亚迪（BYD）为例，称其2025年营业收入为8039亿元，支付给职工的薪酬福利现金为1304亿元，占营收的16.2%，而单辆汽车的直接人工成本占比约为7%—10%。光伏产业从硅料、硅片、电池片到组件的完整生产链条中，直接人工占营收的比例通常只有7%—11%，主要成本来自原材料、生产设备、折旧及知识产权等。作为对照，作者称奔驰集团（Mercedes-Benz Group）的职工薪酬占营收比例为12.1%，丰田（Toyota）约为12%，试图说明薪酬占营收比例较低并不必然意味着企业在压榨员工。作者进一步估算，即使将汽车、机电类企业工人的工资削减三分之一，终端价格也可能只出现3—5个百分点的变化，甚至不足以抵消一次较大的汇率或国际海运价格波动。真正决定现代工业品竞争力的是技术路线、生产良率、规模效应、供应链响应速度和交付周期，而盲目降薪还可能导致熟练技工流失、生产质量下降；作者举例称，一条电池产线良率下降两个百分点，造成的损失甚至可能超过给全体工人加薪的成本。

### 4. 中国汽车在海外并非一味低价销售，部分产品已经具有较强的国际定价能力
作者列举了中国新能源汽车在欧洲市场与国内市场的售价差异：腾势Z9GT国内起售价为26.98万元人民币，欧洲售价据称折合人民币约82万元；比亚迪汉国内17.98万元起，欧洲售价约57万元；吉利银河E5海外版在英国起售价约30万元，国内则为10.98万元。按照视频给出的数字，这些车型的海外售价大约是国内售价的2.7—3.2倍，与“中国企业为了获得出口订单而在海外贴着成本线低价甩卖”的叙事存在明显差别。作者也承认海外售价中包含关税因素，提到欧盟对中国电动车加征的反补贴关税最高曾达到37.6%，但认为即便考虑关税，仍存在一定的产品溢价空间。其核心逻辑是，当一个企业能够依靠产品性能、技术和品牌获得较高的海外售价时，就说明其竞争策略未必只有低价这一种选择。不过，海外零售价格与国内零售价格之间的差额不能直接视为品牌溢价或企业利润，还需要扣除当地税费、渠道、运输、认证、售后和车型配置差异等因素。

### 5. 出口企业对汇率波动的敏感度变化，侧面反映了中国制造业议价能力的提升
作者回顾十几年前的新闻报道，当时只要人民币升值，媒体往往就会采访愁眉苦脸的外贸企业老板，因为人民币升值可能直接导致出口订单流失、利润下降，甚至企业陷入经营困难。其背后的原因是，当时中国出口商品的同质化程度较高，企业主要依靠低价格获取订单，而海外采购商很容易找到其他替代供应商，报价哪怕只差一分钱，都可能失去整个订单。如今，中国出口主力逐渐转向机电产品、新能源汽车、动力电池、光伏设备等工业品，部分产品的技术门槛较高，客户可选择的合格供应商相对有限。具备差异化竞争优势的企业，在面对汇率变化时，可以通过重新议价、金融对冲、成本分摊等方式降低冲击，而不是只能被动接受利润缩水。作者认为，这种汇率敏感度的变化从侧面体现了中国出口商品附加值和议价能力的提升，但仍不能据此认为所有机电出口企业都已经摆脱了汇率风险和价格竞争。

### 6. 欧美部分制造业的衰落，与金融资本化、股东利益最大化和主动产业转移有关
作者将欧美部分制造业竞争力下降的原因追溯到20世纪70年代以后的全球化浪潮，认为这一过程改变的不只是国际贸易的流向，也改变了欧美企业的经营哲学。随着金融资本化（Financialization）的发展，股东价值最大化（Shareholder Value Maximization）成为许多企业的重要经营目标，管理层的薪酬和奖金越来越受到季度财报、股票价格等短期指标影响。企业获得资金后，倾向于进行股票回购、股息分红和并购，而工厂、设备、生产线等需要持续投入的重资产，则容易被视为拖累资产负债表和资本回报率的负担。在这种经营逻辑下，欧美企业通过外包和产业转移，将部分生产环节转向墨西哥、东南亚以及中国，作者因此认为，这些制造业并不完全是被中国抢走的，而是欧美企业自身主动放弃或转移的。制造业能力具有明显的长期积累特征，关闭一条生产线可能只需要一个季度，但重新建立生产线、培养熟练工人、招募工程师和恢复上下游配套企业，往往需要数年甚至更长时间，这也是制造业回流困难的重要原因之一。

### 7. 中国制造业经历了从简单组装到自主品牌、自主技术和自主产业平台的长期升级
中国确实是全球产业转移过程中的重要受益者，但作者强调，承接订单和最终形成独立的工业竞争力并不是一回事。中国企业最初主要负责简单组装和OEM（Original Equipment Manufacturer，原始设备制造商，通常指代工生产），随后逐步发展到ODM（Original Design Manufacturer，原始设计制造商，能够承担产品设计和生产）。在此基础上，中国制造业进一步从生产模组、零部件和代工产品，升级到生产整机、经营自主品牌、建设自主平台，以及掌握自己的技术路线。作者认为，这条产业升级道路持续了大约40年，是无数中国企业长期投入设备、工艺、研发、质量管理和供应链建设的结果，而不是发达国家将制造业转移过来之后自动获得的成果。这一过程意味着，中国企业逐渐从赚取相对有限的加工费，转向参与产品研发、品牌经营、技术创新和更高附加值环节，有机会在全球价值链中获取更多收益。

### 8. 中国制造业真正难以复制的竞争优势，是基础设施、教育体系和完整产业链构成的工业底盘
作者提出一个对比性问题：为什么同样承接发达国家转移出来的产业，印度及部分东南亚国家的制造业发展速度和产业体系完整程度，与中国仍然存在差异？他认为，关键差别不在于有没有国际订单，而在于是否具备支撑大规模现代制造业的基础设施和人力资源体系，中国经过数十年建设，形成了覆盖广泛的电网、港口、公路、铁路和通信网络。与此同时，普及到县城、乡镇的基础教育和大规模工科人才培养，使企业不仅能够购买先进生产设备，还能够找到会看图纸、调试参数、操作机器和解决工艺问题的工人及工程师。作者举例称，在长三角地区，一个零部件可能半天内就能联系到5家供应商，这种高密度产业配套能够减少采购成本、库存压力、运输时间和供应链中断风险。稳定的电力、高效的物流、众多工程师和技术工人，以及企业长期积累的设备与生产工艺，共同构成中国制造的系统性成本优势，这类能力无法仅靠短期低工资政策或引进几座工厂获得。

### 9. 评价制造业工人的待遇，需要结合当地工资水平、生活成本、岗位性质和劳动条件
针对“中国制造企业通过压低员工工资获取出口竞争力”的质疑，作者引用了BOSS直聘上的比亚迪招聘信息，称西安基地普通操作工综合月薪为5500—8000元，焊装、涂装等核心技术岗位月薪为7000—10000元，加班按劳动法核算，入职缴纳五险一金。作为对照，作者称西安制造业城镇非私营单位平均月薪约为5400元，而比亚迪商洛基地操作工月薪约为4500—6000元，商洛当地制造业私营单位平均月薪不足4000元。作者认为，这些岗位的招聘工资高于部分当地制造业平均工资水平，不能简单认为企业为了出口竞争力而刻意将工人工资压在当地低水平。针对网上经常出现的比亚迪与特斯拉（Tesla）工厂待遇对比，他强调特斯拉上海工厂与比亚迪西安、郑州、商洛等基地所处城市不同，房价、房租、消费水平及劳动力市场均存在差异，不能只比较名义月薪。作者还指出，特斯拉上海工厂生产并出口至其他国家的汽车同样属于中国出口，因此较高工资与较强出口竞争力并非必然矛盾，但招聘综合薪资、实际到手收入、基本工资、工作时长和劳动保障仍需分别考察。

### 10. 出口收益通过产业链传导至就业、工资和企业利润，工资上涨与出口增长并非必然矛盾
作者认为，贸易顺差及出口增长带来的经济收益，并不只是停留在整车企业或少数出口企业手中，而是通过一条较长的产业链向社会传导。汽车出口能够带动整车厂工人、电池厂技工、零部件企业操作工的就业，同时也会为货代、报关、港口、物流、海外仓、跨境支付和外贸业务人员创造工资、提成及经营利润。视频援引的数据称，中国制造业城镇非私营单位平均年工资从2015年的46166元增长到2025年的89436元，十年累计名义增长约93.7%，接近翻倍，同期中国出口额总体也在增长。作者据此反问，如果中国制造业的竞争力完全来自低工资，那么在工资大幅上涨的情况下，出口竞争力为什么没有随之明显消失？其结论是，产业升级和劳动生产率提升使企业有可能在保持国际竞争力的同时提高员工薪酬，但出口带来的总收益与收益是否公平地分配给普通劳动者，仍然是两个需要分别讨论的问题。

这句话指出了宏观经济议题如何与个人收入感受结合，从而形成具有较强传播力的舆论叙事。

### 2. 关于出口结构变化
“你拿着20年前看服装厂的逻辑，去解释什么汽车、电池、光伏、造船、工业母机，第一步就走错了。”

### 3. 关于现代制造业的竞争力

现代制造业的竞争已经从单一生产要素的价格竞争，转变为技术、效率、质量和供应链的综合竞争。

“一条产线你关掉，只需要一个季度，想重新开需要好几年，还得有工人，有工程师，有配套的工厂。这些都不是有钱就能马上买回来的。”

## 值得记住的点 / 行动建议
以下结合作者的论证及其延伸含义，整理为可以实际运用的经济分析方法。

### 11. 分析一个宏观经济观点，先检查它成立所需的基本前提
面对“中国出口依靠压低工人工资”的说法，不应立即根据个人情绪判断它是对还是错，而应该先把这个说法拆解成可以验证的经济命题。
例如，它至少涉及以下几个问题：出口商品中劳动密集型产品占多少？人工成本在产品成本中占多少？中国企业的工资水平是否低于可比企业？降低工资能够减少多少单位产品成本？产品竞争力是否主要来自低价？出口收益又是如何分配的？
只有将这些问题分别研究，才能判断工资因素在出口竞争力中究竟扮演了多大的角色。
通用思维方法：先验证前提，再检验因果关系，最后判断结论是否成立。 一个观点即使具有很强的情绪感染力，也不意味着其经济逻辑一定完整。

### 13. 理解生产良率的重要性：减少浪费可能比压缩工资更有效
良率（Yield Rate）是指生产过程中符合质量要求的产品数量，占全部生产产品数量的比例。
在汽车、电池、芯片、光伏等资本密集型制造业中，原材料、设备和生产线价值较高，因此良率下降可能带来非常明显的经济损失。
例如，假设一条生产线每天生产10000件产品：

| 指标 | 改变前 | 改变后 |
| --- | --- | --- |
| 每日生产数量 | 10000件 | 10000件 |
| 生产良率 | 98% | 96% |
| 合格产品 | 9800件 | 9600件 |
| 不合格产品 | 200件 | 400件 |

虽然良率仅下降两个百分点，但不合格产品数量已经翻倍，每天少产出200件合格产品，还可能增加返工、报废及设备占用成本。
这是为什么现代制造企业需要重视熟练工人、工程师和技术人员的长期培养。如果为了节约工资而造成核心技术人员流失，最终产生的经济损失可能远远大于节省下来的人工费用。

### 14. 比较不同国家或地区的工资时，要统一统计口径
网上常见的工资对比，容易将不同城市、不同岗位、不同劳动时间及不同福利条件的数据混在一起。
以视频中比亚迪与特斯拉工厂的对比为例，至少应该从以下维度进行评价：

| 比较维度 | 应该关注的问题 |
| --- | --- |
| 基本工资 | 不加班情况下能够获得多少收入 |
| 综合工资 | 是否包含加班费、绩效和奖金 |
| 工作时长 | 每天、每周实际工作多少小时 |
| 小时工资 | 单位工作时间获得多少报酬 |
| 社会保障 | 是否依法缴纳社保及公积金 |
| 当地工资 | 是否高于当地同类岗位的正常水平 |
| 生活成本 | 房租、交通、饮食等支出是多少 |
| 可支配结余 | 扣除基本生活成本后还能剩多少钱 |
| 劳动环境 | 工作强度、安全性和休息条件如何 |
| 职业发展 | 是否有培训、技能提升和晋升机会 |

工资绝对值高，不一定意味着实际购买力更强；但低生活成本也不能成为低工资、过度加班或不合理劳动条件的免责理由。
比较待遇时，最有参考价值的是实际小时收入、劳动保障、生活成本和长期职业发展机会的综合情况。

### 15. 分析产品是否“低价补贴国外”，不能只看售价，还要看完整成本和利润
判断中国企业是否在海外进行低价销售，需要区分几个不同层面的价格：国内零售价、出口成交价、进口计税价格、海外批发价和海外最终零售价。
视频中中国汽车的海外售价普遍高于国内售价，这至少说明部分出口产品并非直接以极低的终端零售价格销售，但尚不足以证明车企一定拥有很高的海外利润。
海外零售价格大致可以拆解为：
海外最终零售价

车辆出口价格

国际运输及保险

进口关税与反补贴关税

当地增值税等税费

认证、配置调整及合规成本

经销商与售后服务成本

相关企业及渠道利润

因此，真正要验证企业是否在低于成本出口，应该研究出口成交价格、单位生产成本、海外业务毛利率、政府补贴、出口政策及海外销售费用，而不是直接用两国消费者看到的零售价进行判断。

### 16. 看待制造业竞争力，要建立系统思维，而不是寻找单一原因
现代制造业的优势通常不是由某一个因素单独决定，而是多个相互关联的因素共同作用的结果。
例如，基础教育和工程师培养能够提高企业的技术能力，技术进步能够提高生产效率和良率，完整供应链能够缩短研发及交付周期，规模扩张则能够进一步摊薄设备和研发成本。

### 17. 理解贸易顺差的含义，不要把出口额、顺差和企业利润混为一谈
贸易顺差（Trade Surplus）是指在一定统计期间内，一个经济体的出口额大于进口额的部分。
贸易顺差=出口额−进口额贸易顺差=出口额-进口额贸易顺差=出口额−进口额
例如，一个国家出口1000亿元，进口800亿元，其贸易顺差就是200亿元。
但这200亿元并不是政府收到的200亿元，也不是出口企业净赚的200亿元，更不是可以直接分配给居民的200亿元。
需要区分以下概念：

| 概念 | 实际含义 |
| --- | --- |
| 出口额 | 对外销售商品或服务形成的交易金额 |
| 进口额 | 从国外购买商品或服务形成的交易金额 |
| 贸易顺差 | 出口额超过进口额的部分 |
| 企业利润 | 企业收入扣除相关成本和费用后的收益 |
| 工资收入 | 劳动者通过劳动获得的报酬 |
| 国内增加值 | 生产活动在国内新创造的价值 |
| 居民可支配收入 | 居民能够用于消费和储蓄的收入 |

普通人能够通过出口产业获得工资、就业和经营收入，但这些收益主要来源于出口生产及相关经济活动，而不是贸易顺差这个统计数字本身。
因此，评价贸易顺差的经济意义，既要观察出口规模、就业和产业升级，也要观察国内增加值、居民收入、消费能力和收入分配情况。

### 18. 把“国家具有出口竞争力”与“劳动者是否获得合理待遇”作为两个独立问题讨论
这是理解整期视频时尤其需要补充的一点。
一个国家的制造业具有较强的国际竞争力，并不自动证明每一家出口企业都给劳动者提供了合理的工资和工作条件；同样，部分企业存在低工资、长时间加班等问题，也不能证明整个国家的出口竞争力都建立在压低工资的基础上。
完全可以同时承认：中国制造业经过长期产业升级，拥有技术、供应链和生产效率方面的优势；部分劳动者的收入和劳动保障仍然存在改善空间；产业升级创造的收益也需要通过合理的分配机制更多地转化为居民收入。
出口竞争力与劳动者权益并不是只能二选一的关系。
更有价值的问题是：如何在保持制造业竞争力的同时，让技术进步和生产效率提升所产生的收益，通过工资增长、技能提升、就业质量改善及社会保障，更充分地惠及劳动者。

### 19. 普通人可以根据产业升级趋势调整自己的职业发展方向
如果作者对制造业竞争逻辑变化的判断成立，那么未来具有较强竞争力的劳动者，也将越来越依赖专业技能和解决复杂问题的能力，而不仅仅是提供重复性的劳动时间。
值得关注的技能和职业方向包括工业自动化、设备调试与维修、数控加工、质量管理、电气工程、新能源汽车及动力电池技术、供应链管理、国际贸易、跨境物流和海外市场经营等。
这些岗位的共同特征是，需要一定的知识积累、实践经验、专业判断和产业协作能力，与纯粹重复性劳动相比，更有机会获得产业升级产生的新增价值。
对于个人而言，提高自身的劳动生产率、技术能力和岗位不可替代性，是争取更高工资和更强职业议价能力的重要路径之一。
当然，个人技能提升之外，劳动力市场供需、企业分配制度、劳动权益保障等因素同样会影响最终收入。

## 我的点评
这期视频最有价值的地方，是指出了中国出口竞争力已经不能完全用传统的廉价劳动力模型解释，产业结构、单位劳动成本、技术能力、供应链密度和基础设施等因素，确实是理解现代制造业的重要变量。
作者对欧美企业金融资本化、产业转移和工业能力重建困难的分析具有一定解释力，但欧美制造业的变化还受到自动化、产业分工、能源成本、贸易政策及各国比较优势等因素影响，不能全部归因于企业追求短期股东利益。
视频使用的企业薪酬比例、海外汽车售价和制造业平均工资数据具有启发性，但存在统计口径、时间范围、车型配置及样本代表性等问题，工资与出口额同步增长也不能直接证明两者之间的因果关系，更不能用出口额增长替代出口市场份额增长。
尤其需要注意的是，贸易顺差增长、出口竞争力提升、企业利润增长与居民收入分配改善并不是同一个问题，反驳“中国制造完全依靠压低工资”并不等于证明普通劳动者已经充分获得产业升级的收益。
普通人可以吸收这期视频所提供的产业链思维、生产率思维和长期主义视角，同时保留对工资待遇、劳动保障、居民消费能力以及收入分配问题的独立判断。
更全面的结论是：中国制造业的国际竞争力并不必然依赖低工资，而真正高质量的产业升级，应当既能够提高国际竞争力，也能够持续提高国内劳动者的收入、生产效率和生活水平。
