# competitors.md — 竞品监控清单

> 一行一个网址，可用 | 加备注。竞品监控会定时抓取这些页面，
> 跟上次对比，有实质变化（新品、调价、活动、公告）就提醒你。
> 以 # 或 > 开头的是说明，会被跳过。

> 下面是示例，替换成你真正想盯的公开页面：

- https://example.com/products | 竞品A 产品页
- https://example.com/news     | 竞品A 新闻动态

## 说明
- 只监控公开可访问的页面，不登录、不绕过任何限制。
- 重度 JS 动态加载的页面（很多电商商品页）可能抓不到内容，会如实告知。
- 首次添加的网址会先记一份快照，从第二次起才能对比出变化。
