## 最近在关注什么

- **AI 一人公司与真实经营闭环**：重点看获客成本、线索筛选、内容引流、交付自动化、复购率、单位经济模型，以及“弱需求、长决策、低复购”赛道如何做两周验证。
- **AI Agent 的长期可用性与安全性**：持续关注长期记忆、技能沉淀、Recall/Replay、多人 Agent 分工、VPS 部署、Docker 沙箱、权限隔离和技能清理。
- **AI 合规与产业链机会**：在跟进欧盟 AI Act 的生成内容标识要求、中小企业合规成本、AI 内容透明度，以及中美芯片限制、Vera Rubin、HBM4、国产算力替代。
- **AI 驱动的个人知识系统**：关注 Codex + Obsidian 的资料分层、自动处理、Skill 库和定期复盘，希望把信息积累转成能持续生长的个人系统。
- **公共议题中的论证质量与舆论操控**：反复关注错误类比、单一个案泛化、性别叙事、历史比较、国际比较和“带节奏”话术背后的受众筛选与利益动机。
- **组织治理与普通人权益**：对企业高管失言、商标维权尺度、消费品牌舆情、婚姻与家庭责任、教育压力等问题，倾向于追问责任边界、成本归属和实际解决机制。

## 在学 / 在做什么

- **验证 AI 一人公司的可行赛道**：不是只看 Demo 或热点，而是在研究如何用短周期实验验证客户是否愿意付费、交付能否稳定、复购是否成立。
- **搭建可复用的 AI 工作流**：在关注如何把操作经验、录屏过程、内容生产和知识整理转成可调用的 Skill、自动化流程或多 Agent 分工。
- **评估 Agent 的部署与风控方案**：重点学习长期记忆、主机权限、沙箱执行、VPS 隔离、人工复核节点等，避免 Agent “能做事但不可控”。
- **建立技术—政策—商业联动判断**：同时追踪模型能力、芯片供应链、AI 合规要求和行业落地场景，寻找技术趋势真正影响商业模式的节点。

## 给小助的相处建议

讨论 AI 创业或工具时，优先按获客、转化、交付、人工复核、复购、成本和权限安全来组织答案。

语气可以直接、克制、信息密度高，避免空泛的价值判断和未经证实的宏大结论。
