## 📡 Anthropic 新闻

这是一项偏 **具身智能 / 机器人 / 前沿能力评估** 的实验更新。Anthropic 称 Claude Opus 4.7 在部分机器人软件任务上比上一阶段的人类团队快很多，但也明确说它还没有解决低层控制、精确取物等真正困难的机器人问题，值得关注的是它展示了大模型从“辅助人”向“部分自主执行任务”推进的趋势。[Anthropic](https://www.anthropic.com/news/project-fetch-phase-two)

这是 **AI 普惠 / 人才培养 / 非营利组织赋能** 方向的新计划。Anthropic 将投入初始 1.5 亿美元，培训 1000 名早期职业阶段的 fellows，并把他们匹配到美国各地非营利组织中，全职帮助这些机构使用 Claude 改造工作流程。[Anthropic](https://www.anthropic.com/news/claude-corps)

这是最近最重要的 **模型版本更新 / Agent 与编码能力升级**。Opus 4.8 相比 Opus 4.7 强化了编码、agentic tasks、专业工作和长任务协作能力，并同步推出 effort control、Claude Code dynamic workflows、Messages API 更新等功能；官方还强调其更愿意标注不确定性、减少无依据结论。[Anthropic](https://www.anthropic.com/news/claude-opus-4-8)

## 📡 Google DeepMind 博客

已联网核对官方博客，以下只选最近且有实质信息的动态：

1. **6 月 18 日：AI Control Roadmap，用系统级安全保护 AI agents**

这属于 **Agent 安全 / AI 治理 / 内部系统防护** 方向。Google DeepMind 提出把内部 AI agents 当作潜在“内部威胁”来做分层防御，核心不只是模型对齐，还包括监控、权限控制、实时阻断等系统级机制；这对未来多 agent 自动执行任务的安全部署很关键。[Google DeepMind](https://deepmind.google/blog/securing-the-future-of-ai-agents/)
2. **6 月 16 日：用 Gemini 加速英国住房规划审批**

这属于 **公共服务 AI / 政务自动化 / 文档分析** 方向。Google DeepMind 与英国政府等合作开发 AI 规划审批原型，目标是把业主规划申请处理时间缩短 50%，并在 Barnet、Dorset、Camden 等地测试；值得关注的是它强调规划官仍保留最终决策权，AI 主要负责资料抽取、政策匹配、反馈总结和草稿生成。[Google DeepMind](https://deepmind.google/blog/unlocking-uk-house-building-with-ai-accelerated-planning/)
3. **6 月 11 日：设立最高 1000 万美元的多智能体安全研究资助**

这属于 **多智能体系统 / AI 安全研究 / 生态治理** 方向。Google DeepMind 联合 Schmidt Sciences、Cooperative AI Foundation、ARIA、Google.org 发起研究资助，关注大量 AI agents 相互沟通、谈判、交易时可能出现的群体行为和系统性风险；这说明安全研究重点正在从“单个模型评测”转向“agent 群体生态”。[Google DeepMind](https://deepmind.google/blog/investing-in-multi-agent-ai-safety-research/)
4. **6 月 10 日：发布 DiffusionGemma，探索更快的文本生成路线**

这属于 **开放模型 / 文本扩散模型 / 本地推理加速** 方向。DiffusionGemma 是一个实验性开放模型，采用文本扩散思路，不再逐 token 生成，而是并行生成文本块，官方称在专用 GPU 上最高可达 4 倍推理速度；它更适合低延迟、本地交互式工作流，但官方也提醒质量上仍不如标准 Gemma 4。[blog.google](https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/?utm_campaign=gdm&utm_content=&utm_medium=referral&utm_source=deepmind.google)
5. **6 月 9 日：Gemini 3.5 Live Translate 上线实时语音翻译**

这属于 **音频模型 / 实时翻译 / 多语言交互** 方向。Gemini 3.5 Live Translate 支持 70 多种语言的近实时语音到语音翻译，强调保留说话者语调、节奏和音高，并已面向开发者、Google Translate、Google Meet 企业预览等场景推出；这是 Gemini 从文本/多模态能力进一步落到实时语音交互的重要更新。[blog.google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-live-3-5-translate/?utm_campaign=gdm&utm_content=&utm_medium=referral&utm_source=deepmind.google)
6. **6 月 3 日：推出 Gemma 4 12B，本地多模态模型补位**

这属于 **开放模型 / 多模态模型 / 边缘与本地部署** 方向。Gemma 4 12B 面向笔记本本地运行，主打统一、无独立多模态编码器架构，支持视觉和原生音频输入，并可在约 16GB VRAM 或统一内存环境运行；它填补了小型 E4B 与 26B MoE 之间的中等规模模型位置。[blog.google](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/?utm_campaign=gdm&utm_content=&utm_medium=referral&utm_source=deepmind.google)

## 📡 Hugging Face 博客

已联网核对官方博客，最近值得关注的动态如下：

1. **6 月 18 日：MosaicLeaks，研究型 Agent 的隐私泄漏基准**

这是 **Agent 安全 / 企业隐私 / 深度研究工具评测** 方向的新基准。文章指出，研究型 Agent 在同时使用私有文档和外部搜索时，可能通过一连串看似无害的查询泄露内部信息；其提出的 PA-DR 训练方法把答案/完整信息泄漏率从 34.0% 降到 9.9%，同时保持任务成功率。[Hugging Face](https://huggingface.co/blog/ServiceNow/mosaicleaks)
2. **6 月 18 日：Beyond LoRA，重新评估参数高效微调方法**

这是 **模型微调 / PEFT / 开源训练工具** 方向的实用更新。Hugging Face 团队用 PEFT 统一框架比较 LoRA 与多种替代方法，强调 LoRA 虽然最常用，但在不同任务、显存、性能指标下不一定是最佳选择；这对做本地微调、图像生成微调和低成本模型定制很有参考价值。[Hugging Face](https://huggingface.co/blog/peft-beyond-lora)
3. **6 月 18 日：Agentic benchmark，用开放模型评测工具是否“适合 Agent 使用”**

这是 **Agent 工具链 / 软件工程评测 / Transformers 生态** 方向的新思路。文章不只看 Agent 最终答案是否正确，而是评估它调用库、查文档、调试代码的全过程，并用 `transformers` 作为案例；重点是未来软件库不仅要对人类开发者友好，也要对代码 Agent 友好。[Hugging Face](https://huggingface.co/blog/is-it-agentic-enough)
4. **6 月 17 日：Agentic Resource Discovery，让 Agent 动态搜索工具、技能和其他 Agent**

这是 **Agent 协议 / MCP / 工具发现标准** 方向的重要更新。ARD 被描述为位于 MCP、Skills、A2A 前面的“发现层”，目标是让 Agent 在运行时按意图搜索能力，而不是预先手动安装所有工具；Hugging Face 同时给出了 Hub 上的参考实现 Discover Tool。[Hugging Face](https://huggingface.co/blog/agentic-resource-discovery-launch)
5. **6 月 17 日：MolmoMotion，语言引导的 3D 运动预测模型**

这是 **机器人 / 3D 运动预测 / 可控视频生成** 方向的新模型与数据发布。AllenAI 在 Hugging Face 博客发布 MolmoMotion，可根据单帧图像、物体上的 3D 点和动作文本，预测未来几秒的 3D 轨迹；同时开放 MolmoMotion-1M 数据集和 PointMotionBench 基准，适合机器人规划与物理合理视频生成研究。[Hugging Face](https://huggingface.co/blog/allenai/molmomotion)
6. **6 月 17 日：GLM-5.2，面向长程任务的开放模型发布**

这是 **长上下文模型 / 编码 Agent / 开源大模型** 方向的重大模型更新。Z.AI 称 GLM-5.2 支持稳定 100 万 token 上下文、强化长程编码任务，并以 MIT 许可证开放；文章还强调 IndexShare 架构在 1M 上下文下可降低每 token FLOPs，这使其更适合复杂代码工程、自动化研究和长任务 Agent。[Hugging Face](https://huggingface.co/blog/zai-org/glm-52-blog)
