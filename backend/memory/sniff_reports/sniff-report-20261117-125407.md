### 1. WeightBench：评测 AI 是否能直接编程神经网络权重
重点推荐 · 新基准
 2026-11-13
论文：WeightBench: Evaluating Language Models as Weight-Space Programmers（arXiv:2611.18553）。
这是一个评估大模型「权重空间编程」（Weight-Space Programming）能力的新基准，包含 5 个评测方向、42 项任务，涵盖读取、修改、编写神经网络权重，以及模型压缩和识别不可能完成的权重修改。值得关注的是，研究将 AI 的能力边界从写代码、调用工具进一步推进到直接理解和操作其他神经网络的参数；目前模型已经能够完成部分小型网络任务，但距离可靠地修改大型语言模型权重仍有明显差距。

### 2. ModHarness-RL：让 Agent 自己学习和进化运行框架
重点推荐 · Agent 架构
 2026-11-13
论文：ModHarness-RL: Recasting Harnesses as Learnable and Evolving Programs for Agentic RL（arXiv:2611.18533）。
这项研究提出将 Agent 的 Harness（运行框架）从人工编写的固定规则，转变为能够通过强化学习数据不断学习和演化的程序，重点优化历史信息压缩（Compression）和行为引导（Steering）。研究在 CodeSearch、ALFWorld 和 BIRD SQL 等任务上进行了实验，覆盖 1.5B—8B 参数模型，多数实验设置下优于固定 Harness 基线；它值得关注的原因是，未来 Agent 的进化可能不仅发生在模型参数层面，也发生在模型外围的记忆、上下文管理和控制机制上。

### 3. VLAN：面向不同身体条件的视觉语言导航基准
重点推荐 · 新基准

### 4. SignRot：改善大模型低比特量化的新方法
重点推荐 · 模型效率
 2026-11-12
论文：SignRot: LLM Quantization with Massive Outlier-Aware Sign-Adjusted Rotation（arXiv:2611.16502）。
SignRot 针对大模型量化中的异常激活值（Outliers）问题，提出一种符号调整旋转方法，通过识别异常通道、调整符号分布并结合非对称激活量化，改善低比特量化效果。它只需要一次校准前向传播，推理时增加的操作主要是逐元素符号翻转；论文报告在 LLaMA 3 70B 上结合 QuaRot 后取得 WikiText2 困惑度 5.88、平均零样本推理准确率 72.73 的结果，并报告优于 SpinQuant 的表现。该方法已被 NeurIPS 2026 接收，对关注大模型本地部署、显存压缩和推理效率的人尤其值得关注。
原文：[arXiv:2611.16502](https://arxiv.org/abs/2611.16502?utm_source=chatgpt.com)

### 5. IBMARL：通过模仿学习加速多智能体强化学习
值得跟进 · 多智能体
 2026-11-13
论文：Imitation Bootstrapped Multi-Agent Reinforcement Learning（arXiv:2611.18543）。
研究提出 IBMARL，将人类演示、模仿学习和多智能体强化学习结合起来：演示者不需要同时操控所有 Agent，而是轮流控制其中一个，其余 Agent 使用已有策略行动，再通过集中式 Critic 选择合适的动作组合。在四个合作型多智能体强化学习基准上，论文报告该方法在两个任务中比演示学习基线快 2.6—4.2 倍超越模仿策略，在另外两个任务中也实现了超越；这对机器人协作、团队决策和多 Agent 协同训练有实际研究价值。
原文：[arXiv:2611.18543](https://arxiv.org/abs/2611.18543?utm_source=chatgpt.com)

### 6. LECAT：研究大模型究竟如何从预训练中学会概念
值得跟进 · 模型认知与评测
 2026-11-13
论文：LECAT: Measuring LLM Category Learning from Pretraining Data（arXiv:2611.18419）。
LECAT 提出一套研究大模型类别知识学习能力的评测框架，区分记住训练数据中的类别规则、推广到未见过的实例，以及根据具体语境灵活应用知识三种能力。研究发现，单纯重复规则式文本可能反而削弱模型灵活运用类别知识的能力，而多样化的知识表达方式更有助于稳健学习；这项研究值得关注，因为它从预训练数据的组织方式切入，探讨模型为什么能够（或不能）真正掌握概念，而不只是记忆文本。
