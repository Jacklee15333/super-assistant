中文标题：005、第五节：从单数到复数，主谓一致

一句话概括

这节课通过 this / that / these / those、is / are、hat / hats、man / men、woman / women、child / children 等例子，帮助学习者理解英语从单数到复数的变化、主谓一致规则，以及所属关系中 ’s 和复数 s 的区别。

背景与主题

这是 Teacher Eric / 瑞杰老师英语课的第五节课，承接前四节关于代词、指代关系、所属关系、基础时态和互动行为的内容。前四节已经让学习者从“静态描述一个人或物”逐步进入“描述人和物之间的互动”。这一节的重点是进一步处理“数量”问题：一个和多个怎么说，单数和复数怎么变化，主语变复数后 is 为什么要变成 are。老师还把前几节的难点，如 this / that / these / those、they、his / her、man’s / woman’s 等内容重新带入练习中，形成一次 1 到 5 单元的小总结。

核心观点
1. 第五节课的核心任务，是把“一个”扩展到“多个”

老师开头回顾说，前四节已经从基础代词、指代关系、时态和互动行为，逐步把英语句子从不能动的静态个体，推进到可以互动的事物关系。第五节课则集中解决“数量关系”，也就是一个东西和多个东西在英语中如何表达。比如只有一顶帽子时，说 “This is a hat.”（这是一顶帽子。）；有两顶帽子时，就要说 “These are hats.”（这些是帽子。）。这里不仅 this 变成 these，is 也变成 are，名词 hat 也要变成 hats。这说明英语中数量变化会影响多个位置：指示词、be 动词和名词形式都要跟着变。

2. this / that / these / those 的区别，本质是“远近 + 单复数”

上一节课里很多人容易混淆 these / those 和 they，这一节老师专门用实践来巩固。This 表示近处的一个，that 表示远处的一个；these 表示近处的多个，those 表示远处的多个。比如近处一只手是 “This is a hand.”（这是一只手。），近处多只手就是 “These are hands.”（这些是手。）。如果远处有一群孩子在公园种树，就要说 “Those children over there are planting trees in the park.”（那边那些孩子正在公园里种树。）。这里的 those 强调“那些、远处、多个”，而 they 只是泛指“他们 / 它们”，不强调远近。

3. 主谓一致的基础规则：一个用 is，多个用 are

这一节反复强调 is 和 are 的区别。一个东西存在或被描述时，用 is，比如 “This is a hat.”、“This is a hand.”、“This is a table.”；多个东西存在或被描述时，用 are，比如 “These are hats.”、“These are hands.”、“These are tables.”。老师把 is / are 类比成汉语里的“是”或一种存在状态，但英语会根据数量变化改变形式。很多学生在考试中会把 is / are 混用，比如多个主语还写 is，或者单数主语误写 are。老师提醒，这些看似很小的地方，正是高考和基础英语中大量失分的来源。

4. 英语名词复数通常加 s，但高频古老词会有不规则变化

老师先用规则变化举例：一顶帽子是 hat，多顶帽子是 hats；一只手是 hand，多只手是 hands；一张桌子是 table，多张桌子是 tables；一个男孩是 boy，多个男孩是 boys；一个女孩是 girl，多个女孩是 girls。但他随后指出，一些非常常用、历史较古老的词并不按简单加 s 的方式变化。比如一个男人是 man，多个男人不是 mans，而是 men；一个女人是 woman，多个女人不是 womans，而是 women；一个孩子是 child，多个孩子不是 childs，而是 children。老师解释说，越古老、越常用的词，越可能保留古英语、德语系或其他历史来源中的变化形式，所以不要焦虑，反复接触几次就会熟。

5. 复数 s 和所属关系 ’s 不是一回事

本节课第一次明确强调 复数 s 和 所有格 ’s 的区别。比如 hands 表示“很多只手”，这里的 s 是复数；而 the man’s hand 表示“这个男人的手”，这里的 ’s 表示所属关系，相当于中文里的“的”。老师举例说 “It is the man’s hand.”（这是这个男人的手。），这里的 man’s 不是复数，而是“男人的”。同样，“It is the woman’s hand.”（这是这个女人的手。） 里 woman’s 也表示“女人的”。老师提醒，是否有一撇非常重要，不加一撇可能只是复数，加一撇才表示所属关系。

6. 所属关系可以用完整名词，也可以用 his / her 简化

老师通过帽子和手的例子说明，英语中可以用完整名词所有格，也可以用代词所有格。比如 “This is a man’s hat.”（这是一顶男人的帽子。），也可以在语境明确时说 “His hat...”；“This is a woman’s hat.”（这是一顶女人的帽子。），也可以说 “Her hat...”。当帽子在男人手里时，可以说 “This man’s hat is in his hand.”（这个男人的帽子在他的手里。）；当帽子在女人头上时，可以说 “This woman’s hat is on her head.”（这个女人的帽子在她的头上。）。老师还提醒，与其辛苦反复写 the woman’s hands，日常表达中不如直接用 her hands，因为代词本来就是为了简洁指代。

7. 英语是表音系统，微小尾音会影响准确理解

老师在讲 hands、hats、tables、women 等词时强调，英语是表音系统，声音必须有差别，听的人才能在紧急或快速交流中听得准确。比如 hand 和 hands 的尾音不同，hat 和 hats 的尾音也不同，这些尾音不是可有可无的装饰，而是传递数量信息的重要部分。老师还提到，古英语比现代英语更加复杂、更加精确，过去一千年里英语已经基于实用主义简化了很多，所以学习者不必害怕这些变化。现在要掌握的无非就是几个基础规则和高频例外。只要多听、多说、多走几遍，英语的单复数和发音差异会逐渐形成感觉。

8. 考试中的难点，往往正是 this / these、is / are、man / men 这些基础细节

老师特别提醒，不要嫌基础内容烦，因为很多高考学生也会在 these / those / this / that / he / she / her 这些地方犯错。比如题目中给出三只手，答案应该是 “These are hands.”；给出三个男人，应该是 “These are men.”；给出三张桌子，应该是 “These are tables.”；给出两个女人，应该是 “These are women.”。这些题看似简单，但如果主谓一致、复数形式、拼写和发音没有同步建立，句子就容易乱。老师作为改卷老师也指出，学生常见错误就是这里漏 s，那里复数错，is / are 混用，导致句子结构混乱。

9. 第五节课同时是 1 到 5 单元的滚动复习

这节课不只是讲新知识，还不断回顾前面学过的内容。比如 this / that / these / those 来自第二、三节；his / her / man’s / woman’s 来自第三节；will give、are planting 又回顾第四节的时态入门。老师通过 “These children over there are planting trees in the park.” 这类句子，把远近、复数、正在进行、地点介词一起串起来。又通过 “These male doctors are from the city hospital and will give us a health talk.” 引入复数医生、来源地点和未来动作。这样做的目的不是让学生一次背完所有知识，而是让大脑在反复运用中逐渐形成英语结构感。

10. 最后的志愿者标志描述，是一次从基础句到进阶表达的综合示范

课程最后给出一个综合运用任务：尽可能详细描述中国青年志愿者的图标及其内在含义。老师先用前五单元能理解的简单表达来描述：“This is a symbol.”（这是一个标志。）、“It is a heart shape.”（它是一个心形。）、“In the heart, there is a hand.”（在心里面，有一只手。）、“This hand looks like a bird.”（这只手看起来像一只鸟。）。随后他又给出更高级的表达，如 “This is the symbol of the Chinese Youth Volunteers.”（这是中国青年志愿者的标志。），并解释红心可能代表 love、care、hope，手可能代表青年亲手参与服务，鸟可能代表 peace、love、unity。最后还补充了作文式表达，提到外部是红心，内部是手形，外观像字母 Y，象征 Youth，鸽子象征 friendship、peace and hope。

本节核心主题：
从单数到复数，理解数量关系、名词复数、主谓一致，以及所属关系 ’s 与复数 s 的区别。

本节核心指示词：

this：这个，近处单数。

that：那个，远处单数。

these：这些，近处复数。

those：那些，远处复数。

they：他们 / 她们 / 它们，只指代多个对象，不强调远近。

本节核心主谓一致规则：

一个对象：This is... / That is...

多个对象：These are... / Those are...

单数名词通常搭配 is。

复数名词通常搭配 are。

规则复数例子：

hat → hats：帽子。

hand → hands：手。

table → tables：桌子。

boy → boys：男孩。

girl → girls：女孩。

doctor → doctors：医生。

hat → hats：帽子。

tree → trees：树。

不规则复数例子：

man → men：男人。

woman → women：女人。

child → children：孩子。

老师对不规则复数的解释：
一些最常用、历史较古老的词，可能保留古英语、德语系或其他欧洲语系来源中的形式，不完全遵循后期普遍化的加 s 规则。

所有格重点：

the man’s hand：这个男人的手。

the woman’s hand：这个女人的手。

a man’s hat：一顶男人的帽子。

a woman’s hat：一顶女人的帽子。

men’s hats：男人们的帽子 / 男士帽。

women’s hats：女人们的帽子 / 女士帽。

复数 s 与所有格 ’s 的区别：

hands：很多只手，表示复数。

man’s hand：男人的手，表示所属。

hats：很多顶帽子。

men’s hats：男士帽 / 男人们的帽子，既有不规则复数 men，又有所有格 ’s。
